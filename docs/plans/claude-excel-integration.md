# Plan: Bridge xlsdocs to Claude for Excel

## Context
xlsdocs.com is a Fumadocs (v14.7.7) + Next.js 16 + Tailwind v4 site with MDX
function pages generated by a Node page generator. XLOOKUP is the master
template. There is an existing custom "Ask Claude" side panel that calls the
Anthropic API with my own key.

Claude for Excel is Anthropic's Excel add-in. It works on the user's live
workbook, and skills enabled in a user's Claude settings also work inside it.
Strategy: complement the add-in, don't compete with it. No Office.js add-in.

Ground rule: content accuracy beats everything. Never invent function
behavior, performance claims, or Claude product details. If unsure, leave a
TODO for me to verify.

## Phase 1: "Try it in Claude for Excel" prompts (start here)
- Add an optional `claudePrompts` field to function page frontmatter
  (array of { title, prompt }).
- Build a `<ClaudePrompts>` MDX component: a section of copyable prompt
  cards matching the existing design system (emerald accent, Geist/DM Mono,
  light/dark), reusing the copy-button pattern from the ExcelCode component.
- Add 3–4 realistic prompts to the XLOOKUP page only (e.g. auditing lookups,
  converting VLOOKUP to XLOOKUP, debugging #N/A).
- Update the page generator so new pages get the field and component.
- Stop and show me the XLOOKUP page before touching other pages.

## Phase 2: xlsdocs Claude skill
- Before building, check the current Agent Skills format in Anthropic's
  docs (docs.claude.com) and confirm the folder/SKILL.md structure and
  frontmatter fields. Don't rely on memory.
- Write a build script (scripts/build-skill.mjs) that generates a skill
  folder from the MDX function pages: a SKILL.md with name, description,
  and when-to-use guidance, plus per-function reference files (syntax,
  arguments, edge cases, common errors). Pull only from the page content;
  add nothing that isn't on the page.
- Output a zip to /public/downloads/ for users to download.
- Add a docs page explaining what the skill is and how to add it in
  Claude settings, with a TODO for me to confirm the install steps.
- Pilot with XLOOKUP only, then expand.

## Phase 3: Refocus the Ask Claude panel
- Narrow the panel's system prompt and quick-question chips toward:
  explaining a pasted formula, comparing functions, and walking through the
  page's interactive calculator.
- Ground answers in the current page's content (pass the page text as
  context).
- Add basic per-session rate limiting to control API cost.
- Don't change the API key handling without asking me.

## Working rules
- One phase per session. Use plan mode first and show me the plan.
- Match existing components and styling; don't add new dependencies
  without asking.
- Run the dev server and confirm the page builds before calling a phase done.
