Excel has several hundred keyboard shortcuts, and memorizing all of
them isn't the point — a small, well-chosen set covers almost
everything you'll actually reach for. These 32 are the ones worth
burning into muscle memory, grouped by what they're for, Windows and
Mac side by side.

<Callout type="idea">
  `F4` to cycle a cell reference through `A1` → `$A$1` → `A$1` →
  `$A1` → back to `A1` is the single highest-value shortcut on this
  list if you write formulas by hand — no more manually typing dollar
  signs. On Mac, `⌘+T` does the same job (`Fn+F4` also works in
  current versions).
</Callout>

A few worth calling out specifically:

- **Ctrl+Shift+End / Ctrl+Shift+End** extends the current selection
  all the way to the last cell with data — the fastest way to select
  an entire table without knowing exactly how many rows it has.
- **Ctrl+Arrow key / ⌘+Arrow key** jumps to the edge of the current
  block of data in that direction, stopping at the first gap — the
  same movement double-clicking a cell's border performs, just from
  the keyboard.
- **Ctrl+Space** and **Shift+Space** select an entire column or row
  respectively, on both platforms — worth knowing since they're easy
  to mix up with each other.
