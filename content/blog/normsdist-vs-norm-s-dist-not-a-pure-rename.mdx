Excel 2010 renamed a batch of statistical functions to make their
names clearer — `TTEST` became `T.TEST`, `NORMDIST` became
`NORM.DIST`, and so on. For almost every one of these pairs, the old
and new names are **completely interchangeable**: same arguments, same
order, same results. `NORMSDIST` and `NORM.S.DIST` look like just
another pair in that batch. They aren't.

## The assumption that breaks here

<Callout type="warn">
  `NORM.S.DIST` requires a **second argument**, `cumulative`, that
  `NORMSDIST` never had. Typing `=NORM.S.DIST(1.96)` — swapping in the
  new name with the same one argument the old function took — returns
  `#VALUE!`, not the probability you expected.
</Callout>

<ExcelCode>{`=NORMSDIST(1.96)          → 0.9750
=NORM.S.DIST(1.96)        → #VALUE!
=NORM.S.DIST(1.96, TRUE)  → 0.9750`}</ExcelCode>

The fix is simple once you know it's needed — add `TRUE` as the second
argument. But nothing about the error message points you there, and
the natural instinct (since every *other* renamed statistical function
really is a drop-in swap) is to assume the same is true here.

## Why this one function got an extra argument

`NORMDIST` already had a `cumulative` argument before the 2010 rename
— `TRUE` for the cumulative probability, `FALSE` for the raw
probability density. `NORMSDIST`, its "standard" sibling (mean 0,
standard deviation 1), never got that same flexibility — it only ever
computed the cumulative form. When Microsoft renamed it to
`NORM.S.DIST`, they used the opportunity to bring it in line with
`NORM.DIST` and add the density option it had been missing. The
rename and the new capability happened in the same release, which is
exactly why it's easy to assume the rename was the *only* change.

<ExcelCode>{`=NORM.S.DIST(1.96, TRUE)   → 0.9750  ' cumulative — same as NORMSDIST(1.96)
=NORM.S.DIST(1.96, FALSE)  → 0.0584  ' density — NORMSDIST has no equivalent`}</ExcelCode>

There's no way to get that second line's result out of `NORMSDIST` at
all — not a different argument, not a workaround. The density option
genuinely didn't exist before the rename.
