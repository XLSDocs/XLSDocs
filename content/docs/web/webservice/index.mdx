Call a web service over HTTP or HTTPS and return its response as
text, right inside a cell. WEBSERVICE only issues GET requests and
has no support for headers, authentication, or POST bodies — it's a
lightweight way to pull a URL's contents in, not a full HTTP client.

## Return value

The response body as text, up to Excel's 32,767-character cell
limit. WEBSERVICE recalculates like any other worksheet function —
whenever the workbook recalculates — rather than on a timer or a
fixed refresh schedule.

## Description

WEBSERVICE is the simplest way to bring live web data into a
worksheet without VBA or Power Query, but it's deliberately narrow:
GET requests only, no custom headers, no authentication beyond
whatever's embedded in the URL itself, and no way to send a request
body. For anything beyond "fetch this URL and show me the text," Power
Query or VBA's `MSXML2.XMLHTTP` are the more capable tools.

<Callout type="warn">
  WEBSERVICE **does not work in Excel for the web**, and it appears in
  the Excel for Mac function gallery but never actually returns
  results there — it depends on Windows operating system features.
  Any workbook that leans on WEBSERVICE needs to be opened in
  Windows desktop Excel to actually fetch data.
</Callout>

WEBSERVICE is almost always paired with [ENCODEURL](/docs/web/encodeurl)
when any part of the URL comes from a cell value — user-entered text
or data can easily contain spaces or symbols that would otherwise
break the URL.

## Common errors

### #VALUE! — URL too long

<ExcelCode>{`WEBSERVICE(very_long_url) → #VALUE!`}</ExcelCode>

The GET request limit is 2,048 characters for the whole URL. A URL
built by concatenating several cell values can exceed this
unexpectedly — check the total length if a normally reliable
WEBSERVICE call suddenly errors.

### #VALUE! — response too large

The response from the web service exceeds Excel's 32,767-character
cell limit. There's no way to retrieve a longer response with
WEBSERVICE directly — a paginated API or an external tool would be
needed instead.

### #VALUE! — unsupported protocol or unreachable URL

WEBSERVICE only supports `http://` and `https://` — an `ftp://` or
`file://` URL returns `#VALUE!` immediately. A `https://` URL can
also fail if the service is down, requires authentication WEBSERVICE
can't provide, or blocks requests without a browser-like User-Agent
header.
