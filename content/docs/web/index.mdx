title: Web
description: Pull data from the internet directly into a worksheet, parse XML responses, and encode text for use in a URL.
---

Web functions let a worksheet reach outside itself — fetching a URL's
contents, pulling specific values out of an XML response, and safely
encoding text for use inside a URL. They're the closest thing Excel
has to a built-in HTTP client, without needing Power Query or VBA.
