---
title: Custom Functions
description: Name intermediate values, build reusable functions, and apply them across arrays — all without VBA.
---

LET names intermediate values inside a single formula, and LAMBDA
builds an entire reusable, custom function out of one — no VBA, no
macro-enabled workbook, and it works in Excel for the web. MAP,
BYROW, BYCOL, REDUCE, and SCAN apply a LAMBDA across an array —
element by element, row by row, or column by column — and MAKEARRAY
builds a brand new array from a size and a rule.
