Assign a name to an intermediate value inside a formula, then reuse
that name instead of repeating the same expression — shorter
formulas, computed once instead of once per repetition, and easier
to actually read.

## Return value

Whatever `calculation` evaluates to, with every `nameN` inside it
substituted for its corresponding `valueN`.

## Description

LET solves the "repeated sub-expression" problem that makes long
formulas hard to read and slow to run — instead of writing the same
`VLOOKUP(...)` or `FILTER(...)` three times in one formula, compute
it once, give it a name, and reference that name everywhere else.
Excel also only evaluates each named value once, rather than once
per use, which can meaningfully speed up a formula that previously
repeated an expensive lookup or calculation.

<Callout type="info">
  Names defined earlier in the same LET can be used in the value
  expressions that come after them — `LET(total, SUM(A:A), avg,
  total/COUNT(A:A), avg)` uses `total` while defining `avg`. Order
  matters: a name can't be used before it's been defined.
</Callout>

## Common errors

### Forgetting the final calculation argument

<ExcelCode>{`LET(total, SUM(A:A)) → #VALUE! (missing the calculation)`}</ExcelCode>

Every LET needs a final argument after the name/value pairs — the
formula that actually uses them:

<ExcelCode>{`LET(total, SUM(A:A), total)`}</ExcelCode>

### Using a name that looks like a cell reference

<ExcelCode>{`LET(A1, 5, A1*2) → error — "A1" isn't a valid LET name`}</ExcelCode>

Names can't be formatted like a cell reference. Pick a descriptive
word instead:

<ExcelCode>{`LET(price, 5, price*2)`}</ExcelCode>
