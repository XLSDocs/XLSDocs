Apply a custom calculation to every element of an array (or several
arrays at once, element by element) without a helper column — the
array-formula equivalent of a loop that transforms each item.

## Return value

A spilled array the same size and shape as the input array(s), with
every element replaced by the result of calling `lambda` on it (or on
the corresponding elements, if multiple arrays were passed).

## Description

MAP is the array-formula version of "do this to every item in the
list" — instead of writing one formula and dragging it down a column,
MAP spills the whole transformed array from a single formula. Passing
more than one array lets `lambda` combine corresponding elements
(like a row-by-row calculation across two columns) without SUMPRODUCT
or a helper column.

<Callout type="warn">
  Every array passed to MAP must be the **same size** — MAP calls
  `lambda` once per position across all of them together, so a
  mismatched size (or an argument count in `lambda` that doesn't
  match the number of arrays) produces an error instead of a result.
</Callout>

## Common errors

### #VALUE! — lambda's parameter count doesn't match the number of arrays

<ExcelCode>{`MAP(A2:A10, LAMBDA(x, y, x+y)) → #VALUE!`}</ExcelCode>

One array was passed, but `lambda` expects two parameters. Either
pass a second array, or reduce `lambda` to one parameter.

### The result looks like one repeated value instead of a transformed array

This usually means `lambda`'s calculation doesn't actually reference
its parameter — double-check the parameter name inside the
calculation matches what's declared, and that it's actually used.

### Mismatched array sizes

<ExcelCode>{`MAP(A2:A10, B2:B5, LAMBDA(x,y,x+y)) → #VALUE!`}</ExcelCode>

All arrays passed to MAP must have the same dimensions — a 9-row
array paired with a 4-row array can't be matched element by element.

## Related functions

- [LAMBDA](/docs/custom-functions/lambda) — defines the calculation
  MAP applies to each element.
- [BYROW](/docs/custom-functions/byrow) and [BYCOL](/docs/custom-functions/bycol) —
  apply a lambda to a whole row or column at once, instead of to
  each individual element.
- [REDUCE](/docs/custom-functions/reduce) — collapses an array to a
  single accumulated value instead of transforming it element by
  element.
- [SCAN](/docs/custom-functions/scan) — like REDUCE, but returns every
  intermediate accumulated value as an array.
