---
title: BYROW examples
description: Worked examples for BYROW — row totals, weighted scores, conditional flags, and indexing into a row's columns.
---

<FunctionNav />

<ExampleCard number="01" label="Row totals across three columns" formula={`=BYROW(A2:C10, LAMBDA(row, SUM(row)))`}>
  Spills a single column of row totals, one per row, without a
  helper column or a dragged-down SUM formula.
</ExampleCard>

<ExampleCard number="02" label="Row-wise average" formula={`=BYROW(A2:F10, LAMBDA(row, AVERAGE(row)))`}>
  Averages each row across all 6 columns, spilling one average per
  row.
</ExampleCard>

<ExampleCard number="03" label="Flag rows where every value passes a threshold" formula={`=BYROW(A2:C10, LAMBDA(row, AND(row>0)))`}>
  Returns TRUE for a row only if every value in it is greater than
  0, FALSE otherwise — one flag per row.
</ExampleCard>

<ExampleCard number="04" label="Weighted score using specific columns" formula={`=BYROW(A2:C10, LAMBDA(row, INDEX(row,1)*0.5 + INDEX(row,2)*0.3 + INDEX(row,3)*0.2))`}>
  Indexes into specific positions of each row to apply different
  weights to each column before combining them.
</ExampleCard>

<ExampleCard number="05" label="Forgetting to reduce the row to one value" formula={`=BYROW(A2:C10, LAMBDA(row, row))`}>
  Each result cell shows a nested array instead of a single number —
  the lambda needs an aggregate like SUM or AVERAGE to collapse the
  row properly.
</ExampleCard>
