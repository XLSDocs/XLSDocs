Collapse an entire array down to one value by processing it element
by element, carrying an accumulated result forward each step — a
running total, a concatenated string, or any calculation that needs
to "remember" what came before.

## Return value

A single value — whatever the accumulator holds after `lambda` has
run once for every element in `array`.

## Description

REDUCE processes an array left to right, calling `lambda` once per
element with two arguments: the accumulated result so far, and the
current element. Whatever `lambda` returns becomes the accumulator
for the next element — after the last one, that final accumulator
value is REDUCE's result.

<Callout type="info">
  Skipping `initial_value` uses the array's **first element** as the
  starting accumulator, and `lambda` runs starting from the second
  element. This matters for calculations that aren't simply additive
  (like string concatenation) — leaving out an explicit
  `initial_value` when one is needed produces a subtly wrong result,
  not an error.
</Callout>

## Common errors

### The result is off by one element

This usually means `initial_value` was omitted when the calculation
actually needed a real starting point (like `0` for a sum that should
include every element, or `""` for building a string from scratch) —
without it, the first array element becomes the starting accumulator
and is never passed through `lambda` itself.

### #VALUE! — lambda doesn't take exactly two parameters

<ExcelCode>{`REDUCE(0, A2:A10, LAMBDA(x, x*2)) → #VALUE!`}</ExcelCode>

`lambda` must take exactly two parameters — the accumulator first,
then the current element. A single-parameter LAMBDA (built for MAP)
won't work here.

### Confusing REDUCE with SCAN

REDUCE returns only the **final** accumulated value; if the running
total at every step is needed (not just the end result), that's what
SCAN is for — the two share the same argument shape.

## Related functions

- [SCAN](/docs/custom-functions/scan) — the same accumulation logic,
  but returns every intermediate value instead of just the final one.
- [LAMBDA](/docs/custom-functions/lambda) — defines the two-parameter
  accumulator calculation REDUCE runs at each step.
- [MAP](/docs/custom-functions/map) — transforms every element
  independently instead of accumulating a single result across them.
