Turn a formula into a custom, reusable function with its own named
parameters — the same kind of thing VBA's `Function...End Function`
does, but as a plain worksheet formula that works in Excel for the
web too.

## Return value

A function — not a plain value. Calling it with arguments (either
immediately, or later by name once saved) returns whatever
`calculation` evaluates to for those arguments.

## Description

LAMBDA is what makes it possible to build a genuinely custom Excel
function — `TOQUARTER`, `CLEANPHONE`, `WEIGHTEDAVG` — without VBA, a
macro-enabled file, or anything that Excel for the web can't run. A
LAMBDA on its own is just a definition; it needs to actually be
**called** to produce a result, either immediately by appending a
second set of parentheses with the arguments (`LAMBDA(x, x*2)(5)`
returns `10`), or saved once under a name in Name Manager so it can
be called from any cell just like `SUM` or `XLOOKUP`.

<Callout type="warn">
  Typing `=LAMBDA(x, x*2)` into a cell by itself returns `#CALC!` —
  "LAMBDA takes 1 argument(s)." A LAMBDA isn't a value until it's
  called with its arguments: either append them directly
  (`=LAMBDA(x, x*2)(5)`) or save the LAMBDA under a name first.
</Callout>

## How to save a LAMBDA as a reusable function

1. Go to **Formulas → Name Manager → New**.
2. Give it a name (e.g. `TOQUARTER`) — this becomes the function
   name used in formulas.
3. In **Refers to**, paste the LAMBDA formula, without a leading `=`
   and without calling it: `LAMBDA(d, CHOOSE(ROUNDUP(MONTH(d)/3,0), "Q1", "Q2", "Q3", "Q4"))`.
4. Click OK. `=TOQUARTER(A2)` now works in any cell in the workbook.

## Common errors

### #CALC! from an uncalled LAMBDA

<ExcelCode>{`=LAMBDA(x, x*2) → #CALC! ("LAMBDA takes 1 argument(s).")`}</ExcelCode>

Call it with arguments instead of leaving it bare:

<ExcelCode>{`=LAMBDA(x, x*2)(5)`}</ExcelCode>

### Forgetting to remove the leading = when saving in Name Manager

<ExcelCode>{`=LAMBDA(x, x*2) in the "Refers to" field → error`}</ExcelCode>

Name Manager's "Refers to" field needs the formula **without** a
leading `=`:

<ExcelCode>{`LAMBDA(x, x*2)`}</ExcelCode>

- [MAP](/docs/custom-functions/map), [BYROW](/docs/custom-functions/byrow),
