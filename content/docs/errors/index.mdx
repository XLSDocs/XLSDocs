Every function page on this site documents the specific errors it can
return. This section indexes the error values themselves — `#REF!`,
`#VALUE!`, and the rest — so you can start from what you're actually
staring at in a cell, rather than needing to already know which
function caused it.

## Error codes

<Cards className="grid-cols-3">
  <Card title="#REF!" description="A formula points to a cell, range, or sheet that no longer exists." href="/docs/errors/ref" />
  <Card title="#VALUE!" description="A formula received the wrong type of input — text where a number was expected, most often." href="/docs/errors/value" />
  <Card title="#NAME?" description="Excel doesn't recognize something in the formula — a misspelled function, missing quotes, or a function your version doesn't have." href="/docs/errors/name" />
  <Card title="#N/A" description="A lookup or match ran successfully but found no matching value." href="/docs/errors/na" />
  <Card title="#DIV/0!" description="A formula divides by zero — or by a blank cell, which Excel treats as zero." href="/docs/errors/div-0" />
  <Card title="#NUM!" description="A formula's numeric input or result is invalid — out of range or mathematically impossible." href="/docs/errors/num" />
  <Card title="#SPILL!" description="A dynamic array formula is correct, but something is blocking the cells it needs to spill into." href="/docs/errors/spill" />
</Cards>
