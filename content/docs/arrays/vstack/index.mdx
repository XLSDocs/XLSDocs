Combine multiple ranges or arrays into a single spilled array,
stacked one on top of the other — no copy-pasting rows from separate
sheets into one combined list.

## Return value

A single dynamic array containing every row from every argument, in
order, spilled into the cells below/right of the formula.

## Description

VSTACK is the formula equivalent of pasting several tables one below
another — combining January/February/March sales sheets into one
continuous list, or merging a "new records" range under an existing
table, all as a live formula that updates when any source range
changes. It works across sheets (`=VSTACK(Jan!A:C, Feb!A:C, Mar!A:C)`)
just as easily as within one.

<Callout type="warn">
  If the arguments have different numbers of columns, VSTACK doesn't
  error — it pads the narrower rows with `#N/A` on the right so every
  row in the result has the same width. Mismatched column counts are
  usually a sign the wrong ranges were selected, even though VSTACK
  itself won't complain.
</Callout>

## Common errors

### #N/A padding from mismatched column counts

<ExcelCode>{`VSTACK(A1:B5, D1:F5) → rows from A1:B5 get an extra #N/A column`}</ExcelCode>

Both ranges need the same number of columns to combine cleanly —
adjust the range widths to match:

<ExcelCode>{`VSTACK(A1:C5, D1:F5)`}</ExcelCode>

### #SPILL! — blocked spill range

Cells below or beside the formula already contain data. Clear the
spill range, or move the formula somewhere clear.

## Related functions

- [UNIQUE](/docs/arrays/unique) — often wraps VSTACK to deduplicate
  a combined list: `UNIQUE(VSTACK(...))`.
- [SORT](/docs/arrays/sort) — often wraps VSTACK to put the combined
  rows in order.
- [FILTER](/docs/arrays/filter) — can run on VSTACK's result to pull
  matching rows out of the combined list.
