Generate a list of sequential numbers — 1, 2, 3, ... or any custom
start and step — without typing them in or dragging a fill handle.
Commonly used to feed another function's `k` or index argument
automatically.

## Return value

A dynamic array of `rows` × `columns` sequential numbers, filled
row by row starting from `start` and incrementing by `step`, spilled
into the cells below/right of the formula.

## Description

SEQUENCE is a dynamic array function — like FILTER and SORT, it
returns a live spill range rather than a single value. Its most
common real use isn't as a standalone list, but as a generator for
another function's numeric argument — feeding `k` = 1, 2, 3 into
LARGE or SMALL to spill a whole ranked list in one formula, instead
of writing the same call three separate times.

<Callout type="warn">
  SEQUENCE requires **Excel 365 or Excel 2021**, like other dynamic
  array functions. It is not available in Excel 2019, 2016, or
  earlier — those versions will show `#NAME?`.
</Callout>

## Common errors

### #SPILL! — blocked spill range

Cells below or to the right of the formula already contain data.
Clear the spill range, or move the formula somewhere clear.

### #VALUE! — non-numeric arguments

<ExcelCode>{`SEQUENCE("five") → #VALUE!`}</ExcelCode>

All four arguments must be numbers, not text.

### Expecting a 2D grid without specifying columns

<ExcelCode>{`SEQUENCE(5) → a single column of 5 numbers, not a grid`}</ExcelCode>

Without `columns`, SEQUENCE defaults to one column — pass a second
argument for a multi-column grid: `SEQUENCE(5, 3)`.
