automatically and updates live as the source data changes.

## Return value

A dynamic array of the distinct values in `array`, in order of first
appearance, spilled into the cells below/right of the formula.

## Description

UNIQUE is a dynamic array function — like FILTER and SORT, it returns
a live spill range rather than a single value. By default it returns
every value once (true "distinct" — the same idea as Remove
Duplicates, but as a live formula). Text comparisons ignore case, the
same convention as COUNTIF/XLOOKUP.

<Callout type="warn">
  `exactly_once=TRUE` does **not** mean "distinct" — it means "appears
  exactly one time." A value that shows up 3 times is excluded
  entirely, not collapsed to one row. For a plain deduplicated list,
  leave `exactly_once` at its default (`FALSE`).
</Callout>

## Common errors

### #CALC! — empty result

`array` is empty, or (with `exactly_once=TRUE`) every value in
`array` happens to be duplicated at least once, leaving nothing that
qualifies.

### Confusing exactly_once with a plain distinct list

<ExcelCode>{`UNIQUE(A2:A10, FALSE, TRUE) → only values appearing once`}</ExcelCode>

If the goal is a deduplicated list (each value shown once, regardless
of how many times it appeared), omit the third argument or pass
`FALSE`:

<ExcelCode>{`UNIQUE(A2:A10)`}</ExcelCode>

### #SPILL! — blocked spill range

Cells below the formula already contain data. Clear the spill range,
or move the formula somewhere clear.

## Related functions

  alphabetized list of distinct values: `SORT(UNIQUE(...))`.
- [FILTER](/docs/arrays/filter) — combines with UNIQUE for "distinct
  values matching a condition": `UNIQUE(FILTER(...))`.
- [COUNTIF](/docs/math/countif) — useful alongside UNIQUE to count how
  many times each distinct value occurs.
