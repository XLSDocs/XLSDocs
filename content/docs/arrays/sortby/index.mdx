Sort a range or array by a *different* array's values — useful when
the sort key isn't a column you want in the output, or when the sort
needs more than one level (region, then amount within region).

## Return value

A dynamic array containing every row of `array`, reordered according
to `by_array1` (and any additional sort-key pairs), spilled into the
cells below/right of the formula. The source data is untouched.

## Description

SORTBY separates *what gets sorted* (`array`) from *what it's sorted
by* (`by_array1`, `by_array2`, ...) — the sort key doesn't need to be
part of the returned array at all, and multiple sort levels are
built in via repeated by_array/sort_order pairs, unlike SORT which
only takes one sort_index.

<Callout type="warn">
  SORTBY requires **Excel 365 or Excel 2021**, like other dynamic
  array functions. It is not available in Excel 2019, 2016, or
  earlier — those versions will show `#NAME?`.
</Callout>

## Common errors

### #VALUE! — mismatched sizes

<ExcelCode>{`SORTBY(A2:A10, B2:B9) → #VALUE!`}</ExcelCode>

Every `by_array` must be the same height (or width) as `array` —
here `array` is 9 rows (A2:A10) and `by_array1` is 8 rows (B2:B9).

### Sort levels applied in the wrong order

<ExcelCode>{`SORTBY(A2:C10, C2:C10, 1, B2:B10, -1)`}</ExcelCode>

Sort-key pairs are applied in the order they're listed, most
significant first — this sorts by column C ascending *first*, then
by column B descending as a tiebreaker. Swapping the pairs changes
which one takes priority.

### #CALC! — empty array

`array` is empty, often because it's fed by a FILTER call that
matched nothing. Give the upstream FILTER an `if_empty` fallback so
SORTBY never receives an empty array.
