---
title: CHOOSEROWS examples
description: Worked examples for CHOOSEROWS — first and last row, reordering rows, and the out-of-range error.
---

<FunctionNav />

<ExampleCard number="01" label="First and last row only" formula={`=CHOOSEROWS(A1:C10, 1, -1)`}>
  Returns just row 1 and the last row, skipping everything in
  between.
</ExampleCard>

<ExampleCard number="02" label="Reversing row order" formula={`=CHOOSEROWS(A1:C5, -1, -2, -3, -4, -5)`}>
  Lists rows from last to first, returning the entire array with its
  rows in reverse order.
</ExampleCard>

<ExampleCard number="03" label="Duplicating a header row above a summary" formula={`=VSTACK(CHOOSEROWS(A1:C10, 1), CHOOSEROWS(A1:C10, -1))`}>
  Combines the header row (row 1) with just the last row, using
  VSTACK to stack them into a compact 2-row summary.
</ExampleCard>

<ExampleCard number="04" label="Selecting a non-contiguous subset" formula={`=CHOOSEROWS(A1:C20, 2, 5, 9)`}>
  Pulls exactly rows 2, 5, and 9 — an arbitrary, non-contiguous
  selection TAKE alone couldn't express.
</ExampleCard>

<ExampleCard number="05" label="Out-of-range row number" formula={`=CHOOSEROWS(A1:C10, 25)`}>
  Returns `#VALUE!` — the range only has 10 rows, so row 25 doesn't
  exist.
</ExampleCard>
