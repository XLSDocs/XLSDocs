Combine multiple ranges or arrays into a single spilled array, joined
side by side — VSTACK's horizontal counterpart, for putting separate
columns or tables next to each other instead of one below another.

## Return value

A single dynamic array containing every column from every argument,
side by side in order, spilled into the cells to the right of/below
the formula.

## Description

HSTACK is VSTACK turned sideways — instead of stacking rows on top of
each other, it lines columns up next to each other. It's the formula
way to combine separate lookup results, or bring columns from two
different ranges (even different sheets) into one contiguous block,
without copy-pasting.

<Callout type="warn">
  If the arguments have different numbers of rows, HSTACK doesn't
  error — it pads the shorter columns with `#N/A` at the bottom so
  every column in the result has the same height. A mismatched row
  count is usually a sign the wrong ranges were selected, even though
  HSTACK itself won't complain.
</Callout>

## Common errors

### #N/A padding from mismatched row counts

<ExcelCode>{`HSTACK(A1:A10, C1:C5) → the second column gets #N/A padding below row 5`}</ExcelCode>

Both ranges need the same number of rows to combine cleanly — adjust
the range heights to match:

<ExcelCode>{`HSTACK(A1:A10, C1:C10)`}</ExcelCode>

### #SPILL! — blocked spill range

Cells to the right of or below the formula already contain data.
Clear the spill range, or move the formula somewhere clear.
