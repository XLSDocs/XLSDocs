Flatten a multi-row, multi-column array down into a single column —
TOROW's vertical counterpart, for turning a table into a flat list
that reads down the sheet instead of across it.

## Return value

A single-column spilled array containing every value from `array`,
in the order determined by `scan_by_column`.

## Description

TOCOL is TOROW turned sideways — same flattening logic, same
`ignore`/`scan_by_column` arguments, just spilling down a column
instead of across a row. It's the natural shape for feeding a
flattened list into something that expects a vertical range, like a
data validation list or a single-column chart series.

<Callout type="info">
  `scan_by_column` changes the **order** values come out in, not just
  the shape. With the default `FALSE`, a 2-row, 3-column array reads
  row 1 fully, then row 2. With `TRUE`, it reads column 1 fully
  (both rows), then column 2 — the same values, a different sequence.
</Callout>

## Common errors

### Unexpected value order

<ExcelCode>{`TOCOL(A1:B2) → A1, B1, A2, B2 (row by row, the default)`}</ExcelCode>

If column-by-column order was actually wanted, pass `TRUE` for
`scan_by_column`:

<ExcelCode>{`TOCOL(A1:B2, 0, TRUE) → A1, A2, B1, B2`}</ExcelCode>

### Blanks or errors showing up unexpectedly in the result

<ExcelCode>{`TOCOL(A1:C5) → includes blank cells and any #N/A or other errors present`}</ExcelCode>

Pass an `ignore` value to drop them during flattening instead of
filtering afterward:

<ExcelCode>{`TOCOL(A1:C5, 3)`}</ExcelCode>

### Expecting TOCOL to remove duplicates

TOCOL only reshapes — it doesn't deduplicate. Wrap the result in
`UNIQUE` if distinct values are also needed:
`UNIQUE(TOCOL(A1:C5))`.
