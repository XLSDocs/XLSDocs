Pull out one or more specific columns from an array by number — the
first column, the last column, or any combination in any order —
CHOOSEROWS's horizontal counterpart.

## Return value

A spilled array containing the requested columns from `array`, in
the exact order the column numbers were given — not necessarily
their original order.

## Description

CHOOSECOLS is CHOOSEROWS turned sideways: instead of a whole list of
row numbers, it takes a list of column numbers and returns every row
for each of them, in whatever order they're listed. It's a common
way to reorder or reduce a wide table down to just the columns
actually needed, without deleting or hiding columns in the source
data itself.

<Callout type="idea">
  Column numbers don't have to be in order, and the **same column can
  be selected more than once** — `CHOOSECOLS(array, 3, 1, 3)` returns
  column 3, then column 1, then column 3 again. Useful for reordering
  or duplicating columns, not just picking a subset.
</Callout>

## Common errors

### #VALUE! — a column number is out of range

<ExcelCode>{`CHOOSECOLS(A1:C10, 5) → #VALUE! (only 3 columns exist)`}</ExcelCode>

Every column number must fall within `array`'s actual column count —
unlike TAKE, CHOOSECOLS doesn't just return what's available.

### Expecting contiguous columns without listing each one

For a simple contiguous block of columns from the start or end,
`TAKE` (with its column argument) is simpler than listing every
individual column number.

### Forgetting that order in equals order out

<ExcelCode>{`CHOOSECOLS(A1:D10, 4, 1) → column 4 first, then column 1 — not sorted`}</ExcelCode>

The result follows the order the column numbers were given in, not
their original position in `array` — useful for reordering
columns, but a surprise if ascending order was assumed.
