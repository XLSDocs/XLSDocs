Sort a range or array by any column (or row), ascending or
descending — no manual re-sorting, and the result updates live as the
source data changes. The sorted rows spill automatically into the
cells below the formula.

## Return value

A dynamic array containing every row of `array`, reordered by
`sort_index`, spilled into the cells below/right of the formula. The
source data itself is untouched.

## Description

SORT is a dynamic array function — like FILTER, it returns a spill
range rather than a single value, and updates live as the source data
changes without re-entering the formula. It replaces manually
re-sorting a range (or Data → Sort) when the result needs to stay
live.

<Callout type="warn">
  SORT requires **Excel 365 or Excel 2021**, like other dynamic array
  functions. It is not available in Excel 2019, 2016, or earlier —
  those versions will show `#NAME?`.
</Callout>

## Common errors

### #VALUE! — sort_index out of range

<ExcelCode>{`SORT(A2:C10, 5) → #VALUE!`}</ExcelCode>

`sort_index` must point to a column that actually exists within
`array` — here `array` only has 3 columns, so `5` is invalid.

### #CALC! — empty array

`array` is empty or every value was filtered out upstream (e.g.
`SORT(FILTER(...))` where FILTER matched nothing). Wrap the FILTER
call with an `if_empty` fallback so SORT never receives an empty
array.

### #SPILL! — blocked spill range

Cells below the formula already contain data. Clear the spill range,
or move the formula somewhere clear.

### Mixed text and numbers sort unexpectedly

Numbers always sort before text in ascending order, and errors sort
last, regardless of `sort_order` — a column mixing types (e.g. some
cells "N/A", others numeric) can produce a sort order that looks
wrong until this rule is accounted for.

## Related functions

- [SORTBY](/docs/arrays/sortby) — sorts one array using the order of
  a separate array, useful when the sort key isn't in the result
  itself or a multi-level sort is needed.
- [FILTER](/docs/arrays/filter) — often wrapped inside SORT to sort
  only the rows that match a condition.
- [UNIQUE](/docs/arrays/unique) — combines well with SORT for an
  alphabetized list of distinct values: `SORT(UNIQUE(...))`.
