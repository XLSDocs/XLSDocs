Pull a specific number of rows and/or columns from an array — the
first 5 rows, the last 3 columns, or both at once — without slicing a
range by hand or counting cells.

## Return value

A spilled array containing just the requested rows and/or columns
from `array`, in their original order.

## Description

TAKE is a formula-based alternative to manually selecting a smaller
range out of a larger one — "just the first 10 rows," "just the last
3 columns," or both together. The sign of each argument controls the
direction: positive counts from the start (top or left), negative
counts from the end (bottom or right), which makes "the last N rows"
a one-argument formula instead of a COUNTA-and-OFFSET combination.

<Callout type="info">
  `TAKE(array, -5)` takes the **last** 5 rows, not the first — the
  negative sign is what flips the direction. This is the cleanest way
  to grab "the most recent N rows" from a table that keeps growing,
  without OFFSET or a manually maintained row count.
</Callout>

## Common errors

### The wrong end of the array gets returned

<ExcelCode>{`TAKE(A1:A20, 5) → first 5 rows, not the last 5`}</ExcelCode>

A positive `rows` argument always takes from the top. For the last 5
rows instead, use a negative number:

<ExcelCode>{`TAKE(A1:A20, -5)`}</ExcelCode>

### #VALUE! — rows or columns isn't a whole number

Both arguments must be integers — a fractional row/column count (like
`2.5`) returns an error rather than rounding.

### Asking for more rows than the array has

This isn't an error — TAKE simply returns every row available if
`rows` exceeds the array's actual size, rather than padding or
erroring.
