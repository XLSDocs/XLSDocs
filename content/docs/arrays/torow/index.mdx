Flatten a multi-row, multi-column array down into a single row — a
one-step way to turn a table into a flat list without nested
formulas or nested nested FILTER/HSTACK combinations.

## Return value

A single-row spilled array containing every value from `array`, in
the order determined by `scan_by_column`.

## Description

TOROW collapses a 2D range into one flat row, which is useful
whenever downstream logic (a chart, a COUNTIF, a text join) needs a
simple list rather than a grid shape. The `ignore` argument means
blank cells or error values scattered through a range don't have to
be cleaned up first — TOROW can skip them while flattening in the
same step.

<Callout type="info">
  `scan_by_column` changes the **order** values come out in, not just
  the shape. With the default `FALSE`, a 2-row, 3-column array reads
  row 1 fully, then row 2. With `TRUE`, it reads column 1 fully
  (both rows), then column 2 — the same values, a different sequence.
</Callout>

## Common errors

### Unexpected value order

<ExcelCode>{`TOROW(A1:B2) → A1, B1, A2, B2 (row by row, the default)`}</ExcelCode>

If column-by-column order was actually wanted, pass `TRUE` for
`scan_by_column`:

<ExcelCode>{`TOROW(A1:B2, 0, TRUE) → A1, A2, B1, B2`}</ExcelCode>

### Blanks or errors showing up unexpectedly in the result

<ExcelCode>{`TOROW(A1:C5) → includes blank cells and any #N/A or other errors present`}</ExcelCode>

Pass an `ignore` value to drop them during flattening instead of
filtering afterward:

<ExcelCode>{`TOROW(A1:C5, 3)`}</ExcelCode>

### Expecting TOROW to remove duplicates

TOROW only reshapes — it doesn't deduplicate. Wrap the result in
`UNIQUE` if distinct values are also needed:
`UNIQUE(TOROW(A1:C5))`.
