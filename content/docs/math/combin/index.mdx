Count how many different groups of a given size can be chosen from a
larger set, where the **order** items are picked in doesn't matter —
choosing A-then-B counts the same as B-then-A.

## Return value

The number of ways to choose `number_chosen` items from a group of
`number`, ignoring order — mathematically, `number! / (number_chosen!
× (number − number_chosen)!)`.

## Description

COMBIN answers "how many different 5-card hands can be dealt from a
52-card deck?" style questions — situations where a group is being
selected, not arranged in a sequence. If the order of selection
matters instead (first place, second place, third place, not just
"which three"), `PERMUT` is the function built for that instead.

<Callout type="warn">
  COMBIN counts **combinations**, not **permutations** — {'{A, B}'}
  and {'{B, A}'} are the same combination and only counted once.
  Choosing 2 people from a group of 3 has 3 combinations
  (`COMBIN(3,2)`), but 6 permutations (`PERMUT(3,2)`) once order is
  considered.
</Callout>

Choosing all 5 items from a group of 5 has only one possible
combination — the whole group itself — which is why `COMBIN(5, 5)`
returns `1`.

## Common errors

### #NUM! — number_chosen is negative or greater than number

<ExcelCode>{`COMBIN(5, 7) → #NUM!`}</ExcelCode>

`number_chosen` can't exceed `number` — there's no way to choose 7
items from a group of only 5.

### Confusing COMBIN with PERMUT

<ExcelCode>{`COMBIN(3, 2) → 3, not 6`}</ExcelCode>

If the order of selection actually matters (first vs. second place,
not just "which two"), `PERMUT` is the correct function —
`PERMUT(3,2)` returns `6`.
