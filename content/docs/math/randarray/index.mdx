Generate a whole grid of random numbers in one formula — RAND's
dynamic-array counterpart, with control over the grid size, value
range, and whether the results are whole numbers or decimals.

## Return value

A dynamic array of `rows` × `columns` random numbers between `min`
and `max`, spilled into the cells below/right of the formula.

## Description

RANDARRAY is a dynamic array function — it fills a whole grid of
random values in a single formula, instead of writing `=RAND()` in
one cell and copying it across a range. With no arguments at all,
`RANDARRAY()` behaves just like `RAND()`, returning a single
decimal between 0 and 1.

<ExcelCode>{`=RANDARRAY(3, 2, 1, 100, TRUE) → a 3-row, 2-column grid of random whole numbers from 1 to 100`}</ExcelCode>

<Callout type="warn">
  **RANDARRAY requires Excel 365 or Excel 2021**, like other
  dynamic array functions. It is not available in Excel 2019, 2016,
  or earlier — those versions will show `#NAME?`.
</Callout>

<Callout type="warn">
  **Every result recalculates whenever the workbook does**, the
  same volatile behavior as RAND and RANDBETWEEN. If a fixed set of
  random values is needed, copy the results and paste them back as
  values (Paste Special → Values).
</Callout>

## Common errors

### #VALUE! — min is not less than max

<ExcelCode>{`RANDARRAY(1, 1, 10, 5) → #VALUE!`}</ExcelCode>

`min` must be strictly less than `max`.

### #SPILL! — blocked spill range

Cells below or to the right of the formula already contain data.
Clear the spill range, or move the formula somewhere clear.

## Related functions

- [RAND](/docs/math/rand) — returns a single random decimal between
  0 and 1, without the array/grid capability.
- [RANDBETWEEN](/docs/math/randbetween) — returns a single random
  whole number in a range, the single-cell version of what
  RANDARRAY's `whole_number` argument does across a grid.
- [SEQUENCE](/docs/arrays/sequence) — another dynamic array
  generator, producing a predictable sequence instead of random
  values.
