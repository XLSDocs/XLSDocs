Return a random whole number between two bounds, both inclusive — the
straightforward way to get a random integer without scaling RAND's
0–1 output by hand.

## Return value

A random whole number `n` where `bottom ≤ n ≤ top`. A new value is
generated every time the workbook recalculates.

## Description

Unlike `RAND` (which always returns a decimal strictly less than 1),
RANDBETWEEN returns a whole number, and both bounds are **inclusive**
— `RANDBETWEEN(1, 6)` (simulating a die roll) can actually return `6`,
not just values up to but excluding it.

<Callout type="warn">
  RANDBETWEEN is **volatile**, exactly like `RAND` — it recalculates
  on every workbook recalculation, so a cell showing `=RANDBETWEEN(1,
  100)` will show a different number almost every time it's viewed. To
  freeze a randomly-generated value permanently, copy it and use
  **Paste Special → Values**.
</Callout>

## Common errors

### #NUM! — bottom is greater than top

<ExcelCode>{`RANDBETWEEN(10, 1) → #NUM!`}</ExcelCode>

`bottom` must be less than or equal to `top` — swap the arguments if
they were entered backwards.

### The result keeps changing every time I look at it

This is expected — RANDBETWEEN is volatile and recalculates on every
recalculation. Use Paste Special → Values to freeze a specific roll
permanently.

### Decimal bounds get silently truncated

<ExcelCode>{`RANDBETWEEN(1.9, 5.1) → still only returns whole numbers, treating bounds as 2 and 5`}</ExcelCode>

Even though decimal `bottom`/`top` values are accepted without
erroring, RANDBETWEEN always returns a whole number — non-integer
bounds get rounded toward the middle of the range before generating.
