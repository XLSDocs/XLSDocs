title: AVERAGEIF

Average a range of values, but only for rows that match **one**
condition — the same single-condition shape as SUMIF, just averaging
instead of summing. For more than one condition, use
[AVERAGEIFS](/docs/math/averageifs) instead.

## Return value

The average of `average_range` (or `range`, if `average_range` is
omitted) values in rows where `criteria` matches. Returns `#DIV/0!`
if no rows match, since averaging zero items is a division by zero.

## Description

AVERAGEIF is the single-condition version of AVERAGEIFS, and follows
the same argument shape as SUMIF — `average_range` is the last,
optional argument, unlike AVERAGEIFS which puts it first and
required.

<Callout type="warn">
  Unlike SUMIF, which returns `0` when nothing matches, AVERAGEIF
  throws `#DIV/0!` — there's no sensible average of zero rows. Wrap
  it in IFERROR if a zero-match result should show `0` or a message
  instead.
</Callout>

## Common errors

### #DIV/0! — no rows match

<ExcelCode>{`AVERAGEIF(A2:A10, "West", B2:B10) → #DIV/0! (when no row is "West")`}</ExcelCode>

There's nothing to average. Wrap it in IFERROR for a fallback:

<ExcelCode>{`IFERROR(AVERAGEIF(A2:A10, "West", B2:B10), 0)`}</ExcelCode>

### #VALUE! — mismatched range sizes

<ExcelCode>{`AVERAGEIF(A2:A10, "West", B2:B9) → #VALUE!`}</ExcelCode>

`average_range` must be the same size as `range` — here one is 9 rows
and the other is 10.

### Silently wrong average — forgetting average_range

<ExcelCode>{`AVERAGEIF(Sales[Region], "West", Sales[Region]) → averages Region, not Amount`}</ExcelCode>

This doesn't throw an error — it just averages the wrong column,
because `average_range` was left out of the third argument by
mistake.

## Related functions

- [AVERAGEIFS](/docs/math/averageifs) — the multi-condition version of
  AVERAGEIF, with `average_range` as the *first, required* argument
  instead of last and optional.
- [SUMIF](/docs/math/sumif) — same single-condition matching, but
  totals the matching rows instead of averaging them.
- [COUNTIF](/docs/math/countif) — same idea, counting matching rows
  instead of averaging a value range.
- [IFERROR](/docs/logical/iferror) — wraps AVERAGEIF to replace
  `#DIV/0!` on a zero-match result with a fallback value.
