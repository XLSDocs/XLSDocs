Return the **arccosine** — the angle whose cosine is the given
number. The input must be between `-1` and `1` (cosine never exceeds
that range), and the result comes back in **radians**, between `0`
and `π`.

## Return value

The angle, in radians, whose cosine is `number`, always between `0`
and `π` (0° to 180°). Wrap the result in
[DEGREES](/docs/math/degrees) to convert it to degrees.

## Description

ACOS is the inverse of [COS](/docs/math/cos) — given a cosine ratio,
it finds the angle. Because cosine repeats itself (many different
angles share the same cosine value), ACOS can only ever return one
answer per input, so Excel always returns the result in the `0` to
`π` range — the *principal* value, not necessarily the specific angle
a real-world problem has in mind.

<Callout type="warn">
  **ACOS(COS(x)) does not always return x back.** It only round-trips
  correctly when `x` is already inside `0` to `π`. `COS(RADIANS(-60))`
  is `0.5`, the same as `COS(RADIANS(60))` — so `ACOS` of either one
  returns the angle for 60°, never -60°, because 60° is the principal
  value cosine can't distinguish -60° from.
</Callout>

## Common errors

### #NUM! — an argument outside -1 to 1

<ExcelCode>{`ACOS(1.5) → #NUM! (no angle has a cosine greater than 1)`}</ExcelCode>

Cosine never exceeds `-1` to `1`, so any `number` outside that range
has no valid angle and ACOS returns `#NUM!`.

### Forgetting to convert the result to degrees

<ExcelCode>{`ACOS(0.5) → 1.0472 (radians, not the 60 degrees someone may expect)`}</ExcelCode>

ACOS's result is always in radians. Wrap it in `DEGREES()`, or
multiply by `180/PI()`, to get a degree value.
