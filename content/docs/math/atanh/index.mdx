Return the **inverse hyperbolic tangent** — given a hyperbolic
tangent value, find the number that produced it. The input must be
strictly between `-1` and `1` (hyperbolic tangent never reaches
those edges), and unlike [ATAN](/docs/math/atan), the *result* is
unbounded rather than capped.

## Return value

The number whose hyperbolic tangent is `number`. Unbounded — as
`number` approaches `1` or `-1`, the result grows without limit in
that direction.

## Description

ATANH inverts [TANH](/docs/math/tanh). Because TANH is strictly
increasing and maps every real number onto the open interval between
`-1` and `1` without ever repeating a value, ATANH has no
principal-value complication: `ATANH(TANH(x))` returns exactly `x`
back, for every `x` — the same clean round trip ASINH has with SINH.

<Callout type="warn">
  **ATANH's domain is the opposite shape of ATAN's.** ATAN accepts
  any number and returns a *bounded* angle; ATANH only accepts a
  *bounded* input (strictly between -1 and 1) and can return an
  unbounded result. Passing exactly `1` or `-1` — TANH's own
  unreachable limits — raises `#NUM!`, since no finite `x` produces
  exactly those values.
</Callout>

## Common errors

### #NUM! — an argument of exactly -1 or 1

<ExcelCode>{`ATANH(1) → #NUM! (hyperbolic tangent only approaches, never reaches, 1)`}</ExcelCode>

TANH never actually produces `1` or `-1` for any finite input — it
only approaches them — so ATANH has no finite answer for either edge
value and returns `#NUM!`.

### #NUM! — an argument outside -1 to 1

<ExcelCode>{`ATANH(1.5) → #NUM! (outside the valid -1 to 1 range entirely)`}</ExcelCode>

Hyperbolic tangent never exceeds `-1` to `1`, so any `number` outside
that range has no valid input to invert.
