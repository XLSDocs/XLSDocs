Add up numbers — literal values, cell references, ranges, or any mix
of the three. The most basic Math function, and the building block
behind SUMIF/SUMIFS for conditional totals.

## Return value

The total of every numeric value across all arguments. Text and
blank cells within a range are ignored, not treated as zero or an
error.

## Description

SUM accepts any mix of literal numbers, single cell references, and
full ranges in one call — `=SUM(A1, B2:B10, 100)` is valid. It's the
foundation every conditional/aggregate Math function builds on:
SUMIF and SUMIFS are SUM with a condition attached.

<Callout type="warn">
  A cell that *looks* numeric but is actually stored as text (common
  after importing data from another system) is silently excluded from
  SUM's total — no error, just a total that's lower than expected.
  Use `VALUE()` or a paste-special multiply-by-1 trick to convert
  text-formatted numbers back to real numbers.
</Callout>

## Common errors

### #VALUE! — a referenced cell contains an error

<ExcelCode>{`SUM(A1:A10) → #VALUE! (if any cell in A1:A10 is itself an error)`}</ExcelCode>

Unlike text (which SUM quietly skips), an error value inside the
range propagates — track down and fix the source error first.

### Silently low total — text-formatted numbers

<ExcelCode>{`SUM(A1:A10) → skips any cell where the number is stored as text`}</ExcelCode>

Not an error, just a total that's missing some values. Numbers
imported from CSV/other systems are a common source of this.

### SUM includes hidden/filtered rows — unlike SUBTOTAL

<ExcelCode>{`SUM(A1:A100) → totals every row, even ones hidden by a filter`}</ExcelCode>

If the goal is "total only the currently visible rows," use
`SUBTOTAL(109, A1:A100)` instead — plain SUM always includes hidden
and filtered-out rows.
