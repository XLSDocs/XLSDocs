Return the **cotangent** of an angle — the reciprocal of
[TAN](/docs/math/tan), equal to `1/TAN(number)` or, equivalently,
`COS(number)/SIN(number)`. Like every Excel trig function, the angle
must be in **radians**.

## Return value

The cotangent of `number` — equal to `1/TAN(number)`. Unbounded, like
TAN itself, but flipped: COT grows large where TAN is near zero, and
approaches zero where TAN grows large.

## Description

COT is one of the three "reciprocal" trig functions (alongside
[SEC](/docs/math/sec) and [CSC](/docs/math/csc)), each defined as 1
divided by one of the three core trig functions. COT specifically
inverts TAN: `COT(x) = 1/TAN(x) = COS(x)/SIN(x)`. Like TAN, it
expects `number` in radians — convert a degree value with
[RADIANS](/docs/math/radians) first.

<Callout type="warn">
  **COT(0) is undefined and raises #DIV/0!**, the mirror image of
  TAN's own undefined point at 90°. Since `COT(x) = COS(x)/SIN(x)`,
  and `SIN(0)` is `0`, the division has no answer.
</Callout>

also `1`.

## Common errors

### #DIV/0! — an argument of exactly 0

<ExcelCode>{`COT(0) → #DIV/0! (cotangent is undefined at 0, the mirror of TAN's undefined point at 90°)`}</ExcelCode>

Any `number` whose sine is exactly zero (`0`, `π`, `2π`, and so on)
has no defined cotangent.

### #NUM! — an argument too large

<ExcelCode>{`COT(200000000) → #NUM! (exceeds the 2^27 absolute-value limit)`}</ExcelCode>

`number` must have an absolute value below `2^27` (about 134
million) — an unusually specific limit that's easy to hit by
accident with a formula that generates very large radian values.
