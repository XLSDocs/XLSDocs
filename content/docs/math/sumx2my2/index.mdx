For each pair of corresponding values in `array_x` and `array_y`,
compute `x² - y²`, then add all those differences together — the
"X-squared Minus Y-squared" sum.

## Return value

The sum, across every corresponding pair of values, of each pair's
`x² - y²`. For `array_x = {2,3}` and `array_y = {4,1}`, the result
is `-4` (`(2²-4²) + (3²-1²)` = `-12 + 8`).

## Description

SUMX2MY2 is one of four related functions (alongside SUMSQ,
SUMX2PY2, and SUMXMY2) built for sum-of-squares calculations across
two paired arrays. Each one combines squaring and differencing in a
slightly different order, and the names spell out exactly which: X2
(x squared), M (minus), Y2 (y squared) — square each value first,
then subtract, then sum.

<ExcelCode>{`=SUMX2MY2({2,3}, {4,1}) → -4`}</ExcelCode>

<Callout type="warn">
  **Don't confuse SUMX2MY2 with SUMXMY2.** SUMX2MY2 squares each
  value *before* subtracting (`x² - y²`); SUMXMY2 subtracts first,
  then squares the difference (`(x-y)²`). They produce different
  results for the same inputs.
</Callout>

## Related functions

- [SUMX2PY2](/docs/math/sumx2py2) — adds the squares instead of
  subtracting them.
- [SUMXMY2](/docs/math/sumxmy2) — subtracts first, then squares the
  difference, rather than squaring each value first.
- [SUMSQ](/docs/math/sumsq) — sums the squares of a single list,
  rather than comparing two paired arrays.
