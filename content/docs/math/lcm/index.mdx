Find the least common multiple — the smallest whole number that every
given number divides into evenly. `LCM(4, 6)` is `12`, the smallest
number both 4 and 6 divide into with no remainder.

## Return value

The smallest whole number that every argument divides into evenly,
with no remainder.

## Description

LCM shows up most often when things need to line up on a shared
cycle — two events repeating every 4 days and every 6 days both land
on the same day again every `LCM(4, 6) = 12` days — or when combining
fractions with different denominators into a common one.

<Callout type="warn">
  Adding another number to the list can only grow the LCM, never
  shrink it — each additional value adds one more number the result
  needs to divide into. `LCM(4, 6)` is `12`, but `LCM(4, 6, 9)` grows
  to `36`, since `12` alone isn't divisible by `9`.
</Callout>

`8` shares enough factors with `4` and `6` to keep the result smaller
(`24`), while `5` — sharing no factors with either — forces the LCM
all the way up to `60`.

## Common errors

### #NUM! — a negative number

<ExcelCode>{`LCM(4, -6) → #NUM!`}</ExcelCode>

LCM only accepts non-negative whole numbers — a negative argument
isn't valid.

### Expecting the result to shrink with more numbers

<ExcelCode>{`LCM(4, 6, 9) → 36, larger than LCM(4, 6) alone`}</ExcelCode>

Each additional number can only add another divisibility requirement,
so the LCM of a longer list is never smaller than the LCM of any
subset of it.
