Round a number to a given number of decimal places — or to the
nearest ten, hundred, or thousand using a negative digit count.
Standard "round half away from zero" rounding, not banker's
rounding.

## Return value

`number` rounded to `num_digits` digits, using standard "round half
away from zero" rules — `0.5` always rounds up in magnitude, never
down to the nearest even number.

## Description

ROUND is the general-purpose rounding function — `num_digits`
controls both direction and place. `ROUND(3.14159, 2)` gives
`3.14`; `ROUND(1250, -2)` rounds to the nearest hundred, giving
`1300`. Unlike ROUNDUP/ROUNDDOWN, which always round in one fixed
direction, ROUND rounds toward whichever value is actually closer.

<Callout type="info">
  A negative `num_digits` rounds to the left of the decimal point —
  `-1` rounds to the nearest ten, `-2` to the nearest hundred, and so
  on. This is the same digit-count convention TEXT and other
  Excel formatting functions use.
</Callout>

## Common errors

### Result looks wrong — display formatting vs actual rounding

<ExcelCode>{`ROUND(3.14159, 2) → 3.14 (a real, stored value — not just a display format)`}</ExcelCode>

Unlike changing a cell's number format (which only changes how a
value *displays*), ROUND changes the actual stored value — useful
when later formulas need the rounded figure specifically, not just
its appearance.

### Expecting banker's rounding

<ExcelCode>{`ROUND(2.5, 0) → 3 (not 2, unlike some statistical rounding conventions)`}</ExcelCode>

Excel's ROUND always rounds `.5` away from zero, regardless of
whether the result ends up even or odd — there's no built-in
banker's-rounding option.
