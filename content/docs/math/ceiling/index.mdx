Round a number up to the nearest multiple of a given value — not
just a decimal place, but a genuine "round up to the next 5, next
0.25, or next 100" step size. The function behind pricing to the
nearest nickel, or scheduling to the nearest quarter-hour.

## Return value

`number` rounded up to the nearest multiple of `significance`.
`CEILING(22, 5)` returns `25`; `CEILING(0.12, 0.25)` returns `0.25`.

## Description

Unlike ROUNDUP, which rounds to a number of *digits*, CEILING rounds
to a multiple of any arbitrary value — the nearest nickel (`0.05`),
the nearest quarter-hour on a timesheet (`1/96` of a day, or more
simply `"0:15"`), or the nearest full case of 24 units. This makes
it the right tool whenever the rounding step isn't a clean power of
ten.

<Callout type="warn">
  `number` and `significance` must have the **same sign** —
  `CEILING(-22, 5)` (a negative number with a positive significance)
  returns `#NUM!`. For negative numbers, `significance` needs to be
  negative too: `CEILING(-22, -5)`.
</Callout>

## Common errors

### #NUM! — mismatched signs

<ExcelCode>{`CEILING(-22, 5) → #NUM!`}</ExcelCode>

`number` is negative but `significance` is positive — they need to
match in sign:

<ExcelCode>{`CEILING(-22, -5) → -20`}</ExcelCode>

### #DIV/0! — significance is zero

<ExcelCode>{`CEILING(22, 0) → #DIV/0!`}</ExcelCode>

`significance` can't be zero — there's no multiple of zero to round
to.
