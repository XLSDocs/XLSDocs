Find the largest numeric value among a set of numbers, cells, or
ranges. For the 2nd, 3rd, or nth largest instead of the single
biggest, use LARGE.

## Return value

The largest numeric value across all arguments. Text and blank cells
within a range are ignored. If nothing numeric is found, MAX returns
`0`, not an error.

## Description

MAX scans every argument (literal numbers, cell references, ranges,
or a mix) and returns the single largest value found, ignoring
non-numeric cells along the way — the same scanning behavior as
SUM/AVERAGE/COUNT, just returning the maximum instead of a total,
mean, or count.

<Callout type="info">
  MAX quietly returns `0` (not an error) if every argument is
  non-numeric — worth double-checking the range actually contains
  numbers if `0` shows up unexpectedly.
</Callout>

## Common errors

### #VALUE! — a referenced cell contains an error

<ExcelCode>{`MAX(A1:A10) → #VALUE! (if any cell in A1:A10 is itself an error)`}</ExcelCode>

An error value inside the range propagates, unlike text (which MAX
quietly skips).

### Unexpectedly returns 0

<ExcelCode>{`MAX(A1:A10) → 0 (if every cell is text or blank)`}</ExcelCode>

Not an error — MAX found nothing numeric to compare, so it falls back
to `0`. Check the range actually has numeric values.

### Wanting the 2nd or 3rd largest, not the biggest

<ExcelCode>{`MAX(A1:A10) → always the single largest value, never 2nd or 3rd`}</ExcelCode>

Use LARGE for that instead: `LARGE(A1:A10, 2)` returns the
second-largest value.
