For each pair of corresponding values in `array_x` and `array_y`,
subtract first, then square the difference, then add all the
results together — the "X Minus Y, squared" sum.

## Return value

The sum, across every corresponding pair of values, of each pair's
`(x - y)²`. For `array_x = {2,3}` and `array_y = {4,1}`, the result
is `8` (`(2-4)² + (3-1)²` = `4 + 4`).

## Description

SUMXMY2 subtracts each pair of values first, then squares the
difference, then sums every squared difference across the whole
array — exactly the calculation behind a sum-of-squared-errors or
sum-of-squared-residuals, which shows up throughout regression and
variance-style statistics.

<ExcelCode>{`=SUMXMY2({2,3}, {4,1}) → 8`}</ExcelCode>

<Callout type="warn">
  **Don't confuse SUMXMY2 with SUMX2MY2.** SUMXMY2 subtracts first,
  then squares the difference (`(x-y)²`); SUMX2MY2 squares each
  value first, then subtracts (`x²-y²`). They're easy to mix up by
  name, and they return different results.
</Callout>

## Related functions

- [SUMX2MY2](/docs/math/sumx2my2) — squares each value before
  subtracting, rather than subtracting first.
- [SUMX2PY2](/docs/math/sumx2py2) — adds the squares of each pair,
  rather than squaring their difference.
- [SUMSQ](/docs/math/sumsq) — sums the squares of a single list,
  rather than comparing two paired arrays.
