Return the mathematical constant π (pi), accurate to 15 digits — the
ratio of a circle's circumference to its diameter, with no arguments
needed.

## Syntax

<ExcelCode>{`=PI()`}</ExcelCode>

## Parameters

PI takes no arguments — the parentheses are still required, but
always empty.

## Return value

`3.14159265358979`, accurate to 15 significant digits — Excel's
floating-point precision limit.

## Description

PI exists so a formula involving circles, angles, or trigonometry
never needs to hardcode a truncated approximation like `3.14` or
`3.14159` — using `PI()` keeps the full available precision, and
makes the formula's intent obvious to anyone reading it later.

<Callout type="idea">
  Unlike `RAND` or `NOW`, `PI()` is **not volatile** — its result
  never changes, so it doesn't force a recalculation cost the way
  genuinely volatile functions do. There's no downside to using it
  freely throughout a workbook instead of typing the digits by hand.
</Callout>

<ExcelCode>{`=PI() * radius^2 → the area of a circle`}</ExcelCode>

<ExcelCode>{`=2 * PI() * radius → the circumference of a circle`}</ExcelCode>

<ExcelCode>{`=PI() / 180 → the conversion factor from degrees to radians (or use RADIANS() directly)`}</ExcelCode>

## Common errors

### Using a hardcoded approximation instead

<ExcelCode>{`=3.14 * radius^2 → less precise than =PI() * radius^2`}</ExcelCode>

A hand-typed `3.14` or `3.14159` is less accurate than `PI()`'s full
15 digits, and compounds error in a formula chain that uses it
repeatedly. There's no accuracy or performance reason to avoid
`PI()` in favor of typing digits manually.

### Forgetting the parentheses

<ExcelCode>{`=PI → #NAME? (the empty parentheses are required)`}</ExcelCode>

Even with no arguments, the parentheses must still be included:
`PI()`, not `PI`.
