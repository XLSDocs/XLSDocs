Convert `number` into text representing it in `radix` — any base
from 2 (binary) to 36 — with an optional `min_length` to pad the
result with leading zeros.

## Return value

`number` converted to base `radix`, returned as text. `BASE(7, 2)`
returns `"111"`; `BASE(100, 16)` returns `"64"`.

## Description

BASE converts an ordinary decimal number into its representation in
any other base, as text — binary (base 2), hexadecimal (base 16),
or any base up to 36, which uses the letters A-Z for digit values 10
through 35. It's the general-purpose counterpart to DECIMAL, which
converts the other direction.

<ExcelCode>{`=BASE(100, 16) → "64" (100 in hexadecimal)`}</ExcelCode>

<Callout type="idea">
  **`min_length` pads with leading zeros, without truncating.**
  `BASE(15, 2, 10)` returns `"0000001111"` — the binary value for 15
  is only 4 digits long, so it's padded out to the requested 10.
  Passing a `min_length` shorter than the natural result has no
  effect; it never cuts digits off.
</Callout>

## Common errors

### #NUM! — an out-of-range argument

<ExcelCode>{`BASE(100, 1) → #NUM!`}</ExcelCode>
<ExcelCode>{`BASE(100, 37) → #NUM!`}</ExcelCode>

`radix` must be between 2 and 36; `number` and `min_length` have
their own valid ranges too, and any argument outside its range
returns `#NUM!`.

### #VALUE! — a non-numeric number

<ExcelCode>{`BASE("abc", 2) → #VALUE!`}</ExcelCode>

`number` must be a number, a cell containing one, or a formula that
returns one.
