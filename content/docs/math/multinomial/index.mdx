Return the multinomial coefficient of a set of numbers — the
factorial of their sum, divided by the product of each number's own
factorial. A generalization of COMBIN to more than two groups.

## Return value

The factorial of the sum of all the numbers, divided by the product
of each individual number's factorial. `MULTINOMIAL(2, 3, 4)`
returns `1260`.

## Description

MULTINOMIAL generalizes COMBIN beyond a simple yes/no split: where
COMBIN counts the ways to choose a subset from a group, MULTINOMIAL
counts the ways to arrange a total when it's divided into several
distinct groups of specified sizes — like the number of distinct
ways to arrange the letters in a word with repeated letters, or to
split a team into differently-sized roles.

<ExcelCode>{`=MULTINOMIAL(2, 3, 4) → 1260 (9! / (2!×3!×4!))`}</ExcelCode>

<Callout type="info">
  **MULTINOMIAL with exactly two arguments is the same as COMBIN.**
  `MULTINOMIAL(a, b)` and `COMBIN(a+b, a)` compute the same result —
  MULTINOMIAL is COMBIN's generalization to more than two groups.
</Callout>

## Common errors

### #NUM! — a negative argument

<ExcelCode>{`MULTINOMIAL(2, -1, 4) → #NUM!`}</ExcelCode>

Every argument must be `0` or greater.

### #VALUE! — a non-numeric argument

<ExcelCode>{`MULTINOMIAL(2, "abc", 4) → #VALUE!`}</ExcelCode>

Every argument must be a number, a cell containing one, or a
formula that returns one.
