Find the smallest numeric value among a set of numbers, cells, or
ranges. For the 2nd, 3rd, or nth smallest instead of the single
lowest, use SMALL.

## Return value

The smallest numeric value across all arguments. Text and blank cells
within a range are ignored. If nothing numeric is found, MIN returns
`0`, not an error.

## Description

MIN scans every argument (literal numbers, cell references, ranges,
or a mix) and returns the single smallest value found, ignoring
non-numeric cells along the way — the mirror image of MAX.

<Callout type="info">
  MIN quietly returns `0` (not an error) if every argument is
  non-numeric — worth double-checking the range actually contains
  numbers if `0` shows up unexpectedly, especially since `0` could
  also be a genuine smallest value in the data.
</Callout>

## Common errors

### #VALUE! — a referenced cell contains an error

<ExcelCode>{`MIN(A1:A10) → #VALUE! (if any cell in A1:A10 is itself an error)`}</ExcelCode>

An error value inside the range propagates, unlike text (which MIN
quietly skips).

### Ambiguous 0 — genuine value or no numeric data?

<ExcelCode>{`MIN(A1:A10) → 0 (either a genuine zero, or nothing numeric at all)`}</ExcelCode>

Unlike MAX (where a `0` result is usually a clear signal something's
wrong), MIN returning `0` can mean either "the smallest real value is
genuinely 0" or "there's no numeric data at all" — check the range
directly if this ambiguity matters.

### Wanting the 2nd or 3rd smallest, not the lowest

<ExcelCode>{`MIN(A1:A10) → always the single smallest value, never 2nd or 3rd`}</ExcelCode>

Use SMALL for that instead: `SMALL(A1:A10, 2)` returns the
second-smallest value.
