Round a number up to the nearest odd integer — always moving away
from zero, never toward it. `ODD(4)` gives `5`; `ODD(-4)` gives
`-5`, not `-3`.

## Return value

`number` rounded up to the nearest odd integer, always moving away
from zero. Returns `number` unchanged if it's already an odd
integer.

## Description

ODD is [EVEN](/docs/math/even)'s mirror — same "away from zero"
rounding direction, just landing on an odd integer instead of an
even one. `ODD(4)` becomes `5`, and `ODD(-4)` becomes `-5` — moving
further from zero in both cases, not toward positive infinity.

<Callout type="info">
  Like EVEN, "away from zero" and "toward positive infinity" only
  look identical for positive numbers. `ODD(-4)` moves away from
  zero to `-5`, not toward positive infinity to `-3`.
</Callout>

## Common errors

### Expecting ODD to round negative numbers toward zero

<ExcelCode>{`ODD(-4) → -5 (not -3 — ODD moves away from zero, not toward positive infinity)`}</ExcelCode>

Same direction convention as EVEN — ODD always moves further from
zero for both positive and negative inputs.

### Assuming ODD always changes the value

<ExcelCode>{`ODD(5) → 5 (unchanged — 5 is already odd)`}</ExcelCode>

Not an error — an input that's already an odd integer passes through
exactly as given, with no rounding applied.
