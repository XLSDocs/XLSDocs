Return the logarithm of `number` to the `base` you give it — the
general-purpose logarithm function, defaulting to base 10 when no
base is supplied.

## Return value

The logarithm of `number` to `base` — the exponent that `base` would
need to be raised to, to produce `number`.

## Description

LOG is the general-purpose version of the fixed-base logarithm
functions: supply any `base` you need, or omit it entirely for a
base-10 logarithm. `LOG(8, 2)` returns `3`, since 2 raised to the
power of 3 equals 8.

<ExcelCode>{`=LOG(8, 2) → 3 (2 to the power of 3 is 8)`}</ExcelCode>

<Callout type="info">
  **Omitting `base` defaults to 10** — `LOG(100)` and `LOG(100, 10)`
  return the exact same result as `LOG10(100)`. Use LOG when the base
  varies or needs to be a formula argument; use LOG10 when it's
  always base 10 and the dedicated function reads more clearly.
</Callout>

## Common errors

### #NUM! — a non-positive number or base

<ExcelCode>{`LOG(-8, 2) → #NUM!`}</ExcelCode>
<ExcelCode>{`LOG(8, 0) → #NUM!`}</ExcelCode>

Both `number` and `base` must be positive real numbers.

### #VALUE! — a non-numeric argument

<ExcelCode>{`LOG("abc", 2) → #VALUE!`}</ExcelCode>

Both arguments must be numbers, cells containing numbers, or formulas
that return numbers.
