Find the greatest common divisor — the largest whole number that
divides every given number evenly, with no remainder. `GCD(12, 18)`
is `6`, since 6 is the largest number that divides both exactly.

## Return value

The largest whole number that divides every argument evenly, with no
remainder left over.

## Description

GCD shows up most often when simplifying a ratio to its smallest
whole-number form (a 12:18 ratio simplifies to 2:3, since both divide
evenly by their GCD of 6), or figuring out the largest "batch size"
that divides several different quantities evenly.

<Callout type="warn">
  Adding another number to the list can only shrink the GCD, never
  grow it — each additional value adds another constraint the result
  has to satisfy. `GCD(12, 18)` is `6`, but `GCD(12, 18, 8)` drops to
  `2`, since `8` doesn't share the larger common factors `12` and `18`
  have with each other.
</Callout>

<TryIt

`24` shares every factor `12` and `18` already have in common, so the
GCD stays at `6`. `9` and `8` each break one of those shared factors,
shrinking the result.

## Common errors

### #NUM! — a negative number

<ExcelCode>{`GCD(12, -18) → #NUM!`}</ExcelCode>

GCD only accepts non-negative whole numbers — a negative argument
isn't valid.

### Expecting the result to grow with more numbers

<ExcelCode>{`GCD(12, 18, 8) → 2, smaller than GCD(12, 18) alone`}</ExcelCode>

Each additional number can only narrow down the shared factors, so
the GCD of a longer list is never larger than the GCD of any subset
of it.
