Return the **hyperbolic cosecant** of a number — the reciprocal of
[SINH](/docs/math/sinh), equal to `1/SINH(number)`. Like every
hyperbolic function, `number` is a plain real value, not an angle.

## Return value

The hyperbolic cosecant of `number` — equal to `1/SINH(number)`.
Unbounded near `0` (where SINH itself approaches `0`), and shrinking
toward `0` as `number` grows large in either direction.

## Description

CSCH is one of the three "reciprocal" hyperbolic functions (alongside
[SECH](/docs/math/sech) and [COTH](/docs/math/coth)), each defined
as 1 divided by one of the three core hyperbolic functions. CSCH
specifically inverts SINH: `CSCH(x) = 1/SINH(x)`.

<Callout type="idea">
  **CSCH has nothing to do with angles.** Unlike CSC, there's no
  radians-vs-degrees conversion to worry about — `number` is just an
  ordinary real value.
</Callout>

## Common errors

### #DIV/0! — an argument of exactly 0

<ExcelCode>{`CSCH(0) → #DIV/0! (hyperbolic cosecant is undefined at 0, since SINH(0) is 0)`}</ExcelCode>

Since `CSCH(x) = 1/SINH(x)`, and `SINH(0)` is exactly `0`, the
division has no answer.

### Assuming CSCH needs an angle in radians

<ExcelCode>{`CSCH(RADIANS(30)) → not what you want — CSCH takes a plain number, not an angle`}</ExcelCode>

CSCH's argument is an ordinary number, not an angle — converting it
with RADIANS first (a habit carried over from CSC) changes the input
to something unrelated to what was intended.
