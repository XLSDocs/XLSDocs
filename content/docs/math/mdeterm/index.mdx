Return the determinant of `array` — a single number computed from a
square matrix, used throughout linear algebra to test whether a
matrix can be inverted and to solve systems of equations.

## Return value

The matrix determinant of `array`, a single number.
`MDETERM({3,6;1,1})` returns `-3`.

## Description

The determinant is a single value that summarizes certain
properties of a square matrix — most importantly, whether it has an
inverse at all. A determinant of `0` means the matrix is "singular"
and MINVERSE will fail on it with `#NUM!`; any non-zero determinant
means an inverse exists. For a 2×2 range, the formula is simple
(`A1*B2 - B1*A2`); MDETERM computes the equivalent, much more
complex expansion for any square size automatically.

<ExcelCode>{`=MDETERM({3,6;1,1}) → -3`}</ExcelCode>

<Callout type="warn">
  **A "zero" determinant may show as a tiny non-zero number**, like
  `1E-16`, due to floating-point precision limits — MDETERM is
  accurate to about 16 digits. When testing whether a matrix is
  singular, compare against a small tolerance rather than exactly
  `0`.
</Callout>

## Common errors

### #VALUE! — array isn't square

<ExcelCode>{`MDETERM(A1:C2) → #VALUE! (2 rows, 3 columns)`}</ExcelCode>

`array` must have exactly the same number of rows as columns.

### #VALUE! — empty or text cells

<ExcelCode>{`MDETERM(A1:C3) → #VALUE! (if any cell is empty or contains text)`}</ExcelCode>

Every cell in `array` must contain a number.

## Related functions

- [MINVERSE](/docs/math/minverse) — computes a matrix's inverse,
  which only exists when MDETERM is non-zero.
- [MMULT](/docs/math/mmult) — multiplies two matrices together,
  often used alongside MINVERSE to solve equation systems.
- [MUNIT](/docs/math/munit) — generates an identity matrix, which
  always has a determinant of exactly 1.
