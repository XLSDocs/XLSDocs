Calculate what share a subset of data represents of a larger total,
in one argument-light call. PERCENTOF is logically equivalent to
`SUM(data_subset)/SUM(data_all)`, but reads more clearly and was
built specifically to drop into [GROUPBY](/docs/lookup/groupby) and
[PIVOTBY](/docs/lookup/pivotby)'s `function` argument.

## Return value

A decimal number — `0.25` for 25%, not the literal number `25`. The
cell needs percentage number formatting applied for it to display
with a `%` sign.

## Description

PERCENTOF sums both arguments and divides: `SUM(data_subset) /
SUM(data_all)`. `data_subset` doesn't need to be a literal part of
`data_all` — it's just two sums divided — but the function reads most
naturally when it is, which is also its most common use.

<ExcelCode>{`=PERCENTOF(C5, $C$5:$C$12) → what share C5 is of the whole C5:C12 total`}</ExcelCode>

Copied down a column, the same formula with an absolute reference on
`data_all` turns every row into "this row's share of the total" —
one formula away from a 100%-stacked summary without a PivotTable.

<Callout type="info">
  PERCENTOF was introduced alongside [GROUPBY](/docs/lookup/groupby)
  and [PIVOTBY](/docs/lookup/pivotby) specifically so their
  `function` argument could produce "% of total" columns directly,
  but it works standalone in any formula just as well.
</Callout>

## Common errors

### #DIV/0! — data_all sums to zero

<ExcelCode>{`PERCENTOF(A1:A5, B1:B10) → #DIV/0! if SUM(B1:B10) is 0`}</ExcelCode>

Same as any division — if the total sums to zero (every value is
zero, blank, or the range is empty of numbers), there's nothing to
divide by. Wrap it in `IFERROR` for a fallback:

<ExcelCode>{`IFERROR(PERCENTOF(A1:A5, B1:B10), 0)`}</ExcelCode>

### Result looks like a whole number instead of a percentage

<ExcelCode>{`PERCENTOF(250, 1000) → 0.25, displayed as "0.25" if the cell isn't formatted as a percentage`}</ExcelCode>

PERCENTOF always returns a decimal, never a pre-multiplied value
like `25`. Apply percentage number formatting to the cell to see
`25%` instead of `0.25`.

## Related functions

- [GROUPBY](/docs/lookup/groupby) — commonly uses PERCENTOF as its
  `function` argument to produce a "% of total" column per group.
- [PIVOTBY](/docs/lookup/pivotby) — the two-dimensional equivalent,
  same PERCENTOF use case.
- [SUM](/docs/math/sum) — PERCENTOF is literally two SUM calls
  divided; use SUM directly for anything that isn't a percentage.
- [SUMIF](/docs/math/sumif) and [SUMIFS](/docs/math/sumifs) — sum a
  conditional subset before dividing, for a "% of total" that only
  counts matching rows.

## Examples

<ExampleCard number="01" label="Basic — one value's share of a total" formula={`=PERCENTOF(250, 1000)`}>
  Returns `0.25` — format the cell as a percentage to see `25%`.
</ExampleCard>

<ExampleCard number="02" label="Each row's share of a fixed total" formula={`=PERCENTOF(C5, $C$5:$C$12)`}>
  Absolute references on `data_all` keep the denominator fixed when
  this formula is copied down the column — each row becomes "this
  row's share of C5:C12."
</ExampleCard>

<ExampleCard number="03" label="Inside GROUPBY for a % of total column" formula={`=GROUPBY(A2:A76, D2:D76, PERCENTOF)`}>
  Passing PERCENTOF as GROUPBY's aggregation function returns each
  group's share of the overall total, instead of a plain sum.
</ExampleCard>

<ExampleCard number="04" label="Conditional share with SUMIFS" formula={`=SUMIFS(D:D, A:A, "East") / SUM(D:D)`}>
  The manual equivalent for a conditional subset — PERCENTOF itself
  only accepts two ranges, so a filtered share needs SUMIFS (or
  SUMIF) in place of the `data_subset` argument.
</ExampleCard>

<ExampleCard number="05" label="#DIV/0! from an empty total" formula={`=PERCENTOF(A1:A5, B1:B10)`}>
  Returns `#DIV/0!` if `SUM(B1:B10)` is zero — wrap in `IFERROR` to
  return a fallback like `0` instead.
</ExampleCard>
