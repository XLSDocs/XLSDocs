## Return value

The count of cells in `range` that are empty — including cells that
contain a formula whose result is an empty string (`""`).

## Description

COUNTBLANK answers the opposite question from COUNTA: instead of
"how many cells have anything in them," it's "how many don't." It's
commonly used to spot incomplete data — how many rows in a form are
still missing an email address, how many order rows have no ship
date yet. Unlike COUNT, COUNTA, SUM, and most other aggregate
functions, COUNTBLANK only accepts a single `range` argument, not a
variable list of values.

<Callout type="warn">
  COUNTBLANK counts a cell as blank even if it holds a formula that
  **returns** an empty string (`=""`) — visually the cell looks
  empty, and COUNTBLANK agrees, but COUNTA would still count it as
  non-blank since it technically contains a formula. This is the
  opposite gotcha from ISBLANK, which treats `=""` cells as
  non-blank.
</Callout>

## Common errors

### Not matching COUNTA's complement

<ExcelCode>{`COUNT(A1:A10) + COUNTA(A1:A10) + COUNTBLANK(A1:A10) → doesn't always add up to 10`}</ExcelCode>

COUNT only counts numeric cells, so `COUNT + COUNTBLANK` misses any
text cells and undercounts the range's total size. The reliable
identity is `COUNTA(range) + COUNTBLANK(range) = total cells in
range` — use `COUNTA`, not `COUNT`, alongside COUNTBLANK to account
for every cell.

### Passing multiple ranges

<ExcelCode>{`COUNTBLANK(A1:A10, B1:B10) → #VALUE! (only one range is allowed)`}</ExcelCode>

Unlike COUNT or COUNTA, COUNTBLANK doesn't accept a list of ranges —
combine them with addition instead:

<ExcelCode>{`COUNTBLANK(A1:A10) + COUNTBLANK(B1:B10)`}</ExcelCode>

## Related functions

- [COUNTA](/docs/math/counta) — counts non-blank cells, the mirror
  image of COUNTBLANK.
- [COUNT](/docs/math/count) — counts numeric cells only, a narrower
  question than either COUNTA or COUNTBLANK.
- [ISBLANK](/docs/info/isblank) — tests a single cell for blankness,
  with the opposite `=""` behavior from COUNTBLANK.
- [COUNTIF](/docs/math/countif) — `COUNTIF(range, "")` reproduces
  COUNTBLANK's result with more flexibility.
