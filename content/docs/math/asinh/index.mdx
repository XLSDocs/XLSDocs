Return the **inverse hyperbolic sine** — given a hyperbolic sine
value, find the number that produced it. Unlike
[ASIN](/docs/math/asin), there's no restricted input range: `number`
can be anything, and the round trip with
[SINH](/docs/math/sinh) always works perfectly in both directions.

## Return value

The number whose hyperbolic sine is `number`. Same sign as `number`,
unbounded, with no restriction on the input at all.

## Description

ASINH inverts [SINH](/docs/math/sinh). Because SINH is a strictly
increasing function across every real number — it never repeats a
value the way ordinary sine does — ASINH has no "principal value"
complication to worry about: `ASINH(SINH(x))` returns exactly `x`
back, for every `x`, with none of the range restriction ASIN needs
to deal with.

<Callout type="idea">
  **ASINH round-trips perfectly with SINH — always.** This is the
  one place a hyperbolic inverse function is actually *simpler* than
  its ordinary-trig counterpart: ASIN can only recover angles in a
  narrow `-90°` to `90°` window, but ASINH recovers every possible
  input, no exceptions.
</Callout>

## Common errors

### #VALUE! — a non-numeric argument

<ExcelCode>{`ASINH("ten") → #VALUE!`}</ExcelCode>

`number` must be a value Excel can read as numeric — otherwise this
is the rare trig-family function with no domain restriction to worry
about at all.
