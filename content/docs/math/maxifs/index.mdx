Find the largest value in a range, but only among rows that match
**all** of one or more conditions — the highest sale in the West
region, the latest deadline for open projects, and so on.

## Return value

The largest value in `max_range` among rows where every criteria
pair matches. Returns `0` if no rows match — not an error.

## Description

MAXIFS extends MAX the same way SUMIFS extends SUM — every condition
must be true for a row to be considered (AND logic), and each
`criteria_range` must be the same size and shape as `max_range`.

<Callout type="warn">
  MAXIFS puts `max_range` **first**, matching SUMIFS/COUNTIFS/
  AVERAGEIFS — unlike plain MAX, which takes no range/condition pairs
  at all. Don't confuse this with `LARGE`, which finds the *k*th
  largest value with no conditional filtering.
</Callout>

## Common errors

### #VALUE! — mismatched range sizes

<ExcelCode>{`MAXIFS(A2:A10, B2:B9, "West") → #VALUE!`}</ExcelCode>

`criteria_range` must be the same size as `max_range` — here one is
9 rows and the other is 10.

### Returns 0 — no error, but easy to miss

<ExcelCode>{`MAXIFS(A2:A10, B2:B10, "Zzz") → 0`}</ExcelCode>

Not an error — no rows matched "Zzz". Double-check the criteria
value is actually present in `criteria_range`.
