Return the factorial of a number — the product of every whole number
from `1` up to it. `FACT(5)` is `5 × 4 × 3 × 2 × 1`, or `120`.

## Return value

The factorial of `number` (truncated to a whole number first): `1 ×
2 × 3 × ... × number`. Returns `1` for `0`.

## Description

Factorials show up anywhere counting arrangements matters — they're
the building block behind `COMBIN` and `PERMUT`'s formulas, and grow
so quickly that even modest inputs produce enormous results:
`FACT(10)` is already over three million.

<Callout type="warn">
  FACT grows explosively — `FACT(20)` is already over 2.4 quintillion,
  and `FACT(171)` overflows Excel's numeric range entirely, returning
  `#NUM!`. There's rarely a practical reason to compute the factorial
  of a number much larger than 20 or so directly.
</Callout>

`FACT(0)` returns `1`, not `0` — by mathematical convention, the
factorial of zero is defined as the "empty product," the same reason
an empty PRODUCT() also returns 1.

## Common errors

### #NUM! — a negative number

<ExcelCode>{`FACT(-3) → #NUM!`}</ExcelCode>

Factorials are only defined for zero and positive numbers — a
negative input has no valid result.

### #NUM! — the result overflows Excel's numeric range

<ExcelCode>{`FACT(171) → #NUM!`}</ExcelCode>

Factorials grow so quickly that `FACT(171)` and beyond exceed the
largest number Excel can represent (roughly 1.8 × 10³⁰⁸).

### Expecting a small result for a modest-looking input

<ExcelCode>{`FACT(15) → 1,307,674,368,000`}</ExcelCode>

Factorial growth is famously fast — even an input as small as 15
already produces a result over a trillion.
