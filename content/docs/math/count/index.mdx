Count how many cells contain a number — text, blanks, and logical
values are all ignored. For counting *anything* non-blank instead,
use [COUNTA](/docs/math/counta).

## Return value

The count of cells across all arguments that contain a number. Dates
and times count as numbers (Excel stores them as serial numbers).
Text, blank cells, and logical (`TRUE`/`FALSE`) values are excluded.

## Description

COUNT is narrowly scoped to numeric data — it's the right choice when
the question is specifically "how many numbers are here," not "how
many cells have anything in them" (that's COUNTA) or "how many cells
are empty" (that's COUNTBLANK).

<Callout type="info">
  COUNT treats dates and times as numbers, since Excel stores them
  internally as serial numbers — a range of dates will be counted
  just like a range of plain numbers.
</Callout>

## Common errors

### Undercounting — expecting text to be counted too

<ExcelCode>{`COUNT(A1:A10) → only counts numeric cells, skips text like "Pending"`}</ExcelCode>

If the range mixes numbers and text and every non-blank cell should
count, use COUNTA instead:

<ExcelCode>{`COUNTA(A1:A10)`}</ExcelCode>

### TRUE/FALSE not counted

<ExcelCode>{`COUNT(TRUE, FALSE, 1, 2) → 2 (only 1 and 2 count)`}</ExcelCode>

Logical values are excluded from COUNT even though they're
technically 1/0 under the hood — use COUNTA if they should count.

## Related functions

- [COUNTA](/docs/math/counta) — counts every non-blank cell,
  regardless of type, instead of numeric cells only.
- [COUNTIF](/docs/math/countif) — counts cells matching a specific
  condition instead of just "is this numeric."
- [COUNTIFS](/docs/math/countifs) — same idea, with multiple
  conditions combined.
- [SUM](/docs/math/sum) — totals the same numeric cells COUNT counts.
