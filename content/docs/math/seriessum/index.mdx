Evaluate a power series — a sum of terms like
`a₁x^n + a₂x^(n+m) + a₃x^(n+2m) + ...` — directly from `x`, a
starting power, a step between powers, and a list of coefficients.

## Return value

The sum of the power series: for each coefficient `aᵢ` (starting at
index 0), the term `aᵢ × x^(n + i×m)`, all added together.

## Description

SERIESSUM computes a polynomial-like expression in one call,
instead of writing out each power term and coefficient multiplication
by hand. It's most often used to approximate a mathematical function
from its known power-series (Taylor series) coefficients — Microsoft's
own documentation example approximates cosine this way, using the
coefficients `1, -1/2!, 1/4!, -1/6!` with `n=0` and `m=2` to match
cosine's even-power series.

<ExcelCode>{`=SERIESSUM(2, 1, 1, {1,1,1}) → 14 (2^1 + 2^2 + 2^3)`}</ExcelCode>

<Callout type="idea">
  **The number of terms comes entirely from `coefficients`.** Three
  coefficients means three terms, computed at powers `n`, `n+m`,
  and `n+2m` — add or remove coefficients to change how many terms
  the series includes.
</Callout>

## Common errors

### #VALUE! — a non-numeric argument

<ExcelCode>{`SERIESSUM("x", 1, 1, {1,1,1}) → #VALUE!`}</ExcelCode>

Every argument, including each coefficient, must be numeric.
