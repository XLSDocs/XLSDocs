Return the **hyperbolic cotangent** of a number — the reciprocal of
[TANH](/docs/math/tanh), equal to `1/TANH(number)`. Like every
hyperbolic function, `number` is a plain real value, not an angle.

## Return value

The hyperbolic cotangent of `number` — equal to `1/TANH(number)`.
Since TANH never reaches `-1` or `1`, COTH never falls between `-1`
and `1` — the mirror image of TANH's own bounded range.

## Description

COTH is one of the three "reciprocal" hyperbolic functions (alongside
[SECH](/docs/math/sech) and [CSCH](/docs/math/csch)), each defined
as 1 divided by one of the three core hyperbolic functions. COTH
specifically inverts TANH: `COTH(x) = 1/TANH(x)`. As `x` grows large
in either direction, TANH approaches `±1`, so COTH does too — but
near `x = 0`, where TANH itself approaches `0`, COTH grows without
bound instead.

<Callout type="idea">
  **COTH has nothing to do with angles.** Unlike COT, there's no
  radians-vs-degrees conversion to worry about — `number` is just an
  ordinary real value.
</Callout>

## Common errors

### #DIV/0! — an argument of exactly 0

<ExcelCode>{`COTH(0) → #DIV/0! (hyperbolic cotangent is undefined at 0, since TANH(0) is 0)`}</ExcelCode>

Since `COTH(x) = 1/TANH(x)`, and `TANH(0)` is exactly `0`, the
division has no answer.

### Assuming COTH needs an angle in radians

<ExcelCode>{`COTH(RADIANS(45)) → not what you want — COTH takes a plain number, not an angle`}</ExcelCode>

COTH's argument is an ordinary number, not an angle — converting it
with RADIANS first (a habit carried over from COT) changes the input
to something unrelated to what was intended.
