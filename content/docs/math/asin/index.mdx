Return the **arcsine** — the angle whose sine is the given number.
The input must be between `-1` and `1` (sine never exceeds that
range), and the result comes back in **radians**, between `-π/2`
and `π/2`.

## Return value

The angle, in radians, whose sine is `number`, always between `-π/2`
and `π/2` (-90° to 90°). Wrap the result in
[DEGREES](/docs/math/degrees) to convert it to degrees.

## Description

ASIN is the inverse of [SIN](/docs/math/sin) — given a sine ratio, it
finds the angle. Because sine repeats itself (many different angles
share the same sine value), ASIN can only ever return one answer per
input, so Excel always returns the result in the `-π/2` to `π/2`
range — the *principal* value, not necessarily the specific angle a
real-world problem has in mind.

<Callout type="warn">
  **ASIN(SIN(x)) does not always return x back.** It only round-trips
  correctly when `x` is already inside `-π/2` to `π/2`. `SIN(RADIANS(150))`
  is `0.5`, the same as `SIN(RADIANS(30))` — so `ASIN` of either one
  returns the angle for 30°, never 150°, because 30° is the principal
  value sine can't distinguish 150° from.
</Callout>

## Common errors

### #NUM! — an argument outside -1 to 1

<ExcelCode>{`ASIN(1.5) → #NUM! (no angle has a sine greater than 1)`}</ExcelCode>

Sine never exceeds `-1` to `1`, so any `number` outside that range
has no valid angle and ASIN returns `#NUM!`.

### Forgetting to convert the result to degrees

<ExcelCode>{`ASIN(0.5) → 0.5236 (radians, not the 30 degrees someone may expect)`}</ExcelCode>

ASIN's result is always in radians. Wrap it in `DEGREES()`, or
multiply by `180/PI()`, to get a degree value.
