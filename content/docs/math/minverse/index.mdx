## Return value

The inverse of `array`, spilled as a square array the same size as
the input.

## Description

MINVERSE computes a matrix's inverse — conceptually the matrix
equivalent of a reciprocal. Just as multiplying a number by its
reciprocal gives `1`, multiplying a matrix by its inverse gives the
identity matrix (MUNIT's output). The most common real use is
solving a system of linear equations: for a system written as a
matrix equation, multiplying the inverse of the coefficient matrix
by the constants (via MMULT) solves for the unknowns directly.

<Callout type="idea">
  **A common linear-equation solving pattern**:
  `=MMULT(MINVERSE(B2:C3), E2:E3)` solves a 2-variable, 2-equation
  system in one formula — MINVERSE inverts the coefficients, MMULT
  applies that inverse to the constants.
</Callout>

<Callout type="warn">
  **Not every square matrix has an inverse.** A matrix with a
  determinant of exactly `0` (check with MDETERM) is "singular," and
  MINVERSE returns `#NUM!` for it.
</Callout>

## Common errors

### #NUM! — a singular matrix

<ExcelCode>{`MINVERSE({1,2;2,4}) → #NUM! (determinant is 0)`}</ExcelCode>

A matrix whose determinant is `0` has no inverse.

### #VALUE! — array isn't square

<ExcelCode>{`MINVERSE(A1:C2) → #VALUE! (2 rows, 3 columns)`}</ExcelCode>

`array` must have exactly the same number of rows as columns.

## Related functions

- [MDETERM](/docs/math/mdeterm) — computes the determinant that
  determines whether an inverse exists at all.
- [MMULT](/docs/math/mmult) — multiplies matrices together, often
  paired with MINVERSE to solve equation systems.
- [MUNIT](/docs/math/munit) — the identity matrix that results from
  multiplying a matrix by its own inverse.
