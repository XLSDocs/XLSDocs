Count how many cells in a range match **one** condition — orders in
the West region, amounts over $500, and so on. For more than one
condition, use [COUNTIFS](/docs/math/countifs) instead.

## Return value

The count of cells in `range` that match `criteria`. Returns `0` if
nothing matches — not an error.

## Description

COUNTIF is the simplest of the conditional functions — just a range
and a condition, with no separate value range to aggregate since it's
counting matches within `range` itself. It's also the only one of the
three single-condition functions (alongside SUMIF and AVERAGEIF) that
never takes a third argument.

<Callout type="idea">
  COUNTIF matches text **exactly** (ignoring case) unless the criteria
  itself contains a wildcard. `COUNTIF(A:A, "Jan")` will **not** count
  a cell containing "January" — use `"*Jan*"` if a partial match is
  what you actually want.
</Callout>

## Common errors

### Returns 0 — expecting a partial match

<ExcelCode>{`COUNTIF(A:A, "Jan") → 0 (even if cells contain "January")`}</ExcelCode>

COUNTIF's default text match is exact, not "contains." Add wildcards
for a substring match:

<ExcelCode>{`COUNTIF(A:A, "*Jan*")`}</ExcelCode>

### #NAME? — unquoted criteria

<ExcelCode>{`COUNTIF(A:A, West) → #NAME? (missing quotes around "West")`}</ExcelCode>

Text criteria need quotes around them.

### #NAME? — unquoted comparison operator

<ExcelCode>{`COUNTIF(A:A, >100) → #NAME?`}</ExcelCode>

Comparison operators need to be a quoted string:

<ExcelCode>{`COUNTIF(A:A, ">100")`}</ExcelCode>

## Related functions

- [COUNTIFS](/docs/math/countifs) — the multi-condition version of
  COUNTIF, combining several range/criteria pairs with AND logic.
- [SUMIF](/docs/math/sumif) — same single-condition matching, but
  totals a value range instead of counting rows.
- [AVERAGEIF](/docs/math/averageif) — same idea, averaging the
  matching rows instead of counting them.
