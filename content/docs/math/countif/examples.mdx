---
title: COUNTIF examples
description: Worked examples for COUNTIF — basic matching, comparison operators, wildcards, and blank-cell counting.
---

<FunctionNav />

<ExampleCard number="01" label="Basic — count sales by region" formula={`=COUNTIF(Sales[Region], "West")`}>
  Counts every row where Region equals "West".
</ExampleCard>

<ExampleCard number="02" label="Comparison operator" formula={`=COUNTIF(Sales[Amount], ">1000")`}>
  Counts every amount over $1,000 — comparison operators must be part
  of a quoted string.
</ExampleCard>

<ExampleCard number="03" label="Wildcard match" formula={`=COUNTIF(Products[Name], "*Pro*")`}>
  `*` matches any number of characters — this counts every product
  whose name contains "Pro" anywhere.
</ExampleCard>

<ExampleCard number="04" label="Counting blank cells" formula={`=COUNTIF(Sales[Notes], "")`}>
  Passing `""` as the criteria counts rows where that column is
  blank.
</ExampleCard>

<ExampleCard number="05" label="Excluding a value" formula={`=COUNTIF(Sales[Region], "<>West")`}>
  `<>` means "not equal to" — counts every sale **outside** the West
  region.
</ExampleCard>
