## Return value

The square root of `number × π`. `SQRTPI(1)` returns approximately
`1.772454`; `SQRTPI(2)` returns approximately `2.506628`.

## Description

SQRTPI exists purely as a convenience — it saves writing
`SQRT(number*PI())` out by hand. The calculation shows up in
certain geometry and probability formulas (like the normal
distribution's normalizing constant), where a square root of a
multiple of π is a recurring building block.

<ExcelCode>{`=SQRTPI(1) → 1.772454 (the square root of π itself)`}</ExcelCode>

<Callout type="info">
  **SQRTPI(number) is identical to SQRT(number*PI())** — there's no
  behavioral difference, only convenience. Use whichever reads more
  clearly in context.
</Callout>

## Common errors

### #NUM! — a negative argument

<ExcelCode>{`SQRTPI(-1) → #NUM!`}</ExcelCode>

`number` must be `0` or greater — a negative value would require
taking the square root of a negative number, which isn't defined
for real numbers.
