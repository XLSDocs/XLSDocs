Return the **arctangent** — the angle whose tangent is the given
number. Unlike [ASIN](/docs/math/asin) and [ACOS](/docs/math/acos),
`number` can be any real value, and the result comes back in
**radians**, strictly between `-π/2` and `π/2`.

## Return value

The angle, in radians, whose tangent is `number`, always strictly
between `-π/2` and `π/2` (-90° to 90°, exclusive). Wrap the result in
[DEGREES](/docs/math/degrees) to convert it to degrees.

## Description

ATAN is the inverse of [TAN](/docs/math/tan) — given a tangent ratio,
it finds the angle. Because a single tangent ratio can describe an
angle in either of two opposite quadrants, ATAN always resolves to
the *principal* value between `-90°` and `90°` — it has no way to
know whether the real-world angle behind the ratio was actually in
the opposite quadrant instead.

<Callout type="warn">
  **ATAN can't tell quadrants 1 and 4 apart from 2 and 3.** A ratio of
  `1` could come from a 45° angle or a 225° angle (opposite
  direction, same ratio) — ATAN always returns 45°. If the x and y
  components of the original point are both known, use
  [ATAN2](/docs/math/atan2) instead — it uses both to get the correct
  quadrant.
</Callout>

## Common errors

### Expecting an angle outside -90° to 90°

<ExcelCode>{`DEGREES(ATAN(1)) → 45 (never 225, even if that's the real-world angle)`}</ExcelCode>

ATAN always returns a value in the `-90°` to `90°` range, regardless
of which quadrant the original angle actually came from. When the
quadrant matters, use ATAN2 with the original x/y coordinates
instead of ATAN with their ratio.

### Forgetting to convert the result to degrees

<ExcelCode>{`ATAN(1) → 0.7854 (radians, not the 45 degrees someone may expect)`}</ExcelCode>

ATAN's result is always in radians. Wrap it in `DEGREES()`, or
multiply by `180/PI()`, to get a degree value.
