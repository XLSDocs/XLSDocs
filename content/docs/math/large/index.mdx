Find the 2nd, 3rd, or nth largest value in a range — not just the
single biggest, which is all MAX can give you.

## Return value

The `k`th-largest numeric value in `array`. Returns `#NUM!` if `k`
is less than 1 or greater than the count of values in `array`.

## Description

LARGE ranks every value in `array` from biggest to smallest and
returns whichever one sits at position `k` — `LARGE(range, 1)` is
the same as `MAX(range)`, `LARGE(range, 2)` is the runner-up, and so
on. Useful for "top 3" or "top 5" reporting without sorting the
whole dataset.

<Callout type="warn">
  LARGE does **not** skip duplicate values when ranking. If the two
  highest values in a range are both `100`, `LARGE(range, 1)` and
  `LARGE(range, 2)` both return `100` — `k=2` means "second position
  in the ranking," not "second-distinct value."
</Callout>

## Common errors

### #NUM! — k out of range

<ExcelCode>{`LARGE(A2:A10, 15) → #NUM! (only 9 values exist)`}</ExcelCode>

`k` can't exceed the number of values actually in `array`.

### Expecting distinct values, getting duplicates

<ExcelCode>{`LARGE(A2:A10, 2) → 100 (same as LARGE(A2:A10, 1), if 100 appears twice)`}</ExcelCode>

If genuinely distinct values are needed (skipping ties), wrap
`array` in `UNIQUE` first: `LARGE(UNIQUE(A2:A10), 2)`.
