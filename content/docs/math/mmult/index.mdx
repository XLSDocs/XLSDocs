## Return value

The matrix product of `array1` and `array2`, spilled as an array
with `array1`'s row count and `array2`'s column count. Multiplying a
2×3 array by a 3×2 array returns a 2×2 result.

## Description

MMULT performs true matrix multiplication — each element of the
result is a sum of products across a row of `array1` and a column
of `array2`, not a simple element-by-element multiply. This is
genuinely different from SUMPRODUCT, which multiplies two
same-shaped arrays element-by-element and sums the result into a
single number; MMULT produces a whole new matrix, and the two
input arrays don't even need to be the same shape.

<Callout type="warn">
  **The inner dimensions must match.** `array1`'s number of columns
  must equal `array2`'s number of rows — multiplying a 2×3 array by
  a 3×2 array works, but 2×3 by 2×2 doesn't, and returns `#VALUE!`.
</Callout>

## Common errors

### #VALUE! — mismatched inner dimensions

<ExcelCode>{`MMULT(A1:C2, A1:B2) → #VALUE! (2x3 times 2x2 — inner dimensions 3 and 2 don't match)`}</ExcelCode>

`array1`'s column count must equal `array2`'s row count.

### #VALUE! — empty or text cells

<ExcelCode>{`MMULT(A1:B2, D1:E2) → #VALUE! (if any cell is empty or contains text)`}</ExcelCode>

Both arrays must contain only numbers.

## Related functions

- [MINVERSE](/docs/math/minverse) — computes a matrix's inverse,
  often multiplied by another matrix with MMULT to solve equations.
- [MDETERM](/docs/math/mdeterm) — computes a matrix's determinant,
  a related single-number summary rather than a full product.
- [SUMPRODUCT](/docs/math/sumproduct) — multiplies two same-shaped
  arrays element-by-element and sums the result, unlike MMULT's true
  matrix product.
