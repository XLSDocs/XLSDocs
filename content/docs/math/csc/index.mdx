Return the **cosecant** of an angle — the reciprocal of
[SIN](/docs/math/sin), equal to `1/SIN(number)`. Like every Excel
trig function, the angle must be in **radians**.

## Return value

The cosecant of `number` — equal to `1/SIN(number)`. Since SIN never
exceeds `-1` to `1`, CSC never falls between `-1` and `1` — its
result is always `1` or greater, or `-1` or less.

## Description

CSC is one of the three "reciprocal" trig functions (alongside
[SEC](/docs/math/sec) and [COT](/docs/math/cot)), each defined as 1
divided by one of the three core trig functions. CSC specifically
inverts SIN: `CSC(x) = 1/SIN(x)`. Like SIN, it expects `number` in
radians — convert a degree value with [RADIANS](/docs/math/radians)
first.

<Callout type="warn">
  **CSC never returns a result between -1 and 1**, with a visible
  gap right across that range — since SIN itself never exceeds `-1`
  to `1`, its reciprocal can never fall inside that band. CSC jumps
  straight from `≥ 1` to `≤ -1` as the angle crosses SIN's zero
  points, where CSC itself becomes undefined.
</Callout>

The input here is treated as degrees and converted with RADIANS

cosecant inherits sine's own symmetry.

## Common errors

### #DIV/0! — an argument of exactly 0

<ExcelCode>{`CSC(0) → #DIV/0! (cosecant is undefined wherever sine is exactly 0)`}</ExcelCode>

Any `number` whose sine is exactly zero (`0`, `π`, `2π`, and so on)
has no defined cosecant.

### Expecting a result between -1 and 1

<ExcelCode>{`CSC(RADIANS(90)) → 1 (the closest CSC ever gets to 0, never any closer)`}</ExcelCode>

Because CSC is sine's reciprocal, and sine itself never exceeds `-1`
to `1`, CSC's result never lands inside that range — only at or
beyond its edges.
