Round a number down to the nearest multiple of a given value — the
mirror image of CEILING. Useful whenever the rounding step is a
specific increment rather than a decimal place, like rounding a
price down to the nearest nickel or a duration down to a full
billing unit.

## Return value

`number` rounded down to the nearest multiple of `significance`.
`FLOOR(22, 5)` returns `20`; `FLOOR(0.38, 0.25)` returns `0.25`.

## Description

Unlike ROUNDDOWN, which rounds to a number of *digits*, FLOOR rounds
down to a multiple of any arbitrary value — the nearest nickel
(`0.05`), a full billing unit, or a whole case of stock. This makes
it the right tool whenever the rounding step isn't a clean power of
ten.

<Callout type="warn">
  `number` and `significance` must have the **same sign** —
  `FLOOR(-22, 5)` (a negative number with a positive significance)
  returns `#NUM!`. For negative numbers, `significance` needs to be
  negative too: `FLOOR(-22, -5)`.
</Callout>

## Common errors

### #NUM! — mismatched signs

<ExcelCode>{`FLOOR(-22, 5) → #NUM!`}</ExcelCode>

`number` is negative but `significance` is positive — they need to
match in sign:

<ExcelCode>{`FLOOR(-22, -5) → -25`}</ExcelCode>

### #DIV/0! — significance is zero

<ExcelCode>{`FLOOR(22, 0) → #DIV/0!`}</ExcelCode>

`significance` can't be zero — there's no multiple of zero to round
to.
