Multiply a list of numbers, cells, or ranges together — the
multiplication counterpart to `SUM`, useful for chaining growth
rates, discount factors, or any values that need to compound rather
than add.

## Return value

The product of every numeric value across all arguments. Text and
blank cells within a range are ignored, the same way `SUM` treats
them.

## Description

PRODUCT is the natural fit whenever values need to **compound**
rather than **total** — successive growth multipliers, discount
factors applied one after another, or unit conversions chained
together. Multiplying cells manually with `*` works for a handful of
values, but PRODUCT scales cleanly to an entire range without a long
chain of `*` signs.

<Callout type="warn">
  A single `0` anywhere among the arguments collapses the entire
  result to `0`, no matter how many other values were being
  multiplied — the same way one `0` in a chain of manual
  multiplication zeroes out everything downstream of it.
</Callout>

## Common errors

### An unexpectedly small or zero result

<ExcelCode>{`PRODUCT(5, 10, 0, 20) → 0`}</ExcelCode>

Check the arguments for a stray `0` — it collapses the whole product
regardless of the other values.

### Text values silently excluded

<ExcelCode>{`PRODUCT(A2:A5) → ignores any text cells in the range instead of erroring`}</ExcelCode>

Like SUM, PRODUCT quietly skips non-numeric cells within a range
rather than raising an error — a text value expected to participate
in the calculation (like a number stored as text) can silently drop
out.
