Square every number given, then add the squares together — a
single step used throughout statistics, physics, and least-squares
calculations.

## Return value

The sum of the squares of every number given. `SUMSQ(3, 4)` returns
`25` (`9 + 16`).

## Description

SUMSQ squares each value individually, then adds the squares
together — it's not the same as summing first and squaring once.
`SUMSQ(3, 4)` is `25` (`3² + 4²`), while `SUM(3, 4)^2` is `49`
(`(3+4)²`). This distinction matters anywhere sum-of-squares shows
up directly in a formula, like computing a Euclidean distance or a
standard-deviation-style calculation.

<ExcelCode>{`=SUMSQ(3, 4) → 25 (compare to SUM(3,4)^2, which is 49)`}</ExcelCode>

<Callout type="warn">
  **Don't confuse SUMSQ(range) with SUM(range)^2.** They answer
  different questions — SUMSQ squares each value before summing;
  squaring a sum squares the total only once, at the end. The two
  only agree when there's exactly one number involved.
</Callout>

## Common errors

### #VALUE! — a non-numeric argument

<ExcelCode>{`SUMSQ("abc", 4) → #VALUE!`}</ExcelCode>

Direct non-numeric arguments cause an error; text and logical
values inside a range or array argument are simply ignored instead.
