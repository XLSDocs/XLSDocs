Return the **cosine** of an angle. Like every Excel trig function,
the angle must be supplied in **radians** — a degree value needs
converting first, either with [RADIANS](/docs/math/radians) or by
multiplying by `PI()/180`.

## Return value

The cosine of `number`, always between `-1` and `1`.

## Description

COS expects its argument in radians. A degree value has to be
converted before it's passed in — wrap it in
[RADIANS](/docs/math/radians), or multiply it by `PI()/180` directly.

<Callout type="warn">
  Passing a **degree value directly** is the same trap every Excel
  trig function has — `COS(60)` treats `60` as *60 radians*, not 60
  degrees, and returns `-0.952`, nothing like the `0.5` someone
  expecting degree behavior would want. `COS(RADIANS(60))` returns
  the expected `0.5`.
</Callout>

## Common errors

### Wrong result from passing degrees directly

<ExcelCode>{`COS(60) → -0.952 (60 is read as 60 radians, not 60 degrees)`}</ExcelCode>

Excel has no way to tell a bare number is meant as degrees — it's
always radians. Wrap any degree value in `RADIANS()` first.

### #VALUE! — a non-numeric argument

<ExcelCode>{`COS("sixty") → #VALUE!`}</ExcelCode>

`number` must be a value Excel can read as numeric — text that
doesn't look like a number raises `#VALUE!`.
