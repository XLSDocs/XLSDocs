Find the arithmetic mean of a set of numbers — literal values, cell
references, ranges, or any mix. The building block behind
AVERAGEIF/AVERAGEIFS for conditional averages.

## Return value

The arithmetic mean of every numeric value across all arguments.
Returns `#DIV/0!` if there are no numeric values to average.

## Description

AVERAGE sums the same way SUM does, then divides by how many numeric
values it found — text and blank cells are excluded entirely from
both the sum and the count, so they don't drag the average down. A
cell containing `0`, however, is a real numeric value and is
included.

<Callout type="warn">
  Blank cells and cells containing `0` are **not** the same to
  AVERAGE. A blank cell is skipped entirely (excluded from the count
  of values), while a `0` is counted and pulls the average down. If
  a range mixes genuinely-missing data (blank) with genuinely-zero
  data (0), make sure that distinction is intentional before trusting
  the result.
</Callout>

## Common errors

### #DIV/0! — no numeric values to average

<ExcelCode>{`AVERAGE(A1:A10) → #DIV/0! (if every cell is blank or text)`}</ExcelCode>

There's nothing to average. Wrap it in IFERROR for a fallback:

<ExcelCode>{`IFERROR(AVERAGE(A1:A10), 0)`}</ExcelCode>

### #VALUE! — a referenced cell contains an error

<ExcelCode>{`AVERAGE(A1:A10) → #VALUE! (if any cell in A1:A10 is itself an error)`}</ExcelCode>

An error value inside the range propagates, unlike text (which
AVERAGE quietly skips).

### Unexpected average — blanks vs zeros

<ExcelCode>{`AVERAGE(10, 20, "", 30) → 20 (blank excluded from the count)
AVERAGE(10, 20, 0, 30) → 15 (zero included in the count)`}</ExcelCode>

Both look similar at a glance, but produce different results — check
whether a "missing" value should genuinely be blank or should be `0`.
