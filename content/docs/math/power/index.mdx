Raise `number` to the `power` given — the same calculation the `^`
operator performs, but as a function, which makes it usable anywhere
a formula argument is expected instead of an inline operator.

## Return value

`number` raised to `power`. A negative `power` gives a reciprocal
(`POWER(2, -1)` is `0.5`); a fractional `power` gives a root
(`POWER(9, 0.5)` is `3`).

## Description

POWER and the `^` operator compute exactly the same thing —
`POWER(2, 3)` and `2^3` both return `8`. POWER exists mainly for
readability in a long formula, and because it can be passed directly
as an argument to another function (like LAMBDA) where an inline
operator sometimes reads less clearly. A fractional exponent doubles
as a general-purpose root function: `POWER(n, 1/2)` is a square root,
`POWER(n, 1/3)` is a cube root, and so on for any root.

<Callout type="warn">
  A **negative base with a fractional power** returns `#NUM!`, even
  when the real-numbered root genuinely exists — `POWER(-8, 1/3)`
  should mathematically be `-2` (the real cube root of -8), but Excel
  returns `#NUM!` instead of computing it, since its exponent
  algorithm doesn't handle negative bases with non-integer exponents.
</Callout>

## Common errors

### #NUM! — negative base with a fractional exponent

<ExcelCode>{`POWER(-8, 1/3) → #NUM! (even though the real cube root of -8 is -2)`}</ExcelCode>

Excel's POWER can't compute a fractional root of a negative base
directly. If the real root is genuinely needed, it has to be
computed around the sign manually — take the root of the positive
version, then reapply the negative sign afterward.

### Confusing POWER's argument order

<ExcelCode>{`POWER(2, 10) → 1024 (2 to the 10th power, not 10 to the 2nd)`}</ExcelCode>

`number` is the base and `power` is the exponent, in that order —
the same order as writing `2^10` — reversing them changes the
result completely.
