Return the unit matrix — also called the identity matrix — of size
`dimension`: a square array of 1s down the diagonal and 0s
everywhere else.

## Return value

A `dimension` × `dimension` array, spilled, with `1` along the main
diagonal and `0` everywhere else.

## Description

The identity matrix is the matrix equivalent of the number `1`:
multiplying any compatible matrix by it leaves that matrix
unchanged, the same way multiplying any number by `1` leaves it
unchanged. MUNIT generates one of any size directly, without typing
out the 1s and 0s by hand — mostly useful as a building block or
sanity check alongside MMULT and MINVERSE.

<ExcelCode>{`=MUNIT(3) → a 3×3 array: {1,0,0;0,1,0;0,0,1}`}</ExcelCode>

<Callout type="idea">
  **A quick way to confirm MINVERSE worked correctly**:
  `MMULT(array, MINVERSE(array))` should return (allowing for tiny
  floating-point rounding) the same identity matrix MUNIT would
  generate for that size.
</Callout>

## Common errors

### #VALUE! — a non-positive dimension

<ExcelCode>{`MUNIT(0) → #VALUE!`}</ExcelCode>
<ExcelCode>{`MUNIT(-2) → #VALUE!`}</ExcelCode>

`dimension` must be a positive integer.

## Related functions

- [MMULT](/docs/math/mmult) — multiplying any matrix by its
  matching-size identity returns that matrix unchanged.
- [MINVERSE](/docs/math/minverse) — a matrix multiplied by its own
  inverse produces the identity matrix.
- [MDETERM](/docs/math/mdeterm) — the identity matrix always has a
  determinant of exactly 1.
