For each pair of corresponding values in `array_x` and `array_y`,
compute `x² + y²`, then add all those sums together — the
"X-squared Plus Y-squared" sum.

## Return value

The sum, across every corresponding pair of values, of each pair's
`x² + y²`. For `array_x = {2,3}` and `array_y = {4,1}`, the result
is `30` (`(2²+4²) + (3²+1²)` = `20 + 10`).

## Description

SUMX2PY2 is the "add instead of subtract" sibling of SUMX2MY2: it
squares each pair's values, just like SUMX2MY2, but adds the
squares together instead of subtracting them. Both are rarely
needed outside statistics and physics formulas that specifically
call for this exact combination, like certain regression or
distance-related calculations.

<ExcelCode>{`=SUMX2PY2({2,3}, {4,1}) → 30`}</ExcelCode>

<Callout type="warn">
  **Don't confuse SUMX2PY2 with SUMX2MY2.** They differ only in the
  operator between the squared terms — plus versus minus — but that
  produces very different results for the same data.
</Callout>

## Common errors

## Related functions

- [SUMX2MY2](/docs/math/sumx2my2) — subtracts the squares instead
  of adding them.
- [SUMXMY2](/docs/math/sumxmy2) — subtracts first, then squares the
  difference, rather than squaring each value first.
- [SUMSQ](/docs/math/sumsq) — sums the squares of a single list,
  rather than comparing two paired arrays.
