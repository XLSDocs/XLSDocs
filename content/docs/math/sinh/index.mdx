Return the **hyperbolic sine** of a number — the exponential-based
analogue of ordinary sine, used in engineering and physics formulas
(catenary curves, hyperbolic motion, some probability distributions)
rather than anything to do with triangles or angles.

## Return value

The hyperbolic sine of `number` — unbounded, and the same sign as
`number` (negative input gives a negative result, `SINH(0)` is
exactly `0`).

## Description

SINH is defined by the formula `(e^x − e^-x) / 2`, built from the
exponential function rather than from a circle the way ordinary sine
is. The "hyperbolic" name comes from how it parametrizes a hyperbola
the same way sine and cosine parametrize a circle — it shows up in
catenary-curve formulas (the shape of a hanging cable), certain
probability and signal-processing calculations, and anywhere else
that exponential growth needs an odd (symmetric-around-zero)
function.

<Callout type="idea">
  **SINH has nothing to do with angles.** Unlike SIN, there's no
  radians-vs-degrees conversion to worry about — `number` is just an
  ordinary real value, plugged directly into the exponential formula
  above.
</Callout>

## Common errors

### Assuming SINH needs an angle in radians

<ExcelCode>{`SINH(RADIANS(30)) → not what you want — SINH takes a plain number, not an angle`}</ExcelCode>

SINH's argument is an ordinary number, not an angle — converting it
with RADIANS first (a habit carried over from SIN) changes the input
to something unrelated to what was intended.

### #VALUE! — a non-numeric argument

<ExcelCode>{`SINH("one") → #VALUE!`}</ExcelCode>

`number` must be a value Excel can read as numeric.
