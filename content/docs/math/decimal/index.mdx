Convert `text` — a number written in base `radix` — into an
ordinary base-10 number. The inverse of BASE, which converts
decimal numbers the other direction.

## Return value

The base-10 (decimal) equivalent of `text`, interpreted as a number
in base `radix`. `DECIMAL("FF", 16)` returns `255`;
`DECIMAL(111, 2)` returns `7`.

## Description

DECIMAL is the inverse of BASE: feed it a number written in another
base — binary, hexadecimal, or anything from base 2 through 36 — and
it returns the equivalent ordinary decimal number. Bases above 10
use the letters A-Z for digit values 10 through 35, matching the
convention BASE uses on the way out.

<ExcelCode>{`=DECIMAL("FF", 16) → 255`}</ExcelCode>

<Callout type="info">
  **Letter case doesn't matter.** `DECIMAL("ff", 16)` and
  `DECIMAL("FF", 16)` both return `255` — digit letters are matched
  without regard to case.
</Callout>

## Common errors

### #NUM! — a digit invalid for the given radix

<ExcelCode>{`DECIMAL("2", 2) → #NUM!`}</ExcelCode>

Binary (`radix` 2) only allows the digits 0 and 1 — a `2` isn't a
valid digit in that base.

### #VALUE! — radix out of range

<ExcelCode>{`DECIMAL("10", 1) → #VALUE!`}</ExcelCode>

`radix` must be an integer from 2 to 36.
