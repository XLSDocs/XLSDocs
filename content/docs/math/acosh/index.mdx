Return the **inverse hyperbolic cosine** — given a hyperbolic cosine
value, find the number that produced it. The input must be `1` or
greater (hyperbolic cosine never goes below `1`), and like
[ACOS](/docs/math/acos), the round trip with
[COSH](/docs/math/cosh) doesn't always recover the original sign.

## Return value

The non-negative number whose hyperbolic cosine is `number`. Always
`0` or greater, with `ACOSH(1)` returning exactly `0`.

## Description

ACOSH inverts [COSH](/docs/math/cosh). Just like ordinary cosine,
COSH is an *even* function — `COSH(x)` and `COSH(-x)` always give
the same result — so a single hyperbolic cosine value can't reveal
which of the two possible signs its original input had. ACOSH
always resolves this by returning the non-negative answer.

<Callout type="warn">
  **ACOSH(COSH(x)) does not always return x back.** It only
  round-trips correctly when `x` is already `0` or greater.
  `COSH(-2)` is `3.7622`, the same as `COSH(2)` — so `ACOSH(3.7622)`
  returns `2`, never `-2`, because COSH can't be told apart by sign
  alone.
</Callout>

## Common errors

### #NUM! — an argument below 1

<ExcelCode>{`ACOSH(0.5) → #NUM! (hyperbolic cosine never produces a value below 1)`}</ExcelCode>

COSH's output never drops below `1`, so any `number` below that has
no valid input and ACOSH returns `#NUM!`.

### Expecting ACOSH to recover a negative original value

<ExcelCode>{`ACOSH(COSH(-5)) → 5, not -5`}</ExcelCode>

COSH treats `-5` and `5` identically, so there's no way for ACOSH to
know which one was the real original — it always returns the
non-negative option.
