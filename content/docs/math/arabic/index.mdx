Convert a Roman numeral like "LVII" back into an ordinary Arabic
number — the direct inverse of ROMAN, which converts the other
direction.

## Return value

The Arabic (decimal) number equivalent to the Roman numeral in
`text`. An empty string returns `0`.

## Description

ARABIC reverses ROMAN: feed it a Roman numeral, and it hands back
the ordinary number it represents. `ARABIC("LVII")` returns `57`,
and the comparison round-trips cleanly — `ARABIC(ROMAN(57))` is `57`
again.

<ExcelCode>{`=ARABIC("LVII") → 57`}</ExcelCode>

<Callout type="info">
  **Leading/trailing spaces and letter case are both ignored.**
  `ARABIC(" mcmxii ")` and `ARABIC("MCMXII")` return the same result,
  `1912`.
</Callout>

<Callout type="idea">
  A **non-standard negative Roman numeral** is accepted if a minus
  sign is placed directly before the text — `ARABIC("-MMXI")`
  returns `-2011`, even though a minus sign isn't part of
  traditional Roman numeral notation.
</Callout>

## Common errors

### #VALUE! — not a valid Roman numeral

<ExcelCode>{`ARABIC("ABC") → #VALUE!`}</ExcelCode>
<ExcelCode>{`ARABIC(57) → #VALUE!`}</ExcelCode>

`text` must be an actual Roman numeral string — a plain number, or
text that doesn't form a valid Roman numeral, returns `#VALUE!`.

    # is the common approach:
    values = {"I": 1, "V": 5, "X": 10, "L": 50, "C": 100, "D": 500, "M": 1000}

    def arabic(s):
        s, total, prev = s.upper(), 0, 0
        for ch in reversed(s):
            v = values[ch]
            total += v if v >= prev else -v
            prev = max(prev, v)
        return total
