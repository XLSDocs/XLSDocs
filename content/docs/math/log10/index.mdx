## Return value

The base-10 logarithm of `number` — the exponent that 10 would need
to be raised to, to produce `number`.

## Description

LOG10 is the dedicated base-10 logarithm — the same calculation as
`LOG(number, 10)` or `LOG(number)` with no base given, but as its own
named function for readability. It's the inverse of raising 10 to a
power: `LOG10(100000)` returns `5`, because `10^5` is `100000`.

<ExcelCode>{`=LOG10(100000) → 5`}</ExcelCode>

<Callout type="info">
  **LOG10 is just LOG with the base fixed at 10.** Use LOG10 when the
  base is always 10 and you want a self-documenting formula; use the
  more general LOG function when the base needs to vary.
</Callout>

## Common errors

### #NUM! — a zero or negative argument

<ExcelCode>{`LOG10(0) → #NUM!`}</ExcelCode>
<ExcelCode>{`LOG10(-100) → #NUM!`}</ExcelCode>

The base-10 logarithm is only defined for positive real numbers.

### #VALUE! — a non-numeric argument

<ExcelCode>{`LOG10("abc") → #VALUE!`}</ExcelCode>

`number` must be a number, a cell containing one, or a formula that
returns one.
