Count how many combinations are possible when choosing
`number_chosen` items from `number`, where the *same* item can be
chosen more than once — COMBIN's counterpart for selection with
repetition allowed.

## Return value

The number of ways to choose `number_chosen` items from `number`
options, with repeated choices of the same item allowed.
`COMBINA(4, 3)` returns `20`.

## Description

COMBINA is COMBIN with repetition turned on: COMBIN assumes each of
the `number` items can only be picked once per combination, while
COMBINA allows the same item to be picked multiple times within a
single combination (think of choosing 3 scoops of ice cream from 4
flavors, where you could get two scoops of the same flavor).

<ExcelCode>{`=COMBINA(4, 3) → 20 (compare to COMBIN(4, 3), which returns 4)`}</ExcelCode>

<Callout type="warn">
  **COMBINA and COMBIN answer different questions**, even with
  identical arguments. `COMBIN(4, 3)` counts groups of 3 *distinct*
  flavors chosen from 4 (`4`); `COMBINA(4, 3)` counts groups of 3
  scoops where repeats are allowed (`20`) — a much larger number,
  since repetition opens up far more possible combinations.
</Callout>

## Common errors

### #NUM! — number_chosen larger than number is allowed here (unlike COMBIN)

<ExcelCode>{`COMBINA(2, 5) → 6 (not an error — repetition allows choosing more than number)`}</ExcelCode>

Unlike COMBIN, COMBINA permits `number_chosen` to exceed `number`,
since repeated choices make that meaningful.

### #NUM! — a negative argument

<ExcelCode>{`COMBINA(-1, 2) → #NUM!`}</ExcelCode>

Both `number` and `number_chosen` must be `0` or greater.
