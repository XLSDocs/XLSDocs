Divide `numerator` by `denominator` and return only the integer
portion, discarding whatever remainder is left over — the function
version of integer division.

## Return value

The integer portion of `numerator` divided by `denominator`, with
the remainder discarded. `QUOTIENT(5, 2)` returns `2`;
`QUOTIENT(-10, 3)` returns `-3`.

## Description

QUOTIENT is ordinary division with the decimal portion dropped —
not rounded, just truncated. `5/2` returns `2.5` with the `/`
operator; `QUOTIENT(5, 2)` returns `2`, the whole-number part alone.
It's the companion to MOD: together, `QUOTIENT(a, b)` and
`MOD(a, b)` split a division into its whole and remainder parts.

<ExcelCode>{`=QUOTIENT(5, 2) → 2 (compare to 5/2, which returns 2.5)`}</ExcelCode>

<Callout type="info">
  **Negative results truncate toward zero**, the same way TRUNC
  does — `QUOTIENT(-10, 3)` returns `-3`, not `-4`, since truncation
  drops the fractional part rather than rounding down.
</Callout>

## Common errors

### #DIV/0! — a zero denominator

<ExcelCode>{`QUOTIENT(5, 0) → #DIV/0!`}</ExcelCode>

`denominator` can't be zero.

### #VALUE! — a non-numeric argument

<ExcelCode>{`QUOTIENT("abc", 2) → #VALUE!`}</ExcelCode>

Both arguments must be numbers, cells containing numbers, or
formulas that return numbers.

## Related functions

- [MOD](/docs/math/mod) — returns the remainder that QUOTIENT
  discards.
- [TRUNC](/docs/math/trunc) — truncates a decimal toward zero, the
  same direction QUOTIENT uses for negative results.
- [INT](/docs/math/int) — rounds down toward negative infinity,
  which differs from QUOTIENT for negative results.
