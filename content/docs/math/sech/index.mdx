Return the **hyperbolic secant** of a number — the reciprocal of
[COSH](/docs/math/cosh), equal to `1/COSH(number)`. Like every
hyperbolic function, `number` is a plain real value, not an angle.

## Return value

The hyperbolic secant of `number` — equal to `1/COSH(number)`,
always strictly between `0` and `1`, with the maximum of exactly `1`
occurring at `number = 0`.

## Description

SECH is one of the three "reciprocal" hyperbolic functions (alongside
[CSCH](/docs/math/csch) and [COTH](/docs/math/coth)), each defined
as 1 divided by one of the three core hyperbolic functions. SECH
specifically inverts COSH: `SECH(x) = 1/COSH(x)`.

<Callout type="idea">
  **SECH is the one reciprocal hyperbolic function with no undefined
  point at all.** COSH never equals `0` for any real input (it's
  always `1` or greater), so unlike COTH and CSCH, SECH never raises
  `#DIV/0!` — it's defined for every real number.
</Callout>

## Common errors

### Assuming SECH needs an angle in radians

<ExcelCode>{`SECH(RADIANS(45)) → not what you want — SECH takes a plain number, not an angle`}</ExcelCode>

SECH's argument is an ordinary number, not an angle — converting it
with RADIANS first (a habit carried over from SEC) changes the input
to something unrelated to what was intended.

### Expecting SECH to ever raise #DIV/0!

<ExcelCode>{`SECH(0) → 1 (never an error — unlike SEC(RADIANS(90)), which does raise #DIV/0!)`}</ExcelCode>

Since COSH is never zero, SECH has no undefined point anywhere —
copying the "watch for #DIV/0!" habit from SEC or COT doesn't apply
here.
