Convert `number` into a Roman numeral, returned as text — the
inverse of ARABIC, with an optional `form` argument that controls
how concise the result is.

## Return value

`number` as a Roman numeral, formatted as text in the style `form`
specifies.

## Description

ROMAN converts an ordinary number into Roman numeral text. The
`form` argument trades correctness-to-tradition for brevity: `0`
(the default) gives the familiar "Classic" style everyone
recognizes, while `1` through `4` produce progressively shorter,
less traditional variants that some style guides use for
space-constrained displays.

<ExcelCode>{`=ROMAN(499) → "CDXCIX" (Classic form, the default)`}</ExcelCode>
<ExcelCode>{`=ROMAN(499, 4) → "ID" (Simplified form, the shortest)`}</ExcelCode>

<Callout type="warn">
  **`number` must be between 0 and 3999.** Outside that range, ROMAN
  returns `#VALUE!` — there's no standard Roman numeral
  representation above `3999` (M repeated four times, MMMM, isn't
  considered valid).
</Callout>

## Common errors

### #VALUE! — number out of range

<ExcelCode>{`ROMAN(4000) → #VALUE!`}</ExcelCode>
<ExcelCode>{`ROMAN(-5) → #VALUE!`}</ExcelCode>

`number` must be a whole number from `0` to `3999`.

    # No standard-library equivalent — a lookup-table approach is common:
    values = [
        (1000, "M"), (900, "CM"), (500, "D"), (400, "CD"),
        (100, "C"), (90, "XC"), (50, "L"), (40, "XL"),
        (10, "X"), (9, "IX"), (5, "V"), (4, "IV"), (1, "I"),
    ]

    def to_roman(n):
        result = ""
        for value, symbol in values:
            while n >= value:
                result += symbol
                n -= value
        return result

    print(to_roman(499))
