Round a number down to the nearest whole number — but "down" means
toward negative infinity, not toward zero. `INT(4.7)` gives `4`, and
`INT(-4.7)` gives `-5`, not `-4`. That distinction is the single
biggest source of confusion around this function.

## Return value

The largest integer less than or equal to `number` — always rounding
toward negative infinity, regardless of `number`'s own sign.

## Description

INT is a floor function: it always moves toward negative infinity,
never toward zero. For a positive number this feels like ordinary
"round down" — `INT(4.7)` is `4`. For a negative number, it keeps
going the same direction, past zero — `INT(-4.7)` is `-5`, a smaller
number than `-4.7` itself, not a larger one. This is precisely where
INT and [TRUNC](/docs/math/trunc) part ways: TRUNC always moves
toward zero instead, so `TRUNC(-4.7)` gives `-4`.

<Callout type="warn">
  INT and TRUNC agree on every positive number, which is exactly why
  the difference goes unnoticed until a negative number shows up.
  `INT(-4.7)` is `-5`; `TRUNC(-4.7)` is `-4` — a full integer apart,
  from the same input.
</Callout>

## Common errors

### Expecting INT to truncate toward zero on negative numbers

<ExcelCode>{`INT(-4.7) → -5 (not -4 — INT rounds toward negative infinity, not toward zero)`}</ExcelCode>

If truncating toward zero is actually what's needed (dropping the
decimal portion without changing which side of zero the result lands
on), use TRUNC instead:

<ExcelCode>{`TRUNC(-4.7) → -4`}</ExcelCode>

### Using INT to extract just the decimal portion

<ExcelCode>{`number - INT(number) → the fractional part, but behaves oddly for negative numbers`}</ExcelCode>

This common trick works cleanly for positive numbers, but for
negative numbers INT's rounding-toward-negative-infinity behavior
makes the "fractional part" come out negative-to-positive in a way
that surprises people expecting a simple decimal remainder.

## Related functions

- [TRUNC](/docs/math/trunc) — removes the decimal portion toward
  zero instead of toward negative infinity — the two only disagree
  on negative numbers.
- [ROUND](/docs/math/round) — rounds to the nearest value in either
  direction, rather than always rounding down.
- [MOD](/docs/math/mod) — uses the same floor-based logic internally
  as INT to compute a remainder.
