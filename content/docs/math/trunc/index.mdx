Remove the decimal portion of a number by cutting it off, not
rounding it — and always toward zero, regardless of sign.
`TRUNC(4.9)` is `4`, and `TRUNC(-4.9)` is `-4`, not `-5`.

## Return value

`number` with digits beyond `num_digits` simply cut off — no
rounding, and always truncating toward zero.

## Description

TRUNC chops off digits rather than rounding them — `TRUNC(3.789, 1)`
gives `3.7`, not `3.8`, even though `3.789` is closer to `3.8`.
With no `num_digits` (or `0`), it removes the entire decimal
portion, landing on a whole number the same way
[INT](/docs/math/int) does for positive numbers — but the two
diverge on negative numbers, since TRUNC always moves toward zero
while INT always moves toward negative infinity.

<Callout type="warn">
  TRUNC and INT agree on every positive number, which hides the
  difference until a negative number appears. `TRUNC(-4.9)` is `-4`;
  `INT(-4.9)` is `-5` — a full integer apart, from the exact same
  input.
</Callout>

## Common errors

### Expecting TRUNC to round

<ExcelCode>{`TRUNC(3.789, 1) → 3.7 (not 3.8, even though 3.789 rounds up to 3.8)`}</ExcelCode>

TRUNC never rounds — it only removes digits. If rounding to the
nearest value is actually the goal, use ROUND instead:

<ExcelCode>{`ROUND(3.789, 1) → 3.8`}</ExcelCode>

### Confusing TRUNC with INT on negative numbers

<ExcelCode>{`TRUNC(-4.9) → -4, but INT(-4.9) → -5`}</ExcelCode>

These functions only disagree on negative inputs — TRUNC always
moves toward zero, INT always moves toward negative infinity. Pick
based on which behavior the formula actually needs, not by assuming
they're interchangeable.

## Related functions

- [INT](/docs/math/int) — rounds down toward negative infinity
  instead of toward zero; the two only disagree on negative numbers.
- [ROUND](/docs/math/round) — rounds to the nearest value, rather
  than always cutting toward zero.
- [ROUNDDOWN](/docs/math/rounddown) — very similar to TRUNC, but
  explicitly documented as always rounding toward zero regardless
  of sign, matching TRUNC's own default behavior.
