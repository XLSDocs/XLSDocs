Count how many cells contain **anything** — numbers, text, logical
values, even error values. For counting numeric cells specifically,
use [COUNT](/docs/math/count) instead.

## Return value

The count of cells across all arguments that are not truly empty —
numbers, text, `TRUE`/`FALSE`, and error values all count. Only
genuinely blank cells are excluded.

## Description

COUNTA answers "how many rows have anything in them," regardless of
what type of data that is — useful for counting how many rows of a
table are actually filled in, as opposed to COUNT's narrower "how
many numbers."

<Callout type="warn">
  A cell containing a formula that evaluates to an empty string
  (`=""`) **looks** blank but is **not** blank to COUNTA — it still
  counts, since the cell technically contains a formula result.
  This is a common source of a COUNTA total that's higher than
  expected.
</Callout>

## Common errors

### Overcounting — formulas returning ""

<ExcelCode>{`COUNTA(A1:A10) → counts a cell holding =IF(B1="","","x") even when it displays blank`}</ExcelCode>

The cell isn't truly empty — it holds a formula, even if that
formula's result is an empty string. COUNTBLANK also treats these
cells as non-blank for the same reason.

### Confusing COUNTA with COUNT

<ExcelCode>{`COUNTA(A1:A10) → counts text rows too, unlike COUNT`}</ExcelCode>

If only numeric cells should count, use COUNT instead — COUNTA
counts every non-blank cell regardless of type.
