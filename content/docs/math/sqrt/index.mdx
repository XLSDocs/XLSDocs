Return the positive square root of a number — the value that,
multiplied by itself, gives back the original number. `SQRT(16)` is
`4`, since `4 × 4` is `16`.

## Return value

The positive square root of `number`. Returns `#NUM!` if `number` is
negative.

## Description

SQRT is the common, dedicated case of a general power operation —
`SQRT(n)` computes exactly the same thing as
[`POWER(n, 0.5)`](/docs/math/power), just with a clearer name for the
single most common root anyone needs. Every positive number has two
mathematical square roots (one positive, one negative), but SQRT
always returns only the positive one.

<Callout type="warn">
  A negative `number` returns `#NUM!` — Excel has no built-in support
  for imaginary numbers in SQRT (there's a separate `IMSQRT` for
  working with complex numbers specifically). Squaring a negative
  number first, intentionally or by formula error, is the most common
  way a negative value ends up inside SQRT unexpectedly.
</Callout>

## Common errors

### #NUM! — negative input

<ExcelCode>{`SQRT(-4) → #NUM!`}</ExcelCode>

Check where the negative value is coming from — if it's the result
of a subtraction that could go either way, `SQRT(ABS(number))` at
least avoids the error, though it changes the math (it's no longer a
true square root of the original signed value).

### Expecting both the positive and negative root

<ExcelCode>{`SQRT(16) → 4 only (not also -4, even though -4 × -4 is also 16)`}</ExcelCode>

SQRT always returns just the positive root. If the negative root is
also needed, it has to be computed separately as `-SQRT(number)`.
