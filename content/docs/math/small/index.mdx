Find the 2nd, 3rd, or nth smallest value in a range — not just the
single lowest, which is all MIN can give you.

## Return value

The `k`th-smallest numeric value in `array`. Returns `#NUM!` if `k`
is less than 1 or greater than the count of values in `array`.

## Description

SMALL ranks every value in `array` from smallest to biggest and
returns whichever one sits at position `k` — `SMALL(range, 1)` is
the same as `MIN(range)`, `SMALL(range, 2)` is the next-lowest, and
so on. Useful for "bottom 3" or "lowest 5" reporting without sorting
the whole dataset.

<Callout type="warn">
  SMALL does **not** skip duplicate values when ranking. If the two
  lowest values in a range are both `10`, `SMALL(range, 1)` and
  `SMALL(range, 2)` both return `10` — `k=2` means "second position
  in the ranking," not "second-distinct value."
</Callout>

## Common errors

### #NUM! — k out of range

<ExcelCode>{`SMALL(A2:A10, 15) → #NUM! (only 9 values exist)`}</ExcelCode>

`k` can't exceed the number of values actually in `array`.

### Expecting distinct values, getting duplicates

<ExcelCode>{`SMALL(A2:A10, 2) → 10 (same as SMALL(A2:A10, 1), if 10 appears twice)`}</ExcelCode>

If genuinely distinct values are needed (skipping ties), wrap
`array` in `UNIQUE` first: `SMALL(UNIQUE(A2:A10), 2)`.
