Average a range of values, but only for rows that match **all** of
one or more conditions — the same condition-matching shape as
SUMIFS, just averaging instead of summing.

## Return value

The average of `average_range` values in rows where every criteria
pair matches. Returns `#DIV/0!` if no rows match — unlike SUMIFS or
COUNTIFS, which return `0` on no matches, since averaging zero items
is a division by zero.

## Description

AVERAGEIFS extends AVERAGE the same way SUMIFS extends SUM — every
condition must be true for a row to count toward the average (AND
logic), and each `criteria_range` must be the same size and shape as
`average_range`.

<Callout type="warn">
  Unlike SUMIFS and COUNTIFS, AVERAGEIFS throws `#DIV/0!` when no
  rows match — it isn't a silent `0`. Wrap it in IFERROR if a
  zero-match result should show `0` or a message instead.
</Callout>

## Common errors

### #DIV/0! — no rows match

<ExcelCode>{`AVERAGEIFS(A2:A10, B2:B10, "West") → #DIV/0! (when no row is "West")`}</ExcelCode>

There's nothing to average. Wrap it in IFERROR for a fallback:

<ExcelCode>{`IFERROR(AVERAGEIFS(A2:A10, B2:B10, "West"), 0)`}</ExcelCode>

### #VALUE! — mismatched range sizes

<ExcelCode>{`AVERAGEIFS(A2:A10, B2:B9, "West") → #VALUE!`}</ExcelCode>

`criteria_range` must be the same size as `average_range` — here one
is 9 rows and the other is 10.

### Unquoted criteria or operator

<ExcelCode>{`AVERAGEIFS(A:A, B:B, West) → #NAME?
AVERAGEIFS(A:A, B:B, >100) → #NAME?`}</ExcelCode>

Text criteria and comparison operators both need quotes — for a
cell-driven comparison, concatenate the operator with `&`:

<ExcelCode>{`AVERAGEIFS(A:A, B:B, ">"&D2)`}</ExcelCode>
