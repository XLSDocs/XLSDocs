Return the double factorial of `number` — the product of `number`
and every second integer below it, down to either `1` or `2`
depending on whether `number` is odd or even.

## Return value

The double factorial of `number` — the product of `number`,
`number - 2`, `number - 4`, and so on, stopping at `1` (for an odd
`number`) or `2` (for an even `number`).

## Description

FACTDOUBLE skips every other term that an ordinary factorial (FACT)
would include. For an even number like 6, it multiplies
`6 × 4 × 2 = 48`; for an odd number like 7, it multiplies
`7 × 5 × 3 × 1 = 105`. It shows up in certain combinatorics and
series formulas where the "skip-one" pattern specifically matters.

<ExcelCode>{`=FACTDOUBLE(6) → 48 (6×4×2)`}</ExcelCode>
<ExcelCode>{`=FACTDOUBLE(7) → 105 (7×5×3×1)`}</ExcelCode>

<Callout type="info">
  **Don't confuse this with FACT twice, or `FACT(number)/2`** — the
  double factorial isn't FACT applied twice, and it isn't a simple
  fraction of the ordinary factorial. It's a genuinely different
  product: every *other* integer, not every integer halved.
</Callout>

## Common errors

### #NUM! — a negative argument

<ExcelCode>{`FACTDOUBLE(-3) → #NUM!`}</ExcelCode>

`number` must be `0` or greater.

### #VALUE! — a non-numeric argument

<ExcelCode>{`FACTDOUBLE("abc") → #VALUE!`}</ExcelCode>

`number` must be a number, a cell containing one, or a formula that
returns one.
