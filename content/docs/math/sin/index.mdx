Return the **sine** of an angle. The angle must be supplied in
**radians** — not degrees — so a degree value needs converting first,
either with [RADIANS](/docs/math/radians) or by multiplying by
`PI()/180`.

## Return value

The sine of `number`, always between `-1` and `1`.

## Description

SIN expects its argument in radians, the same unit used throughout
Excel's trig functions. A degree value has to be converted before
it's passed in — wrap it in [RADIANS](/docs/math/radians), or
multiply it by `PI()/180` directly, which does the same conversion
inline.

<Callout type="warn">
  Passing a **degree value directly** is the single most common
  mistake with SIN — `SIN(30)` treats `30` as *30 radians* (roughly
  4.77 full rotations), not 30 degrees, and returns `-0.988`, nothing
  like the `0.5` someone expecting degree behavior would want.
  `SIN(RADIANS(30))` returns the expected `0.5`.
</Callout>

## Common errors

### Wrong result from passing degrees directly

<ExcelCode>{`SIN(30) → -0.988 (30 is read as 30 radians, not 30 degrees)`}</ExcelCode>

Excel has no way to tell a bare number is meant as degrees — it's
always radians. Wrap any degree value in `RADIANS()` first.

### #VALUE! — a non-numeric argument

<ExcelCode>{`SIN("thirty") → #VALUE!`}</ExcelCode>

`number` must be a value Excel can read as numeric — text that
doesn't look like a number raises `#VALUE!`.
