Round `number` up to the nearest integer or multiple of
`significance`, always rounding toward positive infinity —
functionally identical to CEILING.PRECISE, added under this name for
compatibility with the Open Document Format (ODF) spreadsheet
standard.

## Return value

`number` rounded up to the nearest multiple of `significance`,
always moving toward positive infinity. `ISO.CEILING(4.3, 2)`
returns `6`; `ISO.CEILING(-4.3)` returns `-4`.

## Description

ISO.CEILING exists specifically so that spreadsheets following the
ODF (OpenDocument Format) standard — used by applications like
LibreOffice Calc and Google Sheets — have a function name that
matches what the standard specifies, while behaving exactly like
Excel's own CEILING.PRECISE. There's no behavioral difference
between the two; it's purely a naming-compatibility function.

<ExcelCode>{`=ISO.CEILING(4.3, 2) → 6 (next multiple of 2 at or above 4.3)`}</ExcelCode>

<Callout type="info">
  **ISO.CEILING and CEILING.PRECISE are interchangeable.** Pick
  ISO.CEILING when matching a formula imported from or shared with
  an ODF-based tool; otherwise, either name works identically in
  Excel.
</Callout>

## Common errors

### Zero result from a zero argument

<ExcelCode>{`ISO.CEILING(0, 5) → 0`}</ExcelCode>
<ExcelCode>{`ISO.CEILING(4.3, 0) → 0`}</ExcelCode>

If either `number` or `significance` is `0`, the result is `0` —
there's no non-zero multiple to round a zero value to.

## Related functions

- [CEILING.PRECISE](/docs/math/ceiling-precise) — functionally
  identical, Excel's own non-ODF name for the same behavior.
- [CEILING.MATH](/docs/math/ceiling-math) — adds a `mode` argument
  to control negative-number rounding direction, rather than always
  rounding toward positive infinity.
- [FLOOR.PRECISE](/docs/math/floor-precise) — the rounding-down
  counterpart, always rounding toward negative infinity.
