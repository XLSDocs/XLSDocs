Return the **hyperbolic tangent** of a number — the exponential-based
analogue of ordinary tangent, used in statistics, machine learning
(it's a classic neural-network activation function), and engineering
formulas rather than anything to do with triangles or angles.

## Return value

The hyperbolic tangent of `number`, always strictly between `-1` and
`1` — it approaches those edges as `number` grows large in either
direction, but never actually reaches them.

## Description

TANH is defined as `SINH(x) / COSH(x)`, the hyperbolic equivalent of
tangent being sine over cosine. Unlike ordinary TAN, which is
unbounded and periodic, TANH flattens out toward `-1` and `1` as its
input grows — an S-shaped curve that makes it a popular "squashing"
function wherever an unbounded value needs compressing into a fixed
range, most notably as an activation function in neural networks.

<Callout type="idea">
  **TANH has nothing to do with angles.** Unlike TAN, there's no
  radians-vs-degrees conversion to worry about, and TANH never
  blows up the way TAN does near 90° — it smoothly approaches `1`
  instead.
</Callout>

## Common errors

### Assuming TANH needs an angle in radians

<ExcelCode>{`TANH(RADIANS(45)) → not what you want — TANH takes a plain number, not an angle`}</ExcelCode>

TANH's argument is an ordinary number, not an angle — converting it
with RADIANS first (a habit carried over from TAN) changes the input
to something unrelated to what was intended.

### Expecting TANH to blow up like TAN does

<ExcelCode>{`TANH(100) → 1 (rounded; never actually reaches 1, and never spikes the way TAN does near 90°)`}</ExcelCode>

TAN grows without bound near its undefined points; TANH does the
opposite — it flattens out, asymptotically approaching but never
touching `1` or `-1`.
