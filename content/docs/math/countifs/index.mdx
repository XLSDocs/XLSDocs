Count how many rows match **all** of one or more conditions — orders
over $500 that are also unpaid, employees in a department hired
after a given date, and so on.

## Return value

The count of rows where every criteria pair matches. Returns `0` if
no rows match — not an error.

## Description

COUNTIFS is COUNTIF extended to multiple conditions, combined with
AND logic — a row only counts if **every** criteria pair matches.
Unlike SUMIFS/AVERAGEIFS, there's no value range to aggregate; it's a
pure row count.

<Callout type="info">
  Every `criteria_range` must be the same size and shape as the
  others — mixing a 10-row range with a 9-row range throws
  `#VALUE!`, the same failure mode as SUMIFS and AVERAGEIFS.
</Callout>

## Common errors

### #VALUE! — mismatched range sizes

<ExcelCode>{`COUNTIFS(A2:A10, "West", B2:B9, "Paid") → #VALUE!`}</ExcelCode>

Both criteria ranges must be the same size — here one is 9 rows and
the other is 10.

### Returns 0 — unquoted criteria

<ExcelCode>{`COUNTIFS(A:A, West) → #NAME? (missing quotes around "West")`}</ExcelCode>

Text criteria need quotes around them.

### Unquoted comparison operator

<ExcelCode>{`COUNTIFS(A:A, >D2) → #NAME?`}</ExcelCode>

Comparison operators need to be a quoted string concatenated with the
cell reference:

<ExcelCode>{`COUNTIFS(A:A, ">"&D2)`}</ExcelCode>

## Related functions

- [COUNTIF](/docs/math/countif) — the single-condition version of
  COUNTIFS, for when only one range/criteria pair is needed.
- [SUMIFS](/docs/math/sumifs) — same multi-condition AND logic, but
  totals a value range instead of counting rows.
- [AVERAGEIFS](/docs/math/averageifs) — same AND logic, averaging a
  value range instead of counting rows.
- [IFERROR](/docs/logical/iferror) — useful alongside COUNTIFS when
  dividing a sum by a count that might be zero.
- [SUMPRODUCT](/docs/math/sumproduct) — handles OR logic across
  conditions, which COUNTIFS can't express directly.
