Return the **inverse hyperbolic cotangent** — given a hyperbolic
cotangent value, find the number that produced it. The input must
have an absolute value **greater than 1** — the opposite restriction
from [ATANH](/docs/math/atanh), which requires an input *less than*
1 in absolute value.

## Return value

The number whose hyperbolic cotangent is `number`. Same sign as
`number`, approaching `0` as `|number|` grows large, and growing
without bound as `|number|` approaches `1` from either side.

## Description

ACOTH inverts [COTH](/docs/math/coth). Because `COTH(x)` never
produces a value between `-1` and `1` for any real nonzero `x`, its
inverse ACOTH only accepts inputs outside that same range — mirroring
exactly how [ACOSH](/docs/math/acosh) only accepts `COSH`'s own
output range (`1` or greater), rather than ACOSH's actual input rule.

<Callout type="warn">
  **ACOTH's domain is the complement of ATANH's.** ATANH requires
  `-1 < number < 1`; ACOTH requires `number < -1` or `number > 1` —
  together, every real number except exactly `-1`, `1`, and the
  interval between them is covered by one function or the other,
  with no overlap.
</Callout>

## Common errors

### #NUM! — an argument between -1 and 1

<ExcelCode>{`ACOTH(0.5) → #NUM! (hyperbolic cotangent never produces a value strictly between -1 and 1)`}</ExcelCode>

`number` must fall outside `-1` to `1` entirely (not even touching
the endpoints) — a value in that range has no real input that
could have produced it.

### Confusing ACOTH's domain with ATANH's

<ExcelCode>{`ACOTH(0.9) → #NUM!, while ATANH(0.9) works fine — opposite domains`}</ExcelCode>

ACOTH and ATANH split the real number line into complementary
halves — a value that works for one is exactly the kind of value
that fails for the other.
