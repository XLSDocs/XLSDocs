Return a single member or tuple from an OLAP cube connection —
confirming it actually exists in the cube, and giving it a cell
reference other cube functions can point to.

## Return value

The member or tuple identified by `member_expression`, displayed
using `caption` if supplied or the cube's own default caption
otherwise.

## Description

CUBEMEMBER is the foundational cube function — it validates that a
member or tuple genuinely exists in the connected cube and gives it a
worksheet cell reference. Every other cube function that accepts a
`member_expression` argument can point at a `CUBEMEMBER` cell instead
of repeating the raw MDX string, which is both easier to read and
avoids retyping a long expression in multiple formulas.

<Callout type="warn">
  When a `CUBEMEMBER` cell is used as an argument inside another cube
  function, Excel passes along the underlying MDX expression, not the
  caption text displayed in the cell — changing `caption` never
  changes what other formulas referencing that cell actually retrieve.
</Callout>

<ExcelCode>{`=CUBEMEMBER("Sales", "[Product].[Category].[Bikes]") → "Bikes"`}</ExcelCode>

<ExcelCode>{`=CUBEMEMBER("Sales", "[Product].[Category].[Bikes]", "Bike Sales") → "Bike Sales"`}</ExcelCode>

## Common errors

### #NAME? — the connection doesn't exist or the server is unreachable

`connection` must exactly match an existing workbook connection name,
and the OLAP server it points to must actually be reachable.

### #N/A — the member doesn't exist, or the MDX syntax is wrong

`member_expression` must be valid MDX identifying a real member in
the cube. A typo in a dimension, hierarchy, or member name returns
`#N/A` rather than a partial or guessed match.

### #VALUE! — member_expression is over 255 characters as a literal string

A long MDX expression typed directly into the formula hits a
255-character limit. Put the expression in a cell instead (up to
32,767 characters) and reference that cell.
