---
title: Cube
description: Pull members, sets, and aggregated values directly from an OLAP cube connection — no PivotTable required.
---

Cube functions pull data straight out of an OLAP cube — a multi-
dimensional data source like SQL Server Analysis Services, or an
Excel Data Model connected as an OLAP source — without building a
PivotTable first. They require a live cube connection to actually
return data; none of the examples on these pages can be tried in a
plain worksheet the way `SUMIFS` or `VLOOKUP` can.
