## Return value

The number of members or tuples in `set`.

## Description

CUBESETCOUNT does exactly one thing: count how many items are in a
set that `CUBESET` already built. It's often used alongside
`CUBERANKEDMEMBER` in a loop-like pattern — count the set first, then
pull ranked members `1` through that count into a spilled list, or
check the count before assuming a "top 10" set actually has 10 items
to show.

<Callout type="idea">
  A set filtered down to a small category can easily have fewer
  members than expected — checking `CUBESETCOUNT` before looping
  through ranked members with `CUBERANKEDMEMBER` avoids pulling
  `#N/A` for ranks past the set's actual size.
</Callout>

<ExcelCode>{`=CUBESETCOUNT(A1) → 12, if A1 holds a CUBESET of 12 products`}</ExcelCode>

## Common errors

### #N/A — set doesn't reference a valid CUBESET result

`set` must point to (or contain) an actual, successfully-built
`CUBESET` — a cell with plain text or an unrelated formula doesn't
count.

### #NAME? — the underlying CUBESET's connection is invalid

Since `CUBESETCOUNT` just counts an already-built set, an error here
usually traces back to the `CUBESET` formula it references, not
`CUBESETCOUNT` itself.
