Return one specific component of a Key Performance Indicator (KPI)
already defined inside the cube — the actual value, the target goal,
a status indicator, or one of several other pieces that together make
up a single KPI.

## Return value

The requested component of `kpi_name` — its meaning depends entirely
on `kpi_property`.

## Description

A KPI in an OLAP cube isn't a single number — it's a small bundle of
related values that together describe performance against a target.
CUBEKPIMEMBER pulls out exactly one of those pieces at a time, chosen
by `kpi_property`:

| Value | Constant | Returns |
|---|---|---|
| 1 | KPIValue | The actual current value |
| 2 | KPIGoal | The target value being measured against |
| 3 | KPIStatus | The state of the KPI at this moment (on track, at risk, etc.) |
| 4 | KPITrend | A measure of the value's change over time |
| 5 | KPIWeight | The relative importance assigned to this KPI |
| 6 | KPICurrentTimeMember | The temporal context the KPI is being evaluated at |

<Callout type="idea">
  Displaying a full KPI dashboard typically means calling
  CUBEKPIMEMBER **multiple times** for the same `kpi_name` — once per
  property needed (value, goal, and status are the most common
  three) — since each call only returns one component.
</Callout>

<ExcelCode>{`=CUBEKPIMEMBER("Sales", "Gross Profit Margin", 1) → the current value`}</ExcelCode>

<ExcelCode>{`=CUBEKPIMEMBER("Sales", "Gross Profit Margin", 3) → the status indicator (e.g. on-track / at-risk / off-track)`}</ExcelCode>

## Common errors

### #NAME? — the connection doesn't exist or the server is unreachable

`connection` must exactly match an existing workbook connection name
pointing to a reachable OLAP server.

### #N/A — kpi_name doesn't exist, or kpi_property is outside 1-6

`kpi_name` must match a KPI that's genuinely defined in the cube
(CUBEKPIMEMBER can't create one), and `kpi_property` only accepts
whole numbers from 1 to 6.

### The cell only shows the KPI's name, not a number

That's expected specifically when `kpi_property` is 1 (KPIValue) —
the cell displays the KPI's name rather than a raw number by design;
the underlying value is still what other formulas referencing this
cell will retrieve.
