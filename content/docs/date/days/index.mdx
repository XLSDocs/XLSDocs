## Return value

The number of days between `start_date` and `end_date`.
`DAYS("15-Mar-2021", "1-Feb-2021")` returns `42`.

## Description

DAYS is a thin wrapper around plain date subtraction — `DAYS(end,
start)` returns the same result as `end - start` when both are
genuine dates. Its main value is readability and resilience: it
reads clearly as "days between these two dates" in a formula, and it
accepts text dates directly, converting them the same way DATEVALUE
would, rather than requiring a pre-converted serial number.

<ExcelCode>{`=DAYS("15-Mar-2021", "1-Feb-2021") → 42`}</ExcelCode>

<Callout type="warn">
  **Argument order is `end_date` first, then `start_date`** — the
  opposite of how the two dates usually get written in a sentence.
  `DAYS(A2, A3)` with A2 the later date and A3 the earlier date
  gives a positive result; swapping them gives the same magnitude,
  negated.
</Callout>

## Common errors

### #VALUE! — text that isn't a recognizable date

<ExcelCode>{`DAYS("not a date", "1-Feb-2021") → #VALUE!`}</ExcelCode>

Both arguments must be real dates, or text Excel can parse as a
date.

## Related functions

- [DATEDIF](/docs/date/datedif) — measures the gap between two
  dates in years, months, or days, instead of only days.
- [DAYS360](/docs/date/days360) — counts days using a 360-day-year
  accounting convention instead of real calendar days.
- [NETWORKDAYS](/docs/date/networkdays) — counts only business days
  between two dates, excluding weekends and holidays.
