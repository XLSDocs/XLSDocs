Return the current date **and** time, with no arguments — like
TODAY, but including the time of day, and recalculating every time
the workbook does.

## Syntax

<ExcelCode>{`=NOW()`}</ExcelCode>

## Parameters

NOW takes no arguments — the parentheses are still required, but
always empty.

## Return value

The current date and time as a serial number (the integer part is
the date, the decimal part is the time of day), based on your
system clock. Updates automatically whenever the workbook
recalculates.

## Description

NOW is TODAY's sibling, adding the current time to the date. Like
TODAY, it's a **volatile** function — it recalculates on every
workbook recalculation (opening the file, editing any cell, or
pressing F9), not on a timer, so it won't tick forward while you
watch a static, unedited sheet.

<Callout type="warn">
  Like TODAY(), NOW() isn't a way to record a fixed timestamp — a
  cell showing `=NOW()` will show a different time the next time the
  workbook recalculates. To record a fixed moment, insert a static
  value instead (see Common errors below).
</Callout>

## Common errors

### Result shows a number instead of a date and time

<ExcelCode>{`=NOW() → 46876.53472 (not formatted as a date/time)`}</ExcelCode>

NOW returns a serial number — the cell needs a datetime format code
like `"mm/dd/yyyy hh:mm:ss"` to display it as a readable date and
time.

### A recorded timestamp keeps changing

<ExcelCode>{`=NOW() → shows a different time every time the sheet recalculates`}</ExcelCode>

NOW() always reflects the current moment — it's not a snapshot. To
insert a fixed, unchanging timestamp, press **Ctrl+;** for the date,
then a space, then **Ctrl+Shift+;** for the time, while editing the
cell.
