Find the date that's a given number of working days away from a
start date — weekends skipped automatically, holidays skipped too if
a list is supplied. The inverse of NETWORKDAYS: instead of counting
business days between two known dates, this finds the date itself.

## Return value

The date that is `days` working days after (or before, if negative)
`start_date`, skipping weekends and any dates listed in `holidays`.

## Description

WORKDAY answers "what date is 10 business days from now" — the
calculation behind realistic due-date estimates, shipping timelines,
and deadline scheduling that needs to account for weekends (and
optionally holidays) rather than a naive calendar-day addition.

<Callout type="warn">
  `start_date` itself is **never** counted as one of the `days` — it's
  purely the starting point. `WORKDAY(A2, 1)` returns the *next*
  working day after `A2`, not `A2` itself, even if `A2` is a weekday.
</Callout>

## Common errors

### Off-by-one from expecting start_date to count

<ExcelCode>{`WORKDAY(DATE(2027,1,4), 1) → January 5, 2027 (the next day, not Jan 4 itself)`}</ExcelCode>

`start_date` is the starting point, not counted as day one of the
result — `days=1` means "one working day after this date."

### Weekends hardcoded to Saturday/Sunday

Like NETWORKDAYS, plain WORKDAY always treats Saturday and Sunday as
the weekend, with no argument to change that — use
[WORKDAY.INTL](/docs/date/workday-intl) for a custom weekly schedule.
