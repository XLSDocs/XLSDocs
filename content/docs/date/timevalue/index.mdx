Convert text that looks like a time — but isn't actually a time
value yet — into the real fractional serial number Excel uses
internally for times. The time-of-day equivalent of DATEVALUE.

## Return value

The time serial number corresponding to `time_text` — a fraction
between `0` (midnight) and `0.999...` (just before the next
midnight).

## Description

Just as DATEVALUE turns date-looking text into a real date, TIMEVALUE
turns time-looking text into a real time value — a fraction
representing how far through a 24-hour day that time falls.
`TIMEVALUE("12:00 PM")` returns exactly `0.5`, since noon is halfway
through the day; `TIMEVALUE("6:00 AM")` returns `0.25`, one quarter
of the way through.

<Callout type="warn">
  If `time_text` includes a date portion as well (like
  `"1/15/2026 2:30 PM"`), TIMEVALUE discards the date entirely and
  returns only the time fraction. Use DATEVALUE separately on the
  same text to recover the date portion if both parts are needed.
</Callout>

## Common errors

### Result displays as a decimal instead of a time

<ExcelCode>{`TIMEVALUE("2:30 PM") → 0.604167 (correct, just needs a time format applied)`}</ExcelCode>

Not an error — apply a time number format to the cell to see it
displayed as a clock time instead of a raw decimal fraction.

### #VALUE! — text Excel can't parse as a time

<ExcelCode>{`TIMEVALUE("not a time") → #VALUE!`}</ExcelCode>

The text has to be in a format Excel actually recognizes as a time.

### Losing the date portion of a combined date-and-time string

<ExcelCode>{`TIMEVALUE("1/15/2026 2:30 PM") → 0.604167 (the time only, date is dropped)`}</ExcelCode>

TIMEVALUE discards any date component entirely. Use DATEVALUE
separately on the same text, and add the two results together, if
both the date and time need to be preserved.
