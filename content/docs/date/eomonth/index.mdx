Find the last day of a month — either the month a date falls in, or
a month some number of months before or after it. The standard
formula behind month-end deadlines, billing dates, and reporting
periods.

## Return value

A date serial number representing the last day of the month that is
`months` months from `start_date`.

## Description

EOMONTH always lands on the final day of a month, regardless of
what day-of-month `start_date` was — unlike EDATE, which keeps the
same day-of-month and only adjusts when the target month is too
short. Use EOMONTH specifically when you want a month boundary
(billing cutoffs, reporting periods, "last day of the quarter"),
not a fixed day offset.

<Callout type="info">
  `EOMONTH(start_date, 0)` is the standard way to get "the last day
  of this month" from any date. Add `1` to that result to get the
  first day of the *next* month instead.
</Callout>

## Common errors

### Confusing EOMONTH with EDATE

<ExcelCode>{`EOMONTH(A2, 1) → always the last day of next month, not "A2 plus one month"`}</ExcelCode>

EOMONTH ignores `start_date`'s actual day and always returns a
month-end. If you want the same day-of-month one month later, use
EDATE instead.

### Result shows a number instead of a date

<ExcelCode>{`EOMONTH(A2, 0) → 46783 (not formatted as a date)`}</ExcelCode>

EOMONTH returns a serial number — format the cell as a date if
Excel doesn't apply that formatting automatically.
