Calculate the difference between two dates in whichever unit you
need — complete years for an age, complete months for tenure, or
total days for a duration. The standard formula behind age and
anniversary calculations in Excel.

## Return value

The difference between `start_date` and `end_date`, measured in
whichever `unit` was specified.

## Description

DATEDIF is a legacy function — kept in Excel for backward
compatibility with Lotus 1-2-3, and deliberately left out of
Excel's function autocomplete and Insert Function dialog by
Microsoft, even though it works fine and remains the simplest way to
get a "complete years/months between two dates" result.

<Callout type="warn">
  The `"MD"` unit has long-standing, documented edge-case bugs in
  Excel — it can return negative or otherwise incorrect results for
  certain date combinations. `Y`, `M`, `D`, `YM`, and `YD` are
  reliable; treat `MD` results with suspicion and verify manually if
  you use it.
</Callout>

## Common errors

### #NUM! — start_date is after end_date

<ExcelCode>{`DATEDIF(DATE(2027,6,1), DATE(2027,1,1), "Y") → #NUM!`}</ExcelCode>

`start_date` must be on or before `end_date` — DATEDIF doesn't
handle a negative difference.

### Unreliable results with the "MD" unit

<ExcelCode>{`DATEDIF(A2, B2, "MD") → occasionally wrong, a known Excel bug`}</ExcelCode>

If day-level precision matters and `"MD"` looks off, calculate total
days with `"D"` instead and derive the remainder manually.

## Related functions

- [DATE](/docs/date/date) and [TODAY](/docs/date/today) — the most
  common sources of the two dates DATEDIF compares.
- [EDATE](/docs/date/edate) — the reverse operation: shifts a date
  by a fixed number of months instead of measuring a gap.
- [DateDiff](/docs/vba/datediff) — VBA's near-namesake, with a
  different argument order and different rules for counting boundary
  crossings versus DATEDIF's complete elapsed intervals.
