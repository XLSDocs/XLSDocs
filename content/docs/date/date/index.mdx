## Return value

A date serial number representing the given year, month, and day.
Displays as a formatted date if the cell has date formatting (Excel
usually applies this automatically).

## Description

DATE assembles a real, calculable date from three separate numbers —
useful when year, month, and day come from different cells or
formulas, rather than existing together as a single date already.
Out-of-range `month` or `day` values don't error; they roll over
into the next or previous month/year, which is often used
deliberately for date arithmetic.

<Callout type="info">
  `DATE(year, month + 1, 0)` is a common trick for finding the last
  day of `month` — day `0` means "the day before day 1," which lands
  on the final day of the previous month.
</Callout>

## Common errors

### #NUM! — year out of range

<ExcelCode>{`DATE(10000, 1, 1) → #NUM!`}</ExcelCode>

Excel's date system only supports years from 1900 through 9999.

### Result shows a number instead of a date

<ExcelCode>{`DATE(2027, 3, 15) → 46461 (not formatted as a date)`}</ExcelCode>

DATE returns a serial number — format the cell as a date if Excel
doesn't apply that formatting automatically.

### Unexpected month/year rollover

<ExcelCode>{`DATE(2027, 13, 1) → January 1, 2028, not an error`}</ExcelCode>

Month `13` rolls into January of the following year. This is
expected behavior, often used deliberately, but surprising if you
weren't counting on it.
