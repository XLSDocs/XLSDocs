## Return value

The day of the month as a whole number from 1 to 31.

## Description

DAY reads the day-of-month component straight out of a date's
underlying serial number — the last of the three basic date-part
functions alongside YEAR and MONTH. It's not to be confused with
WEEKDAY, which returns the day *of the week* rather than the day
*of the month*.

<Callout type="info">
  DAY and WEEKDAY are easy to mix up by name — DAY returns 1–31 (day
  within the month), while WEEKDAY returns 1–7 (day within the
  week). Reach for WEEKDAY specifically when the question is "is
  this a Monday," not "is this the 15th."
</Callout>

## Common errors

### #VALUE! — text Excel doesn't recognize as a date

<ExcelCode>{`DAY("not a date") → #VALUE!`}</ExcelCode>

The text needs to be something Excel can actually parse as a date.

### Confusing DAY with WEEKDAY

<ExcelCode>{`DAY(A2) → 15 (the 15th of the month, not a day-of-week number)`}</ExcelCode>

If the goal is "which day of the week is this," use WEEKDAY instead
of DAY.
