Return the number of days between `start_date` and `end_date`,
counted using a 360-day year — twelve 30-day months — rather than
real calendar days. Built for accounting calculations that follow
this convention.

## Return value

The number of days between `start_date` and `end_date`, on a
360-day-year, 30-day-month basis. If `start_date` is later than
`end_date`, the result is negative.

## Description

DAYS360 doesn't count real calendar days — it assumes every month
has exactly 30 days and every year has 360, a long-standing
accounting convention (sometimes called "30/360") for computing
bond interest and loan amortization schedules without the irregular
month lengths of a real calendar getting in the way.

<ExcelCode>{`=DAYS360("1-Jan-2011", "31-Dec-2011") → 360 (a full 360-day year)`}</ExcelCode>

<Callout type="warn">
  **The `method` argument changes how a day-31 date is handled.**
  Under the European method (`TRUE`), any start or end date on the
  31st is simply treated as the 30th. Under the U.S. (NASD) method
  (the default), the rule is more involved: if `end_date` is the
  last day of its month and `start_date` is before the 30th,
  `end_date` is treated as the 1st of the *following* month instead
  of the 30th of its own.
</Callout>

## Common errors

### Results don't match a real calendar-day count

<ExcelCode>{`DAYS360(start, end) ≠ DAYS(end, start) (for most date pairs)`}</ExcelCode>

Not a bug — DAYS360 deliberately counts on a 30-day-month, 360-day-year
basis. Use DAYS for an ordinary calendar day count instead.

  <CodeBlockTab value="Python">
    ```python lineNumbers
    from datetime import date

    # A simplified European-method implementation — the U.S./NASD
    # method has additional end-of-month edge cases not shown here.
    def days360_european(start, end):
        d1 = min(start.day, 30)
        d2 = min(end.day, 30)
        return (end.year - start.year) * 360 + (end.month - start.month) * 30 + (d2 - d1)

    result = days360_european(date(2011, 1, 15), date(2011, 4, 15))
    print(result)  # 90 — three clean 30-day months, no end-of-month edge case
    ```
