Pull the month out of a date as a number from 1 to 12 — useful for
grouping data by month, or comparing the month component of two
dates regardless of year.

## Return value

The month as a whole number from 1 (January) to 12 (December).

## Description

MONTH reads the month component straight out of a date's underlying
serial number. It always returns a plain number, never a month
name — pair it with `TEXT(date, "mmmm")` if a display string like
"January" is what's actually needed.

<Callout type="info">
  MONTH ignores the year entirely, which makes it useful for
  seasonal comparisons — checking whether two dates fall in the same
  month regardless of which year each one is in:
  `MONTH(A2) = MONTH(B2)`.
</Callout>

## Common errors

### #VALUE! — text Excel doesn't recognize as a date

<ExcelCode>{`MONTH("not a date") → #VALUE!`}</ExcelCode>

The text needs to be something Excel can actually parse as a date.

### Expecting a month name instead of a number

<ExcelCode>{`MONTH(A2) → 1 (not "January")`}</ExcelCode>

MONTH always returns a number — use TEXT for a display name:

<ExcelCode>{`TEXT(A2, "mmmm")`}</ExcelCode>
