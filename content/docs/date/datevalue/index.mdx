Convert text that looks like a date — but isn't actually a date
value yet — into the real serial number Excel uses internally for
dates. The standard fix for a column of "dates" imported as plain
text that formulas like YEAR or EDATE otherwise can't touch.

## Return value

The date serial number corresponding to `date_text` — the same
number a genuine date value would have, just derived from parsing
text instead.

## Description

Data imported from another system often arrives as text that merely
*resembles* a date, rather than a real date value — a cell might
display `"1/15/2026"` but fail every date-aware formula, because
Excel still treats it as a string. DATEVALUE bridges that gap: it
parses recognizable date text and returns the equivalent serial
number, which can then be formatted to display as a date, or fed
into YEAR, EDATE, or any other date function.

<Callout type="warn">
  DATEVALUE returns a **plain number**, not something that
  automatically displays as a date — a cell showing `46037` instead
  of a recognizable date just needs a date number format applied.
  The underlying value is correct either way; only the display
  format is missing.
</Callout>

## Common errors

### Result displays as a number instead of a date

<ExcelCode>{`DATEVALUE("1/15/2026") → 46037 (correct, just needs a date format applied)`}</ExcelCode>

Not an error — apply a date number format to the cell to see it
displayed as a date instead of a raw serial number.

### #VALUE! — text Excel can't parse as a date

<ExcelCode>{`DATEVALUE("not a date") → #VALUE!`}</ExcelCode>

The text has to be in a format Excel actually recognizes as a date —
check regional date settings if a format that looks reasonable is
still failing (day/month order varies by locale).

### Losing the time portion of a combined date-and-time string

<ExcelCode>{`DATEVALUE("1/15/2026 2:30 PM") → 46037 (the date only, time is dropped)`}</ExcelCode>

DATEVALUE discards any time component entirely. Use TIMEVALUE
separately on the same text, and add the two results together, if
both the date and time need to be preserved.
