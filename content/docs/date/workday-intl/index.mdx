Find the date that's a given number of working days away from a
start date, using a **customizable weekend** — Friday/Saturday,
Sunday-only, or any other pattern, instead of `WORKDAY`'s fixed
Saturday/Sunday.

## Return value

The date that is `days` working days after (or before, if negative)
`start_date`, skipping the days marked as weekend and any dates
listed in `holidays`.

## Description

WORKDAY.INTL solves the one real limitation of plain `WORKDAY`: a
weekend that's always Saturday/Sunday. Many businesses run on a
different schedule — Friday/Saturday off in parts of the Middle East,
Sunday-only for a six-day work week — and WORKDAY.INTL's `weekend`
argument covers both common presets and fully custom patterns.

The preset codes:

| Code | Weekend days |
| --- | --- |
| 1 (default) | Saturday, Sunday |
| 2 | Sunday, Monday |
| 3 | Monday, Tuesday |
| 4 | Tuesday, Wednesday |
| 5 | Wednesday, Thursday |
| 6 | Thursday, Friday |
| 7 | Friday, Saturday |
| 11 | Sunday only |
| 12 | Monday only |
| 13 | Tuesday only |
| 14 | Wednesday only |
| 15 | Thursday only |
| 16 | Friday only |
| 17 | Saturday only |

For anything else — like a genuinely irregular schedule — pass a
7-character string of `1`s and `0`s starting Monday, where `1` marks
a non-workday: `"0000011"` is the default Saturday/Sunday weekend
written out explicitly.

<Callout type="info">
  `weekend` sits **between** `days` and `holidays` — different
  argument order than plain WORKDAY, where `holidays` is the third
  argument. Omitting `weekend` (passing nothing, not `""`) falls back
  to the standard Saturday/Sunday weekend.
</Callout>

## Common errors

### #NUM! — invalid weekend code

<ExcelCode>{`WORKDAY.INTL(A2, 10, 8) → #NUM! (8 isn't a valid preset code)`}</ExcelCode>

Only `1`–`7` and `11`–`17` are valid preset codes — anything else
needs to be a 7-character `1`/`0` string instead.

### Forgetting the argument shifted position

<ExcelCode>{`WORKDAY.INTL(A2, 10, HolidayList) → treats the holiday range as an invalid weekend code`}</ExcelCode>

Unlike WORKDAY, `weekend` comes third and `holidays` comes fourth —
skip a weekend argument with nothing (not by moving holidays up):

<ExcelCode>{`WORKDAY.INTL(A2, 10, 1, HolidayList)`}</ExcelCode>
