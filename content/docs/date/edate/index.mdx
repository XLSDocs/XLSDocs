Shift a date forward or backward by a whole number of months —
handling month-length differences automatically, so you don't have
to work out how many days are in each month yourself.

## Return value

A date serial number that is `months` months after `start_date`
(or before it, if `months` is negative), keeping the same day of
the month where possible.

## Description

EDATE keeps the same day-of-month when shifting by whole months —
`EDATE(DATE(2027,1,15), 1)` lands on February 15, not "January 15
plus roughly 30 days." When the target month is shorter than
`start_date`'s day would allow (like shifting January 31 forward one
month, into February), EDATE lands on the last valid day of that
month instead of overflowing into the next one.

<Callout type="warn">
  `EDATE(start_date, 1)` adds one **month**, not one day — a common
  mixup with plain arithmetic like `start_date + 1`, which adds a
  single day instead.
</Callout>

## Common errors

### End-of-month rollover confusion

<ExcelCode>{`EDATE(DATE(2027,1,31), 1) → February 28, 2027, not March 3`}</ExcelCode>

February doesn't have 31 days, so EDATE lands on its last valid day
instead of overflowing into March. This is expected, but easy to
mistake for a bug the first time you see it.

### #NUM! — invalid start_date or extreme result

<ExcelCode>{`EDATE("not a date", 1) → #NUM!`}</ExcelCode>

`start_date` must be a genuine date value, and the resulting date
must fall within Excel's supported range.
