Pull the hour out of a time value as a plain number from 0 to 23 —
the time-of-day equivalent of YEAR, MONTH, and DAY, for splitting a
timestamp apart instead of a calendar date.

## Return value

The hour as a whole number from `0` to `23`, using a 24-hour clock —
never a 12-hour value with a separate AM/PM indicator.

## Description

Excel stores a time as the fractional part of a date serial number —
`0.5` is noon, `0.75` is 6:00 PM, and so on across a full day. HOUR
reads that fraction back out as a 24-hour-clock number. It works the
same way whether the cell holds a pure time value or a full
date-and-time timestamp — HOUR only ever looks at the time portion,
ignoring any date attached to it.

<Callout type="info">
  HOUR always returns a 24-hour value — `2:30 PM` returns `14`, not
  `2`. To display a 12-hour hour with AM/PM instead, use a custom
  number format like `"h AM/PM"` on the cell rather than trying to
  convert HOUR's result manually.
</Callout>

## Common errors

### Expecting a 12-hour result

<ExcelCode>{`HOUR("2:30 PM") → 14 (not 2)`}</ExcelCode>

HOUR is always 24-hour. If a 12-hour number is genuinely needed for
display, use `MOD(HOUR(time) - 1, 12) + 1` to convert, or better,
apply a 12-hour number format to the original time cell instead of
reconstructing it from HOUR's result.

### #VALUE! — text Excel doesn't recognize as a time

<ExcelCode>{`HOUR("not a time") → #VALUE!`}</ExcelCode>

The text needs to be something Excel can actually parse as a time —
check the source data isn't stored as unconverted plain text.
