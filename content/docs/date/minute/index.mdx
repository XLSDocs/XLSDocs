## Return value

The minute as a whole number from `0` to `59`.

## Description

MINUTE reads the minute component straight out of a time's
underlying serial fraction, the same way HOUR reads the hour and
SECOND reads the second. It works identically on a pure time value
or the time portion of a full date-and-time timestamp.

<Callout type="info">
  MINUTE only ever returns `0`–`59` — there's no rollover into the
  hour to worry about. A time like `2:75 PM` doesn't exist as valid
  input; Excel would already have normalized it to `3:15 PM` before
  MINUTE ever sees it.
</Callout>

## Common errors

### #VALUE! — text Excel doesn't recognize as a time

<ExcelCode>{`MINUTE("not a time") → #VALUE!`}</ExcelCode>

The text needs to be something Excel can actually parse as a time —
check the source data isn't stored as unconverted plain text.

### Expecting MINUTE to account for the hour

<ExcelCode>{`MINUTE("2:30 PM") → 30 (just the minute — HOUR("2:30 PM") separately gives 14)`}</ExcelCode>

MINUTE only reports the minute component in isolation — combine it
with HOUR separately if a formula needs both pieces together.
