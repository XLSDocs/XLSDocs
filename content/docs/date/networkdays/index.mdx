Count the number of working days between two dates — weekends
excluded automatically, holidays excluded if a list is supplied. The
standard way to calculate a real project deadline or delivery
estimate that skips non-working days.

## Return value

The count of weekdays (Monday–Friday) between `start_date` and
`end_date`, inclusive of both endpoints, minus any dates that appear
in `holidays`.

## Description

NETWORKDAYS answers "how many actual business days are between these
two dates" — the calculation behind realistic project timelines and
delivery estimates, as opposed to a raw calendar-day subtraction that
would incorrectly count weekends as working time.

<Callout type="warn">
  Weekends are hardcoded to Saturday and Sunday — there's no
  argument to change that. For a business that operates on a
  different weekly schedule (e.g. Friday/Saturday off instead of
  Saturday/Sunday), use `NETWORKDAYS.INTL` instead, which adds a
  `weekend` argument to customize which days don't count.
</Callout>

## Common errors

### Off-by-one from expecting an exclusive count

<ExcelCode>{`NETWORKDAYS(DATE(2027,1,4), DATE(2027,1,8)) → 5 (both endpoints included)`}</ExcelCode>

Both `start_date` and `end_date` count as working days if they fall
on weekdays — this isn't a bug, but it does mean the result is one
higher than a naive "days between" calculation might expect.

### Holidays not actually excluded

<ExcelCode>{`NETWORKDAYS(A2, B2, "12/25/2027") → holiday not excluded (text, not a real date range)`}</ExcelCode>

`holidays` needs to reference real date cells or values, not text —
and every holiday date needs to actually fall within
`start_date`/`end_date` to matter.
