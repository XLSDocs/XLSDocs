## Return value

A number representing the day of the week, in whichever numbering
scheme `return_type` selects.

## Description

WEEKDAY converts a date into a number representing which day of the
week it falls on. The numbering scheme is the single biggest source
of confusion — the default (`return_type` omitted or `1`) treats
**Sunday as day 1**, not Monday, which is the opposite of what most
people expect from a "day of the week" number.

<Callout type="warn">
  If a formula needs Monday to be day 1 (common outside the US, and
  in most business-day logic), pass `2` as `return_type`:
  `WEEKDAY(A2, 2)`. The default scheme (`1`, Sunday=1) is easy to use
  by accident and silently produce off-by-one weekend logic.
</Callout>

## Common errors

### Weekend logic is off by one day

<ExcelCode>{`IF(WEEKDAY(A2)=1, "Weekend", "Weekday") → wrong (treats only Sunday as weekend)`}</ExcelCode>

Checking `WEEKDAY(A2)=1` alone only catches Sunday. A real weekend
check needs both ends of the default numbering:

<ExcelCode>{`IF(OR(WEEKDAY(A2)=1, WEEKDAY(A2)=7), "Weekend", "Weekday")`}</ExcelCode>

### Assuming Monday is day 1 without setting return_type

<ExcelCode>{`WEEKDAY(A2) → 2 for a Monday, not 1`}</ExcelCode>

The default scheme makes Monday day **2** (Sunday is 1) — pass `2`
as `return_type` if the formula's logic assumes Monday is day 1.
