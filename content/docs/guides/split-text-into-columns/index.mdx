Splitting "Smith, John" into separate first- and last-name columns,
or breaking a "City, State ZIP" string apart, comes up constantly
with imported or pasted data. There's a modern formula, a classic
wizard, and a manual fallback — pick based on whether the source data
changes.

## A live formula: TEXTSPLIT

<ExcelCode>{`=TEXTSPLIT(A2, ", ")`}</ExcelCode>

[TEXTSPLIT](/docs/text/textsplit) spills the pieces of `A2` into
separate cells automatically, using `", "` as the delimiter. Change
`A2` and the split result updates on its own — no re-running anything.

## A one-time pass: Text to Columns

For a genuinely one-time cleanup where a live formula isn't needed,
**Data → Data Tools → Text to Columns** walks through a wizard:
choose Delimited or Fixed Width, pick the delimiter, and Excel splits
the selected column into however many columns the result needs —
directly into static values, not a formula.

<Callout type="warn">
  **Text to Columns overwrites the columns to its right** unless
  there's enough empty space already there — it isn't a formula, so
  it doesn't ask before replacing whatever's already in those cells.
  TEXTSPLIT, by contrast, spills into blank cells and throws a
  catchable `#SPILL!` instead of silently overwriting anything.
</Callout>

## Manual extraction: LEFT, RIGHT, MID, and FIND

Before TEXTSPLIT existed (any version before Excel 365), the manual
equivalent combines position-finding with text extraction:

<ExcelCode>{`=LEFT(A2, FIND(",", A2) - 1)          ' everything before the comma
=TRIM(MID(A2, FIND(",", A2) + 1, 100)) ' everything after it, trimmed`}</ExcelCode>

[FIND](/docs/text/find) locates the delimiter's position, and
[LEFT](/docs/text/left) / [MID](/docs/text/mid) extract the text
before or after it. This is the version-compatible fallback when
TEXTSPLIT isn't available.
