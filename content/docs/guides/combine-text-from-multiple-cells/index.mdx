Combining a first and last name, or building a full address from
separate columns, can be done three ways in Excel. They all join
text — the differences show up around separators and blank cells.

<TemplateDownload slug="combine-text-from-multiple-cells" />

## The & operator

<ExcelCode>{`=A2 & " " & B2`}</ExcelCode>

The plain `&` operator joins any number of values with no function
call at all — simple, and it works in every Excel version. Any
separator (a space, a comma, a line break) has to be typed in by hand
between each piece.

## CONCAT

<ExcelCode>{`=CONCAT(A2:C2)`}</ExcelCode>

[CONCAT](/docs/text/concat) does the same join, but accepts a whole
range directly instead of listing cells one by one with `&` — useful
once there are more than two or three pieces to combine. It still
inserts **no separator** between items.

## TEXTJOIN

<ExcelCode>{`=TEXTJOIN(", ", TRUE, A2:C2)`}</ExcelCode>

[TEXTJOIN](/docs/text/textjoin) adds two things neither `&` nor
CONCAT has: a `delimiter` inserted **between every item**, and an
`ignore_empty` switch that skips blank cells automatically instead of
leaving a double-comma or stray separator where one was.

<Callout type="idea">
  **TEXTJOIN's `ignore_empty` argument is the real reason to reach
  for it** over CONCAT — joining a range where some cells are blank
  (a missing middle name, an optional address line 2) with `&` or
  CONCAT leaves visible gaps or doubled separators; TEXTJOIN with
  `ignore_empty` set to `TRUE` collapses them cleanly.
</Callout>

## Which one to use

- **`&`** — two or three pieces, no separator needed, maximum
  compatibility.
- **CONCAT** — a whole range, still no separator needed.
- **TEXTJOIN** — a separator between items, or any blank cells that
  need to be skipped rather than leaving a gap.
