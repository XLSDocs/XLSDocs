## Return value

The square root of `inumber`, as text in `x + yi`/`x + yj` form.

## Description

IMSQRT converts `inumber` to polar form (a magnitude via
[IMABS](/docs/engineering/imabs) and an angle via
[IMARGUMENT](/docs/engineering/imargument)), takes the square root of
the magnitude and halves the angle, then converts back — exactly the
same computation [IMPOWER](/docs/engineering/impower) would do with a
`number` argument of `0.5`. IMSQRT exists as its own function purely
for convenience, the same way [SQRT](/docs/math/sqrt) is a dedicated
shorthand for `POWER(n, 0.5)`.

<Callout type="check">
  `3+4i` has an exact, whole-number square root: `2+i`. This isn't a
  coincidence — `3+4i` and `2+i` are related the same way a
  Pythagorean triple like `3-4-5` is: `(2+i)² = 4 + 4i + i² = 3 + 4i`,
  since `i² = -1` turns the `4` into a `3`. Most complex square roots
  come out messy; this input was picked because it doesn't.
</Callout>

`IMSQRT("3+4i")` returns exactly `2+i` — squaring `2+i` gives back
`3+4i` exactly, confirming the round trip. The pure imaginary unit
`"i"` gives `0.7071+0.7071i` (that is, `√2/2` in both parts) — squaring
this also returns exactly to `i`.

## Common errors

### #NUM! — text that isn't a valid complex number

<ExcelCode>{`IMSQRT("hello") → #NUM!`}</ExcelCode>

`inumber` has to be parseable as `x + yi`/`x + yj` text (or a plain
number). Text that doesn't match that pattern at all returns `#NUM!`.

### Expecting a negative real input to error, the way SQRT does

<ExcelCode>{`IMSQRT(-4) → 2i, NOT #NUM! — unlike ordinary SQRT(-4)`}</ExcelCode>

Ordinary `SQRT` can't handle negative numbers and returns `#NUM!`
instead. IMSQRT has no such restriction — a negative real number's
square root is a purely imaginary number (`√-4 = 2i`), which IMSQRT
computes directly instead of erroring.

### Forgetting IMSQRT and IMPOWER(z, 0.5) are the exact same operation

<ExcelCode>{`IMSQRT("3+4i") and IMPOWER("3+4i", 0.5) both return exactly 2+i`}</ExcelCode>

There's no mathematical difference between the two — IMSQRT is purely
a shorter way to write the specific case of IMPOWER where the exponent
is `0.5`, not a separately-computed operation.
