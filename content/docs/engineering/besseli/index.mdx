Evaluate the modified Bessel function of the first kind, order `N`, at
`X` — equivalent to [BESSELJ](/docs/engineering/besselj) evaluated for
a purely imaginary argument, which flips its oscillating behavior into
exponential growth instead.

## Return value

The value of the order-`N` modified Bessel function of the first kind,
evaluated at `X`.

## Description

BESSELI is what you get from
[BESSELJ](/docs/engineering/besselj)'s formula if `x` is replaced with
a purely imaginary number — the alternating signs in BESSELJ's
underlying series cancel out, turning oscillation into steady
exponential growth. Where `J_n(x)` bounces between positive and
negative like a decaying wave, `I_n(x)` only ever grows larger as `x`
increases (for `x > 0`), the same qualitative difference `cosh`/`sinh`
have from `cos`/`sin`.

<Callout type="check">
  Bessel functions of different orders aren't independent — they
  satisfy the recurrence `I_{n-1}(x) − I_{n+1}(x) = (2n/x)·I_n(x)`. At
  `x=1.9, n=1`: `I_0(1.9) − I_2(1.9) = 2.1277 − 0.6033 = 1.5244`, and
  `(2/1.9)·I_1(1.9) = (2/1.9)×1.4482 = 1.5245` (small rounding from
  the 4-decimal display) — the same value either way, a genuine
  mathematical identity.
</Callout>

At a fixed `X` of `1.9`, notice every value is comfortably larger than
the equivalent [BESSELJ](/docs/engineering/besselj) result at the same
`X` and order — `BESSELI(1.9, 0)` is `2.1277` versus
`BESSELJ(1.9, 0)`'s `0.2818` — a direct consequence of growing
exponentially rather than oscillating.

## Common errors

### #NUM! — N is negative

<ExcelCode>{`BESSELI(1.9, -1) → #NUM!`}</ExcelCode>

The order `N` must be `0` or greater. A negative order returns
`#NUM!`.

### #VALUE! — X or N is nonnumeric

<ExcelCode>{`BESSELI("x", 2) → #VALUE!`}</ExcelCode>

Both arguments must be actual numbers — text that can't be interpreted
as one returns `#VALUE!`.

### Expecting BESSELI to oscillate like BESSELJ does

<ExcelCode>{`BESSELI(5, 0) is a large positive number (~27.24), not a value between -1 and 1`}</ExcelCode>

It's easy to expect any "Bessel function" to behave like BESSELJ —
bounded and wave-like. BESSELI grows without bound as `X` increases;
don't be surprised by a large result.
