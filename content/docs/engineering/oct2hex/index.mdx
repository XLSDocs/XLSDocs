Convert an octal number directly to hexadecimal — the reverse of
`HEX2OCT`, and the last function in this conversion family.

## Return value

The hexadecimal equivalent of `number`, as text — padded to `places`
characters if supplied and the result is positive.

## Description

Unlike `HEX2OCT` and `OCT2BIN`/`HEX2BIN`, OCT2HEX doesn't have a
narrower output range to worry about — octal's 30-bit range comfortably
fits within hexadecimal's wider 40-bit range, so every valid
10-character octal input converts cleanly.

<Callout type="idea">
  `OCT2HEX` is functionally identical to chaining `OCT2DEC` into
  `DEC2HEX` — it exists purely as a convenience so the intermediate
  decimal value never needs its own cell.
</Callout>

## Try it

<TryIt
  data={{ '10': '8', '32': '1A', '377': 'FF', '7777777773': 'FFFFFFFFFB' }}
  defaultValue="32"
  label={'Live preview — =OCT2HEX({number})'}
  fieldLabel="number"
/>

`OCT2HEX(32)` returns `1A` — the same value `DEC2HEX(26)` would give.
`OCT2HEX(7777777773)`, the 10-character two's-complement octal form of
-5, returns the full 10-character `FFFFFFFFFB`.

## Common errors

### #NUM! — number isn't valid octal, or has more than 10 characters

`number` can only contain the digits `0` through `7`, and can be at
most 10 characters long.

### #NUM! — places is too small for the result

<ExcelCode>{`OCT2HEX(377, 1) → #NUM!, since "FF" needs 2 characters`}</ExcelCode>

`places` must be large enough to hold every digit of the actual
result — it can only pad with extra leading zeros, never truncate.
