Add together 1 to 255 complex numbers, each written as text in `x +
yi` (or `x + yj`) form — real coefficients combine with real, and
imaginary coefficients combine with imaginary.

## Return value

The sum of all supplied complex numbers, as text in `x + yi`/`x + yj`
form.

## Description

IMSUM adds complex numbers the way complex addition actually works:
real parts add to real parts, and imaginary parts add to imaginary
parts, independently — `(a + bi) + (c + di) = (a+c) + (b+d)i`. It
accepts anywhere from 1 to 255 arguments, so it can total up a whole
range of complex numbers in one call, not just two at a time.

<Callout type="warn">
  Every argument must use the **same** suffix. `IMSUM("3+4i", "1-2j")`
  — one `i`, one `j` — returns `#VALUE!` rather than silently picking
  one convention. Mixing suffixes anywhere in a chain of complex-number
  formulas is one of the most common ways this whole function family
  breaks.
</Callout>

`IMSUM("3+4i", "1-2i")` returns `4+2i` — the real parts `3` and `1` add
to `4`, and the imaginary parts `4` and `-2` add to `2`. Adding the
pure imaginary unit `"i"` (that is, `"0+1i"`) only affects the
imaginary side, giving `3+5i`.

## Common errors

### #VALUE! — mismatched suffixes across arguments

<ExcelCode>{`IMSUM("3+4i", "1-2j") → #VALUE! — one argument uses "i", the other uses "j"`}</ExcelCode>

Every complex number passed to IMSUM has to use the same suffix
throughout the whole call. Pick one convention (usually whichever the
rest of the sheet already uses) and stick with it.

### #NUM! — an argument that isn't a valid complex number

<ExcelCode>{`IMSUM("3+4i", "hello") → #NUM!`}</ExcelCode>

Every argument has to be parseable as `x + yi`/`x + yj` text (or a
plain number). Text that doesn't match that pattern at all returns
`#NUM!`.

### Trying to add complex numbers with the + operator directly

<ExcelCode>{`"3+4i" + "1-2i" → #VALUE! — Excel can't add two text strings with +`}</ExcelCode>

Since complex numbers are stored as text, the ordinary `+` operator
can't combine them the way it combines actual numbers — IMSUM exists
specifically because plain arithmetic operators don't understand this
text format at all.
