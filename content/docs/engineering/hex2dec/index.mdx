and the most commonly useful conversion in this family since hex
values (color codes, memory addresses) show up constantly in
technical work.

## Return value

The decimal equivalent of `number`.

## Description

HEX2DEC reads `number` as a base-16 value and returns its decimal
equivalent. A full 10-character hexadecimal value whose leftmost
hex digit is 8 or higher (meaning its leading bit is 1) is
interpreted as negative, using the same 40-bit two's-complement
convention `DEC2HEX` uses to produce negative results.

<Callout type="idea">
  Hex is the most practically useful conversion base of the whole
  family — HEX2DEC is the function to reach for when a color code, a
  memory address, or any other hex value from outside Excel needs to
  become an ordinary number for calculation.
</Callout>

## Try it

<TryIt
  data={{ '8': '8', '1A': '26', 'FF': '255', 'FFFFFFFFFB': '-5' }}

  label={'Live preview — =HEX2DEC({number})'}
  fieldLabel="number"

`HEX2DEC(FF)` returns 255 — a single byte's maximum value.
`HEX2DEC(FFFFFFFFFB)`, a full 10-character hex value starting with
`F` (≥ 8), returns **-5**, not a huge positive number.

## Common errors

### #NUM! — number isn't valid hexadecimal, or has more than 10 characters

<ExcelCode>{`HEX2DEC(GG) → #NUM!`}</ExcelCode>

`number` can only contain the digits `0-9` and letters `A-F`, and can
be at most 10 characters long.

### Expecting a negative result from any hex digit 8 or higher

<ExcelCode>{`HEX2DEC(FF) → 255, not negative — only a FULL 10-character hex value triggers two's-complement`}</ExcelCode>

A short hex value with a high leading digit is still an ordinary
positive number — the two's-complement sign rule only applies once
the value reaches its full 10-character width.
