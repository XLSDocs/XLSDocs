Convert a binary number (up to 10 digits) directly to octal — the
same two's-complement rules as every other function in this
conversion family.

## Return value

The octal equivalent of `number`, as text — padded to `places`
characters if supplied and the result is positive.

## Description

BIN2OCT converts directly from base 2 to base 8. Because 8 is a power
of 2 (2³), binary and octal digits actually line up cleanly in groups
of three — every octal digit corresponds to exactly 3 binary digits,
which is part of why octal was historically popular as a more compact
stand-in for binary in early computing.

<Callout type="idea">
  `BIN2OCT` is functionally identical to chaining `BIN2DEC` into
  `DEC2OCT` — it exists purely as a convenience so the intermediate
  decimal value never needs its own cell.
</Callout>

## Try it

<TryIt
  data={{ '1000': '10', '11010': '32', '11111111': '377', '1111111011': '7777777773' }}
  defaultValue="11010"
  label={'Live preview — =BIN2OCT({number})'}
  fieldLabel="number"
/>

`BIN2OCT(11010)` returns `32` — the same value `DEC2OCT(26)` would
give. `BIN2OCT(1111111011)` returns a full 10-character `7777777773`,
the two's-complement octal representation of -5.

## Common errors

### #NUM! — number isn't valid binary, or has more than 10 digits

`number` can only contain the digits `0` and `1`, and can be at most
10 digits long.

### #NUM! — places is too small for the result

<ExcelCode>{`BIN2OCT(11111111, 2) → #NUM!, since "377" needs 3 characters`}</ExcelCode>

`places` must be large enough to hold every digit of the actual
result — it can only pad with extra leading zeros, never truncate.
