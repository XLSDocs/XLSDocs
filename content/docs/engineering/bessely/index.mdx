## Return value

The value of the order-`N` Bessel function of the second kind,
evaluated at `X`.

## Description

Bessel's differential equation, like most second-order differential
equations, has **two** independent solutions —
[BESSELJ](/docs/engineering/besselj) is one, and BESSELY is the other.
Both oscillate and decay in amplitude as `X` grows, similar in overall
shape, but they're out of step with each other (analogous to how sine
and cosine both oscillate but are offset from one another). Unlike
BESSELJ, BESSELY's formula includes a logarithm term, which is why it
diverges to negative infinity as `X` approaches `0` — a full physical
solution generally needs a specific *mix* of both BESSELJ and BESSELY
to match whatever boundary conditions the actual problem has.

<Callout type="check">
  Bessel functions of different orders aren't independent — they
  satisfy the recurrence `Y_{n-1}(x) + Y_{n+1}(x) = (2n/x)·Y_n(x)`. At
  `x=1.9, n=1`: `Y_0(1.9) + Y_2(1.9) = 0.4968 + (-0.6699) = -0.1731`,
  and `(2/1.9)·Y_1(1.9) = (2/1.9)×(-0.1644) = -0.1731` — the same value
  either way, the same identity BESSELJ satisfies.
</Callout>

At a fixed `X` of `1.9`, BESSELY's values swing between positive and
negative across orders, similar in spirit to
[BESSELJ](/docs/engineering/besselj)'s own oscillation — but the
specific values are different, since BESSELY and BESSELJ are
genuinely independent solutions, not scaled copies of each other.

## Common errors

### #NUM! — X is zero or negative

<ExcelCode>{`BESSELY(0, 1) → #NUM!`}</ExcelCode>

Unlike BESSELJ, BESSELY requires `X` to be strictly greater than `0` —
its formula includes a logarithm term that diverges at `X = 0` and is
undefined for negative `X`.

### #NUM! — N is negative

<ExcelCode>{`BESSELY(1.9, -1) → #NUM!`}</ExcelCode>

The order `N` must be `0` or greater. A negative order returns
`#NUM!`.

### #VALUE! — X or N is nonnumeric

<ExcelCode>{`BESSELY("x", 2) → #VALUE!`}</ExcelCode>

Both arguments must be actual numbers — text that can't be interpreted
as one returns `#VALUE!`.
