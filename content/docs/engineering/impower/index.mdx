Raise a complex number to a power — the complex-number equivalent of
[POWER](/docs/math/power), accepting integer, fractional, or negative
exponents.

## Return value

`inumber` raised to `number`, as text in `x + yi`/`x + yj` form.

## Description

IMPOWER works by converting `inumber` to **polar form** (a magnitude
via [IMABS](/docs/engineering/imabs) and an angle via
[IMARGUMENT](/docs/engineering/imargument)), raising the magnitude to
`number` and multiplying the angle by `number`, then converting back —
`r^n · (cos(nθ) + i·sin(nθ))`. This works uniformly whether `number` is
a whole number (repeated multiplication), a negative number (a
reciprocal), or a fraction (a root) — unlike
[IMPRODUCT](/docs/engineering/improduct), which can only multiply a
complex number by itself a whole number of times.

## Try it

<TryIt
  data={{ '2': '-7+24i', '0.5': '2+i', '-1': '0.12-0.16i' }}
  defaultValue="2"
  label={'Live preview — =IMPOWER("3+4i", {value})'}
  fieldLabel="number"
/>

`IMPOWER("3+4i", 2)` returns `-7+24i` — the same result
[IMPRODUCT](/docs/engineering/improduct) would give for `"3+4i"`
multiplied by itself. A `number` of `0.5` gives exactly `2+i` — the
same answer [IMSQRT](/docs/engineering/imsqrt) gives for this input,
since a square root **is** raising to the power `0.5`. A `number` of
`-1` gives the reciprocal, `0.12-0.16i`, the same value
[IMDIV](/docs/engineering/imdiv) computes for `1` divided by `"3+4i"`.

## Common errors

### #VALUE! — number is nonnumeric

<ExcelCode>{`IMPOWER("3+4i", "two") → #VALUE!`}</ExcelCode>

`number` must be an actual number — text that can't be interpreted as
one returns `#VALUE!`.

### #NUM! — inumber isn't a valid complex number

<ExcelCode>{`IMPOWER("hello", 2) → #NUM!`}</ExcelCode>

`inumber` has to be parseable as `x + yi`/`x + yj` text (or a plain
number). Text that doesn't match that pattern at all returns `#NUM!`.

### Assuming IMPOWER only works for whole-number exponents

<ExcelCode>{`IMPOWER("3+4i", 0.5) → 2+i, a perfectly valid fractional power — not an error`}</ExcelCode>

Unlike repeated multiplication with
[IMPRODUCT](/docs/engineering/improduct), which only makes sense for
whole numbers, IMPOWER's polar-form approach handles fractional and
negative exponents just as naturally as whole ones.
