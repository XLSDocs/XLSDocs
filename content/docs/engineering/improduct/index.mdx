## Return value

The product of all supplied complex numbers, as text in `x + yi`/`x +
yj` form.

## Description

IMPRODUCT multiplies complex numbers using the same distribution rule
as multiplying two binomials: `(a + bi)(c + di) = (ac - bd) + (ad +
bc)i`. The `-bd` term is easy to forget — since `i × i = -1`, the
product of the two imaginary parts flips sign and merges into the
*real* part of the result, not the imaginary part. It accepts anywhere
from 1 to 255 arguments, multiplying them all together in one call.

<Callout type="warn">
  Multiplying complex numbers is **not** the same as multiplying their
  real parts together and their imaginary parts together separately.
  `IMPRODUCT("3+4i", "5-3i")` isn't `(3×5) + (4×-3)i = 15-12i` — it's
  `27+11i`, because the cross-terms (`ad` and `bc`) and the `i × i =
  -1` flip both have to be accounted for.
</Callout>

`IMPRODUCT("3+4i", "1-2i")` returns `11-2i` — worked out as `(3×1 -
4×-2) + (3×-2 + 4×1)i = (3+8) + (-6+4)i = 11-2i`. Multiplying by the
pure imaginary unit `"i"` rotates the number a quarter turn on the
complex plane, turning `3+4i` into `-4+3i`.

## Common errors

### #VALUE! — mismatched suffixes across arguments

<ExcelCode>{`IMPRODUCT("3+4i", "1-2j") → #VALUE! — one argument uses "i", the other uses "j"`}</ExcelCode>

Every complex number passed to IMPRODUCT has to use the same suffix
throughout the whole call.

### #NUM! — an argument that isn't a valid complex number

<ExcelCode>{`IMPRODUCT("3+4i", "hello") → #NUM!`}</ExcelCode>

Every argument has to be parseable as `x + yi`/`x + yj` text (or a
plain number). Text that doesn't match that pattern at all returns
`#NUM!`.

### Multiplying real and imaginary parts separately

<ExcelCode>{`IMPRODUCT("3+4i", "5-3i") → 27+11i, NOT 15-12i — cross-terms and i² = -1 both matter`}</ExcelCode>

Complex multiplication distributes across all four term-pairs, and the
`i × i` term flips sign into the real part — treating it like
elementwise multiplication of the real and imaginary coefficients
gives a completely wrong answer.
