## Return value

The decimal equivalent of `number`.

## Description

OCT2DEC reads `number` as a base-8 value and returns its decimal
equivalent. A full 10-character octal value whose leftmost digit is 4
or higher (meaning its leading bit is 1) is interpreted as negative,
using the same 30-bit two's-complement convention `DEC2OCT` uses to
produce negative results.

<Callout type="idea">
  `OCT2DEC` and `HEX2DEC` solve the same underlying problem for a
  different base — both exist for the same reason: converting a value
  that arrived in a non-decimal format (from outside Excel, or from
  another one of these conversion functions) back into an ordinary
  number that can be calculated with directly.
</Callout>

## Try it

<TryIt
  data={{ '10': '8', '32': '26', '377': '255', '7777777773': '-5' }}

  label={'Live preview — =OCT2DEC({number})'}
  fieldLabel="number"

`OCT2DEC(32)` returns 26. `OCT2DEC(7777777773)`, a full 10-character
octal value starting with `7` (≥ 4), returns **-5**, not a large
positive number.

## Common errors

### #NUM! — number isn't valid octal, or has more than 10 characters

<ExcelCode>{`OCT2DEC(89) → #NUM!, since 8 and 9 aren't valid octal digits`}</ExcelCode>

`number` can only contain the digits `0` through `7`, and can be at
most 10 characters long.

### Expecting a negative result from any leading digit 4 or higher

<ExcelCode>{`OCT2DEC(377) → 255, not negative — only a FULL 10-character octal value triggers two's-complement`}</ExcelCode>

A short octal value with a high leading digit is still an ordinary
positive number — the two's-complement sign rule only applies once
the value reaches its full 10-character width.
