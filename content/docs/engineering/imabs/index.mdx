Compute the absolute value, or modulus, of a complex number — the
straight-line distance from the origin to the point `(x, y)` on the
complex plane, using the same Pythagorean formula as a right triangle.

## Return value

The absolute value (modulus) of `inumber`, as a non-negative real
number.

## Description

For a complex number `x + yi`, IMABS computes `√(x² + y²)` — exactly
the same formula used to find the hypotenuse of a right triangle with
legs `x` and `y`. Geometrically, this is the distance from the origin
to the point the complex number represents on the complex plane, which
is why the result is always non-negative regardless of whether `x` or
`y` themselves are negative.

## Try it

<TryIt
  data={{ '3+4i': '5', '5+12i': '13', '8+6i': '10' }}
  defaultValue="3+4i"
  label={'Live preview — =IMABS("{value}")'}
  fieldLabel="inumber"
/>

`IMABS("3+4i")` returns `5` — the familiar 3-4-5 right triangle,
since `√(3² + 4²) = √25 = 5`. `"5+12i"` and `"8+6i"` are two more
whole-number ("Pythagorean triple") examples, giving `13` and `10`
respectively.

## Common errors

### #NUM! — text that isn't a valid complex number

<ExcelCode>{`IMABS("hello") → #NUM!`}</ExcelCode>

`inumber` has to be parseable as `x + yi`/`x + yj` text (or a plain
number). Text that doesn't match that pattern at all returns `#NUM!`.

### Expecting a negative result from a negative coefficient

<ExcelCode>{`IMABS("3-4i") → 5, not -5 — the result is always non-negative`}</ExcelCode>

Since IMABS measures a distance, the sign of `x` or `y` never carries
through to the result. `"3-4i"` and `"3+4i"` are different points on
the complex plane, but they're the same distance from the origin, so
IMABS returns the same magnitude for both.
