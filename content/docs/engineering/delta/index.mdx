Test whether two numbers are exactly equal, returning `1` if they
match and `0` if they don't — a plain numeric 1-or-0 flag, rather than
the `TRUE`/`FALSE` an ordinary `=` comparison would give.

## Return value

`1` if `number1` equals `number2`; `0` otherwise.

## Description

DELTA — also known as the Kronecker delta function in math and
physics — does exactly what the ordinary `=` comparison operator does,
except it returns a genuine **number** (`1` or `0`) instead of a
boolean (`TRUE`/`FALSE`). That makes it directly usable in arithmetic:
summing `DELTA` across a range of pairs counts how many of them are
equal, without needing `SUMPRODUCT` or an extra numeric coercion (like
multiplying a `TRUE`/`FALSE` result by `1`) to make an equality test
addable.

`DELTA(5, 5)` returns `1` — the two numbers match exactly. Anything
else, like `DELTA(5, 4)` or `DELTA(5, 0)`, returns `0`, since DELTA
only ever checks for exact equality, not closeness.

## Common errors

### #VALUE! — number1 or number2 is nonnumeric

<ExcelCode>{`DELTA("x", 5) → #VALUE!`}</ExcelCode>

Both arguments must be actual numbers — text that can't be interpreted
as one returns `#VALUE!`.

### Expecting DELTA to test "close enough" rather than exact equality

<ExcelCode>{`DELTA(5, 5.0001) → 0, not 1 — DELTA requires EXACT equality`}</ExcelCode>

DELTA doesn't do any rounding or tolerance — even a tiny difference
means `0`. This matters especially for values computed through a chain
of floating-point arithmetic, where two numbers that look identical
when displayed can differ by a tiny, invisible amount underneath.

### Forgetting number2 defaults to 0, not to number1

<ExcelCode>{`DELTA(0.5) → 0, the same as DELTA(0.5, 0) — NOT automatically 1`}</ExcelCode>

Omitting the second argument doesn't skip the comparison — it compares
`number1` against `0`. `DELTA(0.5)` checks whether `0.5` equals `0`,
which it doesn't, so the result is `0`.
