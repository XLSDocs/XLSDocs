Compute the tangent of a complex number — the ratio of its
[complex sine](/docs/engineering/imsin) to its
[complex cosine](/docs/engineering/imcos), the same relationship that
defines ordinary tangent for real numbers.

## Return value

The tangent of `inumber`, as text in `x + yi`/`x + yj` form.

## Description

IMTAN divides the complex sine of `inumber` by its complex cosine,
exactly mirroring how ordinary tangent is defined for real numbers
(`tan(x) = sin(x)/cos(x)`). Since both
[IMSIN](/docs/engineering/imsin) and
[IMCOS](/docs/engineering/imcos) reduce to their ordinary real
versions on a purely real input, IMTAN does too — `IMTAN(4)` and
`TAN(4)` agree exactly.

<Callout type="warn">
  Unlike real tangent, which grows toward infinity only at specific
  points (odd multiples of `π/2`), complex tangent stays **bounded**
  as the imaginary part grows — it approaches `i` for large positive
  imaginary parts and `-i` for large negative ones. This is the
  opposite of [IMSIN](/docs/engineering/imsin) and
  [IMCOS](/docs/engineering/imcos) themselves, which grow unboundedly
  large.
</Callout>

## Try it

<TryIt
  data={{ '3+4i': '-0.0002+0.9994i', 'i': '0.7616i', '1+i': '0.2718+1.0839i' }}
  defaultValue="3+4i"
  label={'Live preview — =IMTAN("{value}")'}
  fieldLabel="inumber"
/>

`IMTAN("3+4i")` returns `-0.0002+0.9994i` — already very close to
`i`, illustrating how quickly complex tangent approaches that limiting
value as the imaginary part grows. The pure imaginary unit `"i"` gives
exactly `tanh(1)i` (`0.7616i`), following the identity `tan(iy) =
i·tanh(y)`.

## Common errors

### #NUM! — text that isn't a valid complex number

<ExcelCode>{`IMTAN("hello") → #NUM!`}</ExcelCode>

`inumber` has to be parseable as `x + yi`/`x + yj` text (or a plain
number). Text that doesn't match that pattern at all returns `#NUM!`.

### #VALUE! — inumber is a logical value

<ExcelCode>{`IMTAN(TRUE) → #VALUE!`}</ExcelCode>

Passing `TRUE` or `FALSE` directly (rather than complex-number text)
returns `#VALUE!`.

### Expecting IMTAN to grow unboundedly like IMSIN/IMCOS do

<ExcelCode>{`IMTAN("3+4i") → -0.0002+0.9994i, already nearly at the boundary value i — not a huge number`}</ExcelCode>

IMSIN and IMCOS both grow rapidly for larger imaginary parts, but
IMTAN doesn't inherit that growth — the two effects cancel in the
division, and the ratio instead converges toward `±i`.
