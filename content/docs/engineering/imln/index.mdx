## Return value

The natural logarithm of `inumber`, as text in `x + yi`/`x + yj` form.

## Description

IMLN's result is built directly from two other functions already
covered on this site: its real part is `ln(|inumber|)` — the ordinary
natural log of [IMABS](/docs/engineering/imabs)'s result — and its
imaginary part is exactly [IMARGUMENT](/docs/engineering/imargument)'s
result. This is the standard definition of a complex natural
logarithm: `ln(z) = ln(|z|) + i·arg(z)`. For a **positive real**
input, the argument is `0`, so the formula collapses to `ln(x)`,
matching the ordinary `LN` function exactly. Unlike `LN`, however,
IMLN accepts negative real numbers too — real `LN` returns `#NUM!` for
those, while IMLN treats a negative real as a complex number with an
argument of `π` and returns a genuine complex answer.

## Try it

<TryIt

  defaultValue="3+4i"

  fieldLabel="inumber"
/>

`IMLN("3+4i")` returns `1.6094+0.9273i` — and both pieces should look
familiar: `1.6094` is `ln(5)`, since `IMABS("3+4i")` is `5`, and
`0.9273` is exactly `IMARGUMENT("3+4i")`'s own result. The pure
imaginary unit `"i"` gives `ln(1) + iπ/2`, or `1.5708i` — a magnitude
of exactly `1` contributes nothing to the real part.

## Common errors

### #NUM! — inumber is exactly zero

<ExcelCode>{`IMLN("0") → #NUM!`}</ExcelCode>

The natural logarithm of `0` is undefined (it approaches negative
infinity) — the same reason plain `LN(0)` also returns `#NUM!`.

### #NUM! — text that isn't a valid complex number

<ExcelCode>{`IMLN("hello") → #NUM!`}</ExcelCode>

`inumber` has to be parseable as `x + yi`/`x + yj` text (or a plain
number). Text that doesn't match that pattern at all returns `#NUM!`.

### Expecting a negative real input to error, the way LN does

<ExcelCode>{`IMLN(-4) → 1.3863+3.1416i, NOT #NUM! — unlike ordinary LN(-4)`}</ExcelCode>

Ordinary `LN` can't handle negative numbers and errors instead.
IMLN doesn't have that restriction — a negative real number is just a
complex number with an argument of `π`, so IMLN happily returns a
genuine (complex) answer instead of erroring.
