Convert a decimal number to hexadecimal — the reverse of `HEX2DEC`,
and the widest-range conversion in this family, spanning a full
40-bit signed integer.

## Return value

The hexadecimal equivalent of `number`, as text — padded to `places`
characters if supplied and `number` is positive.

## Description

DEC2HEX supports a 40-bit signed range — each of its 10 possible hex
characters represents 4 binary bits, so 10 hex digits cover 40 bits
total, one of which is the two's-complement sign bit. That gives
DEC2HEX by far the widest range of any function in this conversion
family, since `DEC2BIN` is stuck at 10 bits and `DEC2OCT` at 30.

<Callout type="idea">
  Hexadecimal is the most commonly useful base in this entire family
  for real technical work — color codes, memory addresses, and byte
  values are almost always expressed in hex, which is exactly why
  DEC2HEX supports such a wide range compared to its binary and octal
  counterparts.
</Callout>

## Try it

<TryIt
  data={{ '8': '8', '26': '1A', '255': 'FF', '-5': 'FFFFFFFFFB' }}
  defaultValue="26"
  label={'Live preview — =DEC2HEX({number})'}
  fieldLabel="number"
/>

`DEC2HEX(255)` returns `FF` — the familiar maximum value of a single
byte. `DEC2HEX(-5)` returns the full 10-character `FFFFFFFFFB`, the
two's-complement hex representation of -5 across the full 40-bit
width.

## Common errors

### #NUM! — number is outside the valid 40-bit range

<ExcelCode>{`DEC2HEX(600000000000) → #NUM!`}</ExcelCode>

`number` must fall between -549,755,813,888 and 549,755,813,887.

### #NUM! — places is too small for the result

<ExcelCode>{`DEC2HEX(255, 1) → #NUM!, since "FF" needs 2 characters`}</ExcelCode>

`places` must be large enough to hold every digit of the actual
result — it can only pad with extra leading zeros, never truncate.
