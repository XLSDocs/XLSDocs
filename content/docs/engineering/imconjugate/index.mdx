Compute the complex conjugate of a complex number — keep the real
coefficient exactly as-is, and flip the sign of the imaginary
coefficient.

## Return value

The complex conjugate of `inumber`, as text in the same `x + yi`/`x +
yj` form.

## Description

For a complex number `x + yi`, IMCONJUGATE returns `x - yi` — the real
part is untouched, and only the imaginary part's sign flips.
Geometrically, this reflects the point `(x, y)` across the real axis:
the distance from the origin ([IMABS](/docs/engineering/imabs)) stays
exactly the same, while the angle
([IMARGUMENT](/docs/engineering/imargument)) flips sign. Conjugates
show up constantly in complex-number division, since multiplying a
complex number by its own conjugate always produces a purely real
result (`x² + y²`) — the technique
[IMDIV](/docs/engineering/imdiv) uses internally to divide two complex
numbers.

## Try it

<TryIt
  data={{ '3+4i': '3-4i', '1-2i': '1+2i', '5-12i': '5+12i' }}
  defaultValue="3+4i"
  label={'Live preview — =IMCONJUGATE("{value}")'}
  fieldLabel="inumber"
/>

`IMCONJUGATE("3+4i")` returns `3-4i` — the real `3` is unchanged, and
the imaginary `+4i` becomes `-4i`. Since the original imaginary sign
can go either way, an already-negative imaginary part flips positive:
`IMCONJUGATE("1-2i")` returns `1+2i`.

## Common errors

### #NUM! — text that isn't a valid complex number

<ExcelCode>{`IMCONJUGATE("hello") → #NUM!`}</ExcelCode>

`inumber` has to be parseable as `x + yi`/`x + yj` text (or a plain
number). Text that doesn't match that pattern at all returns `#NUM!`.

### Expecting the real part to change too

<ExcelCode>{`IMCONJUGATE("3+4i") → 3-4i, not -3-4i — only the imaginary sign flips`}</ExcelCode>

IMCONJUGATE isn't the same as negating the whole complex number. Only
the imaginary coefficient's sign changes; the real coefficient is left
exactly as it was.
