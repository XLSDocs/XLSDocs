Test whether a value is stored as text — the mirror image of
ISNUMBER. Useful for catching cells where a number got imported as
text, or validating that a field is genuinely a text entry.

## Return value

`TRUE` if `value` is text. `FALSE` for numbers, blanks, logical
values, and errors.

## Description

ISTEXT checks the underlying stored type of a cell, not how it
displays. It's the flip side of ISNUMBER — useful for catching the
same "number imported as text" problem from the opposite direction:
`ISTEXT(A2)` returning `TRUE` on a column that should be numeric is
a quick way to flag rows that need cleanup.

<Callout type="info">
  ISTEXT tests the **underlying value**, not the cell's display
  format. A number cell custom-formatted to show as `"100 units"`
  still returns `FALSE` from ISTEXT — the stored value is still a
  number, only the display changed.
</Callout>

## Common errors

### Confusing display formatting with actual text

<ExcelCode>{`ISTEXT(A1) → FALSE (even if A1 displays as "100 units" via custom formatting)`}</ExcelCode>

Custom number formats change how a value *displays*, not its
underlying type — ISTEXT sees the real stored value.

### Expecting TRUE for a blank cell

<ExcelCode>{`ISTEXT(A1) → FALSE (if A1 is blank)`}</ExcelCode>

A blank cell isn't text — use ISBLANK to test for emptiness
specifically.
