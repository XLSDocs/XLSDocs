Return the **sheet number** of a named sheet or a reference — or,
with no argument at all, the number of the sheet the formula itself
lives on. Counts every sheet in the workbook, including hidden and
very hidden ones.

## Return value

The 1-based position of the named sheet or referenced sheet within
the workbook's full sheet order — including hidden and very hidden
worksheets, and macro, chart, and dialog sheets.

## Description

SHEET is mainly useful for building a formula that needs to know its
own position, or another sheet's position, within the workbook —
for example, numbering a set of monthly tabs in the order they
actually appear, or confirming a sheet exists before referencing it
elsewhere. Unlike a simple visible-tab count, SHEET's numbering
includes every sheet type Excel tracks internally, whether or not
it's currently visible.

<Callout type="warn">
  Because this result depends on the live structure of the actual
  workbook it runs in (which sheets exist, in what order, which are
  hidden), it can't be demonstrated with a fixed example the way a
  pure calculation can — the "Try it" widget used elsewhere on this
  site doesn't apply here.
</Callout>

## Common errors

### #N/A — a sheet name that doesn't exist

<ExcelCode>{`SHEET("NoSuchSheet") → #N/A`}</ExcelCode>

A text argument that doesn't match any real sheet name in the
workbook returns `#N/A`, not `#REF!`.

### #REF! — a broken reference

<ExcelCode>{`SHEET(Sheet1!#REF) → #REF!`}</ExcelCode>

An actual (not text-based) reference that's broken returns `#REF!`
instead — the two invalid-input cases use different error types.
