Return one specific piece of information about a cell — its address,
row, column, contents, data type, or even formatting details like
number format or whether it's locked — selected by a keyword rather
than a separate function per fact.

## Return value

Depends entirely on `info_type` — a number, a text string, or in a
few cases a single-character code. See the table below for what each
keyword returns.

## Description

`info_type` selects what CELL reports back:

| info_type | Returns |
|---|---|
| `"address"` | The reference's address as text (e.g. `"$B$2"`) |
| `"col"` | The column number |
| `"row"` | The row number |
| `"contents"` | The value in the upper-left cell of the reference |
| `"type"` | `"b"` (blank), `"l"` (text/label), or `"v"` (value) |
| `"format"` | A text code for the cell's number format |
| `"width"` | The column width, rounded to the nearest integer |
| `"color"` | `1` if negative values display in color, else `0` |
| `"parentheses"` | `1` if positive/all values display with parentheses, else `0` |
| `"prefix"` | The text alignment prefix character (`'`, `"`, `^`, `\`, or blank) |
| `"protect"` | `1` if the cell is locked, else `0` |
| `"filename"` | The full path and filename of the workbook (blank if unsaved) |

<Callout type="warn">
  Formatting-related `info_type`s (`"format"`, `"color"`,
  `"parentheses"`, `"protect"`, `"width"`) don't automatically
  recalculate when only the cell's **formatting** changes, not its
  value — Excel doesn't treat a formatting-only edit as something
  that needs recalculating. Press **F9** (or make any change that
  forces recalculation) after reformatting if the CELL result looks
  stale.
</Callout>

## Common errors

### The result doesn't update after reformatting a cell

As the callout above explains, `"format"`, `"color"`, `"parentheses"`,
`"protect"`, and `"width"` don't trigger recalculation on their own
when only formatting changes. Force a recalculation (F9) if the
result looks out of date.

### "filename" returns blank

<ExcelCode>{`CELL("filename") → "" (if the workbook has never been saved)`}</ExcelCode>

A workbook that hasn't been saved yet has no path to report. Save the
file at least once, and the full path/filename will appear.

### #VALUE! — an unrecognized info_type

<ExcelCode>{`CELL("adress", B2) → #VALUE! (typo — should be "address")`}</ExcelCode>

`info_type` must exactly match one of the recognized keywords —
Excel doesn't fuzzy-match or suggest corrections for a typo'd one.
