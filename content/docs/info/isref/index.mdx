Test whether a value is a valid **reference** — a cell, range, or
named range that Excel can resolve, as opposed to a plain number,
text string, or an invalid/broken reference.

## Return value

`TRUE` if `value` is a reference Excel can resolve. `FALSE` for a
plain number, text, or anything else that isn't a genuine reference.

## Description

ISREF checks whether `value` is structurally a reference — a cell
(`A1`), a range (`A1:B10`), or a named range — rather than testing
what that reference *contains*. It's most useful paired with
`INDIRECT`, which builds a reference from a text string at
calculation time and can fail if the text doesn't resolve to a real
location: `ISREF(INDIRECT("A1"))` confirms the built reference is
actually valid before relying on it further.

<Callout type="warn">
  **A text string that merely looks like a reference is still
  `FALSE`.** `ISREF("A1")` tests the literal text `"A1"`, which is a
  string, not a reference — it returns `FALSE`. Only an actual cell
  reference, or a function call that resolves to one (like
  `INDIRECT("A1")`), returns `TRUE`.
</Callout>

## Common errors

### Confusing a reference-shaped string with a real reference

<ExcelCode>{`ISREF("A1") → FALSE (this is literal text, not a reference)`}</ExcelCode>

Wrap it in `INDIRECT()` to actually resolve the text into a
reference first: `ISREF(INDIRECT("A1"))` returns `TRUE`.

### Expecting ISREF to validate a hyperlink or external link

<ExcelCode>{`ISREF cannot confirm whether an external workbook link or a HYPERLINK target is still valid`}</ExcelCode>

ISREF only tests references within the structure Excel itself
resolves formulas against — it's not a tool for checking external
file links or hyperlink targets.

## Related functions
