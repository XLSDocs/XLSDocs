Test whether a cell is genuinely empty — no value, no formula, not
even a formula that evaluates to an empty string. Almost always used
inside IF, or wrapped in NOT to test the opposite.

## Return value

`TRUE` if `value` is a genuinely empty cell. `FALSE` for everything
else — including a cell holding a formula that displays nothing.

## Description

ISBLANK is the strictest of the "is this empty" checks — it only
returns `TRUE` for a cell that has never held a value or formula at
all. A cell containing a formula that currently evaluates to `""`
(an empty string) looks empty visually but is **not** blank to
ISBLANK, the same distinction that affects COUNTA/COUNTBLANK.

<Callout type="warn">
  ISBLANK returns `FALSE` for a cell holding `=IF(A1="","","x")`,
  even when that formula's result displays as nothing — the cell
  contains a formula, not true blankness. Test against `=""`
  instead if the goal is "does this cell display as empty."
</Callout>

## Common errors

### Expecting TRUE for a formula that displays blank

<ExcelCode>{`ISBLANK(A1) → FALSE (if A1 = ="")`}</ExcelCode>

The cell isn't truly empty — it holds a formula. Compare against an
empty string instead if visual blankness is what matters:

<ExcelCode>{`A1=""`}</ExcelCode>

### ISBLANK vs a direct comparison to ""

<ExcelCode>{`ISBLANK(A1) vs A1=""`}</ExcelCode>

These aren't interchangeable — `A1=""` is `TRUE` both for a truly
empty cell **and** a formula returning `""`, while `ISBLANK` is
`TRUE` only for the former.
