Test whether a formula's result is `#N/A` specifically — the error
lookup functions like VLOOKUP and MATCH return when nothing matches.
Unlike ISERROR, it doesn't catch other error types like `#REF!` or
`#DIV/0!`.

## Return value

`TRUE` if `value` is specifically the `#N/A` error. `FALSE` for
every other value, including other error types like `#REF!` or
`#VALUE!`.

## Description

ISNA is the narrower, more deliberate sibling of ISERROR — it only
catches `#N/A`, the error most lookup functions (VLOOKUP, XLOOKUP,
MATCH) return when nothing matches. Using ISNA instead of ISERROR
means a genuine formula mistake elsewhere (a broken reference, a
divide-by-zero) stays visible as an error rather than being silently
swallowed by a "not found" fallback meant only for missing matches.

<Callout type="warn">
  For the common "lookup, fall back if not found" pattern,
  [IFNA](/docs/logical/ifna) is simpler and more efficient than
  `IF(ISNA(...), ...)` — it evaluates the lookup once instead of
  twice, and needs no separate ISNA call.
</Callout>

for the same input. That gap is the entire reason ISNA exists
alongside ISERROR.

## Common errors

### Using ISNA when IFNA would be simpler

<ExcelCode>{`IF(ISNA(VLOOKUP(...)), "Not found", VLOOKUP(...)) → works, but evaluates VLOOKUP twice`}</ExcelCode>

Not wrong, just inefficient — IFNA does the same job in one call and
one evaluation:

<ExcelCode>{`IFNA(VLOOKUP(...), "Not found")`}</ExcelCode>

### Masking a real error by using ISERROR instead

<ExcelCode>{`ISERROR(VLOOKUP(...)) → also TRUE for #REF!, #VALUE!, etc., not just missing matches`}</ExcelCode>

If a genuine formula problem (not just a missing lookup match) should
stay visible rather than being replaced by a "not found" fallback,
ISNA is the more precise choice.

## Related functions

- [ISERROR](/docs/info/iserror) — tests for any error type, not just
  `#N/A`.
- [NA](/docs/info/na) — deliberately creates the same `#N/A` error
  ISNA tests for, used as a chart or placeholder value.
- [IFNA](/docs/logical/ifna) — the modern, more efficient replacement
  for `IF(ISNA(...), ...)`.
- [IFERROR](/docs/logical/iferror) — the equivalent shortcut for
  `IF(ISERROR(...), ...)`.
- [XLOOKUP](/docs/lookup/xlookup) — its `if_not_found` argument covers
  this exact pattern natively, without needing ISNA at all.
