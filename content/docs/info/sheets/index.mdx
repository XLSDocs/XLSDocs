Return the **number of sheets** in a reference — or, with no
argument at all, the total number of sheets in the entire workbook.
Counts every sheet, including hidden and very hidden ones.

## Return value

The number of sheets in `reference` — or, if omitted, the total
number of sheets in the whole workbook, including hidden and very
hidden worksheets, plus macro, chart, and dialog sheets.

## Description

SHEETS is most useful with a **3D reference** — a span across
multiple sheet tabs, like `Sheet1:Sheet3!A1` — where it returns how
many sheets that span actually covers (`3`, for a `Sheet1:Sheet3`
span). With no argument, it's a quick way to get the workbook's
total sheet count without manually counting tabs, which is easy to
get wrong once hidden sheets are involved.

<Callout type="warn">
  Because this result depends on the live structure of the actual
  workbook it runs in (how many sheets exist, which are hidden), it
  can't be demonstrated with a fixed example the way a pure
  calculation can — the "Try it" widget used elsewhere on this site
  doesn't apply here.
</Callout>

## Common errors

### #REF! — an invalid reference

<ExcelCode>{`SHEETS(NotARealReference) → #REF!`}</ExcelCode>

A reference argument that doesn't resolve to anything real returns
`#REF!`.

### Expecting SHEETS to exclude hidden sheets

<ExcelCode>{`SHEETS() → includes every hidden and very hidden sheet, not just the visible tabs`}</ExcelCode>

If only the *visible* tab count is needed, SHEETS alone can't filter
that out — a different approach (like VBA, since there's no
worksheet-formula way to test visibility per sheet) is needed.
