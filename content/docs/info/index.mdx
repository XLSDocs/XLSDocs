---
title: Info
description: Test the type or state of a value — is it blank, a number, text, or an error.
---

Information functions test a single value and return `TRUE` or
`FALSE` — is this cell blank, is that result a number, did this
formula error. Almost always used inside IF, or nested inside another
function like NOT, to branch on the answer.
