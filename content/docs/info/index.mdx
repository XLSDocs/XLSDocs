---
title: Info
description: Test the type or state of a value — is it blank, a number, text, a formula, or an error.
---

Information functions test a single value and almost always return
`TRUE` or `FALSE` — is this cell blank, is that result a number, did
this formula error, is this cell a formula at all. Almost always used
inside IF, or nested inside another function like NOT, to branch on
the answer. NA is the one exception: instead of testing for
something, it deliberately creates a placeholder error on purpose.
