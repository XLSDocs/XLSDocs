Test whether a cell's contents are a formula, rather than a plain
typed-in value — the tool behind auditing a sheet to find which cells
actually calculate something versus which ones were hand-entered.

## Return value

`TRUE` if `reference` points to a cell containing a formula. `FALSE`
for a cell holding a plain typed-in value, or an empty cell.

## Description

ISFORMULA answers a question none of the other type-testing functions
can: not what kind of *value* a cell holds, but whether that value
came from a *formula* in the first place. That makes it the basis for
auditing a workbook — highlighting every formula cell with
conditional formatting, or flagging a range where a formula was
accidentally overwritten with a hardcoded number.

<Callout type="warn">
  `reference` has to be an actual **cell reference** — unlike
  ISBLANK, ISNUMBER, and the rest of the IS-functions, ISFORMULA
  can't test a computed value or a literal directly. `ISFORMULA(A1)`
  works; `ISFORMULA(A1+1)` doesn't, because `A1+1` isn't a reference
  to any single cell.
</Callout>

## Common errors

### #VALUE! from passing a computed value instead of a reference

<ExcelCode>{`ISFORMULA(A1+1) → #VALUE!`}</ExcelCode>

`reference` must point directly to a cell. Test the cell itself,
then use its value separately if needed:

<ExcelCode>{`ISFORMULA(A1)`}</ExcelCode>

### Highlighting formula cells across a whole range

ISFORMULA tests one cell at a time — for conditional formatting
across a range, apply the rule `=ISFORMULA(A1)` to the range with A1
as the anchor (Excel adjusts the reference per cell automatically),
rather than expecting one formula to check the whole range at once.

### Confusing "contains a formula" with "the formula returns a number"

ISFORMULA only checks whether the cell's content **is** a formula —
it says nothing about what that formula evaluates to. A formula that
returns an error, text, or a blank-looking result is still `TRUE` to
ISFORMULA.

## Related functions

- [ISBLANK](/docs/info/isblank) — tests whether a cell is empty,
  regardless of whether it holds a formula or a value.
- [ISERROR](/docs/info/iserror) — tests whether a cell's result is an
  error, regardless of whether it's a formula or a hardcoded error
  value.
- [ISNUMBER](/docs/info/isnumber) and [ISTEXT](/docs/info/istext) —
  test what kind of value a cell holds, rather than whether that
  value came from a formula.

## Examples

<ExampleCard number="01" label="Test a single cell" formula={`=ISFORMULA(A2)`}>
  Returns TRUE if A2 contains a formula, FALSE if it holds a plain
  typed-in value or is empty.
</ExampleCard>

<ExampleCard number="02" label="Label formula vs hardcoded cells" formula={`=IF(ISFORMULA(A2), "Formula", "Hardcoded")`}>
  A quick audit label for a neighboring column, flagging which cells
  in a range actually calculate something.
</ExampleCard>

<ExampleCard number="03" label="Conditional formatting rule for a whole range" formula={`=ISFORMULA(A1)`}>
  Applied as a conditional formatting rule to range A1:D100 (with A1
  as the anchor), this highlights every formula cell — Excel adjusts
  the reference per cell automatically, unlike a plain array formula.
</ExampleCard>

<ExampleCard number="04" label="Flagging a formula that was overwritten" formula={`=IF(NOT(ISFORMULA(B2)), "Check: was this overwritten?", "")`}>
  Useful in a template where B2 is expected to always hold a formula
  — flags the cell if someone accidentally typed a value over it.
</ExampleCard>

<ExampleCard number="05" label="Invalid reference error" formula={`=ISFORMULA(A1+1)`}>
  Returns `#VALUE!` — `A1+1` is a calculation, not a reference to a
  single cell, and ISFORMULA requires an actual cell reference.
</ExampleCard>
