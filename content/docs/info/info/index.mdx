Return information about the current **operating environment** —
which OS Excel is running on, which version of Excel, and whether
calculation is set to automatic or manual. Not available in Excel
for the web.

## Return value

Depends on `type_text`: `"system"` returns `"mac"` or `"pcdos"`;
`"osversion"` returns the operating system version as text;
`"release"` returns the Excel version as text; `"recalc"` returns
`"Automatic"` or `"Manual"`. The retired memory-related values
(`"memavail"`, `"memused"`, `"totmem"`) now return `#N/A`.

## Description

INFO exposes a handful of facts about the environment the workbook
is currently running in — useful for a formula or diagnostic sheet
that needs to confirm the platform, version, or calculation mode
rather than assume one. Several `type_text` values that reported
memory usage in much older Excel versions ("memavail", "memused",
"totmem") are no longer supported and return `#N/A` today, even
though they may still appear in documentation written for older
versions.

<Callout type="warn">
  Because this result depends on the live environment it runs in
  (which OS, which Excel version, the current calculation setting),

  doesn't apply here.
</Callout>

## Common errors

### #N/A — a retired memory-related type_text value

<ExcelCode>{`INFO("memavail") → #N/A (no longer supported)`}</ExcelCode>

Older documentation or workbooks built in much earlier Excel
versions may reference `"memavail"`, `"memused"`, or `"totmem"` —
all three now return `#N/A` in current Excel.

### Expecting INFO to work in Excel for the web

<ExcelCode>{`INFO is not available in Excel for the web at all`}</ExcelCode>

A workbook using INFO that's opened in a browser rather than the
desktop app will show an error wherever INFO is used.
