Test whether a value is numeric — including dates and times, which
Excel stores internally as numbers. A common validation check before
running a calculation that would otherwise error on text.

## Return value

`TRUE` if `value` is a number (including dates and times, which are
stored as numbers internally). `FALSE` for text, blanks, logical
values, and errors.

## Description

ISNUMBER is a quick validation check — most often used inside IF to
avoid running a calculation on a cell that might not actually contain
a number yet, or combined with SEARCH/FIND to test whether a
substring was found (SEARCH returns a number on a match, `#VALUE!`
otherwise, so `ISNUMBER(SEARCH(...))` is a common "does this text
contain that substring" pattern).

<Callout type="warn">
  A number that's been formatted or imported as **text** (common
  after a CSV import — often flagged with a small green triangle in
  the cell's corner) returns `FALSE` from ISNUMBER, even though it
  visually looks like a number. Use `VALUE()` to convert it to a real
  number first if needed.
</Callout>

but ISNUMBER sees the underlying stored type — it returns `FALSE`
right alongside plain text, not `TRUE`.

## Common errors

### FALSE for a text-formatted number

<ExcelCode>{`ISNUMBER("100") → FALSE (it's text, not a real number)`}</ExcelCode>

Convert it first if a real number is needed:

<ExcelCode>{`ISNUMBER(VALUE("100")) → TRUE`}</ExcelCode>

### Confusing ISNUMBER with a numeric formatting check

<ExcelCode>{`ISNUMBER(A1) → tests the underlying value, not its display format`}</ExcelCode>

ISNUMBER checks the actual stored value, not how it's formatted —
a cell displaying "$100.00" and a cell displaying "100" both return
`TRUE` if the underlying value is numeric.
