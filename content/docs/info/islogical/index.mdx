Test whether a value is a real logical `TRUE`/`FALSE` value, as
opposed to text that merely looks like one, or a number standing in
for one. Almost always used inside IF, or wrapped in NOT to test the
opposite.

## Return value

`TRUE` if `value` is a genuine logical value (the result of a
comparison, or a literal `TRUE`/`FALSE`). `FALSE` for everything
else, including text or numbers that merely resemble one.

## Description

ISLOGICAL is the strictest of the type-testing functions when it
comes to booleans — it only returns `TRUE` for an actual logical
value, the kind produced by a comparison (`A1>10`) or typed directly
as `TRUE`/`FALSE`. Text that reads as "TRUE" (typed with a leading
apostrophe, or imported from a CSV) and numbers like `1`/`0` that are
sometimes used to represent true/false both fail this test, even
though they're often treated as equivalent elsewhere in Excel.

<Callout type="warn">
  `ISLOGICAL("TRUE")` returns `FALSE` — that's a text string that
  merely says "TRUE," not an actual logical value. This distinction
  matters most with data imported from CSV or another system, where
  values that look like booleans often arrive as plain text instead.
</Callout>

## Common errors

### Text that looks like a boolean returns FALSE

<ExcelCode>{`ISLOGICAL("TRUE") → FALSE`}</ExcelCode>

The cell holds text, not a genuine logical value. Convert it first if
a real boolean is needed:

<ExcelCode>{`=(A1="TRUE")`}</ExcelCode>

### A number used as a flag also returns FALSE

<ExcelCode>{`ISLOGICAL(1) → FALSE`}</ExcelCode>

Even though `1` and `0` are often treated as TRUE/FALSE equivalents
in calculations, ISLOGICAL only accepts genuine logical values —
compare the number instead if that's the actual check needed:
`A1=1`.

### Confusing ISLOGICAL with ISNUMBER on a comparison result

A formula like `A1>10` produces a real logical value, so
`ISLOGICAL(A1>10)` is `TRUE` — but so would `ISNUMBER` be `FALSE`
for the same input, since a logical value isn't a number to Excel's
type system, despite `TRUE`/`FALSE` behaving like `1`/`0` in
arithmetic.
