Calculate the annualized **interest rate implied by a fully invested
security** — one bought at one amount and redeemed at a larger one,
with no periodic coupon along the way.

## Return value

The annualized interest rate implied by growing `investment` into
`redemption` over the span from `settlement` to `maturity`,
returned as a decimal.

## Description

INTRATE is DISC's close cousin, but working in actual dollar amounts
instead of per-$100 price and redemption figures — useful when you
know exactly what was paid and exactly what comes back, rather than
a quoted price:

<ExcelCode>{`INTRATE = (redemption - investment) / investment × (days in a year, per basis) / (days between settlement and maturity)`}</ExcelCode>

<ExcelCode>{`=INTRATE(DATE(2025,2,15), DATE(2025,5,15), 985000, 1000000, 2) → 6.16% (a 985,000 investment redeeming at 1,000,000, basis 2)`}</ExcelCode>

<Callout type="idea">
  **INTRATE and DISC compute the same underlying thing** —
  annualized return on a no-coupon security — but DISC expresses it
  against `redemption` in the denominator, while INTRATE expresses
  it against `investment`. Which one to use just depends on whether
  your numbers are "price per $100" or actual dollar amounts.
</Callout>

A smaller `investment` growing into the same fixed `redemption`
implies a larger annualized return — moving the investment amount
down pushes the computed rate up.

## Common errors

### #NUM! — settlement on or after maturity

<ExcelCode>{`INTRATE(DATE(2025,5,15), DATE(2025,2,15), 985000, 1000000) → #NUM! (settlement is after maturity)`}</ExcelCode>

`settlement` has to fall strictly before `maturity`.

### #NUM! — a non-positive investment or redemption amount

<ExcelCode>{`INTRATE(DATE(2025,2,15), DATE(2025,5,15), 0, 1000000) → #NUM! (investment must be greater than 0)`}</ExcelCode>

Both `investment` and `redemption` have to be positive — an amount
invested or redeemed can't be zero or negative.

    ```python lineNumbers
    from datetime import date

    def intrate(settlement, maturity, investment, redemption, year_days=360):
        # basis=2 (actual/360) only — other bases change year_days and/or
        # how the day span itself is counted
        dim = (maturity - settlement).days
        return (redemption - investment) / investment * (year_days / dim)

    rate = intrate(date(2025, 2, 15), date(2025, 5, 15), 985000, 1000000)
    print(rate)
    ```
