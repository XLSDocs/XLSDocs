Calculate a discount security's **price per $100 face value**, given
a known discount rate — the exact inverse of [DISC](/docs/financial/disc).

## Return value

The security's price per $100 face value, implied by discounting
`redemption` back by `discount`, annualized over the span from
`settlement` to `maturity`.

## Description

PRICEDISC is [DISC](/docs/financial/disc) run in reverse — instead
of taking a known price and solving for the discount rate, it takes
a known discount rate and solves for the price:

<ExcelCode>{`PRICEDISC = redemption × (1 - discount × (days between settlement and maturity) / (days in a year, per basis))`}</ExcelCode>

<ExcelCode>{`=PRICEDISC(DATE(2008,2,16), DATE(2008,3,1), 5.25%, 100, 2) → $99.80 (Microsoft's own documented example)`}</ExcelCode>

<Callout type="idea">
  **PRICEDISC and DISC are exact inverses.** Feeding PRICEDISC's own
  output back into DISC, alongside the same `settlement`,
  `maturity`, `redemption`, and `basis`, returns the original
  `discount` rate exactly.
</Callout>

further below par.

## Common errors

### #NUM! — settlement on or after maturity

<ExcelCode>{`PRICEDISC(DATE(2025,7,1), DATE(2025,1,1), 4%, 100) → #NUM! (settlement is after maturity)`}</ExcelCode>

`settlement` has to fall strictly before `maturity`.

### #NUM! — a non-positive discount rate or redemption value

<ExcelCode>{`PRICEDISC(DATE(2025,1,1), DATE(2025,7,1), 0, 100) → #NUM! (discount must be greater than 0)`}</ExcelCode>

Both `discount` and `redemption` have to be positive numbers.

    ```python lineNumbers
    from datetime import date

    def pricedisc(settlement, maturity, discount, redemption, year_days=360):
        # basis=2 (actual/360) only — other bases change year_days and/or
        # how the day span itself is counted
        dsm = (maturity - settlement).days
        return redemption * (1 - discount * dsm / year_days)

    price = pricedisc(date(2008, 2, 16), date(2008, 3, 1), 0.0525, 100)
    print(price)
    ```
