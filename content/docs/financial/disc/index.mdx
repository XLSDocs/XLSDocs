Calculate a security's **discount rate** — how steeply it's priced
below its redemption value, annualized, the standard way short-term
instruments like Treasury bills are quoted.

## Return value

The security's annualized discount rate, as a decimal — the
proportional gap between `pr` and `redemption`, scaled up to a
full-year rate based on how much of a year sits between
`settlement` and `maturity`.

## Description

Short-term discount instruments (Treasury bills among them) don't
pay a coupon — they're simply sold below their redemption value, and
the return is entirely in that gap. DISC converts a quoted price
into the annualized discount rate that price implies:

<ExcelCode>{`DISC = (redemption - pr) / redemption × (days in a year, per basis) / (days between settlement and maturity)`}</ExcelCode>

<ExcelCode>{`=DISC(DATE(2025,1,1), DATE(2025,7,1), 98, 100, 2) → 3.98% (a security priced at 98 against a redemption value of 100, basis 2)`}</ExcelCode>

<Callout type="idea">
  **DISC and [PRICEDISC](/docs/financial/pricedisc) are exact
  inverses of each other** — DISC takes a known price and solves
  for the discount rate, while PRICEDISC takes a known discount rate
  and solves for the price. Pick whichever one matches the number
  you actually have.
</Callout>

The further `pr` sits below the `100` redemption value, the larger
the discount rate DISC reports — a steeper discount from face value
implies a higher annualized return.

## Common errors

### #NUM! — settlement on or after maturity

<ExcelCode>{`DISC(DATE(2025,7,1), DATE(2025,1,1), 98, 100) → #NUM! (settlement is after maturity)`}</ExcelCode>

`settlement` has to fall strictly before `maturity` — there's no
span to annualize the discount over otherwise.

### #NUM! — a non-positive price or redemption value

<ExcelCode>{`DISC(DATE(2025,1,1), DATE(2025,7,1), 0, 100) → #NUM! (pr must be greater than 0)`}</ExcelCode>

Both `pr` and `redemption` have to be positive numbers — a security
can't be priced at zero or less.

    ```python lineNumbers
    from datetime import date

    def disc(settlement, maturity, pr, redemption, year_days=360):
        # basis=2 (actual/360) only — other bases change year_days and/or
        # how the day span itself is counted
        dsm = (maturity - settlement).days
        return (redemption - pr) / redemption * (year_days / dsm)

    rate = disc(date(2025, 1, 1), date(2025, 7, 1), 98, 100)
    print(rate)
    ```
