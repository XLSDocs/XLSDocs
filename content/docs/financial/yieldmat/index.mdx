Calculate the annual yield of a security that pays **all of its
interest in one lump sum at maturity** — the exact inverse of
[PRICEMAT](/docs/financial/pricemat).

## Return value

The annual yield implied by `pr`, for a security that pays its
entire interest amount in one lump sum at `maturity`, accounting for
interest already accrued between `issue` and `settlement`.

## Description

YIELDMAT is [PRICEMAT](/docs/financial/pricemat) solved in reverse —
given a known price, it finds the yield that price implies, using
the same underlying relationship:

<ExcelCode>{`pr = [100 + (DIM/B × rate × 100)] / [1 + (DSM/B × yld)] - (A/B × rate × 100)`}</ExcelCode>

rearranged to solve for `yld`, where `DIM` is the day count from
`issue` to `maturity`, `DSM` is from `settlement` to `maturity`, `A`
is from `issue` to `settlement`, and `B` is the year length for the
chosen `basis`.

<ExcelCode>{`=YIELDMAT(DATE(2008,3,15), DATE(2008,11,3), DATE(2007,11,8), 6.25%, 100.0123, 0) → 6.10% (Microsoft's own documented example)`}</ExcelCode>

<Callout type="idea">
  **YIELDMAT and PRICEMAT are exact inverses.** Feeding YIELDMAT's
  own output back into PRICEMAT, alongside the same `settlement`,
  `maturity`, `issue`, `rate`, and `basis`, returns the original
  `pr` almost exactly.
</Callout>

## Common errors

### #NUM! — dates out of order

<ExcelCode>{`YIELDMAT(DATE(2025,1,1), DATE(2026,1,1), DATE(2025,4,1), 5%, 100) → #NUM! (issue is after settlement)`}</ExcelCode>

`issue` has to fall on or before `settlement`, which in turn has to
fall before `maturity`.

### #NUM! — a non-positive rate or price

<ExcelCode>{`YIELDMAT(DATE(2025,4,1), DATE(2026,1,1), DATE(2025,1,1), 0, 100) → #NUM! (rate must be greater than 0)`}</ExcelCode>

Both `rate` and `pr` have to be positive numbers.

    ```python lineNumbers
    from datetime import date

    def days_360(d1, d2):
        # US (NASD) 30/360 day count — basis=0, Excel's default
        day1, day2 = d1.day, d2.day
        if day1 == 31:
            day1 = 30
        if day2 == 31 and day1 == 30:
            day2 = 30
        return (d2.year - d1.year) * 360 + (d2.month - d1.month) * 30 + (day2 - day1)

    def yieldmat(settlement, maturity, issue, rate, pr, year_days=360):
        dim = days_360(issue, maturity)
        dsm = days_360(settlement, maturity)
        a = days_360(issue, settlement)
        numerator = 100 + (dim / year_days) * rate * 100
        accrued = (a / year_days) * rate * 100
        lhs = numerator / (pr + accrued)
        return (lhs - 1) / (dsm / year_days)

    yld = yieldmat(date(2008, 3, 15), date(2008, 11, 3), date(2007, 11, 8), 0.0625, 100.0123)
    print(yld)
    ```
