Find the annualized rate of return for cash flows that don't happen
on a neat, regular schedule — the realistic version of IRR for
investments with payments on actual calendar dates instead of evenly
spaced periods.

## Return value

The annualized rate of return that makes the net present value of
the dated cash flows equal to zero. Returns `#NUM!` if the solver
can't converge, or if `values` contains no sign change.

## Description

IRR assumes every cash flow is evenly spaced (one per period).
XIRR drops that assumption entirely — each cash flow gets its own
real date, and the annualized rate accounts for the actual number of
days between them. That makes it the correct choice for real
investments, which almost never land on a perfectly even schedule:
an initial investment in March, a partial return in July, another in
next February.

<Callout type="warn">
  `values` and `dates` must be the **same size**, and each date
  corresponds to the cash flow at the same position — reordering one
  without the other silently produces a wrong (but plausible-looking)
  rate rather than an error.
</Callout>

## Common errors

### #NUM! — no sign change in values

<ExcelCode>{`XIRR({1000,2000,3000}, {dates...}) → #NUM!`}</ExcelCode>

Same requirement as IRR: at least one negative value (the
investment) and one positive value (the return) are both needed.

### Mismatched values and dates sizes

<ExcelCode>{`XIRR(A2:A5, B2:B4) → #NUM! or #VALUE!`}</ExcelCode>

`values` and `dates` must contain exactly the same number of
entries, each pair at the same row position.

### Using XIRR when the cash flows really are evenly spaced

If payments genuinely land on a regular schedule (monthly, exactly),
plain IRR is simpler and doesn't require a separate dates column —
XIRR earns its keep specifically when the spacing is irregular.

    from scipy.optimize import brentq
    from datetime import date

    def xnpv(rate, values, dates):
        d0 = dates[0]
        return sum(v / (1 + rate) ** ((d - d0).days / 365) for v, d in zip(values, dates))

    cash_flows = [-50000, 20000, 35000]
    dates = [date(2026, 3, 1), date(2026, 7, 15), date(2027, 2, 1)]
    rate_of_return = brentq(lambda r: xnpv(r, cash_flows, dates), -0.99, 10)
    print(rate_of_return)
