Calculate the future value of a **starting amount** after a series
of **different** interest rates are applied one after another — one
rate per period, rather than a single constant rate throughout.

## Return value

`principal`, compounded forward by each rate in `schedule` in turn
— equivalent to `principal * (1+rate1) * (1+rate2) * ... * (1+rateN)`.

## Description

[FV](/docs/financial/fv) assumes one constant rate for every period,
which doesn't fit an investment whose rate genuinely changes year to
year — a variable-rate bond, or a forecast that assumes different
growth rates in different years. FVSCHEDULE handles that case
directly: each entry in `schedule` compounds the running total by
its own rate, in sequence.

<ExcelCode>{`=FVSCHEDULE(1, {0.09, 0.11, 0.1}) → 1.3309 (1 compounded by 9%, then 11%, then 10%, in sequence)`}</ExcelCode>

<Callout type="idea">
  **A blank cell in `schedule` counts as 0% interest for that
  period**, not an error — useful for modeling a gap year with no
  growth without needing to type an explicit `0`.
</Callout>

## Common errors

### #VALUE! — a non-numeric value in the schedule

<ExcelCode>{`FVSCHEDULE(1000, {0.05, "n/a", 0.03}) → #VALUE!`}</ExcelCode>

Every entry in `schedule` must be a number or genuinely blank — text
(even something intended as a placeholder) breaks the calculation.

### Confusing FVSCHEDULE with FV

<ExcelCode>{`FV(0.1, 3, 0, -1000) → assumes the same 10% rate for all 3 periods; FVSCHEDULE needs a different rate per period`}</ExcelCode>

Use plain [FV](/docs/financial/fv) when the rate is genuinely
constant across every period — FVSCHEDULE is only needed when the
rate actually varies.
