Convert a Treasury bill's **discount rate** into its **bond-
equivalent yield** — the number that lets a T-bill be compared
apples-to-apples against a coupon-paying bond, which quotes its
return on a different basis entirely.

## Return value

The bond-equivalent yield — equal to `(365 * discount) / (360 - (discount * DSM))`,
where DSM is the number of days between `settlement` and `maturity`.

## Description

A T-bill's quoted discount rate isn't directly comparable to a
bond's quoted yield — they're calculated on different bases (a
360-day year against face value, versus other conventions a bond
might use). TBILLEQ translates a T-bill's discount rate into the
equivalent yield figure a bond-equivalent comparison needs,
specifically so a T-bill and a coupon-paying bond can be evaluated
side by side on the same terms.

<ExcelCode>{`=TBILLEQ("3/31/2008", "6/1/2008", 0.0914) → 0.09415, or 9.42% (a 62-day bill at a 9.14% discount rate)`}</ExcelCode>

<Callout type="warn">
  **TBILLEQ uses a 365-day year**, unlike
  [TBILLPRICE](/docs/financial/tbillprice) and
  [TBILLYIELD](/docs/financial/tbillyield), which both use a
  360-day year — part of why the bond-equivalent yield comes out
  higher than the plain discount rate, beyond just the face-value-
  vs-price-paid difference TBILLYIELD already has.
</Callout>

## Common errors

### #NUM! — a non-positive discount rate

<ExcelCode>{`TBILLEQ("3/31/2008", "6/1/2008", 0) → #NUM!`}</ExcelCode>

`discount` must be strictly greater than `0`.

### Assuming TBILLEQ and TBILLYIELD return the same thing

<ExcelCode>{`TBILLEQ and TBILLYIELD both describe a T-bill's "yield" but on different day-count bases — they're not interchangeable`}</ExcelCode>

Use TBILLYIELD for the bill's own money-market yield (matching how
T-bills are typically quoted); use TBILLEQ specifically when
comparing against a bond that uses the 365-day convention.

        dsm = (maturity - settlement).days
        return (365 * discount) / (360 - (discount * dsm))
