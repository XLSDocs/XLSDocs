Calculate the price per $100 face value of a **coupon-paying bond**
— the standard bond-pricing calculation, accounting for every
remaining coupon payment and the accrued interest since the last one.

## Return value

The clean price per $100 face value — the present value of every
remaining coupon plus the redemption amount, discounted at `yld`,
with interest already accrued since the last coupon subtracted back
out.

## Description

Unlike [PRICEDISC](/docs/financial/pricedisc) or
[PRICEMAT](/docs/financial/pricemat), PRICE handles a bond that pays
a coupon on a recurring schedule — the general case most bonds
actually use. It discounts every coupon still owed between
`settlement` and `maturity`, plus the final `redemption` payment,
back to present value at the periodic yield:

<ExcelCode>{`dirty price = redemption/(1+y)^(N-1+p) + Σ coupon/(1+y)^(k-1+p), for k = 1 to N`}</ExcelCode>

<ExcelCode>{`PRICE = dirty price - accrued interest since the last coupon`}</ExcelCode>

Where `N` is the number of coupons remaining, `coupon` is
`redemption × rate / frequency`, `y` is `yld / frequency`, and `p`
is how much of the current coupon period is still ahead of
`settlement` (`1` exactly on a coupon date, smaller mid-period).

<ExcelCode>{`=PRICE(DATE(2008,2,15), DATE(2017,11,15), 5.75%, 6.5%, 100, 2, 0) → $94.63 (Microsoft's own documented example)`}</ExcelCode>

<Callout type="idea">
  **When `yld` exactly equals `rate`, PRICE returns exactly
  `redemption` (typically par, `100`)** — a bond priced to yield
  exactly its own coupon rate always trades at face value. Set `yld`
  above `rate` for a discount (price below par), or below `rate`
  for a premium (price above par).
</Callout>

With the coupon rate fixed at `5%`, a `yld` below that rate prices
the bond above par, and a `yld` above it prices the bond below par
— the inverse relationship between yield and price that defines
bond pricing.

## Common errors

### #NUM! — settlement on or after maturity

<ExcelCode>{`PRICE(DATE(2030,1,1), DATE(2025,1,1), 5%, 6.5%, 100, 2) → #NUM! (settlement is after maturity)`}</ExcelCode>

`settlement` has to fall strictly before `maturity`.

### #NUM! — an invalid frequency

<ExcelCode>{`PRICE(DATE(2025,1,1), DATE(2030,1,1), 5%, 6.5%, 100, 3) → #NUM! (frequency must be 1, 2, or 4)`}</ExcelCode>

`frequency` only accepts `1` (annual), `2` (semiannual), or `4`
(quarterly) — no other coupon schedule is supported.

    ```python lineNumbers
    # A simplified version covering only the case where settlement falls
    # exactly on a coupon date (N whole periods remaining, nothing accrued) —
    # the general mid-period case needs the DSC/E/A day-count adjustment too
    def price_on_coupon_date(rate, yld, frequency, periods_remaining, redemption=100):
        coupon = redemption * rate / frequency
        y = yld / frequency
        price = redemption / (1 + y) ** periods_remaining
        for k in range(1, periods_remaining + 1):
            price += coupon / (1 + y) ** k
        return price

    price = price_on_coupon_date(0.05, 0.065, 2, 10)
    print(price)
    ```
