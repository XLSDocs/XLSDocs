Calculate a bond's **modified duration** — a direct estimate of how
much its price moves for a given change in yield, derived from
[DURATION](/docs/financial/duration)'s Macaulay duration.

## Return value

The modified duration, in years — [DURATION](/docs/financial/duration)'s
Macaulay duration adjusted to more directly approximate the bond's
price sensitivity to a change in yield.

## Description

Macaulay duration measures a weighted-average time to cash flows,
but modified duration is the number actually used to estimate price
sensitivity — it rescales Macaulay duration by the periodic yield:

<ExcelCode>{`MDURATION = Macaulay duration / (1 + yld / frequency)`}</ExcelCode>

<ExcelCode>{`=MDURATION(DATE(2008,1,1), DATE(2016,1,1), 8%, 9%, 2, 1) → 5.736 years (Microsoft's own documented example)`}</ExcelCode>

<Callout type="idea">
  **Modified duration approximates the percentage price change for
  a small change in yield** — a bond with a modified duration of
  `5.736`, for example, is estimated to lose roughly `5.736%` of its
  price for each 1 percentage point `yld` rises (and gain roughly
  that much if `yld` falls instead). It's an approximation that gets
  less accurate for larger yield swings.
</Callout>

Modified duration runs consistently a bit below Macaulay duration
for the same inputs — dividing by `(1 + yld/frequency)` always
shrinks the number slightly.

## Common errors

### #NUM! — settlement on or after maturity

<ExcelCode>{`MDURATION(DATE(2030,1,1), DATE(2025,1,1), 5%, 6%, 2) → #NUM! (settlement is after maturity)`}</ExcelCode>

`settlement` has to fall strictly before `maturity`.

### #NUM! — an invalid frequency

<ExcelCode>{`MDURATION(DATE(2025,1,1), DATE(2030,1,1), 5%, 6%, 3) → #NUM! (frequency must be 1, 2, or 4)`}</ExcelCode>

`frequency` only accepts `1`, `2`, or `4`.

    ```python lineNumbers
    # Simplified version covering only the case where settlement falls
    # exactly on a coupon date — see DURATION's own code sample for the
    # Macaulay duration this builds on
    def mduration_on_coupon_date(coupon_rate, yld, frequency, periods_remaining, redemption=100):
        coupon = redemption * coupon_rate / frequency
        y = yld / frequency
        price = 0.0
        weighted = 0.0
        for k in range(1, periods_remaining + 1):
            cf = coupon + redemption if k == periods_remaining else coupon
            pv = cf / (1 + y) ** k
            price += pv
            weighted += k * pv
        macaulay_years = (weighted / price) / frequency
        return macaulay_years / (1 + y)

    years = mduration_on_coupon_date(0.08, 0.09, 2, 16)
    print(years)
    ```
