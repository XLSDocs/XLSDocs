Find the **previous coupon payment date** before settlement — the
actual calendar date, the mirror image of
[COUPNCD](/docs/financial/coupncd).

## Return value

The most recent coupon date before `settlement`, as a date serial
number.

## Description

Coupon dates are spaced `12/frequency` months apart, counting
backward from `maturity`. COUPPCD walks that schedule to find the
last one that falls on or before `settlement`:

<ExcelCode>{`=COUPPCD(DATE(2011,1,25), DATE(2011,11,15), 2, 1) → 11/15/2010 (Microsoft's own documented example)`}</ExcelCode>

<Callout type="idea">
  **COUPPCD is also [ACCRINT](/docs/financial/accrint)'s implicit
  starting point** for a bond that's already paid at least one
  coupon — once settlement is past the very first coupon period,
  accrued interest counts from this previous coupon date, not from
  the security's original issue date.
</Callout>

## Common errors

### #NUM! — settlement on or after maturity

<ExcelCode>{`COUPPCD(DATE(2011,11,15), DATE(2011,1,25), 2, 1) → #NUM! (settlement is after maturity)`}</ExcelCode>

`settlement` has to fall strictly before `maturity`.

### The result displays as a number instead of a date

<ExcelCode>{`COUPPCD(...) → 40492 (format the cell as a date to see 11/15/2010)`}</ExcelCode>

Like every Excel date, COUPPCD's result is a plain serial number
under the hood — format the cell as a date to display it the way
you'd expect.

    ```python lineNumbers
    from datetime import date
    from dateutil.relativedelta import relativedelta

    def previous_coupon_date(settlement, maturity, frequency):
        interval = relativedelta(months=12 // frequency)
        ncd = maturity
        while ncd > settlement:
            ncd -= interval
        while ncd <= settlement:
            ncd += interval
        return ncd - interval

    pcd = previous_coupon_date(date(2011, 1, 25), date(2011, 11, 15), 2)
    print(pcd)
    ```
