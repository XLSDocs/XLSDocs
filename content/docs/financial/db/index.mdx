Calculate depreciation using the fixed-declining balance method — a
constant rate applied to the asset's remaining book value each
period, so the depreciation amount itself shrinks year over year
instead of staying flat like SLN.

## Return value

The depreciation expense for `period`, computed by applying a fixed
rate (derived from `cost`, `salvage`, and `life`) to whatever book
value remains after prior periods' depreciation.

## Description

DB first computes a fixed rate: `1 − (salvage / cost)^(1/life)`,
rounded to 3 decimal places. Every period, that rate is applied to
the asset's **current** book value (cost minus all depreciation taken
so far), not the original cost — which is why the depreciation
amount itself shrinks each period, front-loading more expense into
the earlier years than SLN's flat schedule.

<Callout type="warn">
  DB's rate is rounded to **3 decimal places** before use, a
  deliberate (if coarse) simplification baked into the function
  itself — this means DB's schedule doesn't reduce the book value to
  *exactly* `salvage` by the end of `life` the way the underlying math
  would suggest, though it typically lands very close.
</Callout>

## Common errors

### #NUM! — salvage is greater than cost, or life is 0

<ExcelCode>{`DB(5000, 50000, 10, 1) → #NUM!`}</ExcelCode>

`salvage` must be less than `cost` for the rate calculation to make
sense — a salvage value higher than the original cost isn't valid.

### The book value doesn't land exactly on salvage after the last period

This is expected, not a calculation error — DB's rate is rounded to 3
decimal places by design, which means the schedule typically ends
very close to, but not precisely at, `salvage`.

### Using DB when DDB (double-declining balance) was intended

<ExcelCode>{`DB(50000, 5000, 10, 1) → $10,300.00, not the same as DDB(50000, 5000, 10, 1) → $10,000.00`}</ExcelCode>

DB and DDB are two different accelerated-depreciation methods with
different rate calculations — they aren't interchangeable, and their
schedules diverge more with each period.

  <CodeBlockTab value="Python">
    ```python lineNumbers
    def db(cost, salvage, life, period, month=12):
        rate = round(1 - (salvage / cost) ** (1 / life), 3)
        total_dep = 0
        for p in range(1, period + 1):
            dep = cost * rate * month / 12 if p == 1 else (cost - total_dep) * rate
            if p < period:
                total_dep += dep
        return dep

    yr1_depreciation = db(50000, 5000, 10, 1)
    ```
