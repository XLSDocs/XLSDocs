Calculate how many days remain **until the next coupon payment**,
counting forward from settlement — the mirror image of
[COUPDAYBS](/docs/financial/coupdaybs).

## Return value

The number of days between `settlement` and the next coupon date
after it.

## Description

COUPDAYSNC finds the first coupon date after `settlement` (the same
date [COUPNCD](/docs/financial/coupncd) returns), then counts how
many days are left until it arrives — the "DSC" figure
[PRICE](/docs/financial/price) and
[DURATION](/docs/financial/duration) use internally to discount the
current, partial coupon period:

<ExcelCode>{`=COUPDAYSNC(DATE(2011,1,25), DATE(2011,11,15), 2, 1) → 110 (Microsoft's own documented example — the next coupon date is 5/15/2011)`}</ExcelCode>

<Callout type="idea">
  **COUPDAYSNC and [COUPDAYBS](/docs/financial/coupdaybs) always
  add up to [COUPDAYS](/docs/financial/coupdays)** — days remaining
  plus days already elapsed in the current coupon period equal the
  period's full length, whatever `settlement` happens to be.
</Callout>

## Common errors

### #NUM! — settlement on or after maturity

<ExcelCode>{`COUPDAYSNC(DATE(2011,11,15), DATE(2011,1,25), 2, 1) → #NUM! (settlement is after maturity)`}</ExcelCode>

`settlement` has to fall strictly before `maturity`.

### #NUM! — an invalid frequency

<ExcelCode>{`COUPDAYSNC(DATE(2011,1,25), DATE(2011,11,15), 3, 1) → #NUM! (frequency must be 1, 2, or 4)`}</ExcelCode>

`frequency` only accepts `1`, `2`, or `4`.

    from datetime import date
    from dateutil.relativedelta import relativedelta

    def next_coupon_date(settlement, maturity, frequency):
        interval = relativedelta(months=12 // frequency)
        ncd = maturity
        while ncd > settlement:
            ncd -= interval
        while ncd <= settlement:
            ncd += interval
        return ncd

    ncd = next_coupon_date(date(2011, 1, 25), date(2011, 11, 15), 2)
    days_nc = (ncd - date(2011, 1, 25)).days  # actual/actual (basis=1) only
    print(days_nc)
