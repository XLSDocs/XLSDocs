Calculate the present-day value of a series of cash flows that don't
have to be equal — unlike PV, which assumes constant payments. The
standard way to evaluate whether a project or investment with
irregular returns is worth its cost.

## Return value

The sum of all cash flows, each discounted back to today's value at
`rate`, based on how many periods away it occurs.

## Description

NPV discounts a series of cash flows that don't need to be equal —
unlike PV, PMT, and FV, which all assume a constant payment amount
every period. This makes it the right tool for evaluating a real
investment or project where returns vary year to year (or are
negative in some periods).

<Callout type="warn">
  NPV assumes `value1` occurs **one full period from now**, not at
  time zero — it discounts every value you give it. An upfront cost
  paid today (time 0, like an initial investment) should **not** be
  included inside the NPV call; add it separately, undiscounted,
  after the NPV result:
  `=NPV(rate, year1, year2, year3) - initial_investment`. Including
  the initial investment as the first argument incorrectly discounts
  a cost that actually happens now.
</Callout>

## Common errors

### Result looks too optimistic — the timing mistake

<ExcelCode>{`NPV(10%, -50000, 15000, 18000, 20000) → wrong (the -50000 gets discounted, but it happens today)`}</ExcelCode>

The initial investment shouldn't be inside the NPV call at all — pull
it out and subtract it undiscounted:

<ExcelCode>{`NPV(10%, 15000, 18000, 20000) - 50000`}</ExcelCode>

### Mismatched cash flow periods

Every value passed to NPV is assumed to be exactly one period apart —
skipping a year, or mixing monthly and annual figures in the same
call, silently produces a meaningless result with no error at all.

## Related functions

- [PV](/docs/financial/pv) — present value of a series of *equal*
  cash flows, simpler when payments genuinely don't vary.
- [RATE](/docs/financial/rate) — solves for a constant interest rate
  given equal payments, a different question than NPV's fixed-rate,
  variable-cash-flow shape.
- [IRR](/docs/financial/irr) — finds the rate that makes NPV equal to
  zero, for the same shape of varying cash flows.
