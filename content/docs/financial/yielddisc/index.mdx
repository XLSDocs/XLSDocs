Calculate a discount security's **annual yield** — the investment
return a buyer actually earns, annualized against the price paid
rather than the redemption value DISC uses.

## Return value

The security's annualized yield — the return earned on the actual
price paid, as opposed to [DISC](/docs/financial/disc)'s discount
rate, which annualizes against the redemption value instead.

## Description

DISC and YIELDDISC both describe the same transaction — buying a
no-coupon security below its redemption value — but they annualize
the gap against different bases. YIELDDISC divides by the price
actually paid, which is the more intuitive "what did I actually
earn on my money" figure:

<ExcelCode>{`YIELDDISC = (redemption - pr) / pr × (days in a year, per basis) / (days between settlement and maturity)`}</ExcelCode>

<ExcelCode>{`=YIELDDISC(DATE(2008,2,16), DATE(2008,3,1), 99.795, 100, 2) → 5.28% (Microsoft's own documented example)`}</ExcelCode>

<Callout type="warn">
  **YIELDDISC's result is always slightly larger than DISC's**, for
  the same security — because it divides by the smaller `pr`
  instead of the larger `redemption`. The two numbers measure
  related but genuinely different things: DISC is the discount rate
  the security is quoted at, while YIELDDISC is the actual return
  earned on the money paid.
</Callout>

A lower price paid for the same `100` redemption value means a
bigger gain relative to what was actually spent — pushing the
computed yield up as `pr` moves down.

## Common errors

### #NUM! — settlement on or after maturity

<ExcelCode>{`YIELDDISC(DATE(2025,7,1), DATE(2025,1,1), 98, 100) → #NUM! (settlement is after maturity)`}</ExcelCode>

`settlement` has to fall strictly before `maturity`.

### #NUM! — a non-positive price or redemption value

<ExcelCode>{`YIELDDISC(DATE(2025,1,1), DATE(2025,7,1), 0, 100) → #NUM! (pr must be greater than 0)`}</ExcelCode>

Both `pr` and `redemption` have to be positive numbers.

  <CodeBlockTab value="Python">
    ```python lineNumbers
    from datetime import date

    def yielddisc(settlement, maturity, pr, redemption, year_days=360):
        # basis=2 (actual/360) only — other bases change year_days and/or
        # how the day span itself is counted
        dsm = (maturity - settlement).days
        return (redemption - pr) / pr * (year_days / dsm)

    yld = yielddisc(date(2008, 2, 16), date(2008, 3, 1), 99.795, 100)
    print(yld)
    ```
