Calculate depreciation using the double-declining balance method — by
default, twice the straight-line rate, applied to the asset's
shrinking book value each period. The most aggressively front-loaded
of Excel's built-in depreciation methods.

## Return value

The depreciation expense for `period`: the smaller of `book_value ×
(factor / life)` or `book_value − salvage` — whichever keeps the
book value from dropping below `salvage`.

## Description

DDB applies a fixed rate — by default, `2 / life` (double the plain
straight-line rate) — to the asset's current book value each period,
the same declining-balance mechanic DB uses, but with a simpler,
salvage-independent rate. `salvage` only comes into play as a floor:
once the book value would drop below it, DDB caps that period's
depreciation instead of overshooting.

<Callout type="warn">
  Because `salvage` only acts as a floor, DDB's schedule often
  **doesn't fully reach** `salvage` by the last period — the
  book value can end up sitting above it, with some depreciable
  amount effectively left unclaimed. Some models switch to
  straight-line for the remaining periods once DDB's rate would fall
  below it, to fully deplete the asset by end of life; DDB alone
  doesn't do this automatically.
</Callout>

## Common errors

### The asset never fully depreciates to salvage value

As the callout above explains, this is DDB's normal behavior, not a
mistake — the fixed rate can leave book value sitting above `salvage`
at the end of `life`. Switch to straight-line for the final period(s)
manually if fully depleting the asset by end of life is required.

### #NUM! — factor or life is zero or negative

<ExcelCode>{`DDB(50000, 5000, 0, 1) → #NUM!`}</ExcelCode>

`life` and `factor` must both be positive numbers — a zero or
negative value for either isn't valid.

### Confusing DDB with DB

<ExcelCode>{`DDB(50000, 5000, 10, 1) → $10,000.00, not the same as DB(50000, 5000, 10, 1) → $10,300.00`}</ExcelCode>

DDB and DB are two distinct accelerated-depreciation methods with
different rate formulas — not interchangeable, even though both
produce a declining-balance-style schedule.

    def ddb(cost, salvage, life, period, factor=2):
        book_value = cost
        dep = 0
        for p in range(1, period + 1):
            dep = min(book_value * factor / life, book_value - salvage)
            dep = max(dep, 0)
            book_value -= dep
        return dep

    yr1_depreciation = ddb(50000, 5000, 10, 1)
