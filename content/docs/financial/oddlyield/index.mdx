Calculate the yield of a bond whose **last coupon period doesn't
match the regular schedule** — the exact inverse of
[ODDLPRICE](/docs/financial/oddlprice).

## Return value

The annual yield implied by `pr`, for a bond whose last coupon
period — between `last_interest` and `maturity` — is shorter or
longer than every regular period before it.

## Description

ODDLYIELD rearranges [ODDLPRICE](/docs/financial/oddlprice)'s
formula to solve directly for yield, since that formula is simple
enough to invert algebraically:

<ExcelCode>{`ODDLYIELD = ([redemption + DCi×coupon] - [Ai×coupon + pr]) / [Ai×coupon + pr] × (frequency / DSCi)`}</ExcelCode>

Where `coupon` is `100 × rate / frequency`, and `DCi`, `DSCi`, and
`Ai` are the same period-length, discounting-span, and
accrued-interest figures ODDLPRICE itself uses.

<Callout type="idea">
  **ODDLYIELD doesn't need iteration, unlike
  [ODDFYIELD](/docs/financial/oddfyield)** — because ODDLPRICE's
  own formula only raises its discounting term to the first power
  (no fractional-exponent summation across multiple quasi-coupon
  periods), it can be rearranged directly to isolate `yld` on one
  side. The result is exact, not an approximation from repeated
  guessing.
</Callout>

<ExcelCode>{`=ODDLYIELD(DATE(2008,2,7), DATE(2008,6,15), DATE(2007,10,15), 3.75%, 99.88, 100, 2, 0) → 4.05% (Microsoft's own documented price, inverted)`}</ExcelCode>

sharply the yield swings here, since this bond's remaining life is
very short, so small price differences translate into large
annualized rate differences.

## Common errors

### #NUM! — dates out of the required order

<ExcelCode>{`ODDLYIELD(DATE(2007,10,15), DATE(2008,6,15), DATE(2008,2,7), 3.75%, 99.88, 100, 2) → #NUM!`}</ExcelCode>

Excel requires `maturity > settlement > last_interest`.

### #NUM! — a negative rate or price

<ExcelCode>{`ODDLYIELD(DATE(2008,2,7), DATE(2008,6,15), DATE(2007,10,15), -3.75%, 99.88, 100, 2) → #NUM!`}</ExcelCode>

Both `rate` and `pr` have to be zero or positive.

    ```python lineNumbers
    def days_360(d1, d2):
        # US (NASD) 30/360 day count — basis=0, Excel's default
        day1, day2 = d1.day, d2.day
        if day1 == 31:
            day1 = 30
        if day2 == 31 and day1 == 30:
            day2 = 30
        return (d2.year - d1.year) * 360 + (d2.month - d1.month) * 30 + (day2 - day1)

    def oddlyield(settlement, maturity, last_interest, rate, pr, redemption, frequency, year_days=360):
        dci = days_360(last_interest, maturity) / year_days * frequency
        dsci = days_360(settlement, maturity) / year_days * frequency
        ai = days_360(last_interest, settlement) / year_days * frequency
        coupon = 100 * rate / frequency
        term1 = dci * coupon + redemption
        term2 = ai * coupon + pr
        return (term1 - term2) / term2 * (frequency / dsci)
    ```
