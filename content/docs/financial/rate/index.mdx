Solve for the interest rate per period given a loan or annuity's
other terms — the payment, the number of periods, and the present
(and optionally future) value. Useful for checking what rate a
lender is actually charging, given only the payment schedule.

## Return value

The interest rate per period that makes the given `pmt`, `pv`, and
`fv` consistent with each other. Returns `#NUM!` if the underlying
iterative solver can't converge on an answer.

## Description

Unlike PMT/PV/FV, which solve their target directly, RATE has no
closed-form solution — Excel approximates it iteratively (Newton's
method), starting from `guess` and refining from there. Most of the
time this converges instantly and invisibly; it's only when the
inputs are unusual that the iteration itself becomes visible, as a
`#NUM!` error.

<Callout type="warn">
  Like PMT and PV, RATE expects `pmt` and `pv` to follow the
  cash-flow sign convention — opposite signs from each other (money
  received now, positive `pv`; money paid out each period, negative
  `pmt`). Using the same sign for both is a common cause of `#NUM!`,
  since it describes a scenario with no valid interest rate.
</Callout>

## Common errors

### #NUM! — the solver failed to converge

<ExcelCode>{`RATE(360, 1073.64, 200000) → #NUM! (pmt and pv have the same sign)`}</ExcelCode>

Check the sign convention first — `pmt` and `pv` should have opposite
signs for a normal loan or annuity:

<ExcelCode>{`RATE(360, -1073.64, 200000)`}</ExcelCode>

### #NUM! — a genuinely hard-to-converge case

Even with correct signs, some combinations of inputs converge slowly
or not at all from the default 10% starting guess. Supplying a
`guess` closer to the expected real answer often resolves it:

<ExcelCode>{`RATE(360, -1073.64, 200000, 0, 0, 0.5%)`}</ExcelCode>

### Result looks tiny — it's a per-period rate, not annual

<ExcelCode>{`RATE(360, -1073.64, 200000) → 0.417% (a monthly rate, not 5%)`}</ExcelCode>

RATE returns the rate for whatever period `nper`/`pmt` used — for a
monthly loan, that's a **monthly** rate. Multiply by periods per year
for the more familiar annual figure:

<ExcelCode>{`RATE(360, -1073.64, 200000) * 12`}</ExcelCode>

## Related functions

- [PMT](/docs/financial/pmt) — solves for the payment instead of the
  rate, given the other terms.
- [PV](/docs/financial/pv) — solves for the present value instead of
  the rate.
- [NPV](/docs/financial/npv) — a related but different question:
  the present value of *uneven* cash flows at a known rate.
- [IRR](/docs/financial/irr) — solves for the rate of *uneven* cash
  flows, instead of RATE's equal-payment assumption.
