calendar date, rather than a day count toward it.

## Return value

The first coupon date after `settlement`, as a date serial number.

## Description

Coupon dates are spaced `12/frequency` months apart, counting
backward from `maturity` — not forward from issue. COUPNCD walks
that schedule to find the first one that falls after `settlement`:

<ExcelCode>{`=COUPNCD(DATE(2011,1,25), DATE(2011,11,15), 2, 1) → 5/15/2011 (Microsoft's own documented example)`}</ExcelCode>

<Callout type="warn">
  **COUPNCD is a step function of `settlement`, not a smooth one** —
  every settlement date within the same coupon period returns the
  exact same next coupon date. The result only changes once
  `settlement` crosses an actual coupon date.
</Callout>

## Common errors

### #NUM! — settlement on or after maturity

<ExcelCode>{`COUPNCD(DATE(2011,11,15), DATE(2011,1,25), 2, 1) → #NUM! (settlement is after maturity)`}</ExcelCode>

`settlement` has to fall strictly before `maturity`.

### The result displays as a number instead of a date

<ExcelCode>{`COUPNCD(...) → 40674 (format the cell as a date to see 5/15/2011)`}</ExcelCode>

Like every Excel date, COUPNCD's result is a plain serial number
under the hood — format the cell as a date to display it the way
you'd expect.

    from datetime import date
    from dateutil.relativedelta import relativedelta

    def next_coupon_date(settlement, maturity, frequency):
        interval = relativedelta(months=12 // frequency)
        ncd = maturity
        while ncd > settlement:
            ncd -= interval
        while ncd <= settlement:
            ncd += interval
        return ncd

    ncd = next_coupon_date(date(2011, 1, 25), date(2011, 11, 15), 2)
    print(ncd)
