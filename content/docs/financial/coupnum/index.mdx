Calculate **how many coupon payments are left** between settlement
and maturity — the `N` figure
[PRICE](/docs/financial/price) and
[DURATION](/docs/financial/duration) sum their cash flows over.

## Return value

The number of coupon payments remaining between `settlement` and
`maturity`, counted as whole coupon dates — starting with the next
one after `settlement` and ending at `maturity` itself.

## Description

Starting from the next coupon date after `settlement` (the same
date [COUPNCD](/docs/financial/coupncd) finds), COUPNUM counts every
remaining coupon payment up through `maturity`:

<ExcelCode>{`=COUPNUM(DATE(2011,1,25), DATE(2011,11,15), 2, 1) → 2 (Microsoft's own documented example — the remaining coupons are 5/15/2011 and 11/15/2011)`}</ExcelCode>

<Callout type="idea">
  **A settlement date just one day after a coupon payment still
  counts the same number of remaining coupons** as a settlement
  date right before the next one — COUPNUM only cares how many
  coupon dates are still ahead, not how much of the current period
  has already elapsed. That finer-grained detail is what
  [COUPDAYBS](/docs/financial/coupdaybs) and
  [COUPDAYSNC](/docs/financial/coupdaysnc) are for.
</Callout>

Moving `settlement` closer to `maturity` reduces the number of
coupon payments still owed — a full year earlier, this semiannual
bond still has four coupons left; close to maturity, only one.

## Common errors

### #NUM! — settlement on or after maturity

<ExcelCode>{`COUPNUM(DATE(2011,11,15), DATE(2011,1,25), 2, 1) → #NUM! (settlement is after maturity)`}</ExcelCode>

`settlement` has to fall strictly before `maturity`.

### #NUM! — an invalid frequency

<ExcelCode>{`COUPNUM(DATE(2011,1,25), DATE(2011,11,15), 3, 1) → #NUM! (frequency must be 1, 2, or 4)`}</ExcelCode>

`frequency` only accepts `1`, `2`, or `4`.

  <CodeBlockTab value="Python">
    ```python lineNumbers
    from datetime import date
    from dateutil.relativedelta import relativedelta

    def coupon_count(settlement, maturity, frequency):
        interval = relativedelta(months=12 // frequency)
        ncd = maturity
        while ncd > settlement:
            ncd -= interval
        while ncd <= settlement:
            ncd += interval
        count = 0
        d = ncd
        while d <= maturity:
            count += 1
            d += interval
        return count

    n = coupon_count(date(2011, 1, 25), date(2011, 11, 15), 2)
    print(n)
    ```
