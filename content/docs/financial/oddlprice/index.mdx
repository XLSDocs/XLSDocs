Calculate the price of a bond whose **last coupon period doesn't
match the regular schedule** — shorter or longer than every coupon
period before it, which happens when the stretch from the last
regular coupon to maturity doesn't divide evenly.

## Return value

The price per $100 face value of a bond whose last coupon period —
between `last_interest` and `maturity` — is shorter or longer than
every regular period before it.

## Description

ODDLPRICE discounts the irregular final stretch of a bond's life
back to present value, then subtracts the interest already accrued
since `last_interest`:

<ExcelCode>{`ODDLPRICE = [redemption + DCi × (100 × rate/frequency)] / [1 + DSCi × yld/frequency] - Ai × (100 × rate/frequency)`}</ExcelCode>

Where `DCi` is the odd last period's length (in regular-period
units), `DSCi` is the discounting span from `settlement` to
`maturity` (also in regular-period units), and `Ai` is the interest
already accrued since `last_interest`.

<Callout type="idea">
  **ODDLPRICE needs only one formula, where
  [ODDFPRICE](/docs/financial/oddfprice) needs two** — because
  there's no equivalent of ODDFPRICE's "quasi-coupon period"
  summation to worry about here: the last period is the *only*
  period left to discount over, however long or short it is,
  rather than one odd period followed by many regular ones still
  ahead.
</Callout>

<ExcelCode>{`=ODDLPRICE(DATE(2008,2,7), DATE(2008,6,15), DATE(2007,10,15), 3.75%, 4.05%, 100, 2, 0) → $99.88 (Microsoft's own documented example)`}</ExcelCode>

## Common errors

### #NUM! — dates out of the required order

<ExcelCode>{`ODDLPRICE(DATE(2007,10,15), DATE(2008,6,15), DATE(2008,2,7), 3.75%, 4.05%, 100, 2) → #NUM!`}</ExcelCode>

Excel requires `maturity > settlement > last_interest`.

### #NUM! — a negative rate or yield

<ExcelCode>{`ODDLPRICE(DATE(2008,2,7), DATE(2008,6,15), DATE(2007,10,15), -3.75%, 4.05%, 100, 2) → #NUM!`}</ExcelCode>

Both `rate` and `yld` have to be zero or positive.

    ```python lineNumbers
    def days_360(d1, d2):
        # US (NASD) 30/360 day count — basis=0, Excel's default
        day1, day2 = d1.day, d2.day
        if day1 == 31:
            day1 = 30
        if day2 == 31 and day1 == 30:
            day2 = 30
        return (d2.year - d1.year) * 360 + (d2.month - d1.month) * 30 + (day2 - day1)

    def oddlprice(settlement, maturity, last_interest, rate, yld, redemption, frequency, year_days=360):
        dci = days_360(last_interest, maturity) / year_days * frequency
        dsci = days_360(settlement, maturity) / year_days * frequency
        ai = days_360(last_interest, settlement) / year_days * frequency
        coupon = 100 * rate / frequency
        return (redemption + dci * coupon) / (1 + dsci * yld / frequency) - ai * coupon
    ```
