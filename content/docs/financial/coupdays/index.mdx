Calculate the **total length, in days, of the coupon period
containing settlement** — the denominator behind every
proration calculation in this site's bond-pricing family.

## Return value

The number of days from the coupon date before `settlement` to the
coupon date after it — the full length of whichever period
`settlement` happens to fall in.

## Description

Every other proration this family of functions does — accrued
interest, the fractional-period adjustment inside
[PRICE](/docs/financial/price) — is expressed as a fraction *of*
this period length. COUPDAYS finds that length directly:

<ExcelCode>{`=COUPDAYS(DATE(2011,1,25), DATE(2011,11,15), 2, 1) → 181 (Microsoft's own documented example — the period runs 11/15/2010 to 5/15/2011)`}</ExcelCode>

<Callout type="warn">
  **A semiannual coupon period isn't always exactly 180 or 182
  days** — under `basis 1` (actual/actual), the real calendar
  length of each half-year period varies slightly depending on
  which months it spans and whether a leap day falls inside it.
  Only the 30/360-style bases (`0` and `4`) force every period to a
  fixed round number of days.
</Callout>

With the same settlement and maturity dates, a higher `frequency`
packs more, shorter coupon periods into the same year — quarterly
periods run roughly a quarter the length of annual ones.

## Common errors

### #NUM! — settlement on or after maturity

<ExcelCode>{`COUPDAYS(DATE(2011,11,15), DATE(2011,1,25), 2, 1) → #NUM! (settlement is after maturity)`}</ExcelCode>

`settlement` has to fall strictly before `maturity`.

### #NUM! — an invalid frequency

<ExcelCode>{`COUPDAYS(DATE(2011,1,25), DATE(2011,11,15), 3, 1) → #NUM! (frequency must be 1, 2, or 4)`}</ExcelCode>

`frequency` only accepts `1`, `2`, or `4`.

    ```python lineNumbers
    from datetime import date
    from dateutil.relativedelta import relativedelta

    def coupon_period_bounds(settlement, maturity, frequency):
        interval = relativedelta(months=12 // frequency)
        ncd = maturity
        while ncd > settlement:
            ncd -= interval
        while ncd <= settlement:
            ncd += interval
        return ncd - interval, ncd  # previous, next

    pcd, ncd = coupon_period_bounds(date(2011, 1, 25), date(2011, 11, 15), 2)
    days_in_period = (ncd - pcd).days  # actual/actual (basis=1) only
    print(days_in_period)
    ```
