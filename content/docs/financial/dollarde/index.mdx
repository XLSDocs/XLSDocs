Convert a dollar amount written as a **fraction** — the way bond and
securities prices are traditionally quoted, like `1.02` meaning "1
and 2/16" — into an ordinary decimal number.

## Return value

`fractional_dollar`, converted to an ordinary decimal number —
`1.02` interpreted against `fraction=16` (1 and 2/16) becomes
`1.125`.

## Description

Bond and securities prices are traditionally quoted in fractions of
a dollar — a price of "101 and 4/32" rather than a decimal. Entered
directly into Excel, `101.04` looks like a decimal number but isn't
one: the `.04` is meant to be read as *4/32*, not *four
hundredths*. DOLLARDE performs that reinterpretation, turning the
fraction-styled number into the actual decimal value Excel can do
ordinary arithmetic with.

<Callout type="warn">
  **The digits after the decimal point are a numerator, not a
  decimal fraction.** `DOLLARDE(1.02, 16)` doesn't mean "1.02 dollars
  converted somehow" — it means "1 and 2/16," which equals `1.125`.
  Treating the input as an ordinary decimal and skipping DOLLARDE
  entirely silently produces the wrong number for any further
  calculation.
</Callout>

## Common errors

### #DIV/0! — a fraction between 0 and 1

<ExcelCode>{`DOLLARDE(1.02, 0.5) → #DIV/0!`}</ExcelCode>

`fraction` needs to be `1` or greater — it's a denominator like 16
or 32, not itself a fraction.

### #NUM! — a negative fraction

<ExcelCode>{`DOLLARDE(1.02, -16) → #NUM!`}</ExcelCode>

`fraction` must be zero or positive; Excel truncates a non-integer
fraction automatically rather than erroring on it.

    import math

    def dollarde(fractional_dollar, fraction):
        n = math.trunc(fractional_dollar)
        frac = abs(fractional_dollar - n)
        digits = math.ceil(math.log10(fraction))
        numerator = round(frac * 10 ** digits)
        return n + numerator / fraction

    result = dollarde(1.02, 16)
