Convert a number between euros and one of the national currencies
that joined the euro, using the fixed official rates set at the time
each currency adopted it — not a live, floating exchange rate.
Requires the **Euro Currency Tools** add-in to be enabled first.

## Return value

`number` converted from `source` to `target`, using the fixed rate
each legacy currency was locked to when it adopted the euro. If
`source` and `target` are the same code, EUROCONVERT returns `number`
unchanged.

## Description

EUROCONVERT exists for a specific historical purpose: converting
amounts between the euro and the national currencies it replaced
(German mark, French franc, Italian lira, and the other legacy EU
currencies), using the exact fixed rate the EU set when each currency
joined — not a market exchange rate that moves day to day.

<ExcelCode>{`=EUROCONVERT(100, "DEM", "EUR") → converts 100 German marks to euros at the fixed 1999 accession rate`}</ExcelCode>

Converting between two non-euro currencies (say, francs to lire)
triangulates through euros internally — convert to euros, then to the
target currency — and `triangulation_precision` controls how many
significant digits that intermediate euro amount is rounded to before
the second conversion.

<Callout type="warn">
  **EUROCONVERT does nothing until the Euro Currency Tools add-in is
  enabled** (File → Options → Add-ins → Manage: Excel Add-ins →
  Euro Currency Tools). Without it, the function isn't recognized at
  all and returns `#NAME?`.
</Callout>

## Common errors

### #NAME? — the add-in isn't enabled

<ExcelCode>{`EUROCONVERT(100, "DEM", "EUR") → #NAME? if Euro Currency Tools isn't enabled`}</ExcelCode>

Enable the Euro Currency Tools add-in first — EUROCONVERT isn't a
built-in function the way most others on this site are.

### #VALUE! — an invalid currency code

<ExcelCode>{`EUROCONVERT(100, "USD", "EUR") → #VALUE! (USD was never a legacy euro-adoption currency)`}</ExcelCode>

`source` and `target` must be euro or one of the specific legacy
currencies that adopted it (DEM, FRF, ITL, and similar) — not an
arbitrary world currency like USD or GBP.
