Calculate the modified internal rate of return — like IRR, a single
rate summarizing a series of cash flows, but one that lets financing
costs and reinvestment returns be set separately instead of assuming
they're both the same as the result itself.

## Return value

A single rate of return for `values`, computed by discounting
outflows at `finance_rate` and compounding inflows forward at
`reinvest_rate`, rather than assuming a single rate applies to both.

## Description

Plain `IRR` implicitly assumes every positive cash flow gets
reinvested at the *same* rate as the result it's solving for —
usually unrealistic, since money coming back from a project rarely
gets reinvested at that project's own return rate. MIRR fixes this by
letting financing cost and reinvestment return be specified
separately: outflows are valued at `finance_rate` (what borrowing
that money would cost), and inflows are grown forward at
`reinvest_rate` (a more realistic rate for whatever they'd actually
be reinvested in).

<Callout type="warn">
  MIRR needs **at least one negative and one positive** value in
  `values` — a series that's all inflows or all outflows has no
  meaningful rate of return to solve for, and returns `#DIV/0!`
</Callout>

The same $50,000 investment and returns as IRR's "base" scenario
(whose plain IRR comes out to about 2.83%). With a 10% financing rate
and a more optimistic 15% reinvestment rate, MIRR rises to 6.58% —
noticeably different from IRR's own answer, since MIRR isn't
assuming the inflows compound at the project's own (much lower) rate.

## Common errors

### #DIV/0! — values has no negative (or no positive) numbers

<ExcelCode>{`MIRR({10000, 20000, 30000}, 10%, 10%) → #DIV/0!`}</ExcelCode>

Every cash flow series needs at least one outflow (negative) and one
inflow (positive) — an all-positive or all-negative series has
nothing to compute a rate of return from.

### Confusing MIRR's result with plain IRR's

<ExcelCode>{`IRR(cash flows) → 2.83%, but MIRR(cash flows, 10%, 15%) → 6.58%`}</ExcelCode>

These aren't measuring the same thing, and shouldn't be expected to
match — MIRR incorporates two additional assumptions (financing and
reinvestment rates) that IRR folds into a single implicit rate
instead.
