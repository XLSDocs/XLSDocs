Calculate how many **periods** an investment needs to grow from
`pv` to `fv`, at a constant per-period rate — "how long until this
investment doubles" turned into a formula.

## Return value

The number of periods needed for `pv` to grow into `fv` at `rate`
per period — equal to `LOG(fv/pv) / LOG(1+rate)`. Not necessarily a
whole number.

## Description

PDURATION answers a specific, common question in reverse from most
financial functions: instead of "how much will this grow to," it's
"how long until this grows to a specific target." It's the single-
rate special case of [NPER](/docs/financial/nper) — PDURATION takes
no `pmt` argument at all, assuming the only thing happening is `pv`
compounding on its own toward `fv`.

<ExcelCode>{`=PDURATION(2.5%, 2000, 2200) → 3.86 (years for $2,000 at 2.5% annual interest to reach $2,200)`}</ExcelCode>

<Callout type="idea">
  The result is rarely a whole number — `3.86` periods means the
  target is reached partway through the 4th period, not that it
  takes exactly 4. Round up with
  [ROUNDUP](/docs/math/roundup) if "how many *complete* periods"
  is what's actually needed.
</Callout>

## Common errors

### #NUM! — a non-positive argument

<ExcelCode>{`PDURATION(2.5%, -2000, 2200) → #NUM! (pv must be positive)`}</ExcelCode>

`rate`, `pv`, and `fv` all have to be positive numbers — PDURATION
has no concept of a negative cash-flow convention the way PMT/FV do.

### Expecting a whole number of periods

<ExcelCode>{`PDURATION(2.5%, 2000, 2200) → 3.86, not 4`}</ExcelCode>

The result is a continuous value, not rounded to the nearest whole
period — wrap in `ROUNDUP` explicitly if a whole-period answer is
needed.
