Calculate a bond's **Macaulay duration** — the weighted-average time
(in years) it takes to receive the bond's cash flows, weighted by
each payment's present value. A standard measure of a bond's
sensitivity to interest-rate changes.

## Return value

The Macaulay duration, in years — the present-value-weighted average
time until each of the bond's remaining cash flows (coupons plus the
final redemption) arrives.

## Description

Every coupon payment and the final redemption amount contributes
some weight to a bond's overall "effective maturity" — a payment
far in the future, discounted heavily, contributes less than one
arriving soon. DURATION computes that weighted average directly:

<ExcelCode>{`Macaulay duration (periods) = [Σ k × CF_k / (1+y)^k] / [Σ CF_k / (1+y)^k], for k = 1 to N`}</ExcelCode>

<ExcelCode>{`Macaulay duration (years) = Macaulay duration (periods) / frequency`}</ExcelCode>

Where `CF_k` is the cash flow in period `k` (the coupon amount, plus
`redemption` for the final period), `y` is `yld / frequency`, and
`N` is the number of coupon periods remaining — the denominator here
is exactly the bond's own [PRICE](/docs/financial/price).

<ExcelCode>{`=DURATION(DATE(2018,7,1), DATE(2048,1,1), 8%, 9%, 2, 1) → 10.9191453 years (Microsoft's own documented example)`}</ExcelCode>

<Callout type="idea">
  **Duration is always shorter than the bond's remaining time to
  maturity**, because every coupon paid along the way pulls some
  weight toward the present — only a zero-coupon bond has a
  duration exactly equal to its time to maturity.
</Callout>

## Common errors

### #NUM! — settlement on or after maturity

<ExcelCode>{`DURATION(DATE(2030,1,1), DATE(2025,1,1), 5%, 6%, 2) → #NUM! (settlement is after maturity)`}</ExcelCode>

`settlement` has to fall strictly before `maturity`.

### #NUM! — an invalid frequency

<ExcelCode>{`DURATION(DATE(2025,1,1), DATE(2030,1,1), 5%, 6%, 3) → #NUM! (frequency must be 1, 2, or 4)`}</ExcelCode>

`frequency` only accepts `1`, `2`, or `4`.

    ```python lineNumbers
    # Simplified version covering only the case where settlement falls
    # exactly on a coupon date — the general mid-period case needs the
    # same DSC/E/A day-count adjustment PRICE uses
    def duration_on_coupon_date(coupon_rate, yld, frequency, periods_remaining, redemption=100):
        coupon = redemption * coupon_rate / frequency
        y = yld / frequency
        price = 0.0
        weighted = 0.0
        for k in range(1, periods_remaining + 1):
            cf = coupon + redemption if k == periods_remaining else coupon
            pv = cf / (1 + y) ** k
            price += pv
            weighted += k * pv
        return (weighted / price) / frequency

    years = duration_on_coupon_date(0.08, 0.09, 2, 59)
    print(years)
    ```
