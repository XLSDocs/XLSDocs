Convert an ordinary **decimal number into fraction notation** — the
traditional way bond and securities prices are quoted, like `1.125`
becoming `1.02` (read as "1 and 2/16"). The exact inverse of
[DOLLARDE](/docs/financial/dollarde).

## Return value

`decimal_dollar`, re-expressed in fraction notation — `1.125`
expressed against `fraction=16` becomes `1.02` (read as "1 and
2/16," not as 1.02 dollars).

## Description

DOLLARFR is the reverse of [DOLLARDE](/docs/financial/dollarde): it
takes an ordinary decimal result from a calculation and re-expresses
it the way bond and securities prices are traditionally quoted —
digits after the decimal point standing for a fraction's numerator,
not a true decimal value. This matters whenever a calculated price
needs to be displayed or re-entered in the market's conventional
fraction format.

<Callout type="warn">
  **The output isn't a true decimal, even though it looks like one.**
  `DOLLARFR(1.125, 16)` returns `1.02` — read as "1 and 2/16," which
  happens to display identically to "one point zero two." Doing
  further ordinary arithmetic on that `1.02` result (adding,
  multiplying) treats it as a real decimal and produces a nonsensical
  answer; convert back with DOLLARDE first if more math is needed.
</Callout>

## Common errors

### #DIV/0! — a fraction of exactly 0

<ExcelCode>{`DOLLARFR(1.125, 0) → #DIV/0!`}</ExcelCode>

`fraction` can't be `0` — it's the denominator of the output
fraction, which has to be a real positive value.

### Doing further math on the result directly

<ExcelCode>{`DOLLARFR(1.125, 16) + DOLLARFR(2.25, 16) → wrong — these are fraction-notation numbers, not decimals to add together`}</ExcelCode>

Convert each result back to a true decimal with DOLLARDE before
combining them in further arithmetic.

    ```python lineNumbers
    import math

    def dollarfr(decimal_dollar, fraction):
        n = math.trunc(decimal_dollar)
        frac = abs(decimal_dollar - n)
        digits = math.ceil(math.log10(fraction))
        numerator = frac * fraction
        return n + numerator / 10 ** digits

    result = dollarfr(1.125, 16)
    ```
