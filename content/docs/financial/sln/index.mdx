Calculate the depreciation expense for one period using the
straight-line method — the same fixed amount every period, spreading
an asset's cost evenly over its useful life.

## Return value

The depreciation expense for one period: `(cost - salvage) / life`
— identical for every period over the asset's life.

## Description

SLN is the simplest depreciation method Excel offers: it subtracts
the asset's expected salvage value from its cost, then divides the
remainder evenly across every period of its useful life. Every
period gets the exact same expense, unlike accelerated methods
(`DDB`, `DB`) that front-load larger depreciation in the earlier
periods and taper off later.

<Callout type="info">
  `life` and the period length implied by `cost`/`salvage` should
  agree on units — if `life` is expressed in years, the result is an
  **annual** depreciation figure; divide by 12 separately for a
  monthly figure. SLN itself has no separate period argument the way
  `DDB` does.
</Callout>

## Common errors

### Forgetting to subtract salvage value first

<ExcelCode>{`SLN(50000, 0, 10) → 5000/year (only correct if salvage is genuinely $0)`}</ExcelCode>

If the asset actually has a resale/scrap value at the end of its
life, leaving `salvage` at 0 overstates depreciation — use the real
expected salvage value:

<ExcelCode>{`SLN(50000, 5000, 10) → 4500/year`}</ExcelCode>

### Expecting a declining depreciation amount

<ExcelCode>{`SLN(50000, 5000, 10) → 4500 every year, not decreasing`}</ExcelCode>

This is expected — straight-line depreciation is flat by definition.
For a front-loaded schedule instead, a different method like `DDB`
is needed.

### Mismatched time units between life and the depreciation period needed

If `life` is in years but a monthly figure is actually needed, divide
SLN's result by 12 separately — the function itself doesn't take a
period-length argument to do that conversion automatically.
