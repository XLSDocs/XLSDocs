Calculate the price per $100 face value of a security that pays
**all of its interest in one lump sum at maturity** — PRICEMAT's
coupon-bearing counterpart to [PRICEDISC](/docs/financial/pricedisc)'s
pure-discount case.

## Return value

The price per $100 face value implied by `yld`, for a security that
pays its entire interest amount in one lump sum at `maturity`,
accounting for interest already accrued between `issue` and
`settlement`.

## Description

PRICEMAT handles a security that accrues interest continuously but
pays it all out at once when it matures — the same payment shape
[ACCRINTM](/docs/financial/accrintm) describes — and solves for what
a buyer should pay today, given a target yield:

<ExcelCode>{`PRICEMAT = [100 + (DIM/B × rate × 100)] / [1 + (DSM/B × yld)] - (A/B × rate × 100)`}</ExcelCode>

Where `DIM` is the day count from `issue` to `maturity`, `DSM` is
from `settlement` to `maturity`, `A` is from `issue` to `settlement`
(the interest already accrued before the trade), and `B` is the
year length for the chosen `basis`.

<ExcelCode>{`=PRICEMAT(DATE(2025,4,1), DATE(2026,1,1), DATE(2025,1,1), 5%, 5%, 0) → $99.95 (settlement 3 months after issue, 9 months before maturity)`}</ExcelCode>

<Callout type="idea">
  **When `yld` exactly equals `rate`, PRICEMAT returns almost exactly
  par (`100`)** — the buyer pays face value because the security's
  stated interest rate already matches the return they're targeting.
  Set `yld` above `rate` for a price below par, or below `rate` for
  a price above par.
</Callout>

security today.

## Common errors

### #NUM! — dates out of order

<ExcelCode>{`PRICEMAT(DATE(2025,1,1), DATE(2026,1,1), DATE(2025,4,1), 5%, 5%) → #NUM! (issue is after settlement)`}</ExcelCode>

`issue` has to fall on or before `settlement`, which in turn has to
fall before `maturity`.

### #NUM! — a non-positive rate or yield

<ExcelCode>{`PRICEMAT(DATE(2025,4,1), DATE(2026,1,1), DATE(2025,1,1), 0, 5%) → #NUM! (rate must be greater than 0)`}</ExcelCode>

Both `rate` and `yld` have to be positive numbers.

    ```python lineNumbers
    from datetime import date

    def days_360(d1, d2):
        # US (NASD) 30/360 day count — basis=0, Excel's default
        day1, day2 = d1.day, d2.day
        if day1 == 31:
            day1 = 30
        if day2 == 31 and day1 == 30:
            day2 = 30
        return (d2.year - d1.year) * 360 + (d2.month - d1.month) * 30 + (day2 - day1)

    def pricemat(settlement, maturity, issue, rate, yld, year_days=360):
        dim = days_360(issue, maturity)
        dsm = days_360(settlement, maturity)
        a = days_360(issue, settlement)
        numerator = 100 + (dim / year_days) * rate * 100
        accrued = (a / year_days) * rate * 100
        return numerator / (1 + (dsm / year_days) * yld) - accrued

    price = pricemat(date(2025, 4, 1), date(2026, 1, 1), date(2025, 1, 1), 0.05, 0.05)
    print(price)
    ```
