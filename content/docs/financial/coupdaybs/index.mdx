Calculate how many days have elapsed **since the last coupon
payment**, up to the settlement date — one of the building blocks
bond-pricing functions like [PRICE](/docs/financial/price) use
internally to prorate accrued interest.

## Return value

The number of days between the coupon date immediately before
`settlement` and `settlement` itself.

## Description

Bonds pay coupons on a fixed schedule derived backward from
`maturity`, spaced `12/frequency` months apart. COUPDAYBS finds the
most recent one of those coupon dates that falls before
`settlement`, then counts the days from there up to `settlement` —
exactly the portion of the current coupon period a seller has
already earned.

<ExcelCode>{`=COUPDAYBS(DATE(2011,1,25), DATE(2011,11,15), 2, 1) → 71 (Microsoft's own documented example — the previous coupon date is 11/15/2010)`}</ExcelCode>

<Callout type="idea">
  **COUPDAYBS and [COUPDAYSNC](/docs/financial/coupdaysnc) always
  add up to [COUPDAYS](/docs/financial/coupdays)** — the days
  already elapsed plus the days still remaining in the current
  coupon period equal the period's total length, no matter where
  `settlement` falls within it.
</Callout>

## Common errors

### #NUM! — settlement on or after maturity

<ExcelCode>{`COUPDAYBS(DATE(2011,11,15), DATE(2011,1,25), 2, 1) → #NUM! (settlement is after maturity)`}</ExcelCode>

`settlement` has to fall strictly before `maturity`.

### #NUM! — an invalid frequency

<ExcelCode>{`COUPDAYBS(DATE(2011,1,25), DATE(2011,11,15), 3, 1) → #NUM! (frequency must be 1, 2, or 4)`}</ExcelCode>

`frequency` only accepts `1`, `2`, or `4`.

    ```python lineNumbers
    from datetime import date
    from dateutil.relativedelta import relativedelta

    def previous_coupon_date(settlement, maturity, frequency):
        interval = relativedelta(months=12 // frequency)
        ncd = maturity
        while ncd > settlement:
            ncd -= interval
        while ncd <= settlement:
            ncd += interval
        return ncd - interval

    pcd = previous_coupon_date(date(2011, 1, 25), date(2011, 11, 15), 2)
    days_bs = (date(2011, 1, 25) - pcd).days  # actual/actual (basis=1) only
    print(days_bs)
    ```
