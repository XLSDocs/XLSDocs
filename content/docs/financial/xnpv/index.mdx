Calculate the present value of cash flows that land on real,
unevenly spaced calendar dates — the realistic version of NPV for
investments that don't pay out on a perfectly regular schedule.

## Return value

The net present value of the dated cash flows, discounted back to
the date of the **first** entry in `dates` using `rate`.

## Description

NPV assumes cash flows happen at even, regular intervals and
discounts each one by a whole number of periods. XNPV instead uses
the actual number of days between each cash flow's real date and the
first date, which is what makes it accurate for investments that pay
out on a genuine, irregular calendar rather than a tidy period-by-
period schedule.

<Callout type="info">
  Unlike NPV, XNPV's first cash flow **is** included in the
  discounting (though at zero discount, since it falls on the
  valuation date itself) — there's no separate "add the initial
  investment outside the function" step the way plain NPV requires.
</Callout>

## Common errors

### Mismatched values and dates sizes

<ExcelCode>{`XNPV(8%, A2:A5, B2:B4) → error`}</ExcelCode>

`values` and `dates` must contain exactly the same number of
entries, each pair at the same row position.

### Confusing XNPV's date handling with NPV's period handling

<ExcelCode>{`NPV(8%, A2:A5) → assumes evenly spaced periods, no dates involved`}</ExcelCode>

If the cash flows don't actually land on a regular schedule, NPV's
result will be inaccurate — that's exactly the gap XNPV closes by
using real dates instead.

### Expecting the initial investment to be added separately

XNPV doesn't have NPV's "leave the first cash flow out, add it back
manually" convention — every cash flow, including the initial
investment, belongs inside `values` alongside its matching date.

  <CodeBlockTab value="Python">
    ```python lineNumbers
    from datetime import date

    def xnpv(rate, values, dates):
        d0 = dates[0]
        return sum(v / (1 + rate) ** ((d - d0).days / 365) for v, d in zip(values, dates))

    cash_flows = [-50000, 20000, 35000]
    dates = [date(2026, 3, 1), date(2026, 7, 15), date(2027, 2, 1)]
    present_value = xnpv(0.08, cash_flows, dates)
    print(present_value)
    ```

  flows, with no dates required.
- [IRR](/docs/financial/irr) — solves for the rate on evenly spaced
