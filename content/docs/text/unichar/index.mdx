Convert a Unicode code point into the actual character it
represents — [CHAR](/docs/text/char)'s full-range counterpart,
covering emoji, accented letters, currency symbols, and virtually
every character used in any written language.

## Return value

The single Unicode character that corresponds to `number`.

## Description

CHAR is limited to codes 1 through 255 and depends on your
computer's local character set for anything above 127. UNICHAR has
neither limitation — it covers the entire Unicode standard, so the
same code point always produces the same character on any computer,
in any region.

<Callout type="idea">
  **UNICHAR is the reliable choice for anything beyond basic
  English letters and punctuation** — currency symbols like `€`
  (8364) and `£` (163), accented letters, and most emoji all have
  well-defined Unicode code points that UNICHAR returns
  consistently, where CHAR's result for the same numbers would be
  unpredictable or simply wrong.
</Callout>

## Common errors

### #VALUE! — a number outside the valid Unicode range

<ExcelCode>{`UNICHAR(0) → #VALUE! (0 isn't a valid code point)`}</ExcelCode>

`number` has to be a genuine Unicode code point — 0 and negative
numbers aren't valid, and the upper bound is 1,114,111 (the highest
code point Unicode defines).

### The character shows as a box or question mark

<ExcelCode>{`UNICHAR(128512) → might display as □ if the cell's font doesn't include that character`}</ExcelCode>

UNICHAR always returns the *correct* character, but your font still
has to actually contain a glyph for it — this is especially common
with emoji code points on an older or limited font.

## Related functions

- [UNICODE](/docs/text/unicode) — the reverse: returns a
  character's Unicode code point.
- [CHAR](/docs/text/char) — the limited-range, locale-dependent
  version of this same lookup.
- [TEXTJOIN](/docs/text/textjoin) — often combined with UNICHAR to
  build strings containing special separator characters.

## Examples

<ExampleCard number="01" label="Basic — insert a currency symbol" formula={`=UNICHAR(8364)`}>
  Returns the Euro sign (€) regardless of the computer's regional
  settings.
</ExampleCard>

<ExampleCard number="02" label="Building a bullet-point list" formula={`=UNICHAR(8226)&" "&A2`}>
  Prefixes each cell's text with a bullet character (•) for a
  simple inline list.
</ExampleCard>

<ExampleCard number="03" label="Adding a checkmark or cross indicator" formula={`=IF(A2="Done", UNICHAR(10003), UNICHAR(10007))`}>
  Shows a checkmark (✓) or cross (✗) based on a status column,
  without needing conditional formatting icons.
</ExampleCard>

<ExampleCard number="04" label="Inserting an arrow between values" formula={`=A2&" "&UNICHAR(8594)&" "&B2`}>
  Joins two values with a right-arrow character (→) between them.
</ExampleCard>

<ExampleCard number="05" label="Finding what code point a character needs" formula={`=UNICHAR(UNICODE(A2)+1)`}>
  Combined with UNICODE, shifts any Unicode character forward by
  one code point.
</ExampleCard>
