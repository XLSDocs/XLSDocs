Join two or more text values into one string — the original text-
joining function, superseded by [CONCAT](/docs/text/concat) but
still fully supported. Still worth knowing since plenty of existing
spreadsheets and older tutorials use it.

## Return value

A single string formed by joining every argument together, in the
order given, with nothing inserted between them.

## Description

CONCATENATE was the original text-joining function, still fully
functional today, but Microsoft's own guidance is to use
[CONCAT](/docs/text/concat) going forward. The practical difference:
CONCATENATE only accepts individual values, one argument per cell —
`CONCATENATE(A1, A2, A3)` — while CONCAT also accepts an entire
range as one argument — `CONCAT(A1:A3)`.

<Callout type="warn">
  Microsoft has marked CONCATENATE as a legacy function — it isn't
  deprecated or scheduled for removal, but new formulas should use
  CONCAT (or [TEXTJOIN](/docs/text/textjoin) for a version with a
  separator) instead. There's no compatibility reason to keep using
  CONCATENATE in a new spreadsheet.
</Callout>

## Common errors

### Trying to pass a whole range as one argument

<ExcelCode>{`CONCATENATE(A1:A5) → only joins A1, ignoring A2:A5`}</ExcelCode>

Unlike CONCAT, CONCATENATE can't expand a range into its individual
cells — each cell needs its own argument:

<ExcelCode>{`CONCATENATE(A1, A2, A3, A4, A5)`}</ExcelCode>

### No separator between joined values

<ExcelCode>{`CONCATENATE(A2, B2) → "JohnSmith" (no space)`}</ExcelCode>

CONCATENATE inserts nothing between arguments — add a literal
separator explicitly:

<ExcelCode>{`CONCATENATE(A2, " ", B2)`}</ExcelCode>

## Related functions

- [CONCAT](/docs/text/concat) — the modern replacement, which also
  accepts whole ranges as a single argument.
- [TEXTJOIN](/docs/text/textjoin) — like CONCAT, but inserts a
  separator between every joined item automatically.
- [TEXT](/docs/text/text) — formats a number or date as text, often
  used inside CONCATENATE to control how a value appears.
