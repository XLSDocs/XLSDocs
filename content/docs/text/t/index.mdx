## Return value

`value` itself, unchanged, if it's text — otherwise an empty string
(`""`).

## Description

T is a narrow, single-purpose compatibility function: unlike
[VALUE](/docs/text/value) (text to number) or
[TEXT](/docs/text/text) (number to formatted text), T does nothing
to its input except decide whether to return it or discard it,
based purely on whether it was already text to begin with.

<Callout type="warn">
  **T is not a way to convert a number into text** — a number
  passed into T doesn't come back as its text representation, it
  comes back as an empty string. For converting a number to text,
  use [TEXT](/docs/text/text) instead.
</Callout>

## Common errors

### Expecting a number to come back as its text form

<ExcelCode>{`T(123) → "" (not "123")`}</ExcelCode>

T only passes text straight through — anything that isn't already
text, including numbers, dates, and logical values, becomes an
empty string instead of a text version of itself.

### Confusing T with TYPE or ISTEXT

<ExcelCode>{`T("hello") → "hello", not TRUE`}</ExcelCode>

T returns the value itself (or an empty string), not a TRUE/FALSE
flag. For a genuine yes/no answer to "is this text?", use
[ISTEXT](/docs/info/istext) instead.

## Related functions

- [VALUE](/docs/text/value) — converts genuine numeric text into
  an actual number, the opposite direction from T.
- [TEXT](/docs/text/text) — converts a number into formatted text,
  which T deliberately does not do.
- [ISTEXT](/docs/info/istext) — returns TRUE or FALSE for whether a
  value is text, rather than conditionally returning it.

## Examples

<ExampleCard number="01" label="Basic — pass through only if text" formula={`=T(A2)`}>
  Returns A2 unchanged if it holds text, or an empty string if it
  holds a number, date, or logical value.
</ExampleCard>

<ExampleCard number="02" label="Building a label only when one exists" formula={`=T(A2)&IF(T(A2)<>"", ": ", "")&B2`}>
  Prefixes a value with a label, but only adds the label and
  separator if the label cell actually contains text.
</ExampleCard>

<ExampleCard number="03" label="Filtering a mixed column to text only" formula={`=TEXTJOIN(", ", TRUE, T(A2:A10))`}>
  Combined with TEXTJOIN, builds a comma-separated list that
  silently skips any non-text entries in the range.
</ExampleCard>
