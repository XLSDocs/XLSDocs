Repeat a piece of text a given number of times in a row — a quick
way to build simple visual bars, separators, or repeated patterns
directly inside a formula.

## Return value

`text` repeated `number_times` times, with nothing inserted between
repetitions.

## Description

REPT is a simple building block, but it's a popular one for quick,
formula-only visualizations — a row of bar characters scaled by a
score or percentage makes a crude but genuinely useful in-cell bar
chart with zero formatting required.

<Callout type="idea">
  **A common pattern: `=REPT("█", ROUND(A2/10,0))`** — repeating a
  solid block character a number of times proportional to a value
  in `A2` turns a plain number into an instant in-cell bar, no
  conditional formatting or actual chart object needed.
</Callout>

## Common errors

### REPT(text, 0) returns an empty string, not an error

<ExcelCode>{`REPT("ab", 0) → "" (an empty string, not #VALUE!)`}</ExcelCode>

Zero repetitions is a valid input — it just means "nothing," not a
mistake, so REPT returns an empty string rather than an error.

### #VALUE! — a negative number_times

<ExcelCode>{`REPT("ab", -1) → #VALUE! (number_times can't be negative)`}</ExcelCode>

`number_times` has to be zero or a positive number.

## Examples

<ExampleCard number="01" label="Basic — repeat a string" formula={`=REPT("ab", 3)`}>
  Repeats "ab" three times in a row, with nothing inserted between
  repetitions.
</ExampleCard>

<ExampleCard number="02" label="A simple in-cell bar chart" formula={`=REPT("█", ROUND(A2/10,0))`}>
  Repeats a solid block character proportionally to a value in
  A2, scaled down by 10 — an instant, formula-only bar chart.
</ExampleCard>

<ExampleCard number="03" label="Building a visual separator row" formula={`=REPT("-", 40)`}>
  Creates a 40-character horizontal rule out of hyphens, useful as a
  plain-text section divider.
</ExampleCard>

<ExampleCard number="04" label="Padding a number to a fixed width" formula={`=REPT("0", 5-LEN(A2))&A2`}>
  Pads a shorter number with leading zeros to a consistent 5-digit
  width, like a product or employee code.
</ExampleCard>

<ExampleCard number="05" label="Visualizing a rating out of 5" formula={`=REPT("★", A2)&REPT("☆", 5-A2)`}>
  Builds a 5-star rating display by repeating filled and empty star
  characters based on a numeric score in A2.
</ExampleCard>
