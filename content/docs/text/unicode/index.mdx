Return the true Unicode code point for the first character of a
text string — [CODE](/docs/text/code)'s full-range counterpart,
giving a consistent result for any character regardless of
operating system or regional settings.

## Return value

The Unicode code point for the first character of `text`.

## Description

CODE's result depends on your computer's local character set, which
makes it unreliable for anything beyond basic ASCII. UNICODE always
returns the character's true Unicode code point — the same number
for the same character on every system, everywhere.

<Callout type="idea">
  **Use UNICODE instead of CODE whenever a character might fall
  outside the basic 1–127 ASCII range** — accented letters, currency
  symbols, and emoji all have well-defined Unicode code points that
  UNICODE reports consistently, where CODE's result for the same
  character could vary by computer.
</Callout>

## Common errors

### #VALUE! — an empty string

<ExcelCode>{`UNICODE("") → #VALUE! (there's no first character to look at)`}</ExcelCode>

An empty string has no first character, so UNICODE has nothing to
return a code point for.

### Expecting UNICODE to check more than the first character

<ExcelCode>{`UNICODE("€100") → 8364 (only the Euro sign, not the digits after it)`}</ExcelCode>

Just like CODE, UNICODE always looks at position 1 only — to check a
different character, extract it first with MID.

## Related functions

- [UNICHAR](/docs/text/unichar) — the reverse: looks up the
  character for a given Unicode code point.
- [CODE](/docs/text/code) — the limited-range, locale-dependent
  version of this same lookup.
- [EXACT](/docs/text/exact) — a case-sensitive whole-string
  comparison, often a better fit than character-by-character
  UNICODE checks.

## Examples

<ExampleCard number="01" label="Basic — check a character's code point" formula={`=UNICODE(A2)`}>
  Returns the Unicode code point for whatever character sits first
  in the cell.
</ExampleCard>

<ExampleCard number="02" label="Diagnosing an invisible mismatch" formula={`=UNICODE(MID(A2,5,1))`}>
  Checks the code point of a specific character position to spot an
  unexpected special character.
</ExampleCard>

<ExampleCard number="03" label="Comparing two similar-looking dashes" formula={`=UNICODE(A2)=UNICODE(B2)`}>
  A hyphen and an en dash look almost identical but have different
  code points — UNICODE reveals the difference.
</ExampleCard>

<ExampleCard number="04" label="Checking if text starts with an emoji" formula={`=UNICODE(A2)>127`}>
  Flags text whose first character falls outside the basic ASCII
  range — a quick way to spot emoji or special symbols up front.
</ExampleCard>

<ExampleCard number="05" label="Shifting a character forward" formula={`=UNICHAR(UNICODE(A2)+1)`}>
  Combined with UNICHAR, shifts any Unicode character forward by
  one code point.
</ExampleCard>
