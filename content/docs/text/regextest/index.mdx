## Return value

`TRUE` if any part of `text` matches `pattern`, `FALSE` otherwise.
REGEXTEST never returns an error for a non-match — only for an
invalid pattern.

## Description

REGEXTEST answers a yes/no question — does this text match a
pattern at all — without extracting or replacing anything. It's the
natural first step when building a more complex REGEXEXTRACT or
REGEXREPLACE formula: confirm the pattern actually matches before
building extraction logic on top of it.

<Callout type="warn">
  REGEXTEST, REGEXEXTRACT, and REGEXREPLACE are rolling out to
  **Excel for Microsoft 365 only** — not Excel 2021, 2019, or 2016,
  and not currently listed as supported in Excel for the web. A
  workbook using these on a 365 install that hasn't received the
  update yet shows `#NAME?`, which looks like a typo in the function
  name but actually means the function isn't available yet in that
  build.
</Callout>

Excel's regex functions use the **PCRE2** flavor of regular
expressions — broadly similar to what most other tools use, but worth
knowing if a pattern that works in, say, Python's `re` module doesn't
behave identically here.

## Common errors

### #VALUE! — invalid pattern syntax

<ExcelCode>{`REGEXTEST("abc123", "[0-9") → #VALUE!`}</ExcelCode>

An unclosed bracket, an unmatched parenthesis, or an unsupported
regex construct in `pattern` produces `#VALUE!`. Testing the pattern
in an online regex tester first (matching PCRE2 rather than another
flavor) catches most syntax mistakes before they hit the formula.

### #NAME? — function not yet available

If REGEXTEST returns `#NAME?` instead of `TRUE`/`FALSE`, the Excel
installation hasn't received these functions yet — they require a
current Microsoft 365 build, not a perpetual-license version like
Excel 2021 or 2019.

### It matches when it shouldn't (or vice versa)

The most common cause is the `case_sensitivity` default: REGEXTEST is
**case-sensitive unless told otherwise**. A pattern like `"excel"`
won't match `"Excel"` unless `case_sensitivity` is explicitly set to
`1`.
