## Return value

`number` written out as Thai-language text, with "Baht" (บาทถ้วน)
appended — unlike most text functions on this site, BAHTTEXT's output
is always in Thai, no matter what language your copy of Excel is set
to.

## Description

BAHTTEXT is a single-purpose function: it spells out a numeric amount
in Thai words, formatted the way Thai currency amounts are
conventionally written. It's the Thai-language equivalent of writing
a check amount in words.

<ExcelCode>{`=BAHTTEXT(1234) → "หนึ่งพันสองร้อยสามสิบสี่บาทถ้วน" ("one thousand two hundred thirty-four Baht")`}</ExcelCode>

<Callout type="info">
  **BAHTTEXT works regardless of your Excel's default language** —
  unlike PHONETIC (which requires a Far East region setting) or the
  DBCS byte-counting functions (whose behavior changes based on your
  default editing language), BAHTTEXT always produces Thai text, on
  any copy of Excel.
</Callout>

<Callout type="idea">
  On Windows, the currency label BAHTTEXT appends can be changed via
  **Regional Settings** (**Regional Options** on older versions) in
  Control Panel; on Mac, via the **Control Panel for Numbers**.
</Callout>

## Common errors

### #VALUE! — a non-numeric argument

<ExcelCode>{`BAHTTEXT("abc") → #VALUE!`}</ExcelCode>

`number` must actually be a number, a cell containing one, or a
formula that returns one.

## Related functions

- [DOLLAR](/docs/text/dollar) — formats a number as currency digits
  with a symbol, rather than spelling it out in words.
- [TEXT](/docs/text/text) — general-purpose number-to-text formatting
  with a custom format code.
- [NUMBERVALUE](/docs/text/numbervalue) — the reverse direction for
  ordinary numeric text, converting formatted text back into a
  number (not applicable to BAHTTEXT's Thai word output).
