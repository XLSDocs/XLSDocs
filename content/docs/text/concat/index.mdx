Join text from multiple cells, ranges, or literal strings into one
combined string. The modern replacement for CONCATENATE — same idea,
but it accepts whole ranges instead of listing every cell by hand.

## Return value

A single text string with every argument joined together, in order,
with no separator between them.

## Description

CONCAT joins its arguments into one string. Unlike the older
CONCATENATE function, an argument can be an entire range
(`CONCAT(A1:A5)`) rather than requiring every cell to be listed
individually — Excel flattens the range and joins every value inside
it.

<Callout type="warn">
  CONCAT converts every argument to plain text, including numbers and
  dates — a date loses its formatting and shows as a serial number
  unless wrapped in `TEXT()` first.
</Callout>

## Common errors

### Dates and numbers lose their formatting

<ExcelCode>{`CONCAT(A2, " - ", B2) → shows a number, not a formatted date, if B2 is a date`}</ExcelCode>

CONCAT converts every value to plain text using its raw underlying
value. Wrap dates or formatted numbers in `TEXT()` first:

<ExcelCode>{`CONCAT(A2, " - ", TEXT(B2, "mm/dd/yyyy"))`}</ExcelCode>

### No separator between joined values

<ExcelCode>{`CONCAT(A1:A5) → joins every value with nothing between them`}</ExcelCode>

CONCAT never inserts a separator. For a comma- or space-separated
list, use TEXTJOIN instead:

<ExcelCode>{`TEXTJOIN(", ", TRUE, A1:A5)`}</ExcelCode>

## Related functions

- [TEXTJOIN](/docs/text/textjoin) — like CONCAT, but inserts a
  separator between every joined item.
- [TEXT](/docs/text/text) — formats a number or date as text, often
  used inside CONCAT to control how a value appears.
- CONCATENATE — the older function CONCAT replaces; still works, but
  doesn't accept whole ranges as a single argument.
