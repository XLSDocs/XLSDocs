Pull a set number of characters from the **start** of a text string —
the first few digits of a code, a country prefix, or the first
initial of a name.

## Return value

The leftmost `num_chars` characters of `text`, as a text string. If
`num_chars` is greater than the length of `text`, the whole string is
returned — not an error.

## Description

LEFT counts from the very first character of `text` and returns
however many characters `num_chars` asks for. It's a fixed-position
extraction — for pulling text up to a variable delimiter (like
everything before the first space), combine it with FIND or SEARCH.

<Callout type="info">
  LEFT counts **characters**, not words — `LEFT("New York", 3)`
  returns `"New"` by coincidence of length, not because it stopped at
  a word boundary.
</Callout>

## Common errors

### #VALUE! — negative num_chars

<ExcelCode>{`LEFT(A2, -1) → #VALUE!`}</ExcelCode>

`num_chars` must be zero or a positive number.

### Extracting up to a variable delimiter

<ExcelCode>{`LEFT(A2, FIND(" ", A2) - 1)`}</ExcelCode>

LEFT alone only extracts a fixed count. Nesting FIND inside it finds
the position of the first space, so this returns everything before
it — useful when the text before the delimiter isn't always the same
length.

## Related functions

  start or end.
- [TRIM](/docs/text/trim) — often used alongside LEFT/RIGHT to clean
