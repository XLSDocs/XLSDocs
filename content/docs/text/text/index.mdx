Convert a number or date into text, formatted exactly the way you
specify — the standard way to keep a formatted value looking right
when it's concatenated into a sentence instead of sitting in its own
cell.

## Return value

`value` formatted as text according to `format_text`. The result is
always a text string, even though `value` was a number.

## Description

Cell formatting (Format Cells) changes how a number *displays*
without changing the underlying value — great on its own, but that
formatting disappears the moment the value is concatenated into a
sentence, since concatenation always uses the raw underlying number.
TEXT solves that by producing an actual formatted text string you can
join into a larger piece of text.

<Callout type="warn">
  TEXT's result is text, not a number — you can concatenate it, but
  you can't do further math on it. If you need the formatted-looking
  value back as a number, convert it with `VALUE()`.
</Callout>

## Common errors

### Using the result in further calculations

<ExcelCode>{`TEXT(A2, "0.00") + 5 → #VALUE!`}</ExcelCode>

TEXT's output is a string, not a number — adding to it directly
fails. Only use TEXT for display or concatenation; for math, work
with the original numeric value instead.

### Using cell-formatting codes that don't apply to formulas

<ExcelCode>{`TEXT(A2, "General") → often not what you expect`}</ExcelCode>

`format_text` needs a real format code (`"0.00"`, `"mm/dd/yyyy"`,
`"$#,##0.00"`) — the same codes from Format Cells' "Custom" category,
not a vague description of the format you want.

## Related functions

- [CONCAT](/docs/text/concat) — TEXT's most common companion, used
  to keep a number or date readable when joined into a sentence.
- [VALUE](/docs/text/value) — converts a text string (including
  TEXT's own output) back into a real number.
- [TEXTJOIN](/docs/text/textjoin) — joins multiple values with a
  separator, often paired with TEXT for formatting each one first.
- [Format](/docs/vba/format) — the VBA equivalent, for formatting a
  value inside code instead of a worksheet formula.
