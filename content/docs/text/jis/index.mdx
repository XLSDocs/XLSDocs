Convert half-width (single-byte) English letters or katakana within a
text string to their full-width (double-byte) equivalents — the
Japanese-locale counterpart to [DBCS](/docs/text/dbcs), under a
different, older name.

## Return value

`text` with any half-width English letters or katakana converted to
full-width. Any other character — including text with no half-width
characters at all — passes through unchanged.

## Description

JIS is a Japanese-locale text function: it widens half-width English
letters and half-width katakana to their full-width forms, the same
operation [DBCS](/docs/text/dbcs) performs under its more general
name. The two functions do the same conversion; JIS is the older,
Japan-specific name for it.

<ExcelCode>{`=JIS("ｴｸｾﾙ") → "エクセル" (half-width katakana widened to full-width)`}</ExcelCode>

<Callout type="warn">
  Microsoft's own documentation lists JIS as available only on a
  narrow set of platforms — **Excel for Microsoft 365 on Mac, Excel
  2024, and Excel 2021 on Mac** — notably not the standard Windows
  365/2021 builds or Excel for the web. If a workbook needs to run
  reliably across both Windows and Mac, or in a browser, use
  [DBCS](/docs/text/dbcs) instead, which performs the identical
  conversion with broader, better-documented support.
</Callout>

## Common errors

### Expecting a visible change on already-full-width text

<ExcelCode>{`JIS("EXCEL") → "EXCEL" (unchanged — no half-width characters to convert)`}</ExcelCode>

JIS only touches half-width English letters and katakana. Ordinary
full-width text, or text with no Japanese-locale half-width
characters at all, passes through exactly as given.

## Related functions

- [DBCS](/docs/text/dbcs) — the modern, more broadly-supported name
  for the identical half-width-to-full-width conversion.
- [ASC](/docs/text/asc) — converts the opposite direction, full-width
  to half-width.
- [PHONETIC](/docs/text/phonetic) — another Far-East-locale text
  function, extracting furigana rather than converting character
  width.
