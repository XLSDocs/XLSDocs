Convert an entire array into a single text string — useful for
displaying a dynamic array's full contents in one cell, or for
building a status message that reports on several values at once.

## Return value

A single text string representing every value in `array` — a flat,
comma-separated list in the default concise format, or a
curly-brace array literal matching formula syntax in strict format.

## Description

A dynamic array spills across multiple cells, which is great for
seeing every result at once but awkward when you actually need all
of it as one piece of text — a status message, a log entry, a
single cell summary. ARRAYTOTEXT flattens the whole thing down into
one string.

<ExcelCode>{`=ARRAYTOTEXT({1,2,3}) → "1, 2, 3" (concise — the default)`}</ExcelCode>

<ExcelCode>{`=ARRAYTOTEXT({1,2,3}, 1) → "{1,2,3}" (strict — valid to paste back into a formula)`}</ExcelCode>

<Callout type="idea">
  **Strict format (`1`) produces text you could paste directly back
  into a formula** as a literal array — row separators become
  semicolons, column separators become commas, and text values are
  wrapped in quotes, exactly matching the syntax Excel itself uses
  for a typed-in array constant.
</Callout>

## Common errors

### #VALUE! — an invalid format

<ExcelCode>{`ARRAYTOTEXT({1,2,3}, 2) → #VALUE! (only 0 or 1 are valid)`}</ExcelCode>

`format` only accepts `0` or `1` — any other number returns an
error.

### Expecting the original cell number formatting to carry over

<ExcelCode>{`ARRAYTOTEXT(A2:A4) → "1234.5, 6789, 10" (raw values, not however A2:A4 happens to be formatted)`}</ExcelCode>

ARRAYTOTEXT always works from the array's underlying values, not
whatever currency, date, or decimal formatting is applied to the
cells it came from.
