Return the numeric code for the first character in a text string —
the exact reverse of [CHAR](/docs/text/char), useful for comparing
characters numerically or diagnosing exactly what an unexpected
character actually is.

## Return value

The numeric code, in your computer's character set, for the first
character of `text`.

## Description

CODE is mostly used as a diagnostic tool — when a string that
*looks* identical to another one fails an exact-match comparison,
CODE on each one's first character (or combined with MID to check
character-by-character) can reveal a sneaky invisible character or
the wrong kind of space or dash that's causing the mismatch.

<Callout type="warn">
  **CODE only ever looks at the first character.**
  `CODE("banana")` and `CODE("berry")` both return the code for
  `"b"` — if you need to check every character in a string, combine
  CODE with MID in a helper column or an array formula instead.
</Callout>

## Common errors

### #VALUE! — an empty string

<ExcelCode>{`CODE("") → #VALUE! (there's no first character to look at)`}</ExcelCode>

An empty string has no first character, so CODE has nothing to
return a code for.

### Expecting CODE to check more than the first character

<ExcelCode>{`CODE("abc") = CODE("azz") → TRUE (both start with "a")`}</ExcelCode>

If two strings share the same first character, CODE returns the
same result for both regardless of what follows — it isn't a
whole-string comparison.

## Related functions

- [CHAR](/docs/text/char) — the reverse: looks up the character for
  a given numeric code.
- [UNICODE](/docs/text/unicode) — the full-Unicode-range version of
  this same lookup.
- [EXACT](/docs/text/exact) — a case-sensitive whole-string
  comparison, often a better fit than character-by-character CODE
  checks.

## Examples

<ExampleCard number="01" label="Basic — check a character's code" formula={`=CODE(A2)`}>
  Returns the numeric code for whatever character sits first in the
  cell.
</ExampleCard>

<ExampleCard number="02" label="Diagnosing an invisible mismatch" formula={`=CODE(MID(A2,5,1))`}>
  Checks the code of a specific character position (here, the 5th)
  to spot an unexpected space or special character.
</ExampleCard>

<ExampleCard number="03" label="Checking if text starts with an uppercase letter" formula={`=CODE(A2)<=90`}>
  Uppercase ASCII letters fall in the range 65–90 — this flags
  whether the first character is one of them.
</ExampleCard>

<ExampleCard number="04" label="Comparing a hyphen against an en dash" formula={`=CODE(A2)=CODE(B2)`}>
  A regular hyphen (code 45) and an en dash (a different code)
  look almost identical but compare as different — CODE reveals it.
</ExampleCard>

<ExampleCard number="05" label="Building a simple character-shift cipher" formula={`=CHAR(CODE(A2)+1)`}>
  Shifts a single character forward by one code point — CODE and
  CHAR used together as inverses.
</ExampleCard>
