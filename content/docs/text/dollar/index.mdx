Convert a number into currency-formatted text — a dollar sign,
thousands separators, and a fixed number of decimal places, all
baked directly into the text itself rather than applied as cell
formatting.

## Return value

`number` as text, formatted with a currency symbol, thousands
separators, and rounded to `decimals` digits after the decimal
point.

## Description

DOLLAR produces an actual text string — not a number with currency
*formatting* applied, the way selecting a currency number format
from the ribbon would. That distinction matters because DOLLAR's
result is left-aligned like any text, can be concatenated directly
into a sentence, and no longer behaves like a number in further
calculations.

<Callout type="warn">
  **A negative `decimals` rounds to the left of the decimal
  point**, not just toward zero decimals. `DOLLAR(1234.567, -2)`
  rounds to the nearest hundred first, returning `"$1,200"` — the
  same rounding behavior [ROUND](/docs/math/round) uses for a
  negative `num_digits`.
</Callout>

## Common errors

### The result won't sum correctly with other numbers

<ExcelCode>{`=DOLLAR(A2)+DOLLAR(B2) → #VALUE! (both are text, not numbers)`}</ExcelCode>

DOLLAR's output is text, not a number — if you need to keep doing
math with the value, apply a currency *number format* to the cell
instead of using DOLLAR, and save DOLLAR for when you specifically
need the formatted result as text (inside a sentence, for example).

### The currency symbol isn't what you expected

<ExcelCode>{`DOLLAR(100) → "£100.00" on a computer set to UK regional settings`}</ExcelCode>

DOLLAR always uses your computer's current regional currency
symbol, not necessarily a literal `$` — on a system set to a
different locale, the symbol (and decimal/thousands separators)
will follow that locale instead.
