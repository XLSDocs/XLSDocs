Convert every letter in a text string to uppercase — the standard
way to normalize inconsistent casing in codes, IDs, or names before
comparing or displaying them.

## Return value

`text` with every letter converted to uppercase. Numbers, spaces,
and symbols pass through unchanged.

## Description

UPPER only affects letter casing — it doesn't trim spaces, remove
punctuation, or otherwise clean up text. It's commonly used to
normalize codes or IDs before comparing them with `=`, since Excel's
text comparison is case-sensitive in some contexts (like
[EXACT](/docs/text/exact)) but not others (like a plain `=`).

<Callout type="idea">
  UPPER returns a **new** text value — it doesn't change whatever
  cell `text` came from. To permanently uppercase a column in place,
  use UPPER in a helper column, then copy and Paste Special → Values
  back over the original.
</Callout>

## Common errors

### Expecting UPPER to clean up more than casing

<ExcelCode>{`UPPER("  excel ") → "  EXCEL " — spaces are untouched`}</ExcelCode>

UPPER only changes letter case. Combine with TRIM if extra spaces
also need removing:

<ExcelCode>{`TRIM(UPPER("  excel "))`}</ExcelCode>

### Result doesn't update the original cell

<ExcelCode>{`=UPPER(A2) → shows uppercase text in the formula's own cell, A2 itself is unchanged`}</ExcelCode>

UPPER produces a new value — it can't modify `A2` directly. Copy the
formula's result and Paste Special → Values over the original cells
if you want the change to stick permanently.

## Related functions

- [LOWER](/docs/text/lower) — converts text to all lowercase
  instead.
- [PROPER](/docs/text/proper) — capitalizes only the first letter of
  each word.
- [TRIM](/docs/text/trim) — often combined with UPPER to clean up
  spacing at the same time as casing.
- [EXACT](/docs/text/exact) — the case-sensitive comparison UPPER is
  often used to normalize text before or around.

## Examples

<ExampleCard number="01" label="Basic — normalize a product code" formula={`=UPPER(A2)`}>
  Converts a mixed-case code like "sku-42" to "SKU-42".
</ExampleCard>

<ExampleCard number="02" label="Case-insensitive comparison" formula={`=IF(UPPER(A2)=UPPER(B2), "Match", "No match")`}>
  Uppercasing both sides before comparing avoids false mismatches
  caused only by casing differences.
</ExampleCard>

<ExampleCard number="03" label="Cleaning up spacing and casing together" formula={`=TRIM(UPPER(A2))`}>
  Removes extra spaces and normalizes casing in one formula.
</ExampleCard>

<ExampleCard number="04" label="Uppercasing part of a string" formula={`=UPPER(LEFT(A2, 3)) & MID(A2, 4, 100)`}>
  Uppercases only the first 3 characters, leaving the rest of the
  string as-is.
</ExampleCard>

<ExampleCard number="05" label="Making a permanent change" formula={`=UPPER(A2:A10) then Paste Special > Values`}>
  Build the uppercase versions in a helper column, then paste the
  results back as values to make the change stick without keeping
  the formula.
</ExampleCard>
