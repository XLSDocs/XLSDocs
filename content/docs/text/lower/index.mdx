Convert every letter in a text string to lowercase — the mirror
image of UPPER, commonly used to normalize email addresses, usernames,
or codes before comparing or storing them.

## Return value

`text` with every letter converted to lowercase. Numbers, spaces,
and symbols pass through unchanged.

## Description

LOWER only affects letter casing, the same as UPPER in reverse. It's
a common normalization step for email addresses and usernames,
since those are conventionally compared and stored in lowercase
regardless of how a user originally typed them.

<Callout type="idea">
  LOWER returns a **new** text value — it doesn't change whatever
  cell `text` came from. To permanently lowercase a column in place,
  use LOWER in a helper column, then copy and Paste Special → Values
  back over the original.
</Callout>

## Common errors

### Expecting LOWER to clean up more than casing

<ExcelCode>{`LOWER("  EXCEL ") → "  excel " — spaces are untouched`}</ExcelCode>

LOWER only changes letter case. Combine with TRIM if extra spaces
also need removing:

<ExcelCode>{`TRIM(LOWER("  EXCEL "))`}</ExcelCode>

### Result doesn't update the original cell

<ExcelCode>{`=LOWER(A2) → shows lowercase text in the formula's own cell, A2 itself is unchanged`}</ExcelCode>

LOWER produces a new value — copy the formula's result and Paste
Special → Values over the original cells if the change needs to
stick permanently.
