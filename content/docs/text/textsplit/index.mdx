Split a string into a live spilled array using a delimiter — no
Text to Columns dialog, no combination of MID/FIND/SEARCH, and no
fixed destination range to worry about ahead of time.

## Return value

A dynamic array of the pieces of `text`, split on `col_delimiter`
(and `row_delimiter`, if given), spilled into the cells
below/right of the formula.

## Description

TEXTSPLIT replaces the pattern of nested MID/FIND/SEARCH formulas —
or a one-time Text to Columns operation — with a single live
formula. Passing both a `col_delimiter` and a `row_delimiter` splits
into a full 2D array at once: a comma-and-semicolon-separated string
like `"a,b;c,d"` becomes a 2x2 grid in one formula. It's the
worksheet-formula counterpart to VBA's `Split` function, but spills
across cells instead of returning a code-side array.

<Callout type="warn">
  When splitting into a 2D array, rows don't have to come out the
  same length — TEXTSPLIT fills the gaps with `#N/A` by default. Use
  `pad_with` to fill with something less alarming, like an empty
  string, if the ragged array is expected rather than an error
  condition.
</Callout>

## Common errors

### #N/A padding from uneven row lengths

<ExcelCode>{`TEXTSPLIT("a,b,c;d,e", ",", ";") → last row padded with #N/A`}</ExcelCode>

Not an error exactly, but a common surprise — supply `pad_with` to
control what fills the gap instead of `#N/A`:

<ExcelCode>{`TEXTSPLIT("a,b,c;d,e", ",", ";", , , "")`}</ExcelCode>

### Consecutive delimiters producing empty pieces

<ExcelCode>{`TEXTSPLIT("a,,b", ",") → {"a", "", "b"} — an empty piece in the middle`}</ExcelCode>

Set `ignore_empty` to `TRUE` to collapse consecutive delimiters
instead of keeping the blank pieces between them:

<ExcelCode>{`TEXTSPLIT("a,,b", ",", , TRUE)`}</ExcelCode>

## Related functions

  [TEXTAFTER](/docs/text/textafter) — pull a single piece around one
  delimiter occurrence, instead of splitting every occurrence at once.
- [Split](/docs/vba/split) — the VBA counterpart, returning a
  code-side array instead of spilling across cells.
- [VSTACK](/docs/arrays/vstack) — combines multiple ranges rather
  than splitting one string, but produces the same kind of spilled
  array result.
