---
title: RIGHT examples
description: Worked examples for RIGHT — fixed-length suffixes, variable-length extraction, and file extensions.
---

<FunctionNav />

<ExampleCard number="01" label="Basic — last 4 characters" formula={`=RIGHT(A2, 4)`}>
  Returns the last 4 characters of A2 — useful for pulling a fixed
  suffix like a year from an invoice code.
</ExampleCard>

<ExampleCard number="02" label="Default num_chars (1 character)" formula={`=RIGHT(A2)`}>
  Omitting `num_chars` returns just the last character.
</ExampleCard>

<ExampleCard number="03" label="Extract a file extension" formula={`=RIGHT(A2, LEN(A2) - FIND(".", A2))`}>
  Works for filenames of any length, since FIND locates the period
  dynamically instead of assuming a fixed position.
</ExampleCard>

<ExampleCard number="04" label="Extracting a number for math" formula={`=VALUE(RIGHT(A2, 4))`}>
  RIGHT always returns text — wrap it in VALUE() to convert back to
  a real number before using it in a calculation.
</ExampleCard>

<ExampleCard number="05" label="Combined with TRIM for messy data" formula={`=RIGHT(TRIM(A2), 5)`}>
  Trimming first avoids counting trailing spaces as part of the last
  5 characters.
</ExampleCard>
