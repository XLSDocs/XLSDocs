Pull a set number of characters from the **end** of a text string —
the last 4 digits of an account number, a file extension, or the
last name from a "Last, First" formatted string.

## Return value

The rightmost `num_chars` characters of `text`, as a text string. If
`num_chars` is greater than the length of `text`, the whole string is
returned — not an error.

## Description

RIGHT counts back from the very last character of `text` and returns
however many characters `num_chars` asks for — the mirror image of
LEFT. For extracting text after a variable-position delimiter (like
everything after the last space), combine it with FIND, SEARCH, and
LEN.

<Callout type="info">
  RIGHT counts **characters**, not words — it has no concept of
  "the last word." For that, you need to locate the last space first
  (typically with a `FIND`/`SUBSTITUTE` combination) and extract from
  there.
</Callout>

## Common errors

### #VALUE! — negative num_chars

<ExcelCode>{`RIGHT(A2, -1) → #VALUE!`}</ExcelCode>

`num_chars` must be zero or a positive number.

### Extracting text after a variable-length start

<ExcelCode>{`RIGHT(A2, LEN(A2) - FIND(" ", A2))`}</ExcelCode>

RIGHT alone only extracts a fixed count from the end. This combines
LEN (total length) and FIND (position of the first space) to work
out how many characters remain after it — useful when the text
before the delimiter isn't always the same length.

## Related functions

- [MID](/docs/text/mid) — extracts from any position, not just the

- [TRIM](/docs/text/trim) — often used alongside LEFT/RIGHT to clean
  up stray whitespace before or after extracting a substring.
- [TEXTAFTER](/docs/text/textafter) — extracts past a delimiter
