Convert full-width characters to their half-width equivalents — used
with double-byte character set (DBCS) languages like Japanese, where
letters and katakana can exist in both a full-width and a half-width
form.

## Return value

`text` with every full-width (double-byte) character converted to its
half-width (single-byte) equivalent. Characters that have no
half-width form, and ordinary single-byte text, pass through
unchanged.

## Description

In languages that use a double-byte character set — Japanese,
Chinese, and Korean — many letters and symbols exist in two visual
widths: a full-width (double-byte) form and a half-width (single-byte)
form. ASC normalizes full-width characters down to their half-width
equivalents, which is useful for cleaning up data entered with the
wrong input-width setting (a common issue when typing Latin letters
or numbers in a Japanese IME still set to full-width mode).

<ExcelCode>{`=ASC("ＥＸＣＥＬ") → "EXCEL" (full-width Latin letters converted to half-width)`}</ExcelCode>

<Callout type="warn">
  **`WorksheetFunction.Asc` in VBA is not the same as VBA's own
  built-in `Asc()` function.** The native VBA `Asc()` returns the
  character code of a string's first character (like Excel's
  [CODE](/docs/text/code)) — a completely different operation. Only
  `Application.WorksheetFunction.Asc` performs the full-width-to-
  half-width conversion described on this page.
</Callout>

## Common errors

### Expecting ASC to change ordinary single-byte text

<ExcelCode>{`=ASC("EXCEL") → "EXCEL" (unchanged — nothing here is full-width)`}</ExcelCode>

ASC only affects characters that actually have a full-width form.
Ordinary half-width Latin text passes through unmodified — this isn't
an error, just a no-op.

    Dim result As String
    result = Application.WorksheetFunction.Asc(Range("A2").Value)

    ' Alternatively, VBA's native StrConv with vbNarrow performs the
    ' same full-width-to-half-width conversion:
    result = StrConv(Range("A2").Value, vbNarrow)
    ```

    text = "ＥＸＣＥＬ"
    # NFKC normalization collapses full-width forms to their
    # half-width equivalents, the same effect as ASC
    result = unicodedata.normalize("NFKC", text)
    ```

## Related functions

- [DBCS](/docs/text/dbcs) — the reverse conversion, from half-width
  to full-width characters.
- [PHONETIC](/docs/text/phonetic) — another Far-East-language text
  function, extracting furigana readings rather than converting
  character width.
- [CLEAN](/docs/text/clean) and [TRIM](/docs/text/trim) — other
  text-normalizing functions, for stripping control characters and
  extra spaces rather than converting character width.
