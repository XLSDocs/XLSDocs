## Return value

The number of characters in `text`, counting every character
including spaces and punctuation.

## Description

LEN is a simple character count, but it's a key building block for
more advanced text formulas — working out how many characters remain
after a known prefix (for RIGHT or MID), validating that input
matches an expected length, or detecting extra whitespace by
comparing `LEN(text)` against `LEN(TRIM(text))`.

<Callout type="idea">
  `LEN(A2) = 0` is a common, precise way to test whether a cell is
  genuinely empty — including a cell that *looks* blank but actually
  contains a zero-length text result from another formula, which
  [ISBLANK](/docs/info/isblank) would not catch.
</Callout>

## Common errors

### Extra spaces inflate the count unexpectedly

<ExcelCode>{`LEN("  excel  ") → 9, not 5`}</ExcelCode>

Leading and trailing spaces count toward the length. Wrap in TRIM
first if you only want to count meaningful characters:

<ExcelCode>{`LEN(TRIM("  excel  "))`}</ExcelCode>

### Detecting whitespace-only differences

<ExcelCode>{`LEN(A2) <> LEN(TRIM(A2)) → TRUE if A2 has extra spaces`}</ExcelCode>

Comparing a cell's length before and after TRIM is a quick way to
flag rows with stray whitespace, without needing to inspect them
visually.

## Related functions

- [TRIM](/docs/text/trim) — often paired with LEN to detect or
  remove extra whitespace before counting.
- [RIGHT](/docs/text/right) and [MID](/docs/text/mid) — commonly
  combined with LEN to extract everything after a known starting
  point.
- [FIND](/docs/text/find) — locates a position within text; LEN is
  often used alongside it to work out how many characters remain.

## Examples

<ExampleCard number="01" label="Basic — count characters" formula={`=LEN(A2)`}>
  Returns the total number of characters in A2, including any
  spaces.
</ExampleCard>

<ExampleCard number="02" label="Validating a fixed-length code" formula={`=IF(LEN(A2)=10, "Valid", "Wrong length")`}>
  Flags any entry that doesn't match an expected 10-character code
  format.
</ExampleCard>

<ExampleCard number="03" label="Detecting extra whitespace" formula={`=LEN(A2) <> LEN(TRIM(A2))`}>
  Returns TRUE if A2 has leading, trailing, or doubled internal
  spaces that TRIM would remove.
</ExampleCard>

<ExampleCard number="04" label="Extracting everything after a known prefix" formula={`=RIGHT(A2, LEN(A2) - 4)`}>
  Uses LEN to work out how many characters remain after skipping a
  fixed 4-character prefix.
</ExampleCard>

<ExampleCard number="05" label="Checking for a truly empty cell" formula={`=IF(LEN(A2)=0, "Empty", "Has content")`}>
  Catches a genuinely zero-length value, including one produced by
  another formula, unlike [ISBLANK](/docs/info/isblank) in some edge cases.
</ExampleCard>
