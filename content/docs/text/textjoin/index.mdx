Join text from multiple cells or ranges the way CONCAT does, but with
a separator inserted between every item — and the option to skip
blank cells automatically instead of leaving gaps.

## Return value

A single text string with every item joined together, separated by
`delimiter`, with blank cells skipped if `ignore_empty` is `TRUE`.

## Description

TEXTJOIN is CONCAT with two extra abilities: a separator between
every joined item, and the option to automatically skip blanks so
you don't end up with a string full of doubled-up separators from
empty cells.

<Callout type="warn">
  `delimiter` and `ignore_empty` come **before** the list of items to
  join — easy to mix up if you're expecting the text arguments
  first, the way CONCAT works.
</Callout>

## Common errors

### Blank cells still create extra delimiters

<ExcelCode>{`TEXTJOIN(", ", FALSE, A1:A5) → extra ", " where cells are blank`}</ExcelCode>

`ignore_empty` was set to `FALSE`. Pass `TRUE` to skip blanks
automatically:

<ExcelCode>{`TEXTJOIN(", ", TRUE, A1:A5)`}</ExcelCode>

### Mixing up the argument order

<ExcelCode>{`TEXTJOIN(A1:A5, ", ", TRUE) → wrong — delimiter and ignore_empty come first`}</ExcelCode>

Unlike CONCAT, TEXTJOIN's first two arguments are always `delimiter`
and `ignore_empty`, before any actual text to join.
