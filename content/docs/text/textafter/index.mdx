Extract the portion of a string that comes after a delimiter — the
mirror image of `TEXTBEFORE`, replacing the older combination of MID
and FIND/SEARCH.

## Return value

The substring of `text` that appears after the specified occurrence
of `delimiter`. Returns `#N/A` if `delimiter` isn't found, unless
`if_not_found` supplies a fallback.

## Description

TEXTAFTER replaces the older pattern of combining `MID` with `FIND`
or `SEARCH` and a length calculation just to grab everything after a
separator — a domain from an email address, a file extension, or
whatever follows the last slash in a path. Like TEXTBEFORE, a
negative `instance_num` counts delimiters from the end of the string
instead of the start.

<Callout type="warn">
  TEXTAFTER returns `#N/A` when `delimiter` doesn't appear in `text`
  at all — not an empty string. Supply `if_not_found` (the sixth
  argument) to return something else instead.
</Callout>

## Common errors

### #N/A — delimiter not found

<ExcelCode>{`TEXTAFTER("no-at-sign-here", "@") → #N/A`}</ExcelCode>

Supply a fallback with `if_not_found` instead of letting the error
propagate:

<ExcelCode>{`TEXTAFTER("no-at-sign-here", "@", 1, 0, 0, "")`}</ExcelCode>

### Forgetting text has more than one delimiter

<ExcelCode>{`TEXTAFTER("a.b.c.txt", ".") → "b.c.txt" (only after the first period)`}</ExcelCode>

With multiple delimiters, `instance_num` controls which one is used
— `-1` finds text after the *last* one instead of the first:

<ExcelCode>{`TEXTAFTER("a.b.c.txt", ".", -1) → "txt"`}</ExcelCode>
