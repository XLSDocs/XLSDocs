Find the position of one piece of text inside another, the same job
as FIND, but ignoring case and supporting `*`/`?` wildcards — useful
when you don't know or don't care about the exact casing of what
you're looking for.

## Return value

The 1-based position of the first occurrence of `find_text` within
`within_text`, ignoring case. Returns `#VALUE!` if `find_text`
doesn't appear.

## Description

SEARCH works like FIND, but with two differences: it ignores case
entirely, and `find_text` can include wildcards — `*` for any number
of characters, `?` for exactly one. Use it when you want a looser
match than FIND's case-sensitive, literal-only behavior.

<Callout type="warn">
  To search for a literal `*` or `?` character (not as a wildcard),
  prefix it with a tilde: `SEARCH("~*", A2)` finds a literal
  asterisk instead of matching any text.
</Callout>

## Common errors

### #VALUE! — text not found

<ExcelCode>{`SEARCH("x", A2) → #VALUE! (no "x" anywhere in A2, in any case)`}</ExcelCode>

Wrap it in IFERROR if a missing match is a valid, expected outcome.

### Wildcard characters matching too broadly

<ExcelCode>{`SEARCH("*", A2) → matches the very start of any text, since * means "any characters"`}</ExcelCode>

If you want a literal asterisk or question mark rather than a
wildcard, escape it with a tilde:

<ExcelCode>{`SEARCH("~*", A2)`}</ExcelCode>
