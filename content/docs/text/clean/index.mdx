Strip non-printable control characters from text — the kind of
invisible junk that shows up when data is exported from an older
system, scraped from a PDF, or pasted from a terminal, rather than
typed directly into Excel.

## Return value

`text` with non-printable characters (the first 32 characters of the
ASCII set — things like line feeds and other control codes) removed.
Printable characters, including regular spaces, are left untouched.

## Description

CLEAN targets a different kind of mess than TRIM. TRIM removes extra
*space* characters; CLEAN removes *control* characters that don't
print at all — often invisible in the cell but disruptive to
formulas, exports, or further text processing. The two are commonly
used together: `TRIM(CLEAN(A2))`.

<Callout type="warn">
  CLEAN doesn't touch the non-breaking space (`CHAR(160)`), even
  though it's often the actual cause of "invisible junk" in
  web-pasted data — that one is printable, just not a regular space,
  so it needs `SUBSTITUTE` instead.
</Callout>

## Common errors

### Text still looks messy after CLEAN

<ExcelCode>{`CLEAN(A2) → still has extra spacing`}</ExcelCode>

The leftover issue is very likely a non-breaking space, not a
control character — CLEAN won't touch it. Combine with SUBSTITUTE:

<ExcelCode>{`CLEAN(SUBSTITUTE(A2, CHAR(160), " "))`}</ExcelCode>

### CLEAN removes line breaks you wanted to keep

<ExcelCode>{`CLEAN(A2) → intentional line breaks (Alt+Enter) are gone too`}</ExcelCode>

CLEAN removes every control character indiscriminately, including a
line break you may have wanted to preserve. If that matters,
substitute the line break for a placeholder first, clean, then
substitute it back.
