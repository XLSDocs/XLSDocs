## Return value

The substring of `text` that appears before the specified occurrence
of `delimiter`. Returns `#N/A` if `delimiter` isn't found, unless
`if_not_found` supplies a fallback.

## Description

TEXTBEFORE replaces the older pattern of combining `LEFT` with `FIND`
or `SEARCH` just to grab everything up to a separator — getting a
domain-free username from an email address, the first word of a
sentence, or a folder path with the file name stripped off. Negative
`instance_num` counts delimiters from the end of the string instead
of the start, useful for a string with more than one occurrence of
the delimiter.

<Callout type="warn">
  TEXTBEFORE returns `#N/A` when `delimiter` doesn't appear in `text`
  at all — not an empty string. Supply `if_not_found` (the sixth
  argument) to return something else instead, the same fallback
  pattern XLOOKUP uses.
</Callout>

## Common errors

### #N/A — delimiter not found

<ExcelCode>{`TEXTBEFORE("no-at-sign-here", "@") → #N/A`}</ExcelCode>

Supply a fallback with `if_not_found` instead of letting the error
propagate:

<ExcelCode>{`TEXTBEFORE("no-at-sign-here", "@", 1, 0, 0, "")`}</ExcelCode>

### Forgetting text has more than one delimiter

<ExcelCode>{`TEXTBEFORE("a.b.c.txt", ".") → "a" (only up to the first period)`}</ExcelCode>

With multiple delimiters, `instance_num` controls which one is used
— `-1` finds text before the *last* one instead of the first:

<ExcelCode>{`TEXTBEFORE("a.b.c.txt", ".", -1) → "a.b.c"`}</ExcelCode>
