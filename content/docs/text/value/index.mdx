Convert a text string that looks like a number, date, or time into
its actual numeric value — the reverse of what TEXT does, and the
standard fix for "numbers stored as text" that won't sum or sort
correctly.

## Return value

The numeric equivalent of `text`. Returns `#VALUE!` if `text` can't
be interpreted as a number, date, or time.

## Description

Cells formatted or entered as text look like numbers but behave like
text — they won't sum, sort numerically, or compare correctly against
real numbers. VALUE converts that text into an actual number Excel
can calculate with. It also works on text dates and times, returning
their serial number equivalent.

<Callout type="info">
  Older workbooks sometimes use `--text` (double unary minus) or
  `text*1` instead of `VALUE(text)` — all three do the same
  conversion. VALUE is the clearer, documented way to write it.
</Callout>

## Common errors

### #VALUE! — text isn't a recognizable number

<ExcelCode>{`VALUE("abc") → #VALUE!`}</ExcelCode>

The text doesn't match any number, date, or time format Excel
recognizes.

### #VALUE! — extra non-numeric characters

<ExcelCode>{`VALUE("123 units") → #VALUE!`}</ExcelCode>

Trailing text like `" units"` breaks the parse. Strip the non-numeric
part first, e.g. with LEFT combined with FIND to locate where the
number ends.
