Test whether two strings are exactly identical — including
uppercase vs lowercase, which every other text comparison in Excel
(`=`, VLOOKUP, COUNTIF, MATCH) ignores by default.

## Return value

`TRUE` if `text1` and `text2` are identical character-for-character,
including case. `FALSE` otherwise.

## Description

Every other text comparison in Excel — the `=` operator, VLOOKUP,
XLOOKUP, MATCH, COUNTIF — treats "West" and "west" as the same
value. EXACT is the one built-in exception: it's case-sensitive, so
it's the right tool whenever the distinction between uppercase and
lowercase genuinely matters, like validating a case-sensitive code
or password field.

<Callout type="info">
  `A2=B2` and `EXACT(A2, B2)` look interchangeable until case
  differs — `"USA"="usa"` returns `TRUE`, but `EXACT("USA", "usa")`
  returns `FALSE`. Reach for EXACT specifically when that difference
  matters.
</Callout>

## Common errors

### Expecting the default comparison to be case-sensitive

<ExcelCode>{`A2=B2 → TRUE (even if A2="USA" and B2="usa")`}</ExcelCode>

The plain `=` operator ignores case — switch to EXACT if the
comparison genuinely needs to be case-sensitive:

<ExcelCode>{`EXACT(A2, B2) → FALSE`}</ExcelCode>

### Leading/trailing spaces cause an unexpected FALSE

<ExcelCode>{`EXACT("USA", "USA ") → FALSE (trailing space)`}</ExcelCode>

EXACT compares every character, including whitespace — wrap both
sides in TRIM first if stray spaces shouldn't count:

<ExcelCode>{`EXACT(TRIM(A2), TRIM(B2))`}</ExcelCode>

## Related functions

- [TRIM](/docs/text/trim) — often paired with EXACT to strip
  incidental whitespace before comparing.
- [UPPER](/docs/text/upper) and [LOWER](/docs/text/lower) — normalize
  case before a comparison, the opposite goal from EXACT.
- [COUNTIF](/docs/math/countif) — matches text case-insensitively by
  default, unlike EXACT.
