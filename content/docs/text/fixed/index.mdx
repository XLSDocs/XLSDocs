Round a number to a fixed number of decimal places and convert it
to text — [DOLLAR](/docs/text/dollar) without the currency symbol,
with an extra option to drop the thousands separators entirely.

## Return value

`number`, rounded to `decimals` digits and converted to text — with
thousands separators unless `no_commas` is `TRUE`.

## Description

FIXED is essentially DOLLAR without the currency symbol — a plain
rounded number as text, with the same negative-decimals-rounds-left
behavior, plus the option to drop the comma separators that DOLLAR
always includes.

<Callout type="idea">
  **`no_commas` is the one option DOLLAR doesn't have** — if you
  want a currency symbol, use DOLLAR; if you want a plain rounded
  number as text with full control over whether thousands
  separators appear, FIXED is the better fit.
</Callout>

## Common errors

### The result won't sum correctly with other numbers

<ExcelCode>{`=FIXED(A2)+FIXED(B2) → #VALUE! (both are text, not numbers)`}</ExcelCode>

FIXED's output is text, not a number — if you still need to do
math with the value, round the actual number with
[ROUND](/docs/math/round) instead and keep it numeric.

### Forgetting no_commas and getting unwanted separators

<ExcelCode>{`FIXED(1234.567, 1) → "1,234.6" (commas included by default)`}</ExcelCode>

If you're building a string that shouldn't contain commas — for a
CSV-style export, for example — pass `TRUE` for `no_commas`
explicitly, since it defaults to including them.

## Related functions

- [DOLLAR](/docs/text/dollar) — the same rounded-text formatting,
  with a currency symbol added.
- [ROUND](/docs/math/round) — rounds a number and keeps it numeric,
  rather than converting it to text.
- [TEXT](/docs/text/text) — a more flexible way to format a number
  as text using a custom format code.
