Replace occurrences of one piece of text with another, by matching
the text content — swap hyphens for slashes, fix a recurring typo
across a column, or strip out a specific unwanted character.

## Return value

`text` with `old_text` replaced by `new_text` — every occurrence by
default, or just the `instance_num`-th one if specified.

## Description

SUBSTITUTE finds and replaces based on matching **text content**,
unlike REPLACE, which replaces based on a fixed position and length.
Use SUBSTITUTE when you know what text you're looking for; use
REPLACE when you know exactly where it sits in the string.

<Callout type="warn">
  SUBSTITUTE is case-sensitive — `SUBSTITUTE(A2, "Text", "Word")`
  won't match a lowercase `"text"` in A2. There's no case-insensitive
  option built in.
</Callout>

## Common errors

### Nothing changes — case doesn't match

<ExcelCode>{`SUBSTITUTE(A2, "Text", "Word") → no change if A2 contains lowercase "text"`}</ExcelCode>

SUBSTITUTE is case-sensitive. Match the exact case, or normalize both
sides first with UPPER/LOWER if the case genuinely varies.

### Replacing every occurrence when only one was wanted

<ExcelCode>{`SUBSTITUTE(A2, "-", "/") → replaces every hyphen, not just the first`}</ExcelCode>

Without `instance_num`, every match gets replaced. Add it to target
just one:

<ExcelCode>{`SUBSTITUTE(A2, "-", "/", 1)`}</ExcelCode>

## Related functions

- [REPLACE](/docs/text/replace) — replaces based on position and
  length instead of matching text content.
- [TRIM](/docs/text/trim) — for regular extra spaces; SUBSTITUTE is
  what handles the non-breaking spaces TRIM can't.
- [CLEAN](/docs/text/clean) — removes non-printable control
  characters, a different kind of cleanup than SUBSTITUTE's targeted
  find-and-replace.
- [Replace](/docs/vba/replace) — VBA's function of this same name
  works like SUBSTITUTE, not like worksheet REPLACE — a common
  source of confusion given the overlapping names.
- [REGEXREPLACE](/docs/text/regexreplace) — replaces based on a full
  regular expression pattern, instead of one exact piece of text.
