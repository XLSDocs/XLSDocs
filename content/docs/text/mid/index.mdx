Extract a chunk of text starting at any position, not just the start
or end — the middle section of a fixed-format code, or a portion of
text you've already located with FIND or SEARCH.

## Return value

`num_chars` characters of `text`, starting at position `start_num`.
Returns an empty string if `start_num` is beyond the length of
`text`, and returns fewer than `num_chars` characters (not an error)
if the string ends before `num_chars` is reached.

## Description

MID is LEFT and RIGHT generalized — instead of always starting at
one end, you give it any starting position. It's most useful either
for fixed-format text (like extracting the middle segment of a
structured ID) or combined with FIND/SEARCH to locate a dynamic
starting point first.

<Callout type="info">
  `LEFT(text, n)` is equivalent to `MID(text, 1, n)`, and `RIGHT`
  can be written with MID plus LEN — LEFT and RIGHT exist mainly
  because they're shorter to write for the two most common cases.
</Callout>

## Common errors

### #VALUE! — invalid start_num

<ExcelCode>{`MID(A2, 0, 3) → #VALUE!`}</ExcelCode>

`start_num` must be `1` or greater — `0` or a negative number throws
an error.

### Empty result — start_num beyond the text length

<ExcelCode>{`MID(A2, 50, 3) → "" (when A2 is shorter than 50 characters)`}</ExcelCode>

Not an error — MID just returns nothing if there's no text left at
that position.

### Extracting from a dynamic starting point

<ExcelCode>{`MID(A2, FIND(" ", A2) + 1, 10)`}</ExcelCode>

Nesting FIND inside `start_num` locates the position dynamically
(here, right after the first space) instead of assuming a fixed
position.
