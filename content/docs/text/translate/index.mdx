Translate a piece of text from one language into another, right
inside a worksheet formula. Like [DETECTLANGUAGE](/docs/text/detectlanguage),
TRANSLATE calls Microsoft Translator over the internet to do the
actual translation — it isn't a local dictionary lookup.

## Return value

The translated text as a string.

## Description

TRANSLATE sends `text` to Microsoft Translator and returns the
result in `target_language`. Both language arguments are optional:
leaving `source_language` out lets the service detect the source
language itself (the same detection [DETECTLANGUAGE](/docs/text/detectlanguage)
exposes directly), and leaving `target_language` out falls back to
Excel's own display language.

<ExcelCode>{`=TRANSLATE(A1, "en", "es") → translates A1 from English to Spanish`}</ExcelCode>

<ExcelCode>{`=TRANSLATE(A1) → auto-detects A1's language and translates into Excel's display language`}</ExcelCode>

<Callout type="warn">
  TRANSLATE is a **service-backed function** — every call sends
  `text` to Microsoft Translator over the internet, shares the same
  daily quota as DETECTLANGUAGE, and doesn't work offline. Supported
  language codes can change over time; check Microsoft's current
  language list rather than assuming an older code is still valid.
</Callout>

## Common errors

### #CONNECT! — no internet connection

<ExcelCode>{`TRANSLATE(A1, "en", "fr") → #CONNECT! if the device is offline`}</ExcelCode>

TRANSLATE can't reach Microsoft Translator without a network
connection. Reconnect and recalculate (F9) to retry.

### #VALUE! — invalid or unsupported language code

<ExcelCode>{`TRANSLATE(A1, "en", "xx") → #VALUE! ("xx" isn't a real language code)`}</ExcelCode>

Both `source_language` and `target_language` need to be codes the
translation service actually recognizes — check the current
supported-language list rather than guessing a code.

### Request throttled — daily quota exceeded

Microsoft Translator enforces a daily quota shared with
DETECTLANGUAGE. Translating a very large number of cells in a short
period can hit that limit — translate once and store the result in
a helper column instead of leaving thousands of live TRANSLATE
formulas recalculating.

## Related functions

- [DETECTLANGUAGE](/docs/text/detectlanguage) — identifies a text's
  language, the same auto-detection TRANSLATE uses internally when
  `source_language` is omitted.
- [TEXT](/docs/text/text) — general-purpose formatting, often
  combined with TRANSLATE to clean up input before translating.
- [IFERROR](/docs/logical/iferror) — wraps TRANSLATE to catch
  `#CONNECT!` and return a fallback when offline.

## Examples

<ExampleCard number="01" label="Basic — translate between two known languages" formula={`=TRANSLATE(A1, "en", "es")`}>
  Translates A1 from English to Spanish.
</ExampleCard>

<ExampleCard number="02" label="Auto-detecting the source language" formula={`=TRANSLATE(A1, , "en")`}>
  Leaving `source_language` blank lets Microsoft Translator detect
  it automatically — useful when A1 could be in any of several
  languages.
</ExampleCard>

<ExampleCard number="03" label="Target language driven by a cell" formula={`=TRANSLATE(A1, "en", B1)`}>
  Pulling `target_language` from B1 instead of hardcoding it lets
  the same formula translate into a different language per row —
  useful for a dataset where each recipient needs a different
  language.
</ExampleCard>

<ExampleCard number="04" label="With a fallback for offline use" formula={`=IFERROR(TRANSLATE(A1, , "en"), A1)`}>
  Falls back to the original, untranslated text instead of
  `#CONNECT!` if the connection drops.
</ExampleCard>

<ExampleCard number="05" label="#VALUE! from an invalid language code" formula={`=TRANSLATE(A1, "en", "xx")`}>
  Returns `#VALUE!` because `"xx"` isn't a language code Microsoft
  Translator recognizes.
</ExampleCard>
