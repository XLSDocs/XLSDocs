Capitalize the first letter of every word and lowercase the rest —
the standard way to fix inconsistently-typed names ("JOHN SMITH" or
"john smith" both become "John Smith").

## Return value

`text` with the first letter of each word capitalized and every
other letter lowercased.

## Description

PROPER treats any character that isn't a letter — spaces, hyphens,
apostrophes — as the end of one word and the start of the next, then
capitalizes the first letter after each of those boundaries. That
works well for most names, but produces genuinely wrong results for
names containing an apostrophe or an intentional internal capital.

<Callout type="warn">
  PROPER capitalizes the letter right after an apostrophe too —
  `"mcdonald's"` becomes `"Mcdonald'S"`, not `"McDonald's"`. It also
  doesn't know to preserve an intentional acronym: `"IBM"` becomes
  `"Ibm"`. Both need manual correction or a more targeted formula.
</Callout>

## Common errors

### Apostrophes get incorrectly re-capitalized

<ExcelCode>{`PROPER("mcdonald's") → "Mcdonald'S", not "McDonald's"`}</ExcelCode>

PROPER treats the apostrophe as a word boundary and capitalizes
whatever follows it. There's no built-in fix — names like this
usually need a manual correction after applying PROPER.

### Acronyms lose their capitalization

<ExcelCode>{`PROPER("IBM stock report") → "Ibm Stock Report"`}</ExcelCode>

PROPER has no way to know "IBM" should stay all-caps — it lowercases
every letter after the first in each word, acronym or not.
