Find every piece of text matching a pattern and replace it —
optionally reusing parts of the match itself in the replacement,
which is what lets REGEXREPLACE reorder text, not just swap it out.

## Return value

`text` with the matched portion(s) replaced by `replacement`. If
`pattern` doesn't match anywhere, REGEXREPLACE returns `text`
completely unchanged — this is normal behavior, not an error.

## Description

Wrapping part of `pattern` in parentheses creates a **capturing
group**, which can then be reused inside `replacement` as `$1` (the
first group), `$2` (the second), and so on. This is what makes
REGEXREPLACE capable of reordering text, not just deleting or
swapping fixed substrings — a "Last, First" name pattern rearranged
into "First Last" is a single formula instead of a combination of
FIND/MID/CONCATENATE.

<Callout type="check">
  Unlike REGEXEXTRACT's `#N/A` on no match, REGEXREPLACE simply
  returns the original text unchanged when nothing matches. This
  makes it safe to apply broadly across a column without needing an
  `IFERROR` wrapper for cells where the pattern doesn't apply.
</Callout>

## Common errors

### #VALUE! — invalid pattern syntax

An unclosed bracket, unmatched parenthesis, or unsupported construct
in `pattern` produces `#VALUE!`.

### #NAME? — function not yet available

REGEXREPLACE requires a current Microsoft 365 build — it returns
`#NAME?` on Excel 2021, 2019, 2016, or a 365 install that hasn't
received the update yet.

### The replacement includes a literal "$1" instead of the captured text

This happens when `replacement` references a capturing group number
that doesn't exist in `pattern` — for example, using `$2` when
`pattern` only has one set of parentheses. Count the parenthesized
groups in `pattern` carefully against every `$n` used in
`replacement`.

### Only one occurrence changed when every match should have

`occurrence` defaults to `0` (replace all), but an explicit positive
or negative number restricts the replacement to just that one match.
Double-check the `occurrence` argument if a formula that should
replace every match only affects one.
