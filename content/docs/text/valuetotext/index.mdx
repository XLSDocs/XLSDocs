Convert any single value into text, with control over whether the
result is wrapped in quotes the way it would need to be typed into
a formula — [ARRAYTOTEXT](/docs/text/arraytotext)'s single-value
counterpart.

## Return value

`value` as text — unquoted in the default concise format, or
wrapped in quotes (if `value` is text) in strict format.

## Description

VALUETOTEXT exists for the same reason
[ARRAYTOTEXT](/docs/text/arraytotext) does, scaled down to a single
value: sometimes you need a value's text representation to actually
match the syntax you'd type into a formula, quotes and all — not
just the value displayed plainly.

<ExcelCode>{`=VALUETOTEXT("Hello") → Hello (concise — no quotes)`}</ExcelCode>

<ExcelCode>{`=VALUETOTEXT("Hello", 1) → "Hello" (strict — quoted, exactly as you'd type it in a formula)`}</ExcelCode>

<Callout type="idea">
  **Strict format only changes the output for text values** —
  numbers, `TRUE`/`FALSE`, and error values look identical in both
  formats, since they're already written the same way whether or
  not they're inside a formula. Only text needs the extra quotes to
  be valid formula syntax.
</Callout>

## Common errors

### #VALUE! — an invalid format

<ExcelCode>{`VALUETOTEXT("Hello", 2) → #VALUE! (only 0 or 1 are valid)`}</ExcelCode>

`format` only accepts `0` or `1` — any other number returns an
error.

### Expecting quotes around a number in strict format

<ExcelCode>{`VALUETOTEXT(123, 1) → 123 (no quotes — numbers never get them)`}</ExcelCode>

Strict format only adds quotes around text values — a number
already looks the same whether or not it's inside quotes in a
formula, so VALUETOTEXT leaves it as-is.

## Related functions

- [ARRAYTOTEXT](/docs/text/arraytotext) — the same concise/strict
  text-formatting idea, for a whole array instead of one value.
- [TEXT](/docs/text/text) — applies a custom display format to a
  number, rather than just choosing quoting style.
- [T](/docs/text/t) — returns a value only if it's already text,
  rather than converting any value type to text.
