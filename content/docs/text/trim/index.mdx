## Return value

`text` with leading and trailing spaces removed, and any run of
multiple spaces between words collapsed to a single space.

## Description

TRIM only touches the regular space character — it removes it from
both ends of the string entirely, and reduces any internal stretch of
several spaces in a row down to exactly one. It's the standard first
step when cleaning up text pulled from another system, a form, or a
paste from the web.

<Callout type="warn">
  TRIM does **not** remove a non-breaking space (`CHAR(160)`), which
  is what web pages often use instead of a regular space. If a cell
  still looks like it has extra space after TRIM, that's usually
  the culprit — combine TRIM with SUBSTITUTE to remove it explicitly.
</Callout>

## Common errors

### TRIM doesn't seem to remove all the spaces

<ExcelCode>{`TRIM(A2) → still looks like it has a gap, even after trimming`}</ExcelCode>

Likely a non-breaking space (`CHAR(160)`), common in text pasted from
a website — TRIM only removes regular spaces. Strip it explicitly
first:

<ExcelCode>{`TRIM(SUBSTITUTE(A2, CHAR(160), " "))`}</ExcelCode>

### Tabs or line breaks remain

<ExcelCode>{`TRIM(A2) → tab or line-break characters are still there`}</ExcelCode>

TRIM only affects the space character — it doesn't touch tabs
(`CHAR(9)`) or line breaks (`CHAR(10)`). Combine with SUBSTITUTE or
CLEAN to remove those.
