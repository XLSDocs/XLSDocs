Find where one string first appears inside another — the VBA
equivalent of Excel's `FIND` and `SEARCH` worksheet functions, for
locating a substring inside code instead of inside a cell formula.

## Return value

The 1-based position of the first character of `string2` within
`string1`, searching from `start` onward. Returns `0` if `string2`
isn't found, and `0` immediately if `string1` is empty.

## Description

InStr answers "where does this substring first appear" — checking
whether a cell's text contains a keyword, finding the position of an
`@` to split an email address, or locating a delimiter before slicing
a string with `Mid`/`Left`/`Right`. Unlike Excel's worksheet
`SEARCH` function, InStr is case-sensitive by default; matching
`FIND`'s case-sensitivity requires no extra argument, but matching
`SEARCH`'s case-insensitivity requires passing `vbTextCompare`
explicitly.

<Callout type="warn">
  `InStr` returns `0`, not `-1` or an error, when nothing is found —
  a common source of an off-by-one bug for anyone expecting a
  "not found" sentinel like `-1`. Always check `InStr(...) = 0`
  explicitly rather than assuming a falsy/negative result.
</Callout>

## Common errors

### Assuming InStr is case-insensitive

<ExcelCode>{`InStr("Hello World", "world") → 0 (case doesn't match)`}</ExcelCode>

By default InStr is case-sensitive — pass `vbTextCompare` to match
regardless of case:

<ExcelCode>{`InStr(1, "Hello World", "world", vbTextCompare)`}</ExcelCode>

### Passing compare without start

<ExcelCode>{`InStr("Hello", "l", vbTextCompare) → argument mismatch — compare needs start supplied too`}</ExcelCode>

`start` is required whenever `compare` is supplied — it can't be
skipped just because the default (position 1) is wanted:

<ExcelCode>{`InStr(1, "Hello", "l", vbTextCompare)`}</ExcelCode>

## In practice

```vb lineNumbers
Function GetDomain(email As String) As String
  Dim atPos As Long
  atPos = InStr(1, email, "@")

  If atPos = 0 Then
    GetDomain = ""
  Else
    GetDomain = Mid(email, atPos + 1)
  End If
End Function
```
