---
title: InputBox examples
description: Worked examples for InputBox — basic prompts, default values, numeric validation, and detecting Cancel.
---

<FunctionNav />

<ExampleCard number="01" label="Basic — ask for a name" formula={`userName = InputBox("Enter your name:")`}>
  Prompts for free-text input and stores whatever was typed.
</ExampleCard>

<ExampleCard number="02" label="Pre-filled default value" formula={`sheetName = InputBox("Sheet name:", "New Sheet", "Sheet" & (Sheets.Count + 1))`}>
  Suggests a default value the user can accept or overwrite.
</ExampleCard>

<ExampleCard number="03" label="Validating numeric input" formula={`If IsNumeric(qtyText) Then qty = CInt(qtyText)`}>
  Checks the typed text is actually a number before converting it,
  since InputBox always returns a string.
</ExampleCard>

<ExampleCard number="04" label="Treating a blank result as Cancel" formula={`If InputBox("Search term:") = "" Then Exit Sub`}>
  Exits early if the user clicked Cancel or submitted nothing.
</ExampleCard>

<ExampleCard number="05" label="Looping until valid input" formula={`Do: entry = InputBox("Enter a positive number:"): Loop Until IsNumeric(entry) And CDbl(entry) > 0`}>
  Keeps re-prompting until the user provides a valid positive number.
</ExampleCard>
