button click to answer.

## Return value

A `String` containing whatever the user typed. Clicking Cancel (or
the box's close button) returns an empty string `""`, indistinguishable
from the user submitting nothing and clicking OK.

## Description

InputBox pauses the macro and shows a text field for the user to
fill in — a name, a quantity, a search term — then hands back
whatever was typed as a plain string. Because the result is always
text, a numeric answer still needs converting (with `CInt`, `CDbl`,
or similar) before it can be used in arithmetic.

<Callout type="warn">
  InputBox can't tell the difference between the user typing nothing
  and clicking Cancel — both return `""`. If that distinction
  matters, check for `""` and treat it as "no input provided" rather
  than trying to detect Cancel specifically.
</Callout>

## Common errors

### Treating the result as a number directly

<ExcelCode>{`InputBox("Enter quantity:") + 1 → type mismatch if the field is left blank or non-numeric`}</ExcelCode>

The return value is always a string — validate and convert it first:

<ExcelCode>{`If IsNumeric(qtyText) Then qty = CInt(qtyText)`}</ExcelCode>

### Confusing InputBox with Application.InputBox

<ExcelCode>{`InputBox("Select a range:") → returns typed text, not a Range object`}</ExcelCode>

Plain `InputBox` (a VBA language function) only returns text. For a
version that can return a real cell range the user clicks on, use
`Application.InputBox` with its `Type` argument set to `8` instead.

## In practice

```vb lineNumbers
Sub PromptForSheetName()
  Dim newName As String
  newName = InputBox("Enter a name for the new sheet:", "New Sheet", "Sheet" & (Sheets.Count + 1))

  If newName = "" Then
    MsgBox "Cancelled — no sheet created.", vbInformation
    Exit Sub
  End If

  Sheets.Add.Name = newName
End Sub
```
