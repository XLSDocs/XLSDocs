Replace every occurrence of a substring with another string —
despite sharing a name with Excel's worksheet `REPLACE` function,
VBA's `Replace` actually works like the worksheet's `SUBSTITUTE`
(find-and-replace by text), not like worksheet `REPLACE`
(position-and-length based).

## Return value

A new string with every occurrence of `find` (up to `count`, if
given) replaced by `replaceWith`, starting the search from `start`.

## Description

The name is the trap here: Excel's worksheet `REPLACE` function
replaces characters at a specific **position and length**, with no
concept of matching text. VBA's `Replace` does the opposite — it
finds occurrences of an actual substring and swaps them out, which is
exactly what the worksheet's `SUBSTITUTE` function does. Anyone
porting logic between VBA and worksheet formulas who assumes the two
`Replace`/`REPLACE` functions behave the same way will get very
different results.

<Callout type="warn">
  VBA's `Replace` behaves like worksheet `SUBSTITUTE`, **not**
  worksheet `REPLACE` — despite having the matching name. If
  position-and-length replacement is actually needed inside VBA, use
  string slicing with `Left`/`Mid`/`Right` instead; `Replace` has no
  equivalent to worksheet REPLACE's position-based behavior at all.
</Callout>

## Common errors

### Assuming Replace works like worksheet REPLACE

<ExcelCode>{`Replace("Hello World", 1, 5) → not valid — Replace doesn't take a position and length`}</ExcelCode>

VBA's `Replace` always matches by text, never by position — there's
no direct VBA equivalent of worksheet `REPLACE`'s position/length
arguments.

### Assuming case-insensitivity by default

<ExcelCode>{`Replace("Hello World", "world", "Earth") → "Hello World" (no match, case differs)`}</ExcelCode>

Like `InStr`, `Replace` is case-sensitive by default. Pass
`vbTextCompare` to match regardless of case:

<ExcelCode>{`Replace("Hello World", "world", "Earth", 1, -1, vbTextCompare)`}</ExcelCode>

### Passing compare without start and count

`start` and `count` are both required whenever `compare` is
supplied — they can't be skipped just because the defaults (position
1, replace all) are wanted:

<ExcelCode>{`Replace("Hello World", "world", "Earth", 1, -1, vbTextCompare)`}</ExcelCode>

## In practice

```vb lineNumbers
Function CleanPhone(raw As String) As String
  Dim result As String
  result = Replace(raw, "-", "")
  result = Replace(result, " ", "")
  result = Replace(result, "(", "")
  result = Replace(result, ")", "")
  CleanPhone = result
End Function
```
