Break a string apart into an array wherever a delimiter appears — the
usual first step for parsing a comma-separated list, a full name, or
any other delimited text pulled from a cell or user input.

## Return value

A zero-based, one-dimensional array of `String` values — `Split("a,b,c",
",")` returns an array where element `0` is `"a"`, `1` is `"b"`, and `2`
is `"c"`.

## Description

Split is the VBA counterpart to Excel's
[TEXTSPLIT](/docs/text/textsplit) — turning one
delimited string into a list of pieces that can be looped over,
indexed into, or reassembled with `Join`. It's the standard way to
parse a comma-separated value pasted from elsewhere, break a full
name into first/last, or process a multi-line string one line at a
time (splitting on `vbCrLf`).

<Callout type="warn">
  The returned array is **zero-based**, not one-based like most
  worksheet-facing VBA collections — `result(0)` is the first piece,
  not `result(1)`. Looping with `For i = 0 To UBound(result)` avoids
  accidentally skipping the first element or overrunning the array.
</Callout>

## Common errors

### Off-by-one from assuming a 1-based array

<ExcelCode>{`parts(1) → the second piece, not the first`}</ExcelCode>

Split's result is zero-based — the first piece is `parts(0)`:

<ExcelCode>{`parts(0)`}</ExcelCode>

### Subscript out of range on a single-piece result

<ExcelCode>{`Split("nodelimiterhere", ",")(1) → Run-time error 9: Subscript out of range`}</ExcelCode>

If the delimiter never appears, the array has only one element
(index `0`) — check `UBound(result)` before assuming a second
element exists.

## In practice

```vb lineNumbers
Sub ParseCommaSeparatedTags()
  Dim tags() As String
  tags = Split(Range("A2").Value, ",")

  Dim i As Long
  For i = 0 To UBound(tags)
    Debug.Print Trim(tags(i))
  Next i
End Sub
```
