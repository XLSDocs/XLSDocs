Display a message box to the user — the most basic way for a macro
to communicate anything, from a simple "Done" notification to a
Yes/No/Cancel confirmation before a destructive action.

## Return value

An `Integer` identifying which button the user clicked — `vbOK` (1),
`vbCancel` (2), `vbYes` (6), `vbNo` (7), and so on, depending on which
`buttons` were shown. If `MsgBox` is used as a statement rather than
assigned to a variable, the return value is simply discarded.

## Description

MsgBox is the simplest way for a macro to talk back to the user —
confirming that a long-running task finished, warning before an
action that can't be undone, or asking a Yes/No/Cancel question and
branching on the answer. `buttons` is built by adding together a
button-set constant (`vbOKOnly`, `vbYesNo`, `vbYesNoCancel`, and so
on) and an icon constant (`vbInformation`, `vbExclamation`,
`vbCritical`, `vbQuestion`) — `vbYesNo + vbQuestion` shows Yes/No
buttons with a question-mark icon.

<Callout type="warn">
  Parentheses around the arguments are only valid when the result is
  captured: `result = MsgBox("Continue?", vbYesNo)`. Called as a bare
  statement with no assignment, parentheses cause a compile error —
  write `MsgBox "Continue?", vbYesNo` instead, without parens.
</Callout>

## Common errors

### Compile error from parentheses on a bare statement

<ExcelCode>{`MsgBox("Done") → Compile error: Expected: end of statement`}</ExcelCode>

Parentheses are only allowed when the return value is being
captured. Drop them for a plain statement call:

<ExcelCode>{`MsgBox "Done"`}</ExcelCode>

### Forgetting to combine buttons and icon constants

<ExcelCode>{`MsgBox("Continue?", vbQuestion) → shows only OK, no Yes/No choice`}</ExcelCode>

`vbQuestion` alone only controls the icon — the button set defaults
to `vbOKOnly` unless a button constant is added in too:

<ExcelCode>{`MsgBox("Continue?", vbYesNo + vbQuestion)`}</ExcelCode>

## In practice

```vb lineNumbers
Sub ConfirmAndDelete()
  Dim response As VbMsgBoxResult
  response = MsgBox("Delete all rows below row 1?", vbYesNo + vbExclamation, "Confirm delete")

  If response = vbYes Then
    Rows("2:" & Rows.Count).Delete
    MsgBox "Rows deleted.", vbInformation
  Else
    MsgBox "Cancelled — nothing was deleted.", vbInformation
  End If
End Sub
```
