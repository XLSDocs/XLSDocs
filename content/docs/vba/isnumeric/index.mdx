Test whether a value — typically a String read from a cell or user
input — can actually be evaluated as a number, before risking a
runtime error by converting it directly with `CInt`, `CDbl`, or
similar.

## Return value

`True` if `expression` can be evaluated as a number. `False`
otherwise — including for `Null` and a zero-length string `""`.

## Description

IsNumeric exists to guard a conversion — checking user input or a
cell's text value before handing it to `CInt`, `CDbl`, `CLng`, or a
similar type-conversion function, which raise a runtime error on
genuinely non-numeric input instead of failing gracefully. It's
permissive about format: leading and trailing spaces, a leading sign,
decimals, and scientific notation are all accepted as numeric.

<Callout type="warn">
  An **uninitialized Variant is numeric** to IsNumeric — `IsNumeric`
  on a freshly declared, never-assigned Variant returns `True`,
  because `Empty` evaluates as `0` in a numeric context. Checking
  `IsEmpty` first (if "was this ever actually set" matters) catches
  what `IsNumeric` alone silently treats as a valid zero.
</Callout>

## Common errors

### Trusting IsNumeric to guarantee a conversion won't overflow

<ExcelCode>{`IsNumeric("999999999999") → True, but CInt("999999999999") → Overflow error`}</ExcelCode>

IsNumeric only confirms a value is numeric **in principle** — it
doesn't check whether the value actually fits the target type's
range. Use a wider type (`CDbl`, `CLng`) or wrap the conversion in
error handling if the input's size isn't guaranteed.

### Expecting Empty to fail the check

<ExcelCode>{`Dim v As Variant\nIsNumeric(v) → True (v is Empty, which evaluates as 0)`}</ExcelCode>

An uninitialized Variant passes IsNumeric — check `IsEmpty` first if
distinguishing "never set" from "genuinely zero" matters.

### Assuming an empty string is numeric

<ExcelCode>{`IsNumeric("") → False`}</ExcelCode>

Unlike `Empty`, a zero-length string is **not** treated as numeric —
only an uninitialized Variant gets that special treatment.

## In practice

```vb lineNumbers
Function SafeToLong(v As Variant) As Long
  If IsNumeric(v) And Not IsEmpty(v) Then
    On Error Resume Next
    SafeToLong = CLng(v)
    On Error GoTo 0
  Else
    SafeToLong = 0
  End If
End Function
```
