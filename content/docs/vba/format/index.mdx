Format a number, date, or string into text using a pattern — the VBA
equivalent of Excel's `TEXT` worksheet function, for building
readable strings inside a macro instead of inside a cell.

## Return value

A `String` containing `expression` rendered according to `format` —
`Format(1234.5, "#,##0.00")` returns `"1,234.50"`,
`Format(Date, "yyyy-mm-dd")` returns something like `"2027-03-14"`.

## Description

Format works like Excel's `TEXT` function, but from inside VBA code
rather than a worksheet cell — building a status-bar message, a file
name with today's date baked in, or a formatted number for a
`MsgBox` prompt. It accepts the same custom-format pattern codes as
Excel's cell formatting (`0`, `#`, `yyyy`, `mm`, `dd`, `@`), plus a
handful of named formats like `"Currency"`, `"Percent"`, and
`"Long Date"`.

<Callout type="info">
  Format's pattern codes are the same ones used in Excel's Format
  Cells dialog — anything that works there (`"$#,##0.00"`,
  `"mmm d, yyyy"`) works identically as the `format` argument here.
</Callout>

## Common errors

### Forgetting format returns a String, not a Date/Number

<ExcelCode>{`If Format(dueDate, "yyyy-mm-dd") > Format(today, "yyyy-mm-dd") Then`}</ExcelCode>

This comparison works only because ISO-style date strings happen to
sort correctly as text — for real date math, compare the original
`Date` values directly instead of their formatted strings.

### Using an Excel formula format code that VBA doesn't recognize

<ExcelCode>{`Format(123, "General") → "123" (fine), but not every worksheet format code has a VBA equivalent`}</ExcelCode>

Most common codes match, but a few worksheet-only formats (like
accounting-style parenthesis negatives) don't translate directly —
test the exact pattern in the Immediate window if the result looks
off.

## In practice

```vb lineNumbers
Sub ExportWithDatedFileName()
  Dim fileName As String
  fileName = "SalesReport_" & Format(Date, "yyyy-mm-dd") & ".xlsx"

  ActiveWorkbook.SaveAs Filename:=ThisWorkbook.Path & "\" & fileName
  MsgBox "Saved as " & fileName, vbInformation
End Sub
```
