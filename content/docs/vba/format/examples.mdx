---
title: Format examples
description: Worked examples for Format — currency, dates, padded numbers, and named formats.
---

<FunctionNav />

<ExampleCard number="01" label="Basic — two decimal places" formula={`Format(1234.5, "#,##0.00")`}>
  Returns "1,234.50" — a thousands separator and exactly two decimal
  places.
</ExampleCard>

<ExampleCard number="02" label="Date for a file name" formula={`Format(Date, "yyyy-mm-dd")`}>
  Returns today's date as a sortable, filename-safe string like
  "2027-03-14".
</ExampleCard>

<ExampleCard number="03" label="Named currency format" formula={`Format(1500, "Currency")`}>
  Uses the system's regional currency settings, e.g. "$1,500.00".
</ExampleCard>

<ExampleCard number="04" label="Zero-padded numbers" formula={`Format(7, "000")`}>
  Returns "007" — useful for building consistently-sized ID or file
  suffixes.
</ExampleCard>

<ExampleCard number="05" label="Percent formatting" formula={`Format(0.256, "0.0%")`}>
  Returns "25.6%", converting a decimal fraction to a display
  percentage.
</ExampleCard>
