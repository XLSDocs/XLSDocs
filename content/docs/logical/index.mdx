---
title: Logical
description: Functions that branch on a condition and return one value or another.
---

Logical functions evaluate a condition — a comparison, an AND/OR
combination — and return different results depending on whether it's
true or false.

  <Card title="IF" description="Return one value if a condition is true, another if it's false." href="/docs/logical/if" />

</Cards>
