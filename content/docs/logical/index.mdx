---
title: Logical
description: Functions that branch on a condition and return one value or another.
---

Logical functions evaluate a condition — a comparison, an AND/OR
combination — and return different results depending on whether it's
true or false.

  <Card title="IF" description="Return one value if a condition is true, another if it's false." href="/docs/logical/if" />

  <Card title="SWITCH" description="Compare one value against a list of exact matches and return the first result that fits." href="/docs/logical/switch" />
  <Card title="IFERROR" description="Catch any formula error and return a fallback value instead." href="/docs/logical/iferror" />
  <Card title="IFNA" description="Catch a #N/A error specifically and return a fallback value instead." href="/docs/logical/ifna" />
  <Card title="AND" description="Return TRUE only if every condition is true." href="/docs/logical/and" />
  <Card title="OR" description="Return TRUE if any condition is true." href="/docs/logical/or" />
  <Card title="NOT" description="Reverse TRUE to FALSE, or FALSE to TRUE." href="/docs/logical/not" />
</Cards>
