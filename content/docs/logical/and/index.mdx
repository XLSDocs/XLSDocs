Test several conditions at once and get back a single `TRUE` or
`FALSE` — `TRUE` only if **every** condition is true. Most often used
inside IF to require more than one thing to be true before branching.

## Return value

`TRUE` if every argument evaluates to `TRUE`. `FALSE` if any single
argument is `FALSE`.

## Description

AND takes any number of conditions and collapses them into one
boolean — useful on its own, but most commonly nested inside IF to
require multiple things to be true before returning a result:
`IF(AND(condition1, condition2), "Ship", "Hold")`.

<Callout type="warn">
  AND doesn't work **element-wise** across a range inside an array
  formula the way you might expect. `AND(A2:A10>0, B2:B10>0)`
  evaluates whether *every* cell in *both* ranges is positive as one
  combined test, not row-by-row. For row-by-row logic inside FILTER or
  a similar dynamic array function, multiply boolean arrays instead:
  `(A2:A10>0)*(B2:B10>0)`.
</Callout>

## Common errors

### #VALUE! — a non-boolean argument

<ExcelCode>{`AND("yes", B2>0) → #VALUE!`}</ExcelCode>

Every argument must evaluate to `TRUE`/`FALSE` (or a number, where `0`
is `FALSE` and anything else is `TRUE`) — plain text like `"yes"`
isn't a valid logical value.

### Wrong result inside FILTER or an array formula

<ExcelCode>{`FILTER(A2:C10, AND(B2:B10="West", C2:C10="Q4")) → wrong / #VALUE!`}</ExcelCode>

AND collapses its arguments to one single TRUE/FALSE, not a
row-by-row array — inside FILTER (or any array-formula context),
multiply the conditions instead:

<ExcelCode>{`FILTER(A2:C10, (B2:B10="West")*(C2:C10="Q4"))`}</ExcelCode>
