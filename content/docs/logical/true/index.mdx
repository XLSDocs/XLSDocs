Return the logical value **TRUE**, with no arguments needed. Typing
the bare word `TRUE` directly into a cell or formula does exactly
the same thing — this function exists mainly for compatibility with
other spreadsheet programs that require it to be called explicitly.

## Syntax

<ExcelCode>{`=TRUE()`}</ExcelCode>

## Parameters

TRUE takes no arguments — the parentheses are still required, but
always empty.

## Return value

The logical value `TRUE`.

## Description

TRUE() and the bare word `TRUE` typed directly into a formula are
completely interchangeable — `=IF(A1=1,TRUE())` and
`=IF(A1=1,TRUE)` do exactly the same thing. Microsoft documents the
function as existing mainly for compatibility with spreadsheet files
imported from other programs that require logical values to be
produced by an explicit function call rather than a bare keyword.

<Callout type="idea">
  There's essentially no reason to type `TRUE()` in a new formula —
  just type `TRUE` directly. The function form only really matters
  when working with a file or template that already uses it, or
  when compatibility with another spreadsheet program's stricter
  syntax is a concern.
</Callout>

## Common errors

### Assuming TRUE() behaves differently from the bare keyword

<ExcelCode>{`IF(TRUE(), "yes", "no") → "yes" — identical to IF(TRUE, "yes", "no")`}</ExcelCode>

There's no behavioral difference between the two forms anywhere in
Excel — one isn't more "official" or safer than the other.

### Forgetting the parentheses

<ExcelCode>{`=TRUE → still works, but is actually the bare keyword, not a call to this function`}</ExcelCode>

Without the parentheses, `TRUE` is read as the logical constant
directly, not as a function call — the result is the same either
way, but it's worth knowing which one is actually being written.
