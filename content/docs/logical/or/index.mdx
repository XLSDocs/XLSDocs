Test several conditions at once and get back a single `TRUE` or
`FALSE` — `TRUE` if **any one** condition is true. Most often used
inside IF to branch when at least one of several things is true.

## Return value

`TRUE` if any argument evaluates to `TRUE`. `FALSE` only if every
argument is `FALSE`.

## Description

OR takes any number of conditions and returns `TRUE` as soon as one
of them is true — the opposite combination logic from AND. Commonly
nested inside IF to match multiple acceptable values:
`IF(OR(status="Approved", status="Pending"), "Process", "Hold")`.

<Callout type="warn">
  Like AND, OR doesn't work **element-wise** across a range inside an
  array formula. `OR(A2:A10="West", A2:A10="East")` evaluates whether
  *any* cell across the whole range matches, not row-by-row. For
  row-by-row OR logic inside FILTER or a similar dynamic array
  function, add boolean arrays instead:
  `(A2:A10="West")+(A2:A10="East")`.
</Callout>

## Common errors

### #VALUE! — a non-boolean argument

<ExcelCode>{`OR("yes", B2>0) → #VALUE!`}</ExcelCode>

Every argument must evaluate to `TRUE`/`FALSE` (or a number, where `0`
is `FALSE` and anything else is `TRUE`) — plain text like `"yes"`
isn't a valid logical value.

### Wrong result inside FILTER or an array formula

<ExcelCode>{`FILTER(A2:C10, OR(B2:B10="West", B2:B10="East")) → wrong / #VALUE!`}</ExcelCode>

OR collapses its arguments to one single TRUE/FALSE, not a row-by-row
array — inside FILTER (or any array-formula context), add the
conditions instead:

<ExcelCode>{`FILTER(A2:C10, (B2:B10="West")+(B2:B10="East"))`}</ExcelCode>

## Related functions

- [AND](/docs/logical/and) — TRUE only if **every** condition is
  true, instead of any one of them.
- [NOT](/docs/logical/not) — reverses a single TRUE/FALSE result.
- [IF](/docs/logical/if) — most commonly wraps OR to branch when at
  least one of several conditions is met.
- [FILTER](/docs/arrays/filter) — needs added boolean arrays instead
  of OR for row-by-row conditions.
