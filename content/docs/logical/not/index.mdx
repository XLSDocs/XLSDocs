but useful for reading a condition as its inverse without rewriting
the comparison itself.

## Return value

`TRUE` if `logical` is `FALSE`. `FALSE` if `logical` is `TRUE`.

## Description

NOT reverses a single logical value — mainly useful when the
condition reads more naturally as an inverse ("not empty," "not
approved") than rewritten with a different operator, or when
wrapping the result of another function whose logic can't easily be
flipped inline (like `NOT(ISBLANK(A2))`).

<Callout type="warn">
  Many uses of NOT can be rewritten more directly with `<>`:
  `NOT(A2="West")` and `A2<>"West"` return the same result, and `<>`
  is usually easier to read. Reach for NOT mainly when wrapping a
  function like ISBLANK/ISNUMBER/ISERROR, where there's no equivalent
  comparison operator to flip.
</Callout>

## Common errors

### #VALUE! — a non-boolean argument

<ExcelCode>{`NOT("yes") → #VALUE!`}</ExcelCode>

`logical` must evaluate to `TRUE`/`FALSE` (or a number, where `0` is
`FALSE` and anything else is `TRUE`) — plain text like `"yes"` isn't
a valid logical value.

### Double negatives that hurt readability

<ExcelCode>{`IF(NOT(ISBLANK(A2)), "Has data", "Empty")`}</ExcelCode>

Not an error, but "not blank" reads slower than the alternative — a
plain comparison against `""` is often clearer:

<ExcelCode>{`IF(A2<>"", "Has data", "Empty")`}</ExcelCode>
