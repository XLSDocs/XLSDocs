Database functions summarize or retrieve values from a table using a
**separate criteria range**, rather than conditions written directly
into the formula — the same underlying mechanic as Excel's classic
Advanced Filter. They predate SUMIFS/COUNTIFS and dynamic-array
FILTER by decades, but the criteria-range approach still does things
those newer functions can't as directly, like combining multiple
independent OR conditions across several fields at once.
