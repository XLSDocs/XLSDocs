Count how many records in a table have a **numeric** value in a
given field, restricted to rows that match conditions listed in a
separate criteria range — DSUM's counting counterpart.

## Return value

The count of records matching `criteria` that also have a **numeric**
value in `field`. Returns `0` if nothing matches.

## Description

DCOUNT shares DSUM's criteria-range mechanic exactly — same-row
conditions are AND, separate-row conditions are OR — but counts
records instead of summing a column. The one detail that trips
people up: DCOUNT only counts a record if `field` holds a **number**
for that record. A row that matches every criterion but has a blank
or text value in the counted field is excluded from the total.

<Callout type="warn">
  Need to count matching records regardless of what type of value is
  in a field — including text, or just presence/absence? That's
  **DCOUNTA**, a related function that counts any non-blank value.
  DCOUNT specifically restricts itself to numeric values, which makes
  it the right choice for "how many records have a valid number
  here?" rather than "how many records exist here at all?"
</Callout>

## Common errors

### The count is lower than expected

Check whether the counted field actually contains numbers for every
matching record — a blank cell, or a number stored as text (common
after importing data), won't be counted by DCOUNT even though the
record matches the criteria.

### The result is 0, but matching rows clearly exist

As with DSUM, the most common cause is a criteria header that doesn't
exactly match a database header. DCOUNT doesn't error on a
non-matching header — it just ignores that criteria row, which can
silently produce 0 instead of pointing at the typo.

### field was omitted and the count looks too high or too low

Without `field`, DCOUNT counts records matching `criteria` that have
**at least one numeric value anywhere** in the record — not a specific
column. This form is rarely what's intended; specifying `field`
explicitly avoids the ambiguity.
