title: Formula & calculation shortcuts
description: Write formulas, cycle reference types, and control when Excel recalculates — without reaching for the ribbon.
---

Writing formulas by hand means constantly toggling reference types,
inserting functions, and occasionally forcing a recalculation —
these shortcuts cover all three without leaving the keyboard.

<Callout type="idea">
  `F4` to cycle a cell reference through `A1` → `$A$1` → `A$1` →
  `$A1` and back is the highest-value shortcut on this entire page if
  you write formulas by hand — no more manually typing dollar signs
  to lock a reference before copying a formula across a range.
</Callout>
