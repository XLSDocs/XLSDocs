Shortcuts for the workbook as a whole, rather than anything inside a
specific cell — opening and saving files, printing, refreshing data
connections, and jumping into the VBA or Power Query editors.

<Callout type="idea">
  `Alt+F11` is worth knowing even if you never write VBA by hand —
  it's the fastest way to jump into the Visual Basic Editor to peek
  at a workbook's macros before running an unfamiliar file someone
  else sent you.
</Callout>
