---
title: Filtering, sorting & outline shortcuts
description: Toggle filters, open a filter's dropdown, and work with grouped/outlined data from the keyboard.
---

Excel's native filtering and sorting is mostly dialog- and
mouse-driven, but a handful of genuinely useful shortcuts cover
turning filters on, opening a filter dropdown, and toggling outline
view.

export const groups = [

<ShortcutTable groups={groups} />

<Callout type="idea">
  With the active cell anywhere inside a filtered column's header
  row, **Alt+Down arrow** opens that column's filter dropdown
  exactly as if it had been clicked — no need to reach for the mouse
  just to change a filter.
</Callout>
