title: Editing & data entry shortcuts
description: Enter, fill, and edit cell contents faster — completing entries, filling ranges, and inserting dates without the mouse.
---

Typing and confirming values is the single most repeated action in
Excel — these shortcuts control exactly where the cursor lands next,
and fill, copy, or clear a whole selection in one keystroke instead
of cell by cell.

<Callout type="idea">
  **Ctrl+Enter** fills an entire selected range with whatever you
  just typed — select 50 cells first, type a value, then press
  Ctrl+Enter instead of Enter, and all 50 get the same value in one
  step. It's different from Ctrl+D/Ctrl+R, which copy from an
  existing cell rather than a fresh entry.
</Callout>
