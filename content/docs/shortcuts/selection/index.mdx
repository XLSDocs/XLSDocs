---
title: Selection shortcuts
description: Select cells, rows, columns, regions, and whole sheets precisely with the keyboard.
---

Selecting the right range by dragging with a mouse gets error-prone
once a table grows past one screen. These shortcuts select exactly
what's needed — a whole column, a contiguous data region, or
everything up to the last used cell — in one keystroke.

<Callout type="idea">
  **Ctrl+Shift+End** is the fastest way to select from the active
  cell all the way to the last used cell in the sheet — no need to
  know in advance how many rows or columns a table has. Combine it
  with Ctrl+Shift+Home to select the opposite direction, back to A1.
</Callout>
