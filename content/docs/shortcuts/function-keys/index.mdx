---
title: Function key shortcuts (F1–F12)
description: What each function key does on its own, and combined with Ctrl, Alt, and Shift, in Excel for Windows and Mac.
---

The F1–F12 row does more in Excel than most people realize — on its
own, each key already has a job, and combining it with Ctrl, Alt, or
Shift unlocks a completely different one. This page collects every
function-key combination in one place, rather than spread across the
task-based pages elsewhere in this section.

<Callout type="warn">
  Windows and Mac assign **genuinely different jobs** to the same
  function key far more often on this page than anywhere else in
  this section — F3, F10, and F12 in particular mean something
  unrelated on each platform. Don't assume a Windows F-key habit
  carries over to Mac (or back) without checking.
</Callout>
