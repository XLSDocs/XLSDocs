Excel has several hundred keyboard shortcuts — far more than anyone
memorizes at once. This section groups the ones worth knowing by
task, with Windows and Mac side by side, verified against
[Microsoft's own keyboard shortcuts reference](https://support.microsoft.com/office/keyboard-shortcuts-in-excel-1798d9d5-842a-42b8-9c99-9b7213f0040f).

Just want a short, curated starting list instead of the full
task-by-task breakdown? See
[32 Excel Keyboard Shortcuts Worth Actually Memorizing](/blog/essential-excel-keyboard-shortcuts).
