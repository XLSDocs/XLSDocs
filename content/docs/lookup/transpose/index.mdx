Flip a range from rows to columns (or columns to rows) — a vertical
list becomes a horizontal one, and vice versa. In modern Excel, the
result spills automatically; in older versions, it needs to be
array-entered into a pre-selected range of the right size.

## Return value

`array` with its rows and columns swapped — an *m* × *n* range becomes
*n* × *m*. Unlike Paste Special → Transpose, the result stays linked
to the source and updates automatically when it changes.

## Description

TRANSPOSE is one of the oldest array functions in Excel, predating
dynamic arrays by decades. In Excel 365 and 2021, it works like any
other spill function — enter it in one cell and the flipped result
spills into the cells below/right automatically. In Excel 2019 and
earlier, there's no spilling: select a range of the exact target size
first (if `array` is 3×2, select a 2×3 range), type the formula, then
confirm with **Ctrl+Shift+Enter** instead of Enter.

<Callout type="warn">
  In non-spilling versions, selecting the wrong size range is the most
  common TRANSPOSE mistake — too small and part of the result is
  silently cut off; too large and the extra cells show `#N/A`. The
  target range always needs exactly as many rows as `array` has
  columns, and exactly as many columns as `array` has rows.
</Callout>

<ExcelCode>{`=TRANSPOSE(A1:C1) → a 3-cell horizontal row becomes a 3-cell vertical column`}</ExcelCode>

<ExcelCode>{`=TRANSPOSE(A1:B3) → a 3-row, 2-column range becomes a 2-row, 3-column range`}</ExcelCode>

## Common errors

### #SPILL! — blocked spill range

Cells in the direction TRANSPOSE needs to spill already contain data.
Clear them, or move the formula somewhere with enough clear room in
both directions.

### #N/A filling part of the result (pre-2021 only)

The array-entered range was sized larger than the actual transposed
result. Reselect the exact target size — rows(`array`)'s column count
by columns(`array`)'s row count — before re-entering with
Ctrl+Shift+Enter.

### Part of the result looks cut off (pre-2021 only)

The opposite problem: the selected range was too small, so only part
of the flipped data fit. Reselect the full correctly-sized range and
re-enter.
