Retrieve **real-time, continuously updating data** from a COM
automation add-in — a market-data feed, a lab instrument, any
external program built to supply live values to Excel. Unlike every
other function on this site, RTD needs a specific add-in installed
to do anything at all.

## Return value

Whatever value the RTD server supplies for the given `topic`
parameters — continuously updated as the server pushes new data,
not just recalculated once. With no matching RTD server actually
installed, RTD returns `#N/A`.

## Description

RTD is Excel's plumbing for genuinely live, push-based data — unlike
a normal formula, which only recalculates when something triggers a
recalculation, an RTD-sourced value can update on its own as the
underlying server pushes new data through, while Excel is in
automatic calculation mode. No RTD server ships with Excel itself;
this function is only useful once a specific third-party or
in-house-built COM automation add-in is actually installed on the
machine running the workbook.

<Callout type="warn">
  **RTD does nothing without a matching add-in already installed.**
  Opening a workbook that uses RTD on a machine without the
  referenced server installed just produces `#N/A` in every RTD
  cell — there's no way to make the function itself supply data
  without that external piece in place first.
</Callout>

## Common errors

### #N/A — no matching RTD server installed

<ExcelCode>{`RTD("SomeVendor.RTDServer", "", "LAST", "MSFT") → #N/A (the add-in isn't installed on this machine)`}</ExcelCode>

Install the specific RTD server the `ProgID` refers to — this isn't
a formula syntax problem, it's a missing external dependency.

### Confusing the server argument's blank vs. quoted-blank requirement

<ExcelCode>{`In a worksheet formula, leave server empty: RTD("Vendor.Server", , "LAST")`}</ExcelCode>

For a locally-running add-in, `server` should be left blank in a
worksheet formula; from VBA specifically, an explicit empty string
(`""`) or `vbNullString` is required instead of a truly omitted
argument.
