Return a cell's **formula as text** — exactly what shows in the
formula bar when that cell is selected, not the value it calculates
to. Useful for documenting a workbook, building an audit sheet, or
showing a formula and its result side by side.

## Return value

The formula in `reference`, as a text string — `=B2*1.08`, say, not
whatever number that formula evaluates to. `#N/A` if the referenced
cell holds a plain value instead of a formula.

## Description

FORMULATEXT turns a formula itself into displayable text, which is
otherwise only visible by selecting the cell and looking at the
formula bar. It's commonly used on an audit or documentation sheet —
one column showing each key cell's live *value*, a neighboring
column (built with FORMULATEXT) showing the exact *formula* that
produced it, so a reviewer doesn't have to click through every cell
individually.

<Callout type="warn">
  **A cell with a plain value, not a formula, returns `#N/A`** — not
  an empty string or `0`. Pair FORMULATEXT with
  [ISFORMULA](/docs/info/isformula) or
  [IFERROR](/docs/logical/iferror) if `reference` might not
  actually contain a formula.
</Callout>

## Common errors

### #N/A — the referenced cell has no formula

<ExcelCode>{`FORMULATEXT(A1) → #N/A (if A1 just holds a plain typed value, like 42)`}</ExcelCode>

Check first with [ISFORMULA](/docs/info/isformula), or wrap the
call in IFERROR, if `reference` isn't guaranteed to hold a formula.

### #N/A — the reference points to a closed workbook

<ExcelCode>{`FORMULATEXT('[OtherFile.xlsx]Sheet1'!A1) → #N/A, if OtherFile.xlsx isn't currently open`}</ExcelCode>

FORMULATEXT can only read a formula from a workbook that's actually
open at calculation time.
