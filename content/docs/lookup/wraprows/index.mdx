Reshape a flat **row or column** of values into a 2D array, starting
a new **row** every `wrap_count` values — the opposite of
flattening, and the row-first counterpart to
[WRAPCOLS](/docs/lookup/wrapcols).

## Return value

A 2D array with `wrap_count` columns, filling across each row before
dropping to the next one. If the final row isn't completely filled,
the leftover cells get `pad_with` (`#N/A` by default).

## Description

WRAPROWS takes a single flat list and lays it out into a grid,
filling **across the first row first**, then dropping to a new row —
the way most people naturally read a numbered list wrapped onto
several lines. This is the opposite fill order from
[WRAPCOLS](/docs/lookup/wrapcols), which fills **down a column
first**.

<ExcelCode>{`=WRAPROWS(A1:F1, 3) → {1,2,3;4,5,6} — a 6-value row wraps into 2 rows of 3, filled left-to-right per row`}</ExcelCode>

<ExcelCode>{`=WRAPROWS(A1:E1, 3, "x") → {1,2,3;4,5,"x"} — 5 values don't fill the second row evenly, so "x" pads the gap`}</ExcelCode>

<Callout type="warn">
  **WRAPROWS and WRAPCOLS fill in opposite orders for the same
  input.** `WRAPROWS(A1:F1, 3)` fills across each row first,
  producing `{1,2,3; 4,5,6}`; `WRAPCOLS(A1:F1, 3)` fills down each
  column first, producing `{1,4; 2,5; 3,6}` instead — same input,
  same `wrap_count`, genuinely different layouts.
</Callout>

## Common errors

### #VALUE! — a two-dimensional vector

<ExcelCode>{`WRAPROWS(A1:C3, 3) → #VALUE! (A1:C3 is a 3x3 grid, not a one-dimensional row or column)`}</ExcelCode>

`vector` must already be a single row or single column — WRAPROWS
doesn't flatten a 2D range first.

### #NUM! — a wrap_count below 1

<ExcelCode>{`WRAPROWS(A1:F1, 0) → #NUM!`}</ExcelCode>

`wrap_count` has to be a positive whole number of `1` or more.
