Turn a text string like `"A1"` or `"Sheet2!B3"` into a real, live
cell reference — useful when the reference itself needs to be built
dynamically, from a sheet name in one cell and a row number in
another, for example.

## Return value

The value at the cell reference described by `ref_text`. If
`ref_text` refers to a range rather than a single cell, INDIRECT
returns a reference usable inside another function like SUM.

## Description

INDIRECT's job is building a reference out of text pieces at
calculation time — combining a sheet name typed in one cell with a
cell address in another to point at a moving target, or switching
which sheet a formula reads from based on a dropdown selection. The
tradeoff is that the reference exists only as text until INDIRECT
evaluates it, so Excel can't track it the way it tracks a normal
formula reference.

<Callout type="warn">
  Because `ref_text` is just a string until evaluated, **INDIRECT
  references silently break if a referenced sheet is renamed** —
  unlike a normal formula reference, which updates automatically.
  It's also volatile, recalculating on every sheet edit, the same
  cost as OFFSET.
</Callout>

## Common errors

### #REF! — the text doesn't resolve to a valid reference

<ExcelCode>{`INDIRECT("Sheet5!A1") → #REF! (if "Sheet5" doesn't exist)`}</ExcelCode>

The text must resolve to a genuinely valid reference — a typo in a
sheet name or cell address produces `#REF!`, not a more specific
error pointing at the actual problem.

### A renamed sheet silently breaks the formula

<ExcelCode>{`INDIRECT("Sales!A1") → #REF! (if the "Sales" sheet was renamed)`}</ExcelCode>

Unlike a normal cell reference, INDIRECT doesn't update automatically
when a referenced sheet is renamed — the text string has to be
updated manually, or built from a cell value that itself gets
updated.

## Related functions

- [OFFSET](/docs/lookup/offset) — also builds a reference
  dynamically, and shares the same volatility cost as INDIRECT.
- [INDEX](/docs/lookup/index) — a non-volatile way to return a
  reference for many of the same use cases.
- [XLOOKUP](/docs/lookup/xlookup) — a more direct choice when the
  goal is retrieving a value, rather than constructing a reference
  from text.
