Search any direction and return matching values. XLOOKUP replaces both
VLOOKUP and HLOOKUP, and is generally cleaner to read than an
INDEX/MATCH combination.

## Syntax

<ExcelCode>{`=XLOOKUP(lookup_value, lookup_array, return_array, [if_not_found], [match_mode], [search_mode])`}</ExcelCode>

## Return value

The matched value from `return_array`. Returns `#N/A` on no match, or
your custom `if_not_found` value if provided.

## Description

XLOOKUP searches a range or array and returns the corresponding item
from another range or array. Unlike VLOOKUP, the lookup column doesn't
need to be the leftmost column — you can look in any direction and
return values to the left, right, above, or below the lookup column.

<Callout type="warn">
  XLOOKUP requires **Excel 365 or Excel 2021**. It is not available in
  Excel 2019, 2016, or earlier — those versions will show `#NAME?`.
</Callout>

## Common errors

### #N/A — no match found

<ExcelCode>{`XLOOKUP("missing", A1:A10, B1:B10) → #N/A`}</ExcelCode>

`if_not_found` wasn't provided. Add a fourth argument to return a
fallback value instead of an error:

<ExcelCode>{`XLOOKUP("missing", A1:A10, B1:B10, "Not found")`}</ExcelCode>

### #VALUE! — mismatched array sizes

<ExcelCode>{`XLOOKUP(A2, A1:A5, B1:B4) → #VALUE!`}</ExcelCode>

`lookup_array` and `return_array` must be the same size — here one
is 5 rows and the other is 4.

### #SPILL! — blocked spill range

<ExcelCode>{`XLOOKUP(A2, A1:A10, B1:C10)`}</ExcelCode>

Returning more than one column spills the result, but cells below the
formula already contain data. Clear the spill range, or prefix with
`@` to force a single value:

<ExcelCode>{`@XLOOKUP(A2, A1:A10, B1:C10)`}</ExcelCode>

### Wildcard matching

<ExcelCode>{`XLOOKUP("*A2*", Names, Prices, "No match", 2)`}</ExcelCode>

Set `match_mode` to `2` to match partial text using `*` and `?`
wildcards.

<Callout type="info">
  VLOOKUP's `range_lookup` defaults to `TRUE` (approximate match),
  which silently returns wrong values when data isn't sorted. XLOOKUP
  defaults to exact match — a much safer starting point.
</Callout>

## Related functions

- [VLOOKUP](/docs/lookup/vlookup) — the classic vertical lookup that
  XLOOKUP replaces. Still worth knowing since it shows up constantly in
  older workbooks.
- [HLOOKUP](/docs/lookup/hlookup) — same idea as VLOOKUP, but searches
  across a row instead of down a column.
- [INDEX](/docs/lookup/index) and [MATCH](/docs/lookup/match) — the
  traditional flexible-lookup combo XLOOKUP was designed to simplify.
- [LOOKUP](/docs/lookup/lookup) — the oldest lookup function, with
  no exact-match option and a strict sorted-data requirement XLOOKUP
  doesn't share.
- [IFERROR](/docs/logical/iferror) — wraps a formula to catch `#N/A`,
  as an alternative to XLOOKUP's own `if_not_found` argument.
