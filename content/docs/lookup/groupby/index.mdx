Group rows by one or more values and aggregate another column
against each group — `SUM` sales by region, `COUNT` orders by
status, `AVERAGE` scores by class — all as a single live formula,
without building a PivotTable.

## Return value

A spilled array: one row per distinct group (or combination of
groups, if `row_fields` has multiple columns), with `function`
applied to `values` for that group — plus header rows and total
rows, depending on `field_headers` and `total_depth`.

## Description

GROUPBY is the formula equivalent of the single most common
PivotTable pattern — group rows by a category and summarize a number
column against each group — built directly into a live, spillable
formula instead of a separate PivotTable object that needs manual
refreshing.

<ExcelCode>{`=GROUPBY(A2:A76, D2:D76, SUM) → total sales (column D) summed for each distinct year (column A)`}</ExcelCode>

<ExcelCode>{`=GROUPBY(C2:C76, D2:D76, SUM, , , -2) → total sales by product, sorted largest to smallest (sort_order -2 sorts descending by the values column)`}</ExcelCode>

<Callout type="warn">
  **GROUPBY needs enough clear space below and to the right to spill
  its full result** — header row, every group row, and any total
  rows `total_depth` adds. Existing data blocking any of that space
  returns `#SPILL!`, the same as any other spilling function.
</Callout>

## Common errors

### #SPILL! — not enough room for the full result

<ExcelCode>{`GROUPBY(A2:A76, D2:D76, SUM) → #SPILL! if the cells below/right already contain data`}</ExcelCode>

Clear enough space for every group row, the header, and any totals
GROUPBY adds — the same fix as any other spilling formula.

### #VALUE! — mismatched row counts

<ExcelCode>{`GROUPBY(A2:A76, D2:D50, SUM) → #VALUE! (row_fields and values don't cover the same number of rows)`}</ExcelCode>

`row_fields`, `values`, and `filter_array` (if supplied) all need to
cover the exact same number of rows.
