Group data by **both rows and columns** at once and aggregate a
value against each row/column combination — the two-dimensional
counterpart to [GROUPBY](/docs/lookup/groupby), and the formula
equivalent of a full PivotTable's row-and-column layout.

## Return value

A spilled 2D array: one row per distinct `row_fields` group, one
column per distinct `col_fields` group, with `function` applied to
`values` for each row/column intersection — plus header rows/
columns and any total rows/columns.

## Description

Where GROUPBY summarizes data down to a single column of grouped
rows, PIVOTBY lays the result out as a genuine two-dimensional grid
— the exact shape a traditional PivotTable produces when it has both
a row field and a column field assigned. It's the formula-based
alternative for a cross-tabulation that needs to stay directly
composable with other formulas, rather than living as a separate
PivotTable object.

<ExcelCode>{`=PIVOTBY(C2:C76, A2:A76, D2:D76, SUM) → total sales (column D), broken out by product (rows, column C) across year (columns, column A)`}</ExcelCode>

<Callout type="warn">
  **PIVOTBY needs clear space for its entire spill area** — the
  header row, the row-label column, any total row, and any total
  column, all at once. A single occupied cell anywhere in that
  footprint returns `#SPILL!`, which can be easy to trigger
  accidentally since the full footprint is larger than just the
  data grid itself.
</Callout>

## Common errors

### #SPILL! — not enough room for the full grid

<ExcelCode>{`PIVOTBY(C2:C76, A2:A76, D2:D76, SUM) → #SPILL! if anything blocks the header row, label column, or totals`}</ExcelCode>

Clear the entire rectangular footprint the result needs — not just
the inner data grid, but its header row and row-label column too.

### #VALUE! — mismatched argument lengths

<ExcelCode>{`PIVOTBY(C2:C76, A2:A50, D2:D76, SUM) → #VALUE! (col_fields covers fewer rows than row_fields and values)`}</ExcelCode>

`row_fields`, `col_fields`, `values`, and `filter_array` (if
supplied) all need to cover the exact same number of source rows.
