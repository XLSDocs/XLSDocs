Insert an image **from a web URL directly into a cell** — unlike a
floating picture object, the image is a formula result that moves,
sorts, and fills with the cell it lives in, the same as any other
value.

## Return value

The image at `source`, rendered inside the cell — a true formula
result, so it moves with the cell on sort/filter/insert, unlike a
floating picture anchored on top of the sheet.

## Description

Before IMAGE, a picture pasted or inserted into a worksheet floated
as a separate object layered over the grid — it didn't belong to any
particular cell, so sorting or filtering the data underneath left
the picture behind, misaligned with its original row. IMAGE fixes
this by making the image itself a cell's actual formula result: a
product catalog with a photo column, for instance, now sorts and
filters correctly with the photos moving right along with their row.

<Callout type="warn">
  **A custom `height`/`width` only works with `sizing=3`.** Supplying
  either one alongside `sizing` 0, 1, or 2 returns `#VALUE!` — those
  three modes size the image automatically and don't accept manual
  dimensions at all.
</Callout>

## Common errors

### #VALUE! — height/width supplied with the wrong sizing mode

<ExcelCode>{`IMAGE("https://...", , 0, 200, 200) → #VALUE! (height/width only work with sizing=3)`}</ExcelCode>

Switch `sizing` to `3` to use custom dimensions, or drop `height`/
`width` entirely to let `sizing` 0, 1, or 2 size the image
automatically.

### #CONNECT! — a network or server problem

<ExcelCode>{`IMAGE("https://example.com/broken-link.jpg") → #CONNECT! (the URL couldn't be reached)`}</ExcelCode>

This reflects a live connectivity problem at calculation time, not a
formula mistake — check the URL is reachable and the internet
connection is working, then recalculate.

### #BLOCKED! — security settings preventing the image

<ExcelCode>{`IMAGE("https://...") → #BLOCKED! (Linked Data Types / web image settings are restricting it)`}</ExcelCode>

Check the workbook's Linked Data Types privacy settings; in Excel
for the web or mobile, images may also need enabling from the
business bar at the top of the workbook.

  <CodeBlockTab value="VBA">
    ```vb lineNumbers
    ' VBA has no built-in IMAGE — inserting a floating Picture object is the closest equivalent,
    ' but it won't behave as a true cell value the way IMAGE does
    ActiveSheet.Pictures.Insert("https://example.com/logo.png").Left = Range("A1").Left
    ```
  </CodeBlockTab>
  <CodeBlockTab value="Python">
    ```python lineNumbers
    import openpyxl
    from openpyxl.drawing.image import Image

    wb = openpyxl.load_workbook("workbook.xlsx")
    ws = wb["Sheet1"]
    ws.add_image(Image("logo.png"), "A1")  # openpyxl also only supports a floating image, not a cell value
    ```
  </CodeBlockTab>
