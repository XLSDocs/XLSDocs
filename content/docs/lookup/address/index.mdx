Build a cell reference as a text string from a row number and column
number — the reverse of what ROW/COLUMN do, useful whenever a
reference needs to be constructed dynamically rather than typed by
hand.

## Syntax

<ExcelCode>{`=ADDRESS(row_num, column_num, [abs_num], [a1], [sheet_text])`}</ExcelCode>

## Return value

A text string representing the cell at `row_num`/`column_num`, in the
`$`-pattern `abs_num` specifies.

## Description

ADDRESS builds a reference as plain text — it does **not** return an
actual, usable reference the way a typed `A1` does. That text can be
displayed, concatenated into a message, or fed into `INDIRECT` to
turn it into a real, live reference.

<Callout type="warn">
  ADDRESS's output is just text, even though it looks exactly like a
  real reference. `=ADDRESS(2,3)` displays `$C$2`, but
  `=ADDRESS(2,3)+1` fails with `#VALUE!` — it isn't a reference until
  wrapped in `INDIRECT`: `=INDIRECT(ADDRESS(2,3))`.
</Callout>

## Common errors

### #VALUE! — treating the result as a real reference

<ExcelCode>{`ADDRESS(2, 3) + 1 → #VALUE!`}</ExcelCode>

ADDRESS returns text, not a reference. Wrap it in `INDIRECT` first if
the actual cell's value is needed:

<ExcelCode>{`INDIRECT(ADDRESS(2, 3)) + 1`}</ExcelCode>

### #VALUE! — row_num or column_num is less than 1

<ExcelCode>{`ADDRESS(0, 3) → #VALUE!`}</ExcelCode>

Both arguments must be positive whole numbers — there's no row 0 or
column 0 to reference.
