Search a range for a value and return its **position** within that
range — the modern replacement for `MATCH`, with a safer default
(exact match instead of approximate) and a few abilities MATCH never
had, like searching from the last item backward.

## Return value

The 1-based position of `lookup_value` within `lookup_array`. Returns
`#N/A` if no match is found — same failure behavior as MATCH.

## Description

XMATCH answers the same "where is it" question as MATCH, but flips
the risky default: MATCH silently assumes an approximate,
sorted-ascending match unless `0` is passed explicitly, while XMATCH
assumes an **exact** match unless told otherwise. It also adds a
`search_mode` argument MATCH never had — searching from the end of
the range backward (`-1`), which is the standard way to find the
*last* occurrence of a value instead of the first.

<Callout type="info">
  XMATCH is the position half of the same modernization that produced
  `XLOOKUP` — in fact, XLOOKUP uses the exact same `match_mode` and
  `search_mode` arguments internally. Learning XMATCH's arguments
  means already knowing XLOOKUP's.
</Callout>

## Common errors

### #N/A — no match found

<ExcelCode>{`XMATCH("Zzz", A1:A10) → #N/A`}</ExcelCode>

`lookup_value` doesn't exist anywhere in `lookup_array`, and
`match_mode` wasn't set to allow a next-smaller/next-larger fallback.

### #N/A — lookup_array is two-dimensional

<ExcelCode>{`XMATCH("Widget", A1:C10) → #N/A`}</ExcelCode>

Like MATCH, `lookup_array` must be a single row or a single column.
