Reshape a flat **row or column** of values into a 2D array, starting
a new **column** every `wrap_count` values — the opposite of
flattening, and the column-first counterpart to
[WRAPROWS](/docs/lookup/wraprows).

## Return value

A 2D array with `wrap_count` rows, filling down each column before
starting the next one. If the final column isn't completely filled,
the leftover cells get `pad_with` (`#N/A` by default).

## Description

WRAPCOLS takes a single flat list and lays it out into a grid,
filling **down the first column first**, then starting a new column
— like reading a list top-to-bottom, left-to-right. This is the
opposite fill order from WRAPROWS, which fills **across a row
first**. Which one to use depends entirely on which reading order
the result should have.

<ExcelCode>{`=WRAPCOLS(A1:F1, 3) → {1,4;2,5;3,6} — a 6-value row wraps into 2 columns of 3, filled top-to-bottom per column`}</ExcelCode>

<ExcelCode>{`=WRAPCOLS(A1:E1, 3, "x") → {1,4;2,5;3,"x"} — 5 values don't fill the second column evenly, so "x" pads the gap`}</ExcelCode>

<Callout type="warn">
  **WRAPCOLS and WRAPROWS fill in opposite orders for the same
  input.** `WRAPCOLS(A1:F1, 3)` fills down each column first,
  producing `{1,4; 2,5; 3,6}`; `WRAPROWS(A1:F1, 3)` fills across each
  row first, producing `{1,2,3; 4,5,6}` instead — same input, same
  `wrap_count`, genuinely different layouts.
</Callout>

## Common errors

### #VALUE! — a two-dimensional vector

<ExcelCode>{`WRAPCOLS(A1:C3, 3) → #VALUE! (A1:C3 is a 3x3 grid, not a one-dimensional row or column)`}</ExcelCode>

`vector` must already be a single row or single column — WRAPCOLS
doesn't flatten a 2D range first.

### #NUM! — a wrap_count below 1

<ExcelCode>{`WRAPCOLS(A1:F1, 0) → #NUM!`}</ExcelCode>

`wrap_count` has to be a positive whole number of `1` or more.
