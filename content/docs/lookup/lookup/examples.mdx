---
title: LOOKUP examples
description: Worked examples for LOOKUP — a grade lookup table, omitting result_vector, and the unsorted-data gotcha.
---

<FunctionNav />

<ExampleCard number="01" label="Basic — a grade lookup table" formula={`=LOOKUP(A2, {0,60,70,80,90}, {"F","D","C","B","A"})`}>
  Finds the largest threshold at or below the score in A2 and
  returns the matching letter grade.
</ExampleCard>

<ExampleCard number="02" label="Using table columns instead of literals" formula={`=LOOKUP(A2, Grades[MinScore], Grades[Letter])`}>
  The same idea, referencing real columns instead of typed-in
  arrays — MinScore must be sorted ascending.
</ExampleCard>

<ExampleCard number="03" label="Omitting result_vector" formula={`=LOOKUP(A2, {10,20,30,40})`}>
  Without a third argument, LOOKUP returns the matching value from
  the lookup range itself — the largest value at or below A2.
</ExampleCard>

<ExampleCard number="04" label="#N/A below the smallest value" formula={`=LOOKUP(5, {10,20,30}, {"A","B","C"})`}>
  Returns `#N/A` — there's no value in the lookup range less than or
  equal to 5.
</ExampleCard>

<ExampleCard number="05" label="The modern equivalent with XLOOKUP" formula={`=XLOOKUP(A2, Grades[MinScore], Grades[Letter], , -1)`}>
  XLOOKUP's `match_mode=-1` finds the same "largest value at or
  below" result, without LOOKUP's silent-failure risk on unsorted
  data.
</ExampleCard>
