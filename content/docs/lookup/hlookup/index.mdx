Search the first row of a range and return a value from a row below
it, in the same column. The horizontal counterpart to VLOOKUP — used
when data is laid out across columns instead of down rows, like a
table with dates or categories running along the top.

## Syntax

<ExcelCode>{`=HLOOKUP(lookup_value, table_array, row_index_num, [range_lookup])`}</ExcelCode>

## Return value

The value from the `row_index_num` row of the matching column.
Returns `#N/A` if no match is found (with `range_lookup` set to
`FALSE`), or a possibly wrong value if `range_lookup` is `TRUE` and
the data isn't sorted.

## Description

HLOOKUP searches across the first row of `table_array` for
`lookup_value`, then returns the value from the same column, counting
down `row_index_num` rows. It's the mirror image of VLOOKUP — VLOOKUP
searches down a column and returns across a row; HLOOKUP searches
across a row and returns down a column.

<Callout type="warn">
  `range_lookup` defaults to `TRUE` (approximate match) if omitted —
  the same mistake that trips people up with VLOOKUP. On unsorted
  data it silently returns the wrong value instead of an error. Pass
  `FALSE` explicitly unless you specifically want an approximate,
  tiered match.
</Callout>

## Common errors

### #N/A — lookup_value not in the first row

<ExcelCode>{`HLOOKUP("SKU-9", A1:J3, 2, FALSE) → #N/A`}</ExcelCode>

`lookup_value` must exist in the **first row** of `table_array` —
HLOOKUP never searches any other row.

### #REF! — row_index_num out of range

<ExcelCode>{`HLOOKUP(A2, A1:J2, 3, FALSE) → #REF!`}</ExcelCode>

`table_array` only has 2 rows here, but `row_index_num` asks for the
3rd.

### Wrong value, no error

<ExcelCode>{`HLOOKUP(A2, A1:J2, 2) → returns a plausible-looking but incorrect value`}</ExcelCode>

`range_lookup` was omitted or `TRUE` on data that isn't sorted
ascending. Always pass `FALSE` unless you specifically want an
approximate match:

<ExcelCode>{`HLOOKUP(A2, A1:J2, 2, FALSE)`}</ExcelCode>

<Callout type="info">
  HLOOKUP can only look **below** its lookup row. If the value you
  need to return sits above the row you're searching, use XLOOKUP or
  INDEX/MATCH instead.
</Callout>

## Related functions

- [VLOOKUP](/docs/lookup/vlookup) — the same idea, searching down a
  column instead of across a row. Far more common in practice, since
  most real-world data runs vertically.
- [XLOOKUP](/docs/lookup/xlookup) — replaces both HLOOKUP and VLOOKUP
  with one function that searches either direction.
- [INDEX](/docs/lookup/index) and [MATCH](/docs/lookup/match) — the
  traditional flexible-lookup combo, useful when neither HLOOKUP nor
  VLOOKUP's fixed search direction fits.
- [IFERROR](/docs/logical/iferror) — wraps HLOOKUP to catch `#N/A`
  and return a fallback value.
