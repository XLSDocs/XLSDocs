Create a clickable link — to a webpage, a file, an email address, or
a cell elsewhere in the same workbook — that shows custom display
text instead of the raw address underneath.

## Return value

A clickable cell displaying `friendly_name` (or `link_location` if
`friendly_name` is omitted) that navigates to `link_location` when
clicked.

## Description

HYPERLINK is the formula equivalent of Insert → Link — the difference
is that it can be built dynamically from other cells, so the
destination or display text can change based on a lookup, a
concatenation, or any other formula logic, rather than being fixed
when the link was manually inserted.

<Callout type="warn">
  To link to a location inside the **same workbook** (another sheet,
  a named range, a specific cell), prefix `link_location` with `#` —
  `"#Sheet2!A1"`, not `"Sheet2!A1"`. Without the `#`, Excel treats the
  text as an external path and the link won't resolve correctly.
</Callout>

## Common errors

### #VALUE! — link_location isn't text

<ExcelCode>{`HYPERLINK(A2, "Click here") → #VALUE! (if A2 is a number, not text)`}</ExcelCode>

`link_location` must evaluate to a text string. Wrap a numeric or
computed value in `TEXT()` first if it needs to become part of a URL
or path.

### The link doesn't go anywhere inside the workbook

Missing the leading `#` on an internal reference is the most common
cause — `"Sheet2!A1"` is treated as an external file path, not a
same-workbook jump. Use `"#Sheet2!A1"` instead.

### Clicking does nothing at all

If `link_location` points to a file path, that file needs to actually
exist at that exact path on the machine opening the workbook —
HYPERLINK doesn't validate the destination, it only builds the link.

    ```vb lineNumbers
    ActiveSheet.Hyperlinks.Add _
      Anchor:=Range("B2"), _
      Address:="https://example.com/orders/" & Range("A2").Value, _
      TextToDisplay:="View order " & Range("A2").Value
    ```
  </CodeBlockTab>

    ```python lineNumbers
    wb = Workbook()

    ```
