Retrieve **historical price data** for a stock, ticker, or other
financial instrument over a date range — daily, weekly, or monthly —
spilled directly into the sheet as an array, with Date and Close
price as the default columns.

## Return value

A spilled array of historical price data for `stock`, one row per
date in the requested interval, with columns in the order given by
`property0`, `property1`, and so on (or just Date and Close, by
default).

## Description

STOCKHISTORY is built on the same live Stocks data connection behind
Excel's Stocks data type — unlike a plain lookup formula, its result
depends on Microsoft's financial-data service being reachable and
having data for the requested instrument. Because it only requires a
ticker and a date range (no add-in installation, unlike
[RTD](/docs/lookup/rtd)), it's the more approachable of this site's
two "live external data" lookup functions — but it still can't be
demonstrated with a fixed worked example the way an ordinary
calculation can.

<Callout type="warn">
  Because this result depends on a live, internet-connected
  financial-data service (and the exact historical prices change
  with every new trading day), it can't be demonstrated with a fixed
  example the way a pure calculation can — the "Try it" widget used
  elsewhere on this site doesn't apply here.
</Callout>

## Common errors

### No data available for the requested instrument

<ExcelCode>{`STOCKHISTORY("^GSPC", "2020-01-01") → no data for many popular index funds, including the S&P 500 itself`}</ExcelCode>

Microsoft's own documentation notes that several widely-used index
instruments simply have no historical data available through this
function, regardless of ticker format.

### Missing today's data right after the market closes

<ExcelCode>{`STOCKHISTORY("MSFT", TODAY()) → may not include today's price yet`}</ExcelCode>

Data generally only becomes available once a trading day fully
completes — querying for the current day before the market closes
(or before the day ends, for some markets) can come back without
today's row yet.

    ' VBA has no built-in STOCKHISTORY — calling the worksheet function from VBA is the usual approach
    Dim result As Variant

    ```

    import yfinance as yf

    # STOCKHISTORY's closest Python equivalent is a dedicated market-data library,

    data = yf.Ticker("MSFT").history(start="2026-01-01", end="2026-12-31")
    ```
  </CodeBlockTab>
