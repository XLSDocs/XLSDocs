Search the first column of a range and return a value from a column to
its right, in the same row. The classic Excel lookup function — still
the most common formula in real-world workbooks, even with XLOOKUP now
available.

## Syntax

<ExcelCode>{`=VLOOKUP(lookup_value, table_array, col_index_num, [range_lookup])`}</ExcelCode>

## Return value

The value from the `col_index_num` column of the matching row. Returns
`#N/A` if no match is found (with `range_lookup` set to `FALSE`), or a
possibly wrong value if `range_lookup` is `TRUE` and the data isn't
sorted.

## Description

VLOOKUP searches down the first column of `table_array` for
`lookup_value`, then returns the value from the same row in the column
`col_index_num` columns to the right. The lookup column must be the
**leftmost** column of `table_array` — VLOOKUP can only look to the
right, never to the left.

<Callout type="warn">
  `range_lookup` defaults to `TRUE` (approximate match) if omitted —
  this is the single most common VLOOKUP mistake. On unsorted data it
  silently returns the wrong value instead of an error. Pass `FALSE`
  explicitly unless you specifically want an approximate, tiered match.
</Callout>

## Common errors

### #N/A — lookup_value not in the first column

<ExcelCode>{`VLOOKUP("SKU-9", A1:C10, 2, FALSE) → #N/A`}</ExcelCode>

`lookup_value` must exist in the **first column** of `table_array` —
VLOOKUP never searches any other column.

### #REF! — col_index_num out of range

<ExcelCode>{`VLOOKUP(A2, A1:B10, 3, FALSE) → #REF!`}</ExcelCode>

`table_array` only has 2 columns here, but `col_index_num` asks for
the 3rd.

### Wrong value, no error

<ExcelCode>{`VLOOKUP(A2, A1:B10, 2) → returns a plausible-looking but incorrect value`}</ExcelCode>

`range_lookup` was omitted or `TRUE` on data that isn't sorted
ascending. Always pass `FALSE` unless you specifically want an
approximate match:

<ExcelCode>{`VLOOKUP(A2, A1:B10, 2, FALSE)`}</ExcelCode>

<Callout type="info">
  VLOOKUP can only look to the **right** of its lookup column. If the
  value you need to return sits to the left of the value you're
  searching for, use XLOOKUP or INDEX/MATCH instead.
</Callout>

## Related functions

- [XLOOKUP](/docs/lookup/xlookup) — the modern replacement that can
  search in any direction and handles missing values more cleanly.
- [HLOOKUP](/docs/lookup/hlookup) — the same idea as VLOOKUP, but
  searches across a row instead of down a column.
- [INDEX](/docs/lookup/index) and [MATCH](/docs/lookup/match) — the
  traditional flexible-lookup combo that can search in any direction,
  unlike VLOOKUP.
- [IFERROR](/docs/logical/iferror) — wraps VLOOKUP to catch `#N/A`
  and return a fallback value.
