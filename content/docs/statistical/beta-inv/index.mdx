## Return value

The value `x` such that `BETA.DIST(x, alpha, beta, TRUE, A, B)`
equals `probability`.

## Description

BETA.INV is most often used in Bayesian analysis to extract a
credible interval from a posterior beta distribution — after
observing data, an analyst updates `alpha` and `beta` to reflect what
was learned, then uses BETA.INV to find, say, the 2.5th and 97.5th
percentiles that bound a 95% credible interval for the true
underlying probability.

<Callout type="idea">
  BETA.INV and `BETA.DIST` are exact inverses:
  `BETA.INV(BETA.DIST(x, alpha, beta, TRUE), alpha, beta)` returns `x`
  back, for any valid `x`, `alpha`, and `beta` on the matching
  interval.
</Callout>

## Common errors

### #NUM! — probability is not strictly between 0 and 1

<ExcelCode>{`BETA.INV(0, 2, 5) → #NUM!`}</ExcelCode>

`probability` must be greater than 0 and less than 1, and both
`alpha` and `beta` must be strictly positive.

### Forgetting to match A and B to how alpha/beta were fit

<ExcelCode>{`BETA.INV(0.5, 2, 5, 0, 100) → 26.44, not 0.2644 — a rescaled result on a 0-100 interval`}</ExcelCode>

If `alpha` and `beta` were determined assuming the default `[0, 1]`
interval, omit `A` and `B` (or explicitly pass `0` and `1`) — adding
a different interval rescales the result to match, which is easy to
do by accident when copying a formula between contexts.
