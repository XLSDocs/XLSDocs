## Return value

The value `x` such that `LOGNORM.DIST(x, mean, standard_dev, TRUE)`
equals `probability`.

## Description

LOGNORM.INV computes `EXP(mean + standard_dev × z)`, where `z` is the
standard-normal z-score for `probability` — the same inverse-normal
lookup `NORM.S.INV` performs, exponentiated back onto the lognormal
scale. Because `EXP` is a strictly increasing function, LOGNORM.INV
inherits the underlying normal distribution's symmetry in z-score
terms even though the result itself is skewed on the original scale.

<Callout type="idea">
  `LOGNORM.INV(0.5, mean, standard_dev)` always equals exactly
  `EXP(mean)` — the median of a lognormal distribution has this clean
  closed form, unlike the gamma or beta distributions covered
  elsewhere in this round, which need genuine numerical inversion even
  at the 50th percentile.
</Callout>

The same `mean = 0`, `standard_dev = 0.5` lognormal distribution used
on `LOGNORM.DIST`'s page. `LOGNORM.INV(0.5, 0, 0.5)` returns exactly
1.0000 — matching `EXP(0)`, confirming the median is exactly `EXP(mean)`
regardless of `standard_dev`.

## Common errors

### #NUM! — probability is not strictly between 0 and 1

<ExcelCode>{`LOGNORM.INV(1, 0, 0.5) → #NUM!`}</ExcelCode>

`probability` must be greater than 0 and less than 1, and
`standard_dev` must be positive.

### Expecting the result to equal EXP(mean) at every probability

<ExcelCode>{`LOGNORM.INV(0.9, 0, 0.5) → 1.8980, not EXP(0) = 1 — that shortcut only applies exactly at probability = 0.5`}</ExcelCode>

Only the median (`probability = 0.5`) has the clean `EXP(mean)`
shortcut — every other percentile genuinely depends on
`standard_dev` too, requiring the full inverse-normal calculation.
