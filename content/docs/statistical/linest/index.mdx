Return a linear regression line's slope and intercept together as a
single array — the same numbers `SLOPE` and `INTERCEPT` calculate
separately, in one formula, with the option to pull the full set of
regression statistics alongside them.

## Return value

With `stats` `FALSE` (the default) and one independent variable: a
2-cell array, `{slope, intercept}`. With `stats` `TRUE`: a 5-row
array adding standard errors, R², the F-statistic, and more beneath
those two values.

## Description

LINEST is the single-formula alternative to calling `SLOPE` and
`INTERCEPT` separately — both values come back from one array
formula, in the fixed order `{slope, intercept}`. Its real power
shows up with multiple regression (several independent variables in
`known_xs`), where SLOPE/INTERCEPT can't help at all — LINEST returns
one slope coefficient per variable, still followed by a single
intercept.

<Callout type="warn">
  LINEST's two values come back **slope first, intercept second** —
  the opposite order from how the equation `y = mx + b` is usually
  written out. Reading them in the wrong order is a common way to
  silently swap a slope and an intercept in a downstream formula.
</Callout>

The result shows `{slope, intercept}` together. With month 1 at its
original 10, LINEST spills `{10, 0}` — the same values `SLOPE` and
`INTERCEPT` compute separately for this exact data. Raising month 1
to 15 or lowering it to 5 changes *both* numbers at once, since
they're two views of the same single regression line.

## Common errors

### Reading slope and intercept in the wrong order

<ExcelCode>{`=INDEX(LINEST(B2:B4,A2:A4),1,1) → the SLOPE, not the intercept`}</ExcelCode>

The first value in LINEST's array is always the slope; the second is
the intercept. Pulling the wrong position with `INDEX` silently
swaps them without any error.

### #N/A — known_ys and known_xs are different sizes

`known_ys` and `known_xs` (when supplied) must contain the same
number of data points.

### Expecting a single cell instead of a spilled array

<ExcelCode>{`LINEST(B2:B4, A2:A4) → spills across 2 cells, not just 1`}</ExcelCode>

LINEST always returns an array, even in its simplest form — make
sure there's a clear cell to its right (or below, with `stats =
TRUE`) for it to spill into.
