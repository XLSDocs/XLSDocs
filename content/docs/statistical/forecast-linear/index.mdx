Predict a value along a linear trend fitted through known historical
data — the identical calculation as `FORECAST`, under a newer name
added purely for symmetry with `FORECAST.ETS`.

## Return value

The predicted `y` value at `x`, based on the best-fit straight line
through `known_xs` and `known_ys` — identical to what `FORECAST`
returns on the same inputs.

## Description

FORECAST.LINEAR and FORECAST calculate the exact same result — there
is no calculation difference between them, and no version of Excel
treats them differently. FORECAST.LINEAR was introduced in Excel 2016
purely for naming symmetry alongside `FORECAST.ETS` (which forecasts
using seasonal patterns instead of a straight line), so the "linear"
method would have an equally explicit name.

<Callout type="idea">
  There's no reason to prefer FORECAST.LINEAR over plain FORECAST —
  they're permanently identical. FORECAST also has the advantage of
  working in every Excel version this site covers, while
  FORECAST.LINEAR requires Excel 2016 or later.
</Callout>

## Common errors

### #N/A — known_ys and known_xs are different sizes

Every value in `known_ys` needs a corresponding value in `known_xs`
at the same position — the two ranges must contain the same number
of data points, the same requirement FORECAST has.

### Assuming FORECAST.LINEAR handles seasonality

FORECAST.LINEAR only fits a straight line — for data with a
repeating seasonal pattern, `FORECAST.ETS` is the function built to
account for that instead.
