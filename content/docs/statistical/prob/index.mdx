Sum the probabilities of every value in a range that falls between a
lower and upper limit — given a custom, hand-specified probability
for each individual outcome, rather than a formula-based
distribution.

## Return value

The sum of every probability in `prob_range` whose corresponding
value in `x_range` falls between `lower_limit` and `upper_limit`,
inclusive.

## Description

Unlike every other function in this round, PROB doesn't assume any
particular mathematical distribution — it works directly from a
custom probability table supplied by hand, one probability per
possible outcome. This makes it the right tool whenever outcomes and
their likelihoods are known individually (a loaded die, survey
response percentages, a discrete payoff table) rather than following
a standard distribution shape like binomial or Poisson.

<Callout type="warn">
  Excel expects `prob_range`'s values to sum to (very close to) 1 —
  if they don't, PROB returns `#N/A` rather than silently normalizing
  or rescaling them. Always double-check a custom probability table
  actually sums to 1 before relying on PROB's result.
</Callout>

## Common errors

### #N/A — prob_range doesn't sum to 1

<ExcelCode>{`PROB(x_range, prob_range, 1, 6) → #N/A if prob_range's values sum to 0.95 or 1.05`}</ExcelCode>

`prob_range` must sum to 1 (Excel allows a small floating-point
tolerance, but a genuinely incomplete or overcounted probability
table returns `#N/A` rather than an approximate answer.

### #N/A — x_range and prob_range are different sizes

<ExcelCode>{`PROB(A2:A6, B2:B7, 1, 6) → #N/A`}</ExcelCode>

Every value in `x_range` needs exactly one matching probability in
`prob_range` — the two ranges must be the same size.
