Return the right-tailed probability of the Student's t-distribution —
the area under the curve to the right of a given t-value, the shape
most one-tailed hypothesis tests actually need.

## Return value

The probability that a t-distributed random variable with
`deg_freedom` degrees of freedom is greater than or equal to `x` — the
area under the curve to the right of `x`.

## Description

T.DIST.RT is the mirror image of `T.DIST`'s cumulative result:
`T.DIST.RT(x, df)` always equals `1 - T.DIST(x, df, TRUE)`. It's the
natural choice for a one-tailed "is the true value greater than this"
question — the same role `T.DIST` plays on the left side.

<Callout type="idea">
  T.DIST.RT doesn't take a `cumulative` argument — unlike `T.DIST`, it
  only ever returns a probability, never a density. There's no
  "right-tailed density" concept, since density doesn't have a
  direction.
</Callout>

The same t-statistic from a 13-observation sample (12 degrees of
freedom) used on `T.DIST`'s page. At `t = 2`, T.DIST.RT returns
0.0343 — only 3.43% of the distribution's area lies to the right of
2, which is exactly `1 - 0.9657` from T.DIST's left-tailed result on
the identical input.

## Common errors

### #NUM! — deg_freedom is less than 1

<ExcelCode>{`T.DIST.RT(2, 0) → #NUM!`}</ExcelCode>

`deg_freedom` must be at least 1.

### Using T.DIST.RT when the test is actually two-tailed

<ExcelCode>{`T.DIST.RT(2, 12) → 0.0343, not the same as the two-tailed 0.0687`}</ExcelCode>

A one-tailed result is only appropriate when the hypothesis being
tested has a direction ("is the mean greater than X," not just
"different from X"). For a non-directional test, use `T.DIST.2T`
instead — it's exactly double this result.
