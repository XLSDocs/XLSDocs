## Return value

The height of the standard normal curve at `x`.

## Description

PHI is a shorthand for exactly what `NORM.S.DIST(x, FALSE)` already
computes — the standard normal probability *density*, not a
cumulative probability. Its own name comes directly from the
mathematical convention of writing the standard normal density
function as the Greek letter φ (phi), reserving the capital Φ for the
cumulative version. Because it's a density rather than a probability,
PHI's output can exceed 1 (its maximum, at `x = 0`, is about 0.3989)
and represents the curve's height, not the chance of any particular
outcome.

<Callout type="idea">
  PHI exists purely as a shorter, more mathematically conventional way
  to write `NORM.S.DIST(x, FALSE)` — the two are otherwise completely
  interchangeable, always returning identical results for the same
  input.
</Callout>

`PHI(0)` returns 0.3989 — the bell curve's peak height, right at its
center. As `x` moves further from 0, the curve's height drops off
quickly: by `x = 2.5`, PHI returns just 0.0175, reflecting how little
of the standard normal curve's height remains that far into the tail.

## Common errors

### Confusing PHI's density with a cumulative probability

<ExcelCode>{`PHI(0) → 0.3989, not the 0.5 cumulative probability at the mean`}</ExcelCode>

PHI returns the curve's **height**, not the probability of a value
falling below `x`. For the cumulative probability at the mean, use
`NORM.S.DIST(0, TRUE)`, which correctly returns 0.5.

### Expecting PHI's output to stay under 1 like a probability

<ExcelCode>{`PHI(0) → 0.3989, always under 1 for the standard normal, but a density in general can exceed 1`}</ExcelCode>

For the standard normal specifically, PHI happens to never exceed
about 0.3989 — but that's a property of this particular curve's
shape, not a general rule that all densities stay below 1. Don't
extend that assumption to differently-scaled distributions.
