Estimate the sample standard deviation across a list of values — but
unlike `STDEV.S`, text counts as `0` and `TRUE`/`FALSE` count as
`1`/`0` instead of being skipped entirely.

## Return value

The sample standard deviation across everything included, where text
counts as `0` and `TRUE`/`FALSE` count as `1`/`0` — unlike `STDEV.S`,
which ignores text and logical values entirely.

## Description

STDEVA is `VARA`'s square root — it measures spread in the same
units as the original data, rather than squared units, while still
applying the same text-as-`0`, logical-as-`1`/`0` treatment. Mixing
genuine numbers with text or logical values usually inflates STDEVA
compared to STDEV.S on the identical range, for the same reason it
inflates VARA.

<Callout type="warn">
  Like VARA, a text entry mixed into an otherwise tightly-clustered
  positive numeric range can noticeably inflate STDEVA compared to
  `STDEV.S` — check whether that inflation reflects real spread in
  the data or just an unintended stray text value.
</Callout>

With the 5th value at `7`, STDEVA returns `4.1833` — the square root
of `VARA`'s `17.5` on the identical data. Pushing the 5th value
farther from the rest of the set (to `15` or `-3`) grows the spread,
and STDEVA along with it.

## Common errors

### #DIV/0! — fewer than 2 non-blank values

STDEVA's formula (like VARA's) divides by `n − 1`, which is zero
with only 1 non-blank value.

### The result is much larger than STDEV.S on the same range

Check for a text entry — it counts as `0` in STDEVA, which can
noticeably raise the calculated spread if the rest of the range's
real numbers are clustered elsewhere. `STDEV.S` would exclude that
same text entry entirely.

        if isinstance(v, bool): return 1 if v else 0
        if isinstance(v, (int, float)): return v
        if v is None: return None
        return 0

    values = [v for v in (to_a_value(v) for v in ["Pass", 8, 9, True, 7]) if v is not None]
    result = np.std(values, ddof=1)  # sample standard deviation
