---
title: RANK examples
description: Worked examples for RANK — a leaderboard, ascending order, and breaking ties.
---

<FunctionNav />

<ExampleCard number="01" label="Basic — sales leaderboard" formula={`=RANK(B2, $B$2:$B$10)`}>
  Ranks each salesperson's total against everyone else's, largest
  first.
</ExampleCard>

<ExampleCard number="02" label="Ascending order (lowest = 1st)" formula={`=RANK(B2, $B$2:$B$10, 1)`}>
  Useful for something like race times, where the smallest value
  should rank 1st.
</ExampleCard>

<ExampleCard number="03" label="Breaking ties for a unique rank" formula={`=RANK(B2,$B$2:$B$10) + COUNTIF($B$2:B2,B2) - 1`}>
  Nudges each tied duplicate to its own sequential rank instead of
  sharing a position.
</ExampleCard>

<ExampleCard number="04" label="Top 3 flag using RANK" formula={`=IF(RANK(B2,$B$2:$B$10)<=3, "Top 3", "")`}>
  Flags only the three highest-ranked rows.
</ExampleCard>

<ExampleCard number="05" label="Rank as a percentage" formula={`=1 - (RANK(B2,$B$2:$B$10)-1)/(COUNT($B$2:$B$10)-1)`}>
  Converts a whole-number rank into a percentile-style figure
  between 0 and 1.
</ExampleCard>
