Measure how spread out a set of numbers is from their average, in
squared units — the building block behind standard deviation.
Mostly useful as an intermediate calculation; STDEV is usually the
more directly interpretable number.

## Return value

The sample variance of the supplied numbers — the average of the
squared differences from the mean. Text and blank cells within a
range are ignored.

## Description

VAR measures spread the same way STDEV does, but in squared units —
which makes it harder to interpret directly (a variance of "400
dollars squared" doesn't mean much intuitively, while its square
root, a $20 standard deviation, does). VAR is mostly useful as an
intermediate calculation, or in statistical formulas that
specifically call for variance rather than standard deviation. VAR
is the older name for what's now formally
[VAR.S](/docs/statistical/var-s).

<Callout type="info">
  VAR is exactly `STDEV` squared, and STDEV is exactly `SQRT(VAR)` —
  they measure the same underlying spread, just in different units.
  Reach for STDEV when the number needs to be interpretable on its
  own; reach for VAR only when a formula specifically requires
  variance. Use [VAR.P](/docs/statistical/var-p) instead of VAR when
  the data is the entire population, not a sample.
</Callout>

## Common errors

### #DIV/0! — fewer than two numeric values

<ExcelCode>{`VAR(5) → #DIV/0!`}</ExcelCode>

Sample variance is undefined with only one value — at least two
numbers are required.

### Misinterpreting the units

<ExcelCode>{`VAR(Prices) → a number in "dollars squared," not dollars`}</ExcelCode>

Not an error, but a common source of confusion — variance is in
squared units of the original data, which rarely has a direct
real-world interpretation. Use STDEV for a number that's actually
meaningful on its own.
