Return an exponential curve's own coefficients (`m` and `b` in `y = b
× mˣ`) as a single array — `LINEST`'s counterpart for data that
compounds rather than changes by a fixed amount each period.

## Return value

With `stats` `FALSE` (the default): a 2-cell array, `{m, b}`, where
`y = b × mˣ` is the best-fit exponential curve through the data. With
`stats` `TRUE`: a 5-row array adding standard errors, R², and more.

## Description

LOGEST is to `GROWTH` what `LINEST` is to `TREND` — instead of
predicting a value, it returns the fitted exponential curve's own
coefficients directly. `m` represents the per-period growth
multiplier (an `m` of `1.1` means 10% growth each period), and `b`
represents the curve's value at `x = 0`.

<Callout type="warn">
  LOGEST's two values come back **`m` first, `b` second** — easy to
  mix up with `LINEST`'s slope-then-intercept order, since the roles
  aren't quite equivalent: `m` here is a *multiplier* applied per
  period, not a linear per-unit change the way LINEST's slope is.
</Callout>

The result shows `{m, b}` together. With month 4 at its original
133.10 (exactly 10% above month 3), LOGEST returns `m = 1.1` — the
10% growth factor — and `b = 90.91`, the curve's value at month `0`.
Pushing month 4 higher or lower shifts the fitted growth rate itself,
since it's no longer a perfectly clean 10% every period.

## Common errors

### #NUM! — known_ys contains a zero or negative value

LOGEST takes the logarithm of `known_ys` internally, same as
`GROWTH` — a zero or negative value has no logarithm, breaking the
calculation.

### Confusing m with a per-unit linear change

<ExcelCode>{`m = 1.1 means "multiply by 1.1 each period," not "add 1.1 each period"`}</ExcelCode>

LOGEST's `m` is multiplicative, unlike LINEST's slope which is
additive — treating them the same way in a downstream formula
produces a badly wrong projection.

### Expecting a single cell instead of a spilled array

LOGEST always returns a 2-cell array (or a 5-row table with `stats =
TRUE`), even in its simplest form — make sure there's clear room for
it to spill into.
