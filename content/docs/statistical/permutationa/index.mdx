Count how many ordered arrangements are possible when items **can be
chosen more than once** — `PERMUT`'s counterpart for situations like
PIN codes or dice rolls, where repetition is allowed.

## Return value

The number of ordered arrangements of `number_chosen` items drawn
from a group of `number`, allowing repeats — mathematically,
`number ^ number_chosen`.

## Description

PERMUTATIONA answers "how many different 4-digit PIN codes are
possible?" style questions — situations where order matters *and*
the same item can be picked again (each digit 0-9 can repeat across
all 4 positions). `PERMUT` assumes each item can only be used once;
PERMUTATIONA drops that restriction entirely, which is why its
formula is a simple power (`numberⁿ`) rather than a ratio of
factorials.

<Callout type="idea">
  PERMUTATIONA's formula is exactly `number ^ number_chosen` — the
  same calculation `POWER(number, number_chosen)` performs directly.
  It's really just a domain-specific name for exponentiation, framed
  around counting repeated-choice arrangements.
</Callout>

A 4-digit PIN code drawn from 10 possible digits (0-9), with repeats
allowed at every position, would be `PERMUTATIONA(10, 4) = 10,000` —
every possible 4-digit combination from 0000 to 9999.

## Common errors

### #NUM! — number or number_chosen is negative

<ExcelCode>{`PERMUTATIONA(-5, 2) → #NUM!`}</ExcelCode>

Both arguments must be zero or positive — a negative group size or
selection count isn't valid.

### Confusing PERMUTATIONA with PERMUT

<ExcelCode>{`PERMUTATIONA(5, 2) → 25, not the same as PERMUT(5, 2) → 20`}</ExcelCode>

PERMUTATIONA allows repeats; PERMUT doesn't. Use PERMUT if each item
can only be selected once (like awarding 1st/2nd/3rd place to
different people).
