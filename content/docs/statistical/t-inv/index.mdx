Find the t-value that corresponds to a given left-tailed probability
— the reverse of `T.DIST`, most often used to find a critical value
for a one-tailed test or a confidence interval.

## Return value

The t-value `x` such that `T.DIST(x, deg_freedom, TRUE)` equals
`probability` — the point with exactly that much area under the
t-distribution curve to its left.

## Description

T.INV is most commonly used to find a **critical value** — the
cutoff a t-statistic needs to clear for a result to count as
significant at a chosen confidence level. Because it's left-tailed,
`probability = 0.95` finds the value with 95% of the distribution to
its left, which is the standard one-tailed 95% critical value; for a
two-tailed 95% confidence level (splitting 5% between both tails),
use `T.INV(0.975, df)` or, more directly, `T.INV.2T(0.05, df)`.

<Callout type="idea">
  T.INV and `T.DIST` are exact inverses of each other:
  `T.INV(T.DIST(x, df, TRUE), df)` returns `x` back, for any valid `x`
  and `df`. This makes T.INV useful for building a confidence interval
  by hand — pairing it with a sample mean and standard error, the same
  role `CONFIDENCE.T` plays in one step.
</Callout>

With 12 degrees of freedom (the same sample-of-13 scenario used
across this round's other pages), `T.INV(0.95, 12)` returns 1.7823 —
a t-statistic would need to clear that value to have only a 5% chance
of occurring by chance in a one-tailed test. Moving to a stricter 99%
threshold requires a noticeably larger t-value: 2.6810.

## Common errors

### #NUM! — probability is not strictly between 0 and 1

<ExcelCode>{`T.INV(1, 12) → #NUM!`}</ExcelCode>

`probability` must be greater than 0 and less than 1 — the exact
boundaries are undefined for an unbounded distribution.

### Using T.INV where T.INV.2T is actually needed

<ExcelCode>{`T.INV(0.95, 12) → 1.7823, not the same as T.INV.2T(0.05, 12) → 2.1788`}</ExcelCode>

T.INV(0.95, df) finds the one-tailed 95% critical value. A two-tailed
95% confidence level needs `T.INV(0.975, df)` or `T.INV.2T(0.05, df)`
— using plain `T.INV(0.95, df)` for a two-tailed interval understates
how wide it should be.
