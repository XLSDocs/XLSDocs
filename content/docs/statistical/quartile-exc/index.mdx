Find the 25th, 50th, or 75th percentile of a dataset using the
**exclusive** method — stricter than `QUARTILE.INC`, and unable to
return the dataset's own minimum or maximum at all.

## Return value

The value at the requested quartile of `array`, using the exclusive
method — always strictly between the dataset's minimum and maximum.

## Description

QUARTILE.EXC treats `array` as a sample drawn from a larger
population, and deliberately excludes the endpoints from its
calculation — unlike `QUARTILE.INC`, it has no `quart = 0` or `quart
= 4` option at all, since those would require extrapolating exactly
to the sample's own min/max rather than estimating a population
quartile.

<Callout type="warn">
  QUARTILE.EXC only accepts `quart` values of `1`, `2`, or `3` — there
  is no exclusive-method equivalent of "quartile 0" or "quartile 4".
  Passing `0` or `4` (both valid for `QUARTILE.INC`) returns `#NUM!`
  here.
</Callout>

## Common errors

### #NUM! — quart is 0 or 4

<ExcelCode>{`QUARTILE.EXC({10,20,30,40}, 0) → #NUM!`}</ExcelCode>

QUARTILE.EXC only accepts `1`, `2`, or `3`. Use `QUARTILE.INC` if the
dataset's actual minimum or maximum is what's needed.

### #NUM! — array is too small for the requested quartile

A very small `array` can push the exclusive method's calculation
outside the valid range even for `quart` values of 1-3 — the
exclusive method needs slightly more data to work with than the
inclusive method does.
