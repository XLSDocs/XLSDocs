Predict values along a linear trend fitted through historical data —
like `FORECAST`, but able to return predictions for **several** new
x values in a single spilled array instead of one at a time.

## Return value

The predicted `y` value(s) at `new_xs`, based on the best-fit
straight line through `known_xs` and `known_ys` — one result per
value in `new_xs`, spilled automatically if more than one is given.

## Description

TREND uses the exact same linear regression as `FORECAST` — the same
best-fit line through `known_xs`/`known_ys` — but its `new_xs`
argument accepts a whole array, returning every prediction in one
formula instead of needing a separate `FORECAST` call per value.

<Callout type="idea">
  `TREND(known_ys, known_xs, x)` and `FORECAST(x, known_ys,
  known_xs)` return exactly the same value for one x — TREND is the
  better choice specifically when several x values need predicting at
  once, since it spills all of them from a single formula.
</Callout>

## Common errors

### #N/A — known_ys and known_xs are different sizes

<ExcelCode>{`TREND({10,20,30}, {1,2,3,4}) → #N/A`}</ExcelCode>

Every value in `known_ys` needs a matching value in `known_xs` at the
same position — both ranges must contain the same number of data
points.

### #SPILL! — blocked spill range

<ExcelCode>{`TREND(B2:B6, A2:A6, {6,7,8}) → #SPILL! if the cells to the right are occupied`}</ExcelCode>

When `new_xs` has more than one value, TREND spills its results —
clear the cells in the spill direction, or move the formula
somewhere with room.

### Expecting TREND to fit a curve, not a straight line

TREND only fits a **linear** trend. If the real relationship curves
(exponential growth, for instance), `GROWTH` is the equivalent
function built for that shape instead.

## Related functions

- [FORECAST](/docs/statistical/forecast) — the single-value version
  of this same linear regression.
- [GROWTH](/docs/statistical/growth) — the equivalent function for an
  exponential (curved) trend instead of a straight line.
- [LINEST](/docs/statistical/linest) — returns the trend line's own
  slope and intercept directly, instead of a predicted value.
