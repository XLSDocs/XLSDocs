Calculate the slope of the straight line that best fits a set of x/y
data points — how much `y` changes for every one-unit increase in
`x`, the same trend line FORECAST uses to make predictions.

## Return value

The slope of the best-fit straight line through the data — the change
in `y` per one-unit change in `x`.

## Description

SLOPE finds the straight line that minimizes the total squared
distance from every point to the line (ordinary least squares
regression), then reports that line's steepness. A slope of `10` means
`y` increases by 10 for every 1-unit increase in `x`; a slope of `0`
means there's no linear relationship at all between the two.

<Callout type="warn">
  The argument order is `known_ys` first, `known_xs` second — the
  opposite of how the pair usually gets written when plotting a chart
  (x, then y). Swapping them by habit is one of the most common
  mistakes with this function; it won't error, it'll just silently
  compute the reciprocal relationship instead.
</Callout>

## Common errors

### #N/A — known_ys and known_xs are different sizes

<ExcelCode>{`SLOPE({10,20,30}, {1,2,3,4}) → #N/A`}</ExcelCode>

Every value in `known_ys` needs a matching value in `known_xs` at the
same position — both ranges must contain the same count of points.

### #DIV/0! — every known_x value is identical

<ExcelCode>{`SLOPE({10,20,30}, {1,1,1}) → #DIV/0!`}</ExcelCode>

A line needs variation along the x-axis to have a defined slope. If
every `known_xs` value is the same, SLOPE can't fit a line through
them.
