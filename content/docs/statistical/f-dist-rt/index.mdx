## Return value

The probability that an F-distributed random variable with
`deg_freedom1` and `deg_freedom2` degrees of freedom is greater than
or equal to `x` — the area under the curve to the right of `x`.

## Description

F.DIST.RT is the mirror image of `F.DIST`'s cumulative result:
`F.DIST.RT(x, df1, df2)` always equals
`1 - F.DIST(x, df1, df2, TRUE)`. It's the standard shape for a
one-tailed variance-ratio question — the underlying calculation
behind an ANOVA F-test's p-value, where a large ratio of between-group
to within-group variance is the evidence a real effect exists.

<Callout type="idea">
  `F.TEST`'s own two-tailed result is built from this same right
  tail: `F.TEST(array1, array2)` equals `2 * MIN(F.DIST.RT(F, df1,
  df2), 1 - F.DIST.RT(F, df1, df2))`, where `F` is the ratio of the
  two arrays' sample variances.
</Callout>

on the identical input.

## Common errors

### #NUM! — x is negative, or either deg_freedom is less than 1

<ExcelCode>{`F.DIST.RT(-1, 3, 10) → #NUM!`}</ExcelCode>

`x` must be non-negative, and both degrees-of-freedom arguments must
be at least 1.

### Forgetting F.DIST.RT's result depends on argument order

<ExcelCode>{`F.DIST.RT(1, 3, 10) → 0.4323, not the same as F.DIST.RT(1, 10, 3) → 0.5677`}</ExcelCode>

Swapping `deg_freedom1` and `deg_freedom2` changes the answer here,
unlike F.TEST's own two-tailed result — match the order to whichever
sample's variance was actually used as the numerator when the
F-statistic was computed.
