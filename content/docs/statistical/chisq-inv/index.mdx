Find the chi-square value that corresponds to a given left-tailed
probability — the reverse of `CHISQ.DIST`, most often used to look up
a critical value for a goodness-of-fit or independence test.

## Return value

The chi-square value `x` such that `CHISQ.DIST(x, deg_freedom, TRUE)`
equals `probability` — the point with exactly that much area under
the chi-square curve to its left.

## Description

CHISQ.INV finds a **left-tailed** critical value. Because a
goodness-of-fit test like `CHISQ.TEST` conventionally works off the
right tail (a large statistic is evidence of a real difference),
looking up the standard "95% confidence" critical value from a
chi-square table actually means passing `0.95` here — the value with
95% of the area to its left is the same value that has only 5% of the
area to its right, which is the usual significance threshold.

<Callout type="idea">
  CHISQ.INV and `CHISQ.DIST` are exact inverses:
  `CHISQ.INV(CHISQ.DIST(x, df, TRUE), df)` returns `x` back, for any
  valid `x` and `df`. And `CHISQ.INV(p, df)` always equals
  `CHISQ.INV.RT(1 - p, df)` — the same critical value, looked up from
  either tail's convention.
</Callout>

## Common errors

### #NUM! — probability is not strictly between 0 and 1

<ExcelCode>{`CHISQ.INV(1, 4) → #NUM!`}</ExcelCode>

`probability` must be greater than 0 and less than 1.

### Passing CHISQ.TEST's own p-value directly

<ExcelCode>{`CHISQ.INV(0.05, 4) → 0.7107, not the 9.4877 critical value a CHISQ.TEST p-value of 0.05 corresponds to`}</ExcelCode>

CHISQ.INV is left-tailed, but a chi-square p-value from CHISQ.TEST is
right-tailed. To find the critical value matching a 0.05 significance
threshold, pass `0.95` to CHISQ.INV (or `0.05` directly to
`CHISQ.INV.RT`) — not the p-value itself.
