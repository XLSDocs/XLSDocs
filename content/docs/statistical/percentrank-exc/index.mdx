Find where a value ranks within a dataset, expressed as a percentage
— the **exclusive** method, which never returns exactly `0` or `1`
even for the dataset's own minimum or maximum.

## Return value

The rank of `x` within `array`, as a fraction strictly between `0`
and `1` — using the exclusive method.

## Description

PERCENTRANK.EXC shares `PERCENTRANK.INC`'s basic idea, but treats
`array` as a sample of a larger population rather than the complete
set — dividing by `n + 1` instead of `n − 1`. The practical
consequence: even the dataset's own smallest value gets a rank
slightly above `0`, and the largest gets a rank slightly below `1`,
since the exclusive method assumes there's always more extreme data
somewhere outside the observed sample.

<Callout type="warn">
  PERCENTRANK.EXC can't evaluate `x` at exactly the dataset's minimum
  or maximum the same way `PERCENTRANK.INC` can — it still returns a
  value for them (close to, but never exactly, `0` or `1`), but `x`
  values *outside* the observed min/max still return `#N/A`, same as
  the inclusive version.
</Callout>

## Common errors

### #N/A — x falls outside the range of array

<ExcelCode>{`PERCENTRANK.EXC({10,30,50,70}, 100) → #N/A`}</ExcelCode>

Same restriction as `PERCENTRANK.INC` — `x` must fall within the
observed minimum and maximum of `array`.

### Expecting the minimum or maximum to return exactly 0 or 1

<ExcelCode>{`PERCENTRANK.EXC({10,30,50,70}, 10) → 0.2, not 0`}</ExcelCode>

This is expected exclusive-method behavior, not an error — use
`PERCENTRANK.INC` if the dataset's own min/max should map to exactly
`0`/`1`.
