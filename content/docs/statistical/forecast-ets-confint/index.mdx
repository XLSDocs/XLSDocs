Return the width of the confidence interval around a `FORECAST.ETS`
forecast — how much uncertainty surrounds that single predicted
number, based on how well the underlying model actually explains its
own historical data.

## Return value

The margin of error around the `FORECAST.ETS` forecast at
`target_date` — the true interval is
`FORECAST.ETS(target_date, ...) ± FORECAST.ETS.CONFINT(target_date, ...)`.

## Description

FORECAST.ETS.CONFINT estimates the margin of error from how well the
fitted exponential smoothing model explains the historical data it
was trained on: a model with small, consistent historical errors
(the same idea `FORECAST.ETS.STAT`'s RMSE and MAE measure directly)
produces a tighter interval, while a model wrestling with noisy or
poorly-fitting history produces a wider one. The interval also widens
the further `target_date` sits beyond the end of the known history —
forecasting 12 months out is inherently less certain than forecasting
1 month out from the same data.

<Callout type="warn">
  This page's example reuses `FORECAST.ETS`'s deliberately
  **noise-free** historical data — every point lands exactly on the
  underlying trend-plus-season pattern, so the fitted model's
  historical error is genuinely zero. That's exactly why the margin
  below comes out to 0.0000 at every confidence level: with a perfect
  historical fit, there's no estimated forecast variance for any
  confidence multiplier to scale up, regardless of exactly how
  Excel's internal formula computes it. Real-world data always has
  some noise, so a genuine forecast in practice will show a real,
  non-zero margin — this example is chosen specifically to make the
  *zero-margin edge case* provably correct, not to represent a
  typical result.
</Callout>

Every confidence level from 80% to 99% returns a margin of exactly
0.0000 on this dataset — not because higher confidence stops
mattering, but because there's zero historical forecast error for
any confidence multiplier to act on. On real, noisy data, raising the
confidence level would widen the margin at every level, the same way
`CONFIDENCE.NORM` and `CONFIDENCE.T` widen with a higher requested
confidence elsewhere on this site.

## Common errors

### #NUM! — confidence_level is outside the 0–1 range

<ExcelCode>{`FORECAST.ETS.CONFINT(target, values, timeline, 1.5) → #NUM!`}</ExcelCode>

`confidence_level` must be strictly between 0 and 1.

### Treating the result as the forecast itself, not a margin

<ExcelCode>{`FORECAST.ETS.CONFINT(target, values, timeline) → a margin, not the forecast — add it to FORECAST.ETS's own result to get the interval's upper bound`}</ExcelCode>

FORECAST.ETS.CONFINT never returns a forecasted value on its own —
it always needs to be combined with a separate `FORECAST.ETS` call at
the same `target_date` to build the actual interval.


  <CodeBlockTab value="Python">
    ```python lineNumbers
    from statsmodels.tsa.holtwinters import ExponentialSmoothing
    from scipy.stats import norm
    import numpy as np

    sales = [100, 125, 100, 105, 120, 145, 120, 125]
    model = ExponentialSmoothing(sales, trend="add", seasonal="add", seasonal_periods=4).fit()
    residual_std = np.std(model.resid, ddof=1)
    margin = norm.ppf(0.975) * residual_std  # 95% confidence
    ```
  </CodeBlockTab>
