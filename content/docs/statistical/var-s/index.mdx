Estimate variance from a sample of data — the modern, explicitly-named
version of `VAR`, introduced so the function name itself makes clear
it's the sample (not population) calculation.

## Return value

The sample variance of the supplied numbers — the average of the
squared differences from the mean, adjusted for sample size. Text and
blank cells within a range are ignored.

## Description

VAR.S computes exactly the same result as the older `VAR` — the `.S`
suffix was added in Excel 2010 as part of the same naming pass that
introduced STDEV.S and STDEV.P, making the sample-vs-population
assumption explicit in the function name rather than implicit. Like
VAR, it's mostly useful as an intermediate calculation or as an input
to formulas that specifically call for variance; STDEV.S is usually
the more directly interpretable number for reporting.

<Callout type="idea">
  VAR.S and VAR always return the same number on the same data. Use
  VAR.S in new formulas for the self-documenting name; existing
  formulas using plain VAR don't need to be changed.
</Callout>

## Common errors

### #DIV/0! — fewer than two numeric values

<ExcelCode>{`VAR.S(5) → #DIV/0!`}</ExcelCode>

Sample variance is undefined with only one value — at least two
numbers are required.

### Using VAR.S on a full population

<ExcelCode>{`VAR.S(range) → slightly overstates spread if range is the entire population`}</ExcelCode>

Not an error, but a common mismatch — VAR.S divides by `n-1`,
assuming the data is a sample. Use `VAR.P` when every relevant data
point is already included.
