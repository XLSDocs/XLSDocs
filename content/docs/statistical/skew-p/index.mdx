Measure how asymmetric a dataset's distribution is around its mean —
`SKEW`'s counterpart when the data being measured **is** the entire
population, not a sample representing a larger one.

## Return value

A skewness value: `0` for a perfectly symmetric distribution,
positive for a right-skewed one, negative for a left-skewed one —
computed treating the given values as the complete population.

## Description

SKEW.P shares SKEW's basic idea — quantifying how lopsided a
distribution is around its mean — but uses the population form of
the underlying standard deviation rather than the sample form,
producing a slightly different (generally smaller in magnitude)
result on the same data.

<Callout type="idea">
  Use SKEW.P only when the dataset genuinely **is** the entire
  population being described, with nothing left out — for instance,
  every student's score in one specific, complete class. If the data
  is a sample meant to represent a larger, only partially-observed
  population (the far more common situation), `SKEW` is the correct
  choice instead.
</Callout>

The same dataset SKEW's example uses. With the last value at `9`,

the identical data, since the two functions divide by different
standard-deviation forms.

## Common errors

### Confusing SKEW.P's result with SKEW's

<ExcelCode>{`SKEW.P({2,4,4,4,5,5,7,9}) → 0.6563, vs. SKEW of the same data → 0.8185`}</ExcelCode>

These aren't meant to match — SKEW.P uses the population standard
deviation internally, SKEW uses the sample standard deviation, so
they diverge on the same data (more noticeably with a smaller
dataset).

### Using SKEW.P on data that's actually a sample

If the values only represent part of a larger population being
studied, `SKEW` (not SKEW.P) is the statistically appropriate choice
— SKEW.P assumes there's nothing left unobserved.
