## Return value

The value of the gamma function at `x`.

## Description

The gamma function is the standard way to extend the factorial to
values that aren't positive integers — including fractions and
(with the exception of zero and negative integers, where it's
undefined) negative numbers. For any positive integer `n`,
`GAMMA(n)` equals `(n − 1)!`, so `GAMMA(5)` returns 24, matching
`FACT(4)`. Every continuous probability distribution in this
section's gamma family (`GAMMA.DIST`, `BETA.DIST`, `CHISQ.DIST`,
`F.DIST`) is built on this same function internally, evaluated at the
distribution's shape parameters.

<Callout type="warn">
  GAMMA grows explosively fast — `GAMMA(171)` already exceeds Excel's
  numeric range and returns `#NUM!`, the same overflow point as
  `FACT(171)`. Use `GAMMALN` (its logarithm) instead whenever the
  input might be large.
</Callout>

`GAMMA(5)` returns 24, matching `4!` (since `GAMMA(n) = (n-1)!` for
whole numbers). `GAMMA(0.5)` returns approximately 1.7725 — exactly
the square root of π, one of the gamma function's most famous
special values, showing the function genuinely extends to
non-integers rather than just interpolating between them.

## Common errors

### #NUM! — x is zero or a negative integer

<ExcelCode>{`GAMMA(0) → #NUM!`}</ExcelCode>

The gamma function has poles (is undefined) at zero and every
negative integer.

### #NUM! from a large positive x

<ExcelCode>{`GAMMA(171) → #NUM!`}</ExcelCode>

The gamma function grows so quickly that it overflows Excel's
numeric range past `x = 170` — the same practical ceiling `FACT`
hits. Use `GAMMALN` if a large `x` needs to be evaluated.
