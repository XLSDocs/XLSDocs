Find the t-value that corresponds to a given two-tailed probability —
the reverse of `T.DIST.2T`, and the most direct way to look up a
critical value for a two-sided confidence interval or hypothesis
test.

## Return value

The positive t-value `x` such that `T.DIST.2T(x, deg_freedom)` equals
`probability` — the critical value a t-statistic's absolute value
needs to reach or exceed for the result to be significant at that
level.

## Description

T.INV.2T is Excel's most direct route to the number printed in a
t-table: pass it a significance level like `0.05` and it returns the
critical value directly, without needing to convert to a one-tailed
equivalent first the way plain `T.INV` requires
(`T.INV(1 - 0.05/2, df)`). This is also the exact value
`CONFIDENCE.T` multiplies by the standard error internally to build a
margin of error.

<Callout type="idea">
  `T.INV.2T(probability, df)` and `T.INV(1 - probability/2, df)`
  always return the same result — T.INV.2T just saves the `1 -
  probability/2` step, and its output is guaranteed non-negative since
  it represents a distance from zero rather than a signed position on
  the curve.
</Callout>

## Try it

<TryIt

  defaultValue="0.05"
  label={'Live preview — =T.INV.2T({probability}, 12)'}
  fieldLabel="probability"
/>

With 12 degrees of freedom (the same sample-of-13 scenario used
across this round's other pages), a two-tailed 95% confidence level
(`probability = 0.05`) needs a t-statistic of at least 2.1788 in
either direction to be significant — noticeably larger than
`T.INV(0.95, 12)`'s 1.7823, since a two-tailed test spreads the same
5% risk across both ends of the curve instead of concentrating it on
one side.

## Common errors

### #NUM! — probability is not strictly between 0 and 1

<ExcelCode>{`T.INV.2T(0, 12) → #NUM!`}</ExcelCode>

`probability` must be greater than 0 and less than 1.

### Passing a one-tailed alpha instead of the total two-tailed probability

<ExcelCode>{`T.INV.2T(0.05, 12) → 2.1788, the two-tailed critical value for a 5% total risk`}</ExcelCode>

`probability` here is the combined risk across both tails, not the
risk in one tail alone — for a 95% two-tailed confidence level, pass
`0.05` directly (not `0.025`); T.INV.2T already splits it in half
internally.
