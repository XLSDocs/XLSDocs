Test whether two samples likely come from populations with the same
variance — the standard way to check whether it's reasonable to
assume equal spread before running a two-sample T.TEST.

## Return value

A two-tailed probability between 0 and 1 — the likelihood of seeing a
ratio of variances at least this extreme by chance alone, if the two
populations actually share the same variance. Smaller values are
stronger evidence the variances genuinely differ.

## Description

F.TEST divides `array1`'s sample variance by `array2`'s to get an
F-statistic, then evaluates it against the F-distribution with
`(n1 − 1, n2 − 1)` degrees of freedom. Because the result is always
two-tailed and F.TEST always reports "how extreme is this ratio,"
swapping `array1` and `array2` inverts the F-statistic but returns the
exact same probability.

<Callout type="idea">
  F.TEST is most often used as a **pre-check before T.TEST** — its
  result helps decide whether `T.TEST`'s `type` argument should be 2
  (equal variance assumed) or 3 (Welch's unequal-variance version). A
  small F.TEST result argues for type 3.
</Callout>

The same "typical spread" group of 5 values (variance 74.5), compared
against three differently-spread groups. Against a similarly-spread
group (variance 56), F.TEST returns 0.7888 — no evidence of a real
difference. Against a much more widely-spread group (variance 1632.5)
or a much tighter one (variance 2.5), it returns 0.0111 and 0.0062 —
both below the common 0.05 threshold, correctly flagging that the
variances really do differ, regardless of which direction.

## Common errors

### #DIV/0! — array2's variance is zero

<ExcelCode>{`F.TEST(A2:A6, B2:B6) → #DIV/0! when every value in B2:B6 is identical`}</ExcelCode>

A variance of zero can't appear in the denominator of the F-statistic
— `array2` needs at least some spread in its values.

### #N/A — fewer than 2 numeric values in either array

<ExcelCode>{`F.TEST(A1, B2:B6) → #N/A`}</ExcelCode>

Sample variance is undefined with fewer than 2 numbers — both arrays
need at least 2 numeric values each.
