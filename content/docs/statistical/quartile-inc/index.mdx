Find the minimum, 25th percentile, median, 75th percentile, or maximum
of a dataset with a single whole-number argument — the modern,
explicitly-named version of `QUARTILE`, and a shortcut for the four
most commonly used percentile cutoffs.

## Return value

The value at the requested quartile of `array`, using the inclusive
method.

## Description

QUARTILE.INC computes exactly the same result as the older
`QUARTILE` — the `.INC` suffix was added in Excel 2010 alongside
`QUARTILE.EXC`, which uses a stricter method that excludes the
dataset's endpoints. QUARTILE.INC is equivalent to calling
`PERCENTILE.INC(array, quart/4)`, just with a more convenient
whole-number argument for the four cutoffs people ask for most often.

<Callout type="idea">
  `QUARTILE.INC(array, 2)` and `MEDIAN(array)` always return the same
  value — the second quartile *is* the median by definition.
</Callout>

## Common errors

### #NUM! — quart is outside the 0–4 range

<ExcelCode>{`QUARTILE.INC({10,20,30,40}, 5) → #NUM!`}</ExcelCode>

`quart` must be a whole number from 0 to 4 — there's no fifth
quartile.

### #VALUE! — array contains no numeric values

<ExcelCode>{`QUARTILE.INC({"a","b","c"}, 2) → #VALUE!`}</ExcelCode>

QUARTILE.INC needs numbers to work with; text-only ranges have no
quartiles to calculate.
