Return the sum of squared deviations from the mean — the raw
building block that variance, standard deviation, and several other
statistics are all built from.

## Return value

The sum of `(each value − mean)²` across every number supplied.

## Description

DEVSQ computes the exact numerator that `VAR.P` divides by `n` (and
`VAR.S` divides by `n − 1`) to get variance — it's rarely used
directly in everyday work, but it's the shared foundation underneath
several other statistics, including regression's sum-of-squares
calculations.

<Callout type="idea">
  `DEVSQ(range) / COUNT(range)` always equals `VAR.P(range)` exactly
  — DEVSQ is simply variance before the final division step.
</Callout>

## Common errors

### Expecting DEVSQ to behave like a "normal" average-based measure

<ExcelCode>{`DEVSQ({2,4,4,4,5,5,7,14}) → 93.875, much larger than AVEDEV's 2.4375 on the same data`}</ExcelCode>

DEVSQ is a **sum**, not an average, and it's built from *squared*
distances — its scale isn't directly comparable to AVEDEV or the
original data's own units at all.

### Using DEVSQ directly as a measure of spread

DEVSQ grows with both the actual spread of the data and simply how
many values are included — more data points means a larger sum,
even without more spread. `VAR.P` (DEVSQ divided by count) is the
properly scaled version for comparing spread across differently-sized
datasets.

## Related functions

  — variance, computed by dividing DEVSQ by the count (or count minus 1).
- [AVEDEV](/docs/statistical/avedev) — a simpler, absolute-value-based
  measure of spread instead of a squared one.
