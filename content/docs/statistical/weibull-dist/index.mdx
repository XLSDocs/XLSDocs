Return a value from the Weibull distribution — the standard model in
reliability engineering for time until a component fails, with a
shape parameter flexible enough to represent early "infant mortality"
failures, random failures, or wear-out failures.

## Return value

With `cumulative` `TRUE`: the probability that a Weibull-distributed
random variable is less than or equal to `x`. With `cumulative`
`FALSE`: the density of that curve at `x`.

## Description

The Weibull distribution's shape parameter `alpha` directly describes
how failure risk changes over time — its single most useful property
in reliability analysis. `alpha < 1` models a decreasing failure
rate (early "infant mortality" defects that show up fast, then
taper off); `alpha = 1` models a constant failure rate (random
failures unrelated to age); `alpha > 1` models an increasing failure
rate (wear-out, where risk grows the longer a part has been in
service). `beta` sets the characteristic scale — roughly, the age by
which about 63% of units have failed.

<Callout type="idea">
  When `alpha = 1`, the Weibull distribution reduces exactly to the
  exponential distribution with rate `1/beta` —
  `WEIBULL.DIST(x, 1, beta, TRUE)` and `EXPON.DIST(x, 1/beta, TRUE)`
  return identical results.
</Callout>

A Weibull distribution with shape `alpha = 2` (an increasing,
wear-out-style failure rate) and scale `beta = 5`. At `x = 5` — the
scale parameter itself — the cumulative probability is always
0.6321, regardless of `alpha`, since `beta` is defined as the point
where the distribution reaches `1 − 1/e`.

## Common errors

### #NUM! — x is negative, or alpha/beta isn't positive

<ExcelCode>{`WEIBULL.DIST(-1, 2, 5, TRUE) → #NUM!`}</ExcelCode>

`x` must be non-negative, and both `alpha` and `beta` must be
strictly positive.

### Assuming alpha = 1 always models "typical" failure behavior

<ExcelCode>{`WEIBULL.DIST(x, 1, beta, TRUE) → assumes a constant failure rate, unrealistic for most mechanical wear-out`}</ExcelCode>

Most real mechanical components wear out over time (`alpha > 1`), not
fail at a constant random rate — fitting `alpha = 1` by default
without checking the actual failure pattern can badly misrepresent
reliability, especially at the tails.
