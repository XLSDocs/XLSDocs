Measure how two datasets vary together, treating the data as a
**sample** meant to estimate a larger population's covariance —
`COVARIANCE.P`'s counterpart for the far more common real-world case.

## Return value

The sample covariance between `array1` and `array2` — the sum of the
product of each pair's deviations from their own means, divided by
`n − 1`.

## Description

COVARIANCE.S shares COVARIANCE.P's basic idea — measuring how two
datasets move together — but divides by `n − 1` instead of `n`, the
same sample-vs-population adjustment `VAR.S` makes over `VAR.P`. This
is the statistically appropriate choice whenever the data being
analyzed is a sample representing a larger, only partially-observed
population, which is the more common situation in practice.

<Callout type="idea">
  `COVARIANCE.S` always comes out slightly **larger in magnitude**
  than `COVARIANCE.P` on the same data, since dividing by a smaller
  number (`n − 1` instead of `n`) produces a bigger result — the same
  relationship `VAR.S` has to `VAR.P`.
</Callout>

## Common errors

### #DIV/0! — fewer than 2 data points

<ExcelCode>{`COVARIANCE.S({5}, {10}) → #DIV/0!`}</ExcelCode>

COVARIANCE.S's formula divides by `n − 1`, which is zero with only 1
data point — at least 2 are required.

### Confusing COVARIANCE.S's result with COVARIANCE.P's

<ExcelCode>{`COVARIANCE.S({1,2,4},{5,10,25}) → 15.8333, vs. COVARIANCE.P of the same data → 10.5556`}</ExcelCode>

These aren't meant to match — the two functions divide by different
denominators, so they diverge on the same data (more noticeably with
smaller datasets).
