Find where a value ranks within a dataset, expressed as a percentage
from 0 to 1 — the modern, explicitly-named version of `PERCENTRANK`,
the reverse operation of `PERCENTILE.INC`.

## Return value

The rank of `x` within `array`, as a fraction from `0` (the minimum)
to `1` (the maximum), using the inclusive method.

## Description

PERCENTRANK.INC computes exactly the same result as the older
`PERCENTRANK` — the `.INC` suffix was added in Excel 2010 alongside
`PERCENTRANK.EXC`, which uses a stricter method that never returns
exactly 0 or 1. PERCENTRANK.INC is the reverse of `PERCENTILE.INC`:
if `PERCENTILE.INC(array, 0.75)` returns some value `v`, then
`PERCENTRANK.INC(array, v)` returns `0.75` back.

<Callout type="idea">
  If `x` isn't found exactly in `array`, PERCENTRANK.INC interpolates
  between the two nearest values rather than erroring — it always
  returns *a* rank, even for values that fall between existing data
  points.
</Callout>

## Common errors

### #N/A — x falls outside the range of array

<ExcelCode>{`PERCENTRANK.INC({10,30,50,70}, 100) → #N/A`}</ExcelCode>

`x` must fall between the minimum and maximum values in `array` —
PERCENTRANK.INC can't extrapolate a rank for a value outside the
observed range.

### #NUM! — significance is less than 1

<ExcelCode>{`PERCENTRANK.INC({10,30,50,70}, 40, 0) → #NUM!`}</ExcelCode>

`significance` controls how many digits the returned fraction is
rounded to, and needs to be at least 1.
