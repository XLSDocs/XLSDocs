Find the value at a given percentile within a set of numbers, using
a stricter statistical convention than `PERCENTILE.INC` — one that
excludes the dataset's own minimum and maximum from the valid range
of `k`.

## Return value

The value at the `k`th percentile of `array`, using the exclusive
method. Unlike `PERCENTILE.INC`, `k` can never actually reach `0` or
`1` — the valid range depends on how many values are in `array`, and
narrows as `array` gets smaller.

## Description

PERCENTILE.EXC uses a different statistical convention than the more
common `PERCENTILE.INC`: it treats the dataset as a *sample* drawn
from a larger population, and excludes the sample's own endpoints
from ever being returned as an exact percentile. That changes the
valid range for `k` — instead of the full `0` to `1`, it's restricted
to `1/(n+1)` through `n/(n+1)`, where `n` is the count of values.
With 9 values, for example, valid `k` runs from about `0.1` to `0.9`;
anything outside that returns `#NUM!`.

<Callout type="warn">
  PERCENTILE.EXC rejects `k` values that `PERCENTILE.INC` accepts
  without complaint — including `k=0` and `k=1`, which always work
  with the inclusive method. The valid range shrinks further with
  smaller datasets, so PERCENTILE.EXC is more likely to return
  `#NUM!` on small samples.
</Callout>

## Common errors

### #NUM! — k outside the valid exclusive range

<ExcelCode>{`PERCENTILE.EXC(A2:A10, 0.05) → #NUM! (with 9 values, valid k starts around 0.1)`}</ExcelCode>

Unlike PERCENTILE.INC, `k` can't reach all the way to `0` or `1` — the
usable range depends on the count of values in `array` and is always
narrower than the full 0–1 span.

### Assuming it matches PERCENTILE.INC

<ExcelCode>{`PERCENTILE.EXC(range, 0.9) ≠ PERCENTILE.INC(range, 0.9)`}</ExcelCode>

Not an error, but a common surprise — the two methods use different
formulas and generally return slightly different values at the same
`k`, even when both accept it.

## Related functions

  common, more forgiving method that accepts the full 0–1 range.
- [PERCENTILE](/docs/statistical/percentile) — the legacy function,
  which always matches PERCENTILE.INC, never PERCENTILE.EXC.
- [MEDIAN](/docs/math/median) — the 50th percentile under either
