Find the value that appears most often in a set of numbers — the
statistical "mode," a different kind of "typical value" than the
mean or median, useful whenever the most common outcome matters more
than the average one.

## Return value

The numeric value that appears most often across all arguments.
Returns `#N/A` if every value appears exactly once — with no repeat,
there's no mode.

## Description

MODE answers "what comes up most often," which can be a genuinely
different answer from AVERAGE or MEDIAN — the most common shoe size
sold, the most frequent order quantity, or the most common response
on a survey with numeric answer choices. MODE is the older name for
what's now formally [MODE.SNGL](/docs/statistical/mode-sngl); if the
data has more than one value tied for most frequent, MODE returns
only the first one encountered.

<Callout type="warn">
  MODE returns `#N/A`, not `0`, when no value repeats at all — every
  number in the set is unique. This is a common surprise for data
  that's mostly continuous (like exact prices or measurements) rather
  than naturally repeating (like categories or ratings).
</Callout>

## Common errors

### #N/A — no value repeats

<ExcelCode>{`MODE(1, 2, 3, 4, 5) → #N/A (every value is unique)`}</ExcelCode>

There's no mode when nothing repeats — this is expected behavior,
not a malformed formula.

### Assuming there's only one mode

<ExcelCode>{`MODE(1, 1, 2, 2, 3) → 1 (the first-encountered tie, not both)`}</ExcelCode>

When multiple values are tied for most frequent, MODE only returns
one of them — use [MODE.MULT](/docs/statistical/mode-mult) (an array
formula) to return every tied mode at once.

## Related functions

- [MODE.SNGL](/docs/statistical/mode-sngl) — the modern,
  explicitly-named version of this same calculation.
- [MODE.MULT](/docs/statistical/mode-mult) — returns every tied mode
  as a spilled array, instead of just the first.
- [MEDIAN](/docs/math/median) — the middle value instead of the most
  frequent one.
- [AVERAGE](/docs/math/average) — the arithmetic mean, a third
  distinct measure of "typical value."
- [COUNTIF](/docs/math/countif) — counts how many times a specific
  value occurs, useful for checking a mode's actual frequency.
