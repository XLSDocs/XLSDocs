Find the smallest number of successes at which the cumulative
binomial probability first reaches or exceeds a given threshold — the
reverse of `BINOM.DIST`'s cumulative mode.

## Return value

The smallest integer `number_s` such that `BINOM.DIST(number_s,
trials, probability_s, TRUE)` is greater than or equal to `alpha`.

## Description

Because the binomial distribution only takes whole-number outcomes,
its cumulative probability jumps in discrete steps rather than rising
smoothly — so BINOM.INV can't just invert a continuous curve the way
`NORM.INV` or `T.INV` do. Instead it walks up through 0, 1, 2, ...
successes, accumulating probability at each step, and stops at the
first value whose cumulative probability clears `alpha`.

<Callout type="warn">
  Because of that step pattern, BINOM.INV's result can look
  "over-satisfied" — the cumulative probability at the returned value
  is usually a little **above** `alpha`, not exactly equal to it,
  since no exact match may land precisely on the requested threshold.
</Callout>

The same 20-trial, 30%-success scenario used across this round's
binomial pages. `BINOM.INV(20, 0.3, 0.9)` returns 9 — the smallest
number of successes whose cumulative probability reaches at least
90%. Notice `alpha = 0.9` and `alpha = 0.95` both return 9: no exact
number of successes lands with cumulative probability between those
two thresholds, so both round up to the same answer.

## Common errors

### #NUM! — alpha is outside the 0–1 range

<ExcelCode>{`BINOM.INV(20, 0.3, 1.5) → #NUM!`}</ExcelCode>

`alpha` must be between 0 and 1.

### Expecting BINOM.INV(trials, p, BINOM.DIST(k, trials, p, TRUE)) to always return k

<ExcelCode>{`BINOM.INV(20, 0.3, BINOM.DIST(6, 20, 0.3, TRUE)) → 6 (matches), but nearby alpha values can round up to the same k`}</ExcelCode>

Because multiple `alpha` values can map to the same returned
`number_s` (the step-function behavior described above), BINOM.INV
and BINOM.DIST aren't smooth inverses of each other the way a
continuous distribution's pair would be — only feeding back an
`alpha` that exactly equals a real cumulative-probability value is
guaranteed to round-trip.
