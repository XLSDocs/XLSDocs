Calculate the y-intercept of the straight line that best fits a set of
x/y data points — the value the trend line predicts for `y` when `x`
is exactly zero, the other half of the same equation SLOPE describes.

## Return value

The y-intercept of the best-fit straight line through the data —
where that line crosses the y-axis.

## Description

Every straight line's equation is `y = slope × x + intercept`.
INTERCEPT calculates the second half of that pair — the same
underlying regression SLOPE calculates the first half of. On a chart,
it's literally the point where the fitted trend line crosses the
vertical axis, at `x = 0`.

<Callout type="idea">
  A meaningless-looking intercept (like a negative sales figure at
  "month zero") doesn't mean the calculation is wrong — it just means
  `x = 0` may fall well outside the range the data was ever actually
  measured over. The intercept describes where the *line* crosses zero,
  not a real, observed condition.
</Callout>

## Common errors

### #N/A — known_ys and known_xs are different sizes

<ExcelCode>{`INTERCEPT({10,20,30}, {1,2,3,4}) → #N/A`}</ExcelCode>

Every value in `known_ys` needs a matching value in `known_xs` at the
same position — both ranges must contain the same count of points.

### #DIV/0! — every known_x value is identical

<ExcelCode>{`INTERCEPT({10,20,30}, {1,1,1}) → #DIV/0!`}</ExcelCode>

A line needs variation along the x-axis to be defined at all. If every
`known_xs` value is the same, no single line — and therefore no single
intercept — can be fit through them.
