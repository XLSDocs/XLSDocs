Test whether two samples likely come from populations with the same
mean, using the Student's t-distribution — the standard hypothesis
test when the population standard deviation isn't known.

## Return value

A probability between 0 and 1 — the likelihood of seeing a difference
between the two samples' means at least this large by chance alone,
if their true population means are actually equal. Smaller values are
stronger evidence the means genuinely differ.

## Description

T.TEST computes a t-statistic from the two samples — how it's
calculated depends entirely on `type`: **paired** (1) looks at the
mean and spread of the differences between matched pairs (before/after
measurements on the same subjects); **equal variance** (2) pools both
samples' variances into one shared estimate, appropriate when the two
groups are reasonably assumed to have similar spread; **unequal
variance** (3), Welch's t-test, doesn't assume equal spread and adjusts
the degrees of freedom accordingly — the safer default when in doubt.
The t-statistic is then converted to a probability using the
t-distribution with the appropriate degrees of freedom, doubled if
`tails` is 2.

<Callout type="warn">
  Picking the wrong `type` on the same data can noticeably change the
  result. Paired only makes sense when each row in `array1` is
  genuinely matched to the same row in `array2` (the same subject,
  measured twice) — running the same two independent groups through
  `type = 1` treats unrelated numbers as if they were paired and
  produces a meaningless answer.
</Callout>

The same two groups of 5 values, tested three different ways with
`tails = 2`. Treated as paired (`type = 1`), the differences are noisy
relative to their spread and T.TEST returns 0.1916 — no significant
difference. Treated as two independent samples with equal variance
(`type = 2`), it returns 0.0761; with unequal variance assumed
(`type = 3`, Welch's test), a very similar 0.0781 — both closer to
(but still above) the common 0.05 significance threshold, since the
independent-samples framing better fits data that was never actually
paired.

## Common errors

### #N/A — array1 and array2 are different sizes with type = 1

<ExcelCode>{`T.TEST(A2:A6, B2:B4, 2, 1) → #N/A`}</ExcelCode>

A paired test requires each value in `array1` to correspond to one in
`array2` — the two ranges must contain the same number of values.

### #NUM! — tails is not 1 or 2

<ExcelCode>{`T.TEST(array1, array2, 3, 2) → #NUM!`}</ExcelCode>

`tails` only accepts 1 (one-tailed) or 2 (two-tailed); any other
value is invalid.
