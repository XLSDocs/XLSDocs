Find the harmonic mean of a set of positive numbers — the correct way
to average rates such as speeds, prices per unit, or anything
expressed as "amount per something," where a plain `AVERAGE`
overstates the true average.

## Return value

The harmonic mean — the reciprocal of the average of the reciprocals
of the supplied numbers.

## Description

The classic case for HARMEAN is averaging speeds over equal
*distances*. Driving 60 mph for the first half of a trip and 30 mph
for the second half doesn't average to 45 mph, because more *time* is
spent at the slower speed — `HARMEAN(60, 30)` correctly returns 40,
the true average speed for the whole trip.

<Callout type="warn">
  HARMEAN requires every value to be strictly positive, the same
  restriction as GEOMEAN. A single zero or negative number makes the
  whole result `#NUM!`.
</Callout>

<Callout type="idea">
  HARMEAN is the right tool specifically when the values are rates
  measured *per unit of something held constant* — equal distances for
  speed, equal dollar amounts for price-per-share. If the underlying
  quantity being averaged isn't a rate like this, AVERAGE or GEOMEAN is
  usually the better fit.
</Callout>

Two equal-distance legs of a trip, driven at 60 mph and a variable
speed. HARMEAN gives the single speed that would cover the same total
distance in the same total time — always closer to the slower speed
than a plain average would suggest.

## Common errors

### #NUM! — a value is zero or negative

<ExcelCode>{`HARMEAN(60, 0, 30) → #NUM!`}</ExcelCode>

Every argument must be greater than zero. A speed of `0` (a full stop)
can't be averaged this way — HARMEAN's reciprocal calculation would
require dividing by zero.

### #DIV/0! — no numeric values supplied

<ExcelCode>{`HARMEAN(A1:A5) → #DIV/0!`}</ExcelCode>

Happens when the range contains no numbers at all. HARMEAN ignores
blank cells and text within a range, but needs at least one numeric
value to compute a result.
