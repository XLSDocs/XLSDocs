Convert a raw value into a z-score — how many standard deviations it
sits above or below the mean. The standard way to compare values from
different scales on one common footing.

## Return value

The z-score: `(x − mean) / standard_dev`.

## Description

Standardizing puts values from different scales — test scores out of
100, a measurement in inches, a dollar amount — onto one shared,
comparable footing: "how many standard deviations away from typical."
A z-score of `2` always means the same thing (unusually high, two
standard deviations above average) regardless of what's actually
being measured, which plain raw values can't do across different
contexts.

<Callout type="idea">
  STANDARDIZE is the building block behind `NORM.S.DIST`: converting a
  value with `STANDARDIZE` and then feeding it into `NORM.S.DIST` gives
  the same result as calling `NORM.DIST` directly on the original
  value, mean, and standard deviation.
</Callout>

130 is 2 standard deviations above.

## Common errors

### #NUM! — standard_dev is zero or negative

<ExcelCode>{`STANDARDIZE(115, 100, 0) → #NUM!`}</ExcelCode>

`standard_dev` must be a positive number — dividing by a zero or
negative spread isn't meaningful.

### Misreading a negative z-score as an error

<ExcelCode>{`STANDARDIZE(85, 100, 15) → -1 (not an error — below-average is expected to be negative)`}</ExcelCode>

A negative result is completely normal — it just means `x` falls
below the mean, not that anything went wrong.
