Return the probability of a given number of failures occurring before
a fixed target number of successes is reached — the "how many misses
before N hits" counterpart to the binomial distribution's "how many
hits in N tries."

## Return value

With `cumulative` `TRUE`: the probability of `number_f` or fewer
failures occurring before the `number_s`-th success. With
`cumulative` `FALSE`: the probability of exactly `number_f` failures
before that success.

## Description

NEGBINOM.DIST flips the usual binomial question around: instead of
fixing the number of trials and asking how many succeed, it fixes the
**target number of successes** and asks how many failures happen
along the way before that target is reached. The special case
`number_s = 1` (stop at the first success) is the geometric
distribution — how many failures before the very first success.

<Callout type="idea">
  The final trial in any NEGBINOM.DIST scenario is always a success —
  by definition, the sequence stops the moment the `number_s`-th
  success occurs. This is the key structural difference from
  `BINOM.DIST`, where the total number of trials is fixed in advance
  and any of them could be the last.
</Callout>

## Common errors

### #NUM! — number_f or number_s is negative, or probability_s is out of range

<ExcelCode>{`NEGBINOM.DIST(-1, 3, 0.5, TRUE) → #NUM!`}</ExcelCode>

`number_f` and `number_s` must both be non-negative, and
`probability_s` must be between 0 and 1.

### Confusing number_f with total trials

<ExcelCode>{`NEGBINOM.DIST(2, 3, 0.5, TRUE) → counts 2 failures plus 3 successes, 5 trials total, not 2 trials`}</ExcelCode>

`number_f` is the failure count on its own — the actual number of
trials run is `number_f + number_s`, since every trial is either one
of the counted failures or one of the required successes.
