Find the F-value that corresponds to a given left-tailed probability
— the reverse of `F.DIST`, most often used to look up a critical
value for a variance-ratio test.

## Return value

The F-value `x` such that `F.DIST(x, deg_freedom1, deg_freedom2,
TRUE)` equals `probability` — the point with exactly that much area
under the F-distribution curve to its left.

## Description

F.INV finds a **left-tailed** critical value. Because a variance-ratio
test conventionally works off the right tail (a large F-statistic is
evidence the two variances genuinely differ), looking up the standard
"95% confidence" critical value from an F-table actually means
passing `0.95` here — the same critical value that `F.INV.RT` would
return by passing `0.05` directly.

<Callout type="idea">
  F.INV and `F.DIST` are exact inverses:
  `F.INV(F.DIST(x, df1, df2, TRUE), df1, df2)` returns `x` back, for
  any valid `x`, `df1`, and `df2`. And `F.INV(p, df1, df2)` always
  equals `F.INV.RT(1 - p, df1, df2)` — the same critical value, looked
  up from either tail's convention.
</Callout>

With 3 and 10 degrees of freedom (the same scenario used across this
round's other F pages), `F.INV(0.95, 3, 10)` returns 3.7083 — the
standard F critical value for a 95% confidence level with this pair
of degrees of freedom, matching standard F-tables.

## Common errors

### #NUM! — probability is not strictly between 0 and 1

<ExcelCode>{`F.INV(1, 3, 10) → #NUM!`}</ExcelCode>

`probability` must be greater than 0 and less than 1.

### Passing F.TEST's own p-value directly

<ExcelCode>{`F.INV(0.05, 3, 10) → 0.1138, not the 3.7083 critical value a 0.05 significance level corresponds to`}</ExcelCode>

F.INV is left-tailed, but a significance level like 0.05 is usually
meant as a right-tailed threshold. To find the critical value
matching a 0.05 significance level, pass `0.95` to F.INV (or `0.05`
directly to `F.INV.RT`) — not the significance level itself.
