Return the probability of a given number of successes when drawing a
fixed-size sample **without replacement** from a finite population —
the distribution `BINOM.DIST` would give the wrong answer for, since
each draw changes the odds for the next.

## Return value

With `cumulative` `TRUE`: the probability of `sample_s` or fewer
successes appearing in the sample. With `cumulative` `FALSE`: the
probability of exactly `sample_s` successes.

## Description

HYPGEOM.DIST is the right tool whenever a sample is drawn from a
finite population without putting items back — a hand of cards, a
batch of parts pulled for inspection, a raffle. Because each draw
permanently removes one item, the probability of success on the next
draw keeps shifting, which is exactly the assumption `BINOM.DIST`
requires to stay fixed.

<Callout type="idea">
  When `number_pop` is very large relative to `number_sample`,
  removing a few items barely moves the odds — HYPGEOM.DIST and
  BINOM.DIST (with `probability_s = population_s / number_pop`)
  converge to nearly the same answer in that case. The two
  distributions only diverge meaningfully when the sample is a
  sizeable fraction of the population.
</Callout>

## Common errors

### #NUM! — sample_s exceeds what's possible given the other arguments

<ExcelCode>{`HYPGEOM.DIST(6, 5, 6, 20, TRUE) → #NUM!, since a 5-item sample can't contain 6 successes`}</ExcelCode>

`sample_s` can't exceed `number_sample`, `population_s`, or what's
mathematically reachable given how many failures exist in the
population — Excel returns `#NUM!` for any combination that isn't
actually possible.

### Using HYPGEOM.DIST when sampling actually has replacement

<ExcelCode>{`HYPGEOM.DIST(2, 5, 6, 20, TRUE) → assumes each of the 20 items can only be drawn once`}</ExcelCode>

If items are put back before the next draw (sampling with
replacement), each draw's odds stay constant and `BINOM.DIST` is the
correct distribution instead.
