Find the F-value that corresponds to a given right-tailed probability
— the reverse of `F.DIST.RT`, and the most direct way to look up an
F critical value using the same convention most F-tables and ANOVA
results are built around.

## Return value

The F-value `x` such that `F.DIST.RT(x, deg_freedom1, deg_freedom2)`
equals `probability` — the critical value an F-statistic needs to
reach or exceed to be significant at that level.

## Description

F.INV.RT takes a significance level like `0.05` and returns the
critical value directly, using the same right-tailed convention most
printed F-tables (and Excel's own ANOVA output) are built around — no
need to convert to `1 - probability` first the way plain `F.INV`
requires.

<Callout type="idea">
  `F.INV.RT(probability, df1, df2)` and `F.INV(1 - probability, df1,
  df2)` always return the same result — F.INV.RT just saves the
  `1 - probability` step, and matches the direction most F-test
  critical-value tables are already printed in.
</Callout>

  defaultValue="0.05"

  fieldLabel="probability"

With 3 and 10 degrees of freedom (the same scenario used across this
round's other F pages), an F-statistic needs to reach at least
3.7083 to be significant at the 5% level — `F.INV.RT(0.05, 3, 10)`
returns exactly that value, identical to `F.INV(0.95, 3, 10)` on
`F.INV`'s own page.

## Common errors

### #NUM! — probability is not strictly between 0 and 1

<ExcelCode>{`F.INV.RT(0, 3, 10) → #NUM!`}</ExcelCode>

`probability` must be greater than 0 and less than 1.

### Forgetting deg_freedom order still matters here

<ExcelCode>{`F.INV.RT(0.05, 3, 10) → 3.7083, not the same as F.INV.RT(0.05, 10, 3) → 8.7855`}</ExcelCode>

Even though F.TEST's own two-tailed result doesn't care about
argument order, F.INV.RT's critical value does — make sure
`deg_freedom1` and `deg_freedom2` match whichever sample's variance
was actually the numerator when the underlying F-statistic was
computed.
