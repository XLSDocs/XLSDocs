Return the probability that the number of successes across a fixed
number of independent trials falls within a given range — without
subtracting two separate `BINOM.DIST` calls to get there.

## Return value

The probability that the number of successes falls between
`number_s1` and `number_s2`, inclusive — or, if `number_s2` is
omitted, the probability of exactly `number_s1` successes.

## Description

BINOM.DIST.RANGE saves the extra subtraction step a range question
would otherwise need with plain `BINOM.DIST`: instead of computing
`BINOM.DIST(number_s2, trials, probability_s, TRUE) −
BINOM.DIST(number_s1 − 1, trials, probability_s, TRUE)`, one call
does both cumulative lookups internally and returns the difference
directly.

<Callout type="idea">
  Notice the **argument order is different** from every other
  distribution function in this family: `trials` and `probability_s`
  come first here, with the success-count arguments last — the
  opposite of `BINOM.DIST`'s `number_s, trials, probability_s`
  ordering. Easy to transpose by habit when switching between the two.
</Callout>

## Common errors

### #NUM! — number_s1 is greater than number_s2

<ExcelCode>{`BINOM.DIST.RANGE(20, 0.3, 10, 4) → #NUM!`}</ExcelCode>

`number_s1` must be less than or equal to `number_s2` when both are
supplied.

### Mixing up the argument order with BINOM.DIST

<ExcelCode>{`BINOM.DIST.RANGE(0.3, 20, 4, 8) → #NUM!, since probability_s can't be 20`}</ExcelCode>

BINOM.DIST.RANGE puts `trials` before `probability_s`, the reverse
of `BINOM.DIST`'s `number_s, trials, probability_s` order — a common
copy-paste mistake between the two.
