Test whether a set of observed counts across categories differs
significantly from a set of expected counts — the standard
goodness-of-fit test for categorical data.

## Return value

A probability between 0 and 1 — the likelihood of seeing a deviation
between observed and expected counts at least this large by chance
alone, if the expected counts are actually correct. Smaller values
are stronger evidence the real distribution doesn't match what was
expected.

## Description

CHISQ.TEST computes a chi-square statistic by summing
`(actual − expected)² / expected` across every category, then
evaluates it against the chi-square distribution with
`(number of categories − 1)` degrees of freedom (one fewer degree of
freedom per row, if the data spans multiple rows and columns). A
result close to 0 means the observed counts diverge sharply from what
was expected; a result close to 1 means the observed counts line up
almost exactly with the expectation.

<Callout type="idea">
  Excel doesn't have a separate function to compute the raw chi-square
  statistic itself before converting it to a probability — CHISQ.TEST
  does both steps at once. To get the raw statistic on its own (for
  comparing against a critical-value table, for example), use
  `=SUMPRODUCT((actual_range - expected_range)^2 / expected_range)`.
</Callout>

## Common errors

### #N/A — actual_range and expected_range are different sizes

<ExcelCode>{`CHISQ.TEST(A2:A4, B2:B5) → #N/A`}</ExcelCode>

Every category in `actual_range` needs a matching expected value in
`expected_range` — the two ranges must be the same size and shape.

### #DIV/0! — an expected value is zero

<ExcelCode>{`CHISQ.TEST(A2:A4, B2:B4) → #DIV/0! when any value in B2:B4 is 0`}</ExcelCode>

Each term in the chi-square statistic divides by the expected count
for that category, so no expected value can be zero.
