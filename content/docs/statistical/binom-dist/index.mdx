Return the probability of a given number of successes across a fixed
number of independent trials, each with the same success probability
— either the exact chance of that many successes, or the cumulative
chance of that many **or fewer**.

## Return value

With `cumulative` `TRUE`: the probability of getting `number_s` **or
fewer** successes across `trials` independent attempts. With
`cumulative` `FALSE`: the probability of getting **exactly**
`number_s` successes.

## Description

BINOM.DIST models the classic "how many successes in N tries" question
— coin flips, defective parts in a batch, conversions out of a
fixed number of visitors — as long as every trial is truly
independent and shares the same success probability. The exact
(`cumulative = FALSE`) result comes from the binomial probability
formula: `C(trials, number_s) × probability_s^number_s ×
(1 − probability_s)^(trials − number_s)`, where `C(trials,
number_s)` is the number of ways to choose which trials succeed.

<Callout type="idea">
  Summing every exact probability from 0 successes up to `number_s`
  gives the same result as `BINOM.DIST(number_s, trials,
  probability_s, TRUE)` directly — cumulative mode just does that sum
  internally rather than requiring one call per outcome.
</Callout>

## Common errors

### #NUM! — number_s, trials, or probability_s is out of range

<ExcelCode>{`BINOM.DIST(25, 20, 0.3, TRUE) → #NUM!`}</ExcelCode>

`number_s` must be between 0 and `trials`, and `probability_s` must
be between 0 and 1.

### Forgetting BINOM.DIST assumes independence

<ExcelCode>{`BINOM.DIST(3, 10, 0.3, TRUE) → assumes each of the 10 trials is unaffected by the others`}</ExcelCode>

If drawing without replacement from a finite population (so each
draw changes the odds for the next), the binomial distribution
doesn't apply — use `HYPGEOM.DIST` instead.
