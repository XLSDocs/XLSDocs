## Return value

The correlation coefficient corresponding to `y`:
`(EXP(2y) − 1) / (EXP(2y) + 1)`, always a value strictly between -1
and 1.

## Description

FISHERINV undoes `FISHER`'s transformation, converting a value that
was manipulated using ordinary normal-distribution statistics (a
confidence interval endpoint, an average of several Fisher-
transformed correlations) back onto the familiar -1-to-1 correlation
scale. No matter how large or small `y` gets, FISHERINV's result
always stays strictly within `(-1, 1)` — it can never produce an
invalid correlation coefficient.

<Callout type="idea">
  FISHERINV is mathematically identical to the hyperbolic tangent
  function, `tanh(y)` — its output range of `(-1, 1)` is exactly
  `tanh`'s own asymptotic range, which is precisely why the Fisher
  transformation works as a bijection onto valid correlation values.
</Callout>

`FISHERINV(0)` returns exactly 0, and `FISHERINV(-0.5)` and
`FISHERINV(0.5)` are exact mirror images (-0.4621 and 0.4621).
`FISHERINV(1)` returns 0.7616 — notice how much the output compresses
toward 1 as the input grows, since the result can never actually
reach or exceed 1.

## Common errors

### Expecting FISHERINV(FISHER(x)) to introduce rounding error

<ExcelCode>{`FISHERINV(FISHER(0.5)) → 0.5, an exact round trip`}</ExcelCode>

FISHER and FISHERINV are exact mathematical inverses — round-tripping
a value through both functions returns the original number back
(subject only to Excel's normal floating-point precision), not a
meaningfully different approximation.

### Feeding a raw correlation coefficient into FISHERINV by mistake

<ExcelCode>{`FISHERINV(0.5) → 0.4621, not the identity function — 0.5 is treated as an already-transformed value`}</ExcelCode>

FISHERINV expects a Fisher-transformed value as input, not a
correlation coefficient directly — passing a raw correlation through
FISHERINV by mistake silently produces a different (and incorrect)
number rather than erroring.
