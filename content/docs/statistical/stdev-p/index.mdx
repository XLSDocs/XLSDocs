Measure how spread out a set of numbers is from their average, when
the data represents an **entire population** — every relevant value,
not a sample drawn from a larger group.

## Return value

The population standard deviation of the supplied numbers. Text and
blank cells within a range are ignored.

## Description

STDEV.P treats the supplied numbers as the **entire population**,
not a sample of something larger — every score on every test that
was given, every unit ever produced, not a subset standing in for a
bigger group. That assumption changes the formula: STDEV.P divides
by `n` (the actual count), while the sample version divides by `n-1`,
which is why STDEV.P always returns a value less than or equal to
STDEV.S on identical data. STDEV.P replaced the older `STDEVP`, which
still works for compatibility but isn't part of Excel's current
naming convention.

<Callout type="warn">
  Using STDEV.P when the data is actually a **sample** — not the
  whole population — understates the true spread. If there's any
  meaningful data outside what's in the range (customers who haven't
  ordered yet, future test-takers), use `STDEV.S` instead.
</Callout>

## Common errors

### Treating a sample as a population

<ExcelCode>{`STDEV.P(SurveyResponses) → understated spread if respondents are a sample, not everyone`}</ExcelCode>

Not an error, but a common source of subtly wrong statistics — most
real-world datasets (survey responses, a batch of test scores) are
samples of a larger group, which calls for `STDEV.S`, not STDEV.P.

### Empty range

<ExcelCode>{`STDEV.P(A1:A1) → #DIV/0! if the range has no numeric values`}</ExcelCode>

STDEV.P needs at least one numeric value to compute against; a fully
blank or text-only range returns an error.
