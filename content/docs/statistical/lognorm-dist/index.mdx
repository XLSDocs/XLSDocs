Return a value from the lognormal distribution — used for positive
quantities whose **logarithm** is normally distributed, like income,
stock prices, and city populations.

## Return value

With `cumulative` `TRUE`: the probability that a lognormally-
distributed random variable is less than or equal to `x`. With
`cumulative` `FALSE`: the density of that curve at `x`.

## Description

A quantity is lognormally distributed when its natural logarithm
follows a normal distribution — which is exactly how LOGNORM.DIST
computes its answer internally:
`LOGNORM.DIST(x, mean, standard_dev, TRUE)` equals
`NORM.S.DIST((LN(x) - mean) / standard_dev, TRUE)`. This pattern
shows up naturally whenever a quantity results from multiplying many
independent random factors together (compounding growth, cumulative
error) rather than adding them — the Central Limit Theorem's
multiplicative cousin.

<Callout type="warn">
  `mean` and `standard_dev` describe **LN(x)**, not `x` itself — a
  common mistake is plugging in the actual average and spread of the
  raw data. If the raw data's own mean and standard deviation are
  known, they need to be converted to the log scale first (or fitted
  from `LN` of the actual data) before use here.
</Callout>

A lognormal distribution with `mean = 0` and `standard_dev = 0.5` on
the log scale. Because `mean = 0`, `LN(1) = 0` sits exactly at the
center, so `LOGNORM.DIST(1, 0, 0.5, TRUE)` returns exactly 0.5000 —
the median of this distribution is 1, not 0.

## Common errors

### #NUM! — x or standard_dev is not positive

<ExcelCode>{`LOGNORM.DIST(-1, 0, 0.5, TRUE) → #NUM!`}</ExcelCode>

`x` must be greater than 0 (a lognormal variable can never be zero or
negative), and `standard_dev` must be positive.

### Plugging in x's own mean and standard deviation instead of LN(x)'s

<ExcelCode>{`LOGNORM.DIST(x, mean_of_x, sd_of_x, TRUE) → wrong, unless mean_of_x and sd_of_x were computed from LN(x), not x`}</ExcelCode>

`mean` and `standard_dev` must describe the logged values —
`=AVERAGE(LN(range))` and `=STDEV.S(LN(range))`, not
`AVERAGE(range)` and `STDEV.S(range)` directly.
