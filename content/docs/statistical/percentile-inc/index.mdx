Find the value at a given percentile within a set of numbers — the
modern, explicitly-named version of `PERCENTILE`, distinguished from
`PERCENTILE.EXC` by allowing `k` across the full inclusive 0–1 range.

## Return value

The value at the `k`th percentile of `array`, using the inclusive
method — `k` can be `0` (the minimum) or `1` (the maximum), as well
as anything in between.

## Description

PERCENTILE.INC computes exactly the same result as the older
`PERCENTILE` — the `.INC` suffix (for "inclusive") was added in
Excel 2010 alongside `PERCENTILE.EXC`, which uses a stricter method
that excludes the dataset's endpoints. PERCENTILE.INC is the more
commonly used and more intuitive of the two: `k=0` always returns the
minimum and `k=1` always returns the maximum, matching how most
people expect percentiles to work.

<Callout type="info">
  PERCENTILE.INC and PERCENTILE always return the same number on the
  same data. Reach for `PERCENTILE.EXC` only when a specific
  statistical convention calls for it — most everyday use cases are
  well served by the inclusive method.
</Callout>

## Common errors

### #NUM! — k outside the 0–1 range

<ExcelCode>{`PERCENTILE.INC(A2:A100, 90) → #NUM!`}</ExcelCode>

`k` needs to be a fraction, not a percentage number — use `0.9` for
the 90th percentile.

### Confusing percentile with percentage

<ExcelCode>{`PERCENTILE.INC(A2:A100, 0.9) → a value from the data, not "90% of something"`}</ExcelCode>

Not an error, but a common misunderstanding — the result is a value
from the dataset's own scale, not a percentage itself.
