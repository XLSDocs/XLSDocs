Calculate the margin of error for estimating a population mean from a
sample — added to and subtracted from the sample mean, it forms a
confidence interval, assuming a normal distribution.

## Return value

The margin of error — a single number. The full confidence interval
is the sample mean plus or minus this value.

## Description

CONFIDENCE.NORM computes exactly the same result as the older
`CONFIDENCE` — the `.NORM` suffix was added in Excel 2010 alongside
`CONFIDENCE.T`, which uses the Student's t-distribution instead of the
normal distribution (better suited to small samples or an unknown
population standard deviation). CONFIDENCE.NORM assumes the
population standard deviation is already known — in practice, that's
often an approximation using the sample's own standard deviation,
which is only reliable with a reasonably large sample size.

<Callout type="warn">
  CONFIDENCE.NORM needs the population standard deviation, not the
  sample standard deviation — if all you have is a sample, you're
  estimating that input too, which is exactly the situation
  CONFIDENCE.T is built to handle more accurately.
</Callout>

## Common errors

### #NUM! — alpha is outside the 0–1 range, or size is less than 1

<ExcelCode>{`CONFIDENCE.NORM(1.5, 5, 40) → #NUM!`}</ExcelCode>

`alpha` must be a value strictly between 0 and 1, and `size` must be
at least 1.

### #VALUE! — any argument is non-numeric

<ExcelCode>{`CONFIDENCE.NORM("high", 5, 40) → #VALUE!`}</ExcelCode>

All three arguments need to be numbers — a text significance level
like `"high"` can't be evaluated.
