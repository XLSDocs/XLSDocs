Find the geometric mean of a set of positive numbers — the correct
way to average rates of change, growth percentages, or anything that
compounds, where a plain `AVERAGE` gives a misleadingly high answer.

## Return value

The geometric mean — the *n*th root of the product of *n* numbers.

## Description

`AVERAGE` adds values and divides by the count. `GEOMEAN` multiplies
values and takes the *n*th root instead — the correct operation for
anything that compounds, like a series of yearly growth rates or
investment returns, where the effect of each period multiplies onto
the last rather than simply adding.

<Callout type="warn">
  GEOMEAN requires every value to be strictly positive. A single zero
  or negative number — including a growth rate expressed as a raw
  percentage like `-5` for a 5% decline instead of `0.95` as a
  multiplier — makes the whole result `#NUM!`.
</Callout>

## Common errors

### #NUM! — a value is zero or negative

<ExcelCode>{`GEOMEAN(1.05, -0.02, 1.08) → #NUM!`}</ExcelCode>

Every argument must be greater than zero. A negative growth rate needs
to be expressed as a multiplier below 1 (a 2% decline is `0.98`, not
`-0.02`) before GEOMEAN can use it.

### #DIV/0! — no numeric values supplied

<ExcelCode>{`GEOMEAN(A1:A5) → #DIV/0!`}</ExcelCode>

Happens when the range contains no numbers at all (all blank or
text). GEOMEAN ignores blank cells and text within a range, but needs
at least one numeric value to compute a result.
