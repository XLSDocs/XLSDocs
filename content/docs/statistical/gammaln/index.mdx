## Return value

The natural logarithm of the gamma function at `x`.

## Description

The gamma function extends the factorial to non-integer values — for
a positive integer `n`, `GAMMA(n)` equals `(n − 1)!`. GAMMALN returns
its natural log instead of the raw value, which matters in practice
because the gamma function itself grows explosively fast (it overflows
a standard floating-point number well before `x = 200`), while its
logarithm stays small and well-behaved. Every gamma-based distribution
function on this site (`GAMMA.DIST`, `BETA.DIST`, `CHISQ.DIST`,
`F.DIST`, and more) is actually computed internally using log-gamma
sums and differences rather than raw gamma values, for exactly this
reason.

<Callout type="idea">
  For a positive integer `n`, `GAMMALN(n + 1)` equals `LN(FACT(n))` —
  a way to compute the log of a huge factorial (say, 500!) without
  ever computing the astronomically large factorial itself, which
  `FACT` alone can't do — it overflows at `171!`.
</Callout>

## Try it

<TryIt

  defaultValue="5"
  label={'Live preview — =GAMMALN({x})'}
  fieldLabel="x"
/>

`GAMMALN(1)` returns 0, since `GAMMA(1) = 1` and `LN(1) = 0`.
`GAMMALN(5)` returns 3.1781 — matching `LN(GAMMA(5))`, and since
`GAMMA(5) = 4! = 24`, this also equals `LN(24)`.

## Common errors

### #NUM! — x is zero or negative

<ExcelCode>{`GAMMALN(0) → #NUM!`}</ExcelCode>

`x` must be strictly positive — the gamma function has poles at zero
and every negative integer.

### Expecting GAMMALN to return the gamma function itself

<ExcelCode>{`GAMMALN(5) → 3.1781, not GAMMA(5) → 24`}</ExcelCode>

GAMMALN returns the **logarithm** of the gamma function. To get the
raw gamma value back, exponentiate the result: `EXP(GAMMALN(5))`
returns 24, matching `GAMMA(5)` directly.
