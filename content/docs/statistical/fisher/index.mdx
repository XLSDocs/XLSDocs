Convert a correlation coefficient (a value between -1 and 1) into a
value that behaves like a normally-distributed variable — making it
possible to build confidence intervals and hypothesis tests around
correlation using ordinary normal-distribution statistics.

## Return value

The Fisher-transformed value of `x`: `0.5 × LN((1 + x) / (1 − x))`.

## Description

`CORREL` and `PEARSON` return a correlation coefficient bounded
between -1 and 1 — but that boundedness makes it awkward to work with
directly using standard normal-distribution statistics, especially
near the extremes where the sampling distribution of correlation
becomes noticeably skewed. FISHER re-expresses a correlation as a
value that's approximately normally distributed with a known standard
error, unlocking the usual toolkit: confidence intervals, hypothesis
tests, and averaging correlations from multiple samples correctly
(averaging raw correlations directly is a known statistical mistake;
averaging their Fisher-transformed values first is the correct
approach).

<Callout type="idea">
  FISHER is mathematically identical to the inverse hyperbolic tangent
  function, `atanh(x)` — the same transformation shows up under that
  name in most statistical software and textbooks outside Excel.
</Callout>

`FISHER(0)` returns exactly 0, and `FISHER(-0.7)` and `FISHER(0.7)`
are exact mirror images of each other (-0.8673 and 0.8673) — the
transformation is symmetric around zero, since `FISHER(-x)` always
equals `-FISHER(x)`.

## Common errors

### #NUM! — x is not strictly between -1 and 1

<ExcelCode>{`FISHER(1) → #NUM!`}</ExcelCode>

`x` must be strictly between -1 and 1 — a correlation of exactly ±1
is a mathematical edge case FISHER can't transform (the underlying
log would divide by zero).

### Averaging raw correlation coefficients directly

<ExcelCode>{`AVERAGE(0.9, 0.5) → 0.7, not the statistically correct way to combine two correlations`}</ExcelCode>

Correlation coefficients aren't linear in the way averages assume —
the statistically sound approach is `FISHERINV(AVERAGE(FISHER(0.9),
FISHER(0.5)))`, which correctly weights the more extreme correlation
less heavily than a naive average would.
