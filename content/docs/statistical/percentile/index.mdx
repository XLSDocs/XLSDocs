Find the value below which a given percentage of the data falls —
the 90th percentile of response times, the 25th percentile of test
scores. A more nuanced view of a distribution than a single average.

## Return value

The value at the `k`th percentile of `array` — `PERCENTILE(range,
0.5)` is equivalent to `MEDIAN(range)`, `PERCENTILE(range, 0)` is
equivalent to `MIN(range)`, and `PERCENTILE(range, 1)` is equivalent
to `MAX(range)`.

## Description

PERCENTILE answers a more nuanced question than AVERAGE — not just
"what's typical," but "where does a specific point in the
distribution actually fall." The 90th percentile of page load times
is a common real-world example: it says 90% of visitors experienced
that time or faster, which is a more honest picture of "typical"
performance than an average that a few slow outliers can skew.
PERCENTILE is the older name for what's now formally
[PERCENTILE.INC](/docs/statistical/percentile-inc).

<Callout type="warn">
  `k` is a **fraction between 0 and 1**, not a whole-number
  percentage — the 90th percentile is `k=0.9`, not `k=90`. Passing
  `90` directly returns `#NUM!`, since it's outside the valid 0–1
  range.
</Callout>

`k=0` and `k=0.5` land exactly on a value in the data (the min, and
the median), so those rows highlight directly. `k=0.9` falls between
the last two values (30 and 35) and has to interpolate — `31` isn't
actually in the dataset at all, which is why no row highlights for
that one.

## Common errors

### #NUM! — k outside the 0–1 range

<ExcelCode>{`PERCENTILE(A2:A100, 90) → #NUM!`}</ExcelCode>

`k` needs to be a fraction, not a percentage number — use `0.9` for
the 90th percentile:

<ExcelCode>{`PERCENTILE(A2:A100, 0.9)`}</ExcelCode>

### Confusing percentile with percentage

<ExcelCode>{`PERCENTILE(A2:A100, 0.9) → a value from the data, not "90% of something"`}</ExcelCode>

Not an error, but a common misunderstanding — the result is a value
*from the dataset's scale* (like a load time in seconds), not a
percentage itself.

## Related functions

- [PERCENTILE.INC](/docs/statistical/percentile-inc) — the modern,
  explicitly-named version of this same calculation.
- [PERCENTILE.EXC](/docs/statistical/percentile-exc) — a stricter
  method that excludes the dataset's endpoints.
- [MEDIAN](/docs/math/median) — the special case of PERCENTILE at
  `k=0.5`.
- [RANK](/docs/statistical/rank) — expresses standing as a
  whole-number position instead of a percentile.
- [LARGE](/docs/math/large) and [SMALL](/docs/math/small) — find a
  value at a specific rank position rather than a percentile.
