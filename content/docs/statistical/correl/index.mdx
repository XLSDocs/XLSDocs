Measure how strongly two sets of numbers move together — a single
value from -1 to 1 summarizing whether they rise and fall in sync, move
in opposite directions, or show no consistent relationship at all.

## Return value

The Pearson correlation coefficient between `array1` and `array2` — a
number from -1 to 1.

## Description

A CORREL result near `1` means the two sets rise and fall together
almost perfectly; near `-1` means they move in opposite directions
almost perfectly (one rises as the other falls); near `0` means
there's little to no *linear* relationship between them at all. Unlike
SLOPE and INTERCEPT, the argument order doesn't matter — `CORREL(A,
B)` and `CORREL(B, A)` always return the same value.

<Callout type="warn">
  CORREL only measures *linear* relationships. Two variables can have a
  strong, perfectly predictable — but curved — relationship and still
  return a CORREL close to `0`, because a curve isn't a straight-line
  pattern. A low correlation rules out a linear relationship, not
  every relationship.
</Callout>

## Common errors

### #N/A — array1 and array2 are different sizes

<ExcelCode>{`CORREL({1,2,3}, {10,20,30,40}) → #N/A`}</ExcelCode>

Both arrays need to contain the same number of data points, since
CORREL pairs them up position by position.

### #DIV/0! — one array has zero variance

<ExcelCode>{`CORREL({5,5,5}, {10,20,30}) → #DIV/0!`}</ExcelCode>

If every value in either array is identical, there's no variation to
correlate against — the calculation divides by a standard deviation
of zero.
