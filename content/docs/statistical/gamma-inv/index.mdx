## Return value

The value `x` such that `GAMMA.DIST(x, alpha, beta, TRUE)` equals
`probability`.

## Description

GAMMA.INV answers "what value has this much of the gamma
distribution's area to its left" — the reverse lookup from
`GAMMA.DIST`'s cumulative mode. Because the gamma distribution is
right-skewed, its percentiles aren't evenly spaced around the mean
the way a normal distribution's are: the gap between the 10th and
50th percentile is smaller than the gap between the 50th and 90th.

<Callout type="idea">
  GAMMA.INV and `GAMMA.DIST` are exact inverses:
  `GAMMA.INV(GAMMA.DIST(x, alpha, beta, TRUE), alpha, beta)` returns
  `x` back, for any valid `x`, `alpha`, and `beta`.
</Callout>

The same shape-2, scale-3 gamma distribution used on `GAMMA.DIST`'s
page (mean = 6). `GAMMA.INV(0.5, 2, 3)` returns 5.0350 — the true

right-skew `GAMMA.DIST`'s own page described.

## Common errors

### #NUM! — probability is not strictly between 0 and 1

<ExcelCode>{`GAMMA.INV(1, 2, 3) → #NUM!`}</ExcelCode>

`probability` must be greater than 0 and less than 1, and both
`alpha` and `beta` must be strictly positive.

### Assuming the median equals alpha × beta

<ExcelCode>{`GAMMA.INV(0.5, 2, 3) → 5.0350, not 6 (which is the mean, alpha × beta)`}</ExcelCode>

Because the gamma distribution is right-skewed, its median
(`GAMMA.INV(0.5, ...)`) sits below its mean — the two aren't the same
value, unlike in a symmetric distribution like the normal.
