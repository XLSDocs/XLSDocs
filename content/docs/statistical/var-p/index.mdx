Measure how spread out a set of numbers is from their average, in
squared units, when the data represents an **entire population** —
every relevant value, not a sample drawn from a larger group.

## Return value

The population variance of the supplied numbers. Text and blank
cells within a range are ignored.

## Description

VAR.P treats the supplied numbers as the **entire population**, so
it divides the sum of squared deviations by `n` (the actual count)
rather than `n-1`. That makes VAR.P always less than or equal to
VAR.S on identical data — same logic as the STDEV.P/STDEV.S
relationship, just in squared units. VAR.P replaced the older
`VARP`, which still works for compatibility.

<Callout type="warn">
  Using VAR.P when the data is actually a **sample** understates the
  true spread. If there's any meaningful data outside what's in the
  range, use `VAR.S` instead.
</Callout>

## Common errors

### Treating a sample as a population

<ExcelCode>{`VAR.P(SurveyResponses) → understated spread if respondents are a sample, not everyone`}</ExcelCode>

Not an error, but a common source of subtly wrong statistics — most
real-world datasets are samples of a larger group, which calls for
`VAR.S`, not VAR.P.

### Misinterpreting the units

<ExcelCode>{`VAR.P(Prices) → a number in "dollars squared," not dollars`}</ExcelCode>

Variance is always in squared units of the original data. Use
`STDEV.P` for a directly interpretable number.
