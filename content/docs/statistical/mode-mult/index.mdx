Find every value tied for most frequent in a set of numbers, returned
as a spilled array — where `MODE`/`MODE.SNGL` only ever return the
first tied value, MODE.MULT returns all of them at once.

## Return value

A vertical array containing every numeric value tied for most
frequent, in the order first encountered. Returns `#N/A` if every
value appears exactly once. If there's a single clear mode with no
tie, the array contains just that one value.

## Description

MODE.MULT exists specifically to solve the limitation that both
`MODE` and `MODE.SNGL` share: when multiple values are tied for most
common, they can only report one of them. MODE.MULT returns every
tied value at once, as a spilled array — enter it in one cell in
Excel 365 and it fills downward on its own, or select a vertical
range and enter it with `Ctrl+Shift+Enter` in older versions where
dynamic arrays aren't available.

<Callout type="warn">
  In pre-365 Excel, MODE.MULT must be entered as a legacy array
  formula (`Ctrl+Shift+Enter`) into a range selected **in advance** —
  select more rows than you expect ties, since extra cells simply
  return `#N/A` rather than resizing automatically the way a modern
  spilled array does.
</Callout>

## Common errors

### #N/A — no value repeats

<ExcelCode>{`MODE.MULT(1, 2, 3, 4, 5) → #N/A (every value is unique)`}</ExcelCode>

There's no mode when nothing repeats, same as MODE.SNGL.

### Only seeing one result

<ExcelCode>{`MODE.MULT(1, 1, 2, 2, 3) → {1; 2} spilled, but only 1 shows if entered without Ctrl+Shift+Enter in pre-365 Excel`}</ExcelCode>

In Excel 365, MODE.MULT spills automatically. In older versions,
forgetting `Ctrl+Shift+Enter` (or not pre-selecting enough cells)
silently truncates the result to just the first tied value.
