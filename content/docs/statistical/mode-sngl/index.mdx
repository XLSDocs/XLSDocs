Find the value that appears most often in a set of numbers — the
modern, explicitly-named version of `MODE`, distinguished from
`MODE.MULT` by returning just one value even when several are tied.

## Return value

The numeric value that appears most often across all arguments.
Returns `#N/A` if every value appears exactly once. If several values
are tied for most frequent, returns only the first one encountered.

## Description

MODE.SNGL computes exactly the same result as the older `MODE` — the
`.SNGL` suffix (for "single") was added in Excel 2010 alongside
`MODE.MULT`, which returns *every* tied mode as a spilled array
instead of just the first. The two functions only diverge in
behavior when there's a genuine tie for most frequent value; on data
with a single clear mode, MODE.SNGL, MODE, and MODE.MULT (spilled to
one cell) would all agree.

<Callout type="idea">
  MODE.SNGL and MODE always return the same number on the same data.
  Reach for `MODE.MULT` instead when the data might have more than
  one value tied for most common and every tied value matters, not
  just the first one found.
</Callout>

## Common errors

### #N/A — no value repeats

<ExcelCode>{`MODE.SNGL(1, 2, 3, 4, 5) → #N/A (every value is unique)`}</ExcelCode>

There's no mode when nothing repeats — this is expected behavior,
not a malformed formula.

### Assuming there's only one mode

<ExcelCode>{`MODE.SNGL(1, 1, 2, 2, 3) → 1 (the first-encountered tie, not both)`}</ExcelCode>

When multiple values are tied for most frequent, MODE.SNGL only
returns one of them — use `MODE.MULT` to return every tied mode at
once.
