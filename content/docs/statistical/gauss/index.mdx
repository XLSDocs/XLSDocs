Return the probability that a standard normal random variable falls
between 0 (the mean) and `x` — a convenient shorthand for a
calculation otherwise built from two separate pieces.

## Return value

The probability that a standard normal random variable falls between
0 and `x`.

## Description

GAUSS packages a very common statistical question — "what fraction of
values fall between the mean and this many standard deviations away"
— into a single call. It's mathematically identical to
`NORM.S.DIST(x, TRUE) - 0.5`: taking the cumulative probability up to
`x` and subtracting the 0.5 that always sits below the mean, leaving
just the probability mass between the mean and `x`.

<Callout type="idea">
  `GAUSS(1.96)` returns almost exactly 0.475 — doubling it gives 0.95,
  the familiar "95% of values fall within about 1.96 standard
  deviations of the mean" rule that underlies the standard 95%
  confidence interval.
</Callout>

`GAUSS(1)` returns 0.3413 — the familiar "34% of values fall within
one standard deviation above the mean" fact behind the 68-95-99.7
rule. `GAUSS(1.96)` returns 0.4750, so `2 × GAUSS(1.96)` gives almost
exactly 0.95 — the standard 95% interval.

## Common errors

### Expecting GAUSS to return the full cumulative probability

<ExcelCode>{`GAUSS(1) → 0.3413, not the 0.8413 cumulative probability up to x = 1`}</ExcelCode>

GAUSS only measures the probability from the **mean** out to `x`, not
from negative infinity. For the full cumulative probability, use
`NORM.S.DIST(x, TRUE)` instead — or add 0.5 to GAUSS's result for a
positive `x`.

### Forgetting to double GAUSS's result for a two-sided interval

<ExcelCode>{`GAUSS(1.96) → 0.4750, not the 0.95 two-sided probability within ±1.96`}</ExcelCode>

GAUSS only covers one side (0 to `x`) — a symmetric two-sided
interval like "within 1.96 standard deviations either way" needs
`2 × GAUSS(x)`.
