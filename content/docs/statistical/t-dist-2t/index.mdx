Return the two-tailed probability of the Student's t-distribution —
the combined area under both tails beyond `x` and `-x`, the p-value
shape most significance tests actually compare against a threshold.

## Return value

The probability that a t-distributed random variable with
`deg_freedom` degrees of freedom is at least as extreme as `x`, in
either direction — the combined area under both tails beyond `x` and
`-x`.

## Description

T.DIST.2T answers "how likely is a result this far from zero, in
either direction" — exactly the question a typical two-sided
hypothesis test asks. Because the t-distribution is symmetric around
0, this is always exactly double the right tail alone:
`T.DIST.2T(x, df) = 2 * T.DIST.RT(x, df)`. This is also the same
value `T.TEST` returns internally when its `tails` argument is 2.

<Callout type="warn">
  `x` must be **non-negative** — T.DIST.2T treats it as a distance
  from zero, not a signed value. Passing a negative `x` returns
  `#NUM!`; use `ABS()` on a raw t-statistic first if it might be
  negative, e.g. `=T.DIST.2T(ABS(t_stat), df)`.
</Callout>

The same t-statistic from a 13-observation sample (12 degrees of
freedom) used on `T.DIST`'s and `T.DIST.RT`'s pages. At `t = 2`,
T.DIST.2T returns 0.0687 — exactly double T.DIST.RT's 0.0343 on the
identical input, since both tails are equally likely by symmetry.
Neither `t = 1.5` (0.1595) nor `t = 2` clears the common 0.05
significance threshold; `t = 2.5` (0.0279) does.

## Common errors

### #NUM! — x is negative

<ExcelCode>{`T.DIST.2T(-2, 12) → #NUM!`}</ExcelCode>

`x` represents a distance from zero, not a signed t-statistic — wrap
a possibly-negative value in `ABS()` before passing it in.

### #NUM! — deg_freedom is less than 1

<ExcelCode>{`T.DIST.2T(2, 0) → #NUM!`}</ExcelCode>

`deg_freedom` must be at least 1.
