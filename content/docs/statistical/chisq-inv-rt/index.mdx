Find the chi-square value that corresponds to a given right-tailed
probability — the reverse of `CHISQ.DIST.RT`, and the most direct way
to look up a chi-square critical value using the same convention
`CHISQ.TEST` reports as a p-value.

## Return value

The chi-square value `x` such that `CHISQ.DIST.RT(x, deg_freedom)`
equals `probability` — the critical value a chi-square statistic
needs to reach or exceed to be significant at that level.

## Description

CHISQ.INV.RT takes a significance level like `0.05` and returns the
critical value directly, using the same right-tailed convention
`CHISQ.TEST` reports as a p-value — no need to convert to
`1 - probability` first the way plain `CHISQ.INV` requires. This is
the function most textbook chi-square tables are actually built
around.

<Callout type="idea">
  `CHISQ.INV.RT(probability, df)` and `CHISQ.INV(1 - probability, df)`
  always return the same result — CHISQ.INV.RT just saves the
  `1 - probability` step, and matches the direction CHISQ.TEST already
  reports its p-value in.
</Callout>

With 4 degrees of freedom (the same 5-category scenario used across
this round's other pages), a chi-square statistic needs to reach at
least 9.4877 to produce a p-value of 0.05 or smaller —
`CHISQ.INV.RT(0.05, 4)` returns exactly that value, identical to
`CHISQ.INV(0.95, 4)` on `CHISQ.INV`'s own page.

## Common errors

### #NUM! — probability is not strictly between 0 and 1

<ExcelCode>{`CHISQ.INV.RT(0, 4) → #NUM!`}</ExcelCode>

`probability` must be greater than 0 and less than 1.

### Confusing this with CHISQ.INV's left-tailed convention

<ExcelCode>{`CHISQ.INV.RT(0.05, 4) → 9.4877, the same value as CHISQ.INV(0.95, 4)`}</ExcelCode>

Both functions can produce the identical critical value — the
difference is only which probability convention gets passed in.
CHISQ.INV.RT matches CHISQ.TEST's own p-value direction, so it's
usually the more natural fit when the significance level is already
known as a small number like 0.05.
