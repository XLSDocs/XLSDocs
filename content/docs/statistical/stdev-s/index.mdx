Estimate standard deviation from a sample of data — the modern,
explicitly-named version of `STDEV`, introduced so the function name
itself makes clear it's the sample (not population) calculation.

## Return value

The sample standard deviation of the supplied numbers — the square
root of the sample variance. Text and blank cells within a range are
ignored.

## Description

STDEV.S computes exactly the same result as the older `STDEV` — the
`.S` suffix (for "sample") was added in Excel 2010 as part of a
broader rename that made the sample-vs-population distinction
explicit in every statistical function's name, rather than something
only STDEV.P's existence hinted at. There's no calculation difference
between STDEV and STDEV.S; the only reason to prefer STDEV.S in new
work is that the name itself documents what the formula assumes.

<Callout type="info">
  STDEV.S and STDEV always return the same number on the same data —
  this isn't a case of "use the newer one because it fixed a bug."
  Older workbooks and add-ins that still reference plain `STDEV` don't
  need to be changed; it isn't deprecated, just superseded in Excel's
  own naming convention.
</Callout>

## Common errors

### #DIV/0! — fewer than two numeric values

<ExcelCode>{`STDEV.S(5) → #DIV/0!`}</ExcelCode>

Sample standard deviation is undefined with only one value — at
least two numbers are required.

### Using STDEV.S on a full population

<ExcelCode>{`STDEV.S(range) → slightly overstates spread if range is the entire population`}</ExcelCode>

Not an error, but a common source of "why don't these match" —
STDEV.S divides by `n-1`, assuming the data is a sample. If every
relevant data point is already included, use `STDEV.P` instead.
