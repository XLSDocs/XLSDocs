Return the standard error of the predicted y value in a linear
regression — a measure of how far off a typical prediction from the
regression line tends to be, in the same units as `y` itself.

## Return value

The standard error of the estimate — roughly, the typical size of
the gap between each actual `y` value and what the regression line
predicted for it.

## Description

Where `RSQ` describes fit as a unitless proportion (0 to 1), STEYX
describes it in the data's own real-world units — a STEYX of `500`
on dollar data means predictions typically miss by around $500,
directly comparable to the scale of the numbers being predicted. This
makes STEYX often more immediately useful for judging whether a
regression's accuracy is actually good enough for a specific
practical purpose.

<Callout type="idea">
  A STEYX of exactly `0` means every single point sits precisely on
  the regression line — no scatter at all. Any real-world dataset with
  genuine noise will show some nonzero STEYX; the question is only
  whether that typical error is small enough to be useful.
</Callout>

## Common errors

### #DIV/0! — fewer than 3 data points

<ExcelCode>{`STEYX({10,20}, {1,2}) → #DIV/0!`}</ExcelCode>

STEYX's formula divides by `n − 2`, which is zero with only 2 data
points — at least 3 are required.

### Confusing STEYX with RSQ

STEYX and RSQ both describe regression fit, but on different scales
— STEYX is in `y`'s own units (useful for "how far off, in real
terms"), while RSQ is a unitless 0-to-1 proportion (useful for "how
much of the variation is explained"). They aren't interchangeable
numbers.
