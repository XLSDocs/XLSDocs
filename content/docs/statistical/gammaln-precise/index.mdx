## Return value

The natural logarithm of the gamma function at `x`.

## Description

GAMMALN.PRECISE calculates exactly the same mathematical quantity as
the older `GAMMALN` — the natural log of the gamma function — but
using a more accurate approximation algorithm internally. For nearly
every practical input a spreadsheet formula would ever use, both
functions return identical results to the precision Excel displays;
the improvement only shows up in edge cases at the far limits of
floating-point precision.

<Callout type="info">
  Microsoft added GAMMALN.PRECISE in Excel 2010 as part of a broader
  wave of "more accurate" statistical function replacements
  (`NORM.S.DIST`, `CONFIDENCE.T`, and others followed the same
  pattern) — GAMMALN itself was never actually wrong for typical
  values, just less numerically robust at extremes than the newer
  algorithm.
</Callout>

## Common errors

### #NUM! — x is zero or negative

<ExcelCode>{`GAMMALN.PRECISE(-2) → #NUM!`}</ExcelCode>

`x` must be strictly positive — the gamma function has poles at zero
and every negative integer.

### Expecting a visibly different result from GAMMALN

<ExcelCode>{`GAMMALN.PRECISE(5) → 3.1781, the same as GAMMALN(5) → 3.1781`}</ExcelCode>

The two functions only diverge at precision far beyond what a
spreadsheet cell typically displays — don't expect to see a
difference in ordinary use.
