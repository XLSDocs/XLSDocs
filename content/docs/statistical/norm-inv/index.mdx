Find the value that corresponds to a given cumulative probability
under a normal distribution with **any** mean and standard deviation
— the exact reverse of `NORM.DIST`.

## Return value

The value `x` such that `NORM.DIST(x, mean, standard_dev, TRUE)`
equals `probability`.

## Description

NORM.INV answers "what value corresponds to the Nth percentile?" for
a normal distribution with a specific mean and standard deviation —
directly in the data's own real-world units, without needing to work
in z-scores and convert back afterward.

<Callout type="idea">
  `NORM.INV(probability, mean, standard_dev)` gives exactly the same
  result as `mean + standard_dev × NORM.S.INV(probability)` — NORM.INV
  just performs that conversion internally.
</Callout>

For IQ scores (mean 100, standard deviation 15), the 97.5th
percentile lands at about 129.4 — roughly `mean + 1.96 × sd`, the
same critical z-value `NORM.S.INV(0.975)` returns.

## Common errors

### #NUM! — probability is 0, 1, or outside that range

<ExcelCode>{`NORM.INV(1, 100, 15) → #NUM!`}</ExcelCode>

`probability` must be strictly between 0 and 1 — no finite value
corresponds to exactly 0% or 100% cumulative probability.

### #NUM! — standard_dev is zero or negative

<ExcelCode>{`NORM.INV(0.5, 100, 0) → #NUM!`}</ExcelCode>

`standard_dev` must be a positive number.
