Measure how spread out a set of numbers is from their average — a
small standard deviation means values cluster tightly around the
mean, a large one means they're scattered widely.

## Return value

The sample standard deviation of the supplied numbers — the square
root of the sample variance. Text and blank cells within a range are
ignored.

## Description

STDEV treats the numbers given to it as a **sample** drawn from a
larger population, not the entire population itself — this affects
the exact formula used (dividing by `n-1` instead of `n`), producing
a slightly larger result than the population version would. STDEV is
the older name for what's now formally
[STDEV.S](/docs/statistical/stdev-s); both compute the identical
result, and STDEV still works in every current Excel version.

<Callout type="warn">
  Using STDEV (sample) when the data actually **is** the entire
  population — not a sample of it — slightly overstates the spread.
  Use [STDEV.P](/docs/statistical/stdev-p) instead when every
  relevant data point is included, not just a subset.
</Callout>

## Common errors

### #DIV/0! — fewer than two numeric values

<ExcelCode>{`STDEV(5) → #DIV/0!`}</ExcelCode>

Sample standard deviation is undefined with only one value — at
least two numbers are required.

### Confusing sample and population versions

<ExcelCode>{`STDEV(range) vs STDEV.P(range) → different results on the same data`}</ExcelCode>

Not an error, but a common source of "why don't these match" —
STDEV divides by `n-1`, STDEV.P divides by `n`. Pick the one that
matches whether the data is a sample or the full population.

## Related functions

- [STDEV.S](/docs/statistical/stdev-s) — the modern, explicitly-named
  version of this same calculation.
- [STDEV.P](/docs/statistical/stdev-p) — the population version, for
  data that isn't a sample.
- [VAR](/docs/statistical/var) — the squared version of standard
  deviation; STDEV is VAR's square root.
- [AVERAGE](/docs/math/average) — the mean that STDEV measures
  spread around.
- [MEDIAN](/docs/math/median) — a different measure of "typical
  value," less sensitive to outliers than AVERAGE.
