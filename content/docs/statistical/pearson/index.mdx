Measure how strongly two datasets move together, from -1 to 1 — the
same calculation as `CORREL`, named after the statistician who
formalized it.

## Return value

The Pearson product-moment correlation coefficient between `array1`
and `array2` — a number from -1 to 1, identical to what `CORREL`
returns on the same data.

## Description

PEARSON and CORREL are the same formula under two names — there is no
calculation difference, and no version of Excel treats them
differently. `PEARSON(A1:A10, B1:B10)` and `CORREL(A1:A10, B1:B10)`
always agree exactly.

<Callout type="idea">
  There's no functional reason to prefer PEARSON over CORREL, or vice
  versa — pick whichever name reads more clearly in context. `CORREL`
  is the more common choice in newer spreadsheets simply because it's
  more self-explanatory to someone unfamiliar with the statistical
  terminology.
</Callout>

## Common errors

### #N/A — array1 and array2 are different sizes

<ExcelCode>{`PEARSON({1,2,3}, {10,20,30,40}) → #N/A`}</ExcelCode>

Both arrays need to contain the same number of data points, since
PEARSON pairs them up position by position — the same requirement
CORREL has.

### #DIV/0! — one array has zero variance

<ExcelCode>{`PEARSON({5,5,5}, {10,20,30}) → #DIV/0!`}</ExcelCode>

If every value in either array is identical, there's no variation to
correlate against.
