Measure how heavy-tailed a distribution is compared to a normal
distribution — a positive result means more extreme outliers than
normal, negative means fewer (a flatter, more evenly-spread shape).

## Return value

The excess kurtosis of the dataset: `0` matches a normal
distribution's tail weight, positive means heavier tails (more
extreme values than a normal distribution would produce), negative
means lighter tails.

## Description

KURT specifically measures **excess** kurtosis — it's calibrated so
a perfectly normal distribution scores `0`, not the "raw" kurtosis
value of `3` that some other statistical tools report. A financial
returns series with more extreme days than a normal distribution
would predict (a common real-world finding) shows up as a positive
KURT, which is exactly the kind of "fatter tails than expected" risk
that a purely normal-distribution-based model would understate.

<Callout type="warn">
  KURT needs **at least 4** data points — its formula's denominator
  includes `(n−2)(n−3)`, which hits zero (and produces `#DIV/0!`) with
  fewer than 4 values.
</Callout>

## Common errors

### #DIV/0! — fewer than 4 data points

<ExcelCode>{`KURT(5, 8, 10) → #DIV/0!`}</ExcelCode>

KURT's formula divides by `(n−2)(n−3)`, which is zero with only 3
values (or fewer) — at least 4 are required.

### Confusing KURT with skewness

<ExcelCode>{`KURT measures tail weight/outlier-proneness, not asymmetry — that's SKEW's job`}</ExcelCode>

A symmetric distribution can still have high or low kurtosis, and a
skewed one can have kurtosis near 0 — the two describe genuinely
different aspects of a distribution's shape.

### Expecting a normal distribution to score 0 exactly on real sample data

Real, finite samples drawn from a truly normal distribution will
still show some random KURT value away from exactly 0 just from
sampling variation — 0 is the theoretical value for a perfect,
infinite normal distribution, not a threshold real data will hit
precisely.
