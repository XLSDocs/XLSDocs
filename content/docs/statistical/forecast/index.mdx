Predict a value along a straight-line trend fitted through existing
data — given a new `x` (like a future date or period number), FORECAST
returns the `y` that trend line predicts for it.

## Return value

The predicted `y` value at `x`, based on the best-fit straight line
through `known_xs` and `known_ys`.

## Description

FORECAST fits a linear regression line — the same line SLOPE and
INTERCEPT would separately calculate — through the historical points,
then evaluates that line's equation at the new `x`. It's the single
function that combines what SLOPE and INTERCEPT do separately: `y =
SLOPE(known_ys, known_xs) × x + INTERCEPT(known_ys, known_xs)`.

<Callout type="idea">
  FORECAST and FORECAST.LINEAR calculate the identical result —
  FORECAST.LINEAR was added later purely for naming symmetry with
  FORECAST.ETS (which forecasts using seasonal patterns, not a straight
  line). Either name works in current Excel; FORECAST is the one that
  also works in every older version.
</Callout>

## Common errors

### #N/A — known_ys and known_xs are different sizes

<ExcelCode>{`FORECAST(6, {10,20,30}, {1,2,3,4}) → #N/A`}</ExcelCode>

Every value in `known_ys` needs a corresponding value in `known_xs` at
the same position — the two ranges must contain the same number of
data points.

### #DIV/0! — every known_x value is identical

<ExcelCode>{`FORECAST(6, {10,20,30}, {1,1,1}) → #DIV/0!`}</ExcelCode>

A straight line needs variation along the x-axis to have a defined
slope. If every `known_xs` value is the same number, no line can be
fit through them.
