Return a value from the **standard** normal distribution — the
normal curve with mean `0` and standard deviation `1` — at a given
z-score, either the cumulative probability up to that point or the
raw density at it.

## Return value

With `cumulative` `TRUE`: the probability that a standard normal
random variable is less than or equal to `z` — a value between 0 and
1. With `cumulative` `FALSE`: the density of the standard normal
curve at `z`.

## Description

NORM.S.DIST works specifically with the **standard** normal
distribution (mean 0, standard deviation 1) — the same curve behind
the familiar 68-95-99.7 rule (about 68% of values fall within 1
standard deviation, 95% within 2, 99.7% within 3). For a normal
distribution with any other mean or standard deviation, `NORM.DIST`
is the general-purpose version.

<Callout type="idea">
  `NORM.S.DIST` replaced the older `NORMSDIST` in Excel 2010, adding
  the `cumulative` argument — `NORMSDIST` always returns the
  cumulative probability with no option for the density instead.
  `NORMSDIST` still works today for backward compatibility.
</Callout>

`z = 1.96` returns `0.9750` — meaning about 97.5% of a standard
normal distribution falls at or below 1.96 standard deviations above
the mean, the reason 1.96 shows up so often in 95%-confidence
calculations.

## Common errors

### #VALUE! — cumulative isn't a valid logical value

<ExcelCode>{`NORM.S.DIST(1, "yes") → #VALUE!`}</ExcelCode>

`cumulative` must be `TRUE` or `FALSE` (or `1`/`0`) — text like
`"yes"` isn't recognized.

### Using NORM.S.DIST when the data isn't standardized

<ExcelCode>{`NORM.S.DIST(115, TRUE) → treats 115 as a z-score of 115, an absurd result`}</ExcelCode>

If the data has a mean other than 0 or a standard deviation other
than 1, convert it to a z-score first with `STANDARDIZE`, or use
`NORM.DIST` directly with the real mean and standard deviation.
