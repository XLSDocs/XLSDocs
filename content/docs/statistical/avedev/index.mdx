Return the average distance of each value from the dataset's own
mean, ignoring direction — a simple, easy-to-explain measure of
spread, unlike variance or standard deviation's squared-distance math.

## Return value

The average of the absolute value of each number's deviation from
the mean of the whole set.

## Description

AVEDEV computes the mean, then averages how far each value sits from
it — treating a value 3 below the mean the same as one 3 above it,
since it uses absolute distance rather than squaring. This makes it
more intuitive to explain than standard deviation, but it's used far
less in formal statistical work because it doesn't have the same
well-understood mathematical properties (like connecting cleanly to
the normal distribution) that variance and standard deviation do.

<Callout type="idea">
  AVEDEV tends to run **smaller** than the standard deviation of the
  same data, since standard deviation's squaring step disproportionately
  weights values that are far from the mean, while AVEDEV weights every
  distance equally.
</Callout>

## Common errors

### Confusing AVEDEV with standard deviation

<ExcelCode>{`AVEDEV({2,4,4,4,5,5,7,9}) → 1.5, vs. STDEV.S of the same data → 2.14`}</ExcelCode>

These measure spread differently and aren't interchangeable — AVEDEV
averages absolute distances; STDEV.S averages *squared* distances
before taking a square root, which weights outliers more heavily.

### Expecting a negative result for below-average values

AVEDEV can never be negative — every individual deviation is
converted to its absolute value before averaging, so direction
(above or below the mean) doesn't affect the result at all.
