Find the z-score that corresponds to a given cumulative probability
under the **standard** normal distribution — the exact reverse of
`NORM.S.DIST`.

## Return value

The z-score `z` such that `NORM.S.DIST(z, TRUE)` equals `probability`.

## Description

NORM.S.INV is where the familiar critical z-values (`1.96` for 95%
confidence, `1.6449` for 90%, `2.576` for 99%) actually come from —
they're just `NORM.S.INV` evaluated at the corresponding two-tailed
or one-tailed probability. It's the standard-normal counterpart to
`NORM.INV`, which works with any mean and standard deviation.

<Callout type="idea">
  `NORM.S.INV` replaced the older `NORMSINV` in Excel 2010 — purely a
  naming change for consistency with the other `.S.` (standard)
  functions added that version. `NORMSINV` still works today and
  returns identical results.
</Callout>

`NORM.S.INV(0.975)` returns `1.96` — the critical z-value behind
every "95% confidence interval" calculation, since a 95% two-tailed
interval leaves 2.5% in each tail, and 1 − 0.025 = 0.975.

## Common errors

### #NUM! — probability is 0, 1, or outside that range

<ExcelCode>{`NORM.S.INV(1) → #NUM!`}</ExcelCode>

`probability` must be strictly between 0 and 1 — the normal
distribution never reaches exactly 0% or 100% cumulative probability
at any finite z-score.

### Confusing a one-tailed and two-tailed probability

<ExcelCode>{`NORM.S.INV(0.95) → 1.6449, not the same z as a "95% confidence interval" (which needs 0.975)`}</ExcelCode>

A 95% two-tailed confidence interval splits the remaining 5% evenly
between both tails (2.5% each), so it needs `NORM.S.INV(0.975)`, not
`NORM.S.INV(0.95)` — mixing these up is one of the most common
mistakes when building a confidence interval by hand.
