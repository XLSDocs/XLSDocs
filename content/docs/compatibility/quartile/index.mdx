QUARTILE is the original name for what's now called
[QUARTILE.INC](/docs/statistical/quartile-inc) — the minimum, 25th
percentile, median, 75th percentile, or maximum of a dataset. The two
functions are **identical**: same arguments, same order, same
results.

<Callout type="warn">
  Microsoft's own documentation says QUARTILE "may not be available in
  future versions of Excel." It still works today, and existing
  workbooks that use it aren't at any immediate risk — but any new
  formula should use [QUARTILE.INC](/docs/statistical/quartile-inc)
  instead.
</Callout>

## Return value

The value at the requested quartile of `array` — exactly what
[QUARTILE.INC](/docs/statistical/quartile-inc) would return.

## Common errors

### #NUM! — quart is outside the 0–4 range

<ExcelCode>{`QUARTILE({10,20,30,40}, 5) → #NUM!`}</ExcelCode>

`quart` must be a whole number from 0 to 4 — there's no fifth
quartile.

### #VALUE! — array contains no numeric values

<ExcelCode>{`QUARTILE({"a","b","c"}, 2) → #VALUE!`}</ExcelCode>

QUARTILE needs numbers to work with; text-only ranges have no
quartiles to calculate.

## Related functions

  replacement; use this in any new formula.
- [QUARTILE.EXC](/docs/statistical/quartile-exc) — a different,
  newer function using a stricter method, not a replacement for this
  one.
- [PERCENTRANK](/docs/compatibility/percentrank) — the reverse
  operation: finds a value's rank instead of the value at a rank.
