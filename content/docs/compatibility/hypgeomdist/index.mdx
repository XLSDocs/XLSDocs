HYPGEOMDIST is the original name for what's now called
[HYPGEOM.DIST](/docs/statistical/hypgeom-dist) — but like
[NEGBINOMDIST](/docs/compatibility/negbinomdist), this isn't a pure
rename. HYPGEOMDIST always computed a single exact probability;
HYPGEOM.DIST added a **required** `cumulative` argument, letting it
also return the running total probability.

<Callout type="warn">
  `HYPGEOMDIST(sample_s, number_sample, population_s, number_pop)` is
  equivalent to
  `HYPGEOM.DIST(sample_s, number_sample, population_s, number_pop, FALSE)`
  — **not** `TRUE`, the same default direction as NEGBINOMDIST, not
  NORMSDIST. There's no shortcut here — always check which cumulative
  value a legacy function's old behavior actually matches.
</Callout>

## Return value

The exact probability of precisely `sample_s` successes appearing in
the sample — always the single-point form, with no way to request the
running total instead.

## Common errors

### #NUM! — sample_s exceeds what's possible given the other arguments

<ExcelCode>{`HYPGEOMDIST(6, 5, 6, 20) → #NUM!, since a 5-item sample can't contain 6 successes`}</ExcelCode>

`sample_s` can't exceed `number_sample`, `population_s`, or what's
mathematically reachable given how many failures exist in the
population.

### Assuming HYPGEOM.DIST(sample_s, number_sample, population_s, number_pop) alone works as the direct replacement

<ExcelCode>{`HYPGEOM.DIST(2, 5, 6, 20) → #VALUE! (missing the required cumulative argument) — use HYPGEOM.DIST(2, 5, 6, 20, FALSE) instead`}</ExcelCode>

Dropping in the new name alone doesn't work — `cumulative` is
required, and must be `FALSE` to match HYPGEOMDIST's legacy behavior.

## Related functions

- [HYPGEOM.DIST](/docs/statistical/hypgeom-dist) — the modern
  replacement; use `HYPGEOM.DIST(..., FALSE)` in any new formula.
- [NEGBINOMDIST](/docs/compatibility/negbinomdist) — another function
  missing a required `cumulative` argument, defaulting to the same
  value (`FALSE`) for the same underlying reason.
- [BINOMDIST](/docs/compatibility/binomdist) — the equivalent legacy
  function for sampling with replacement, which (unlike this one)
  renamed as a pure drop-in.
