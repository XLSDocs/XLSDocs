NORMDIST is the original name for what's now called
[NORM.DIST](/docs/statistical/norm-dist) — Excel 2010 renamed it to
make the connection to its "standard" counterpart,
[NORM.S.DIST](/docs/statistical/norm-s-dist), more obvious. The two
functions are otherwise **identical**: same arguments, same order,
same results.

<Callout type="warn">
  Microsoft's own documentation says NORMDIST "may not be available in
  future versions of Excel." It still works today, and existing
  workbooks that use it aren't at any immediate risk — but any new
  formula should use [NORM.DIST](/docs/statistical/norm-dist) instead.
</Callout>

## Return value

The normal distribution's cumulative probability or density at `x`,
exactly as [NORM.DIST](/docs/statistical/norm-dist) would return.

## Common errors

### #NUM! — standard_dev is 0 or negative

<ExcelCode>{`NORMDIST(42, 40, 0, TRUE) → #NUM!`}</ExcelCode>

A standard deviation of `0` or less isn't mathematically valid — the
same restriction NORM.DIST has.

### #VALUE! — mean or standard_dev is nonnumeric

<ExcelCode>{`NORMDIST(42, "x", 1.5, TRUE) → #VALUE!`}</ExcelCode>

Both arguments must be actual numbers — text that can't be interpreted
as one returns `#VALUE!`.
