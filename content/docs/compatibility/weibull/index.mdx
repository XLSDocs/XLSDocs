WEIBULL is the original name for what's now called
[WEIBULL.DIST](/docs/statistical/weibull-dist) — the standard model
for time-to-failure and reliability analysis. The two functions are
**identical**: same arguments, same order, same results.

<Callout type="warn">
  Microsoft's own documentation says WEIBULL "may not be available in
  future versions of Excel." It still works today, and existing
  workbooks that use it aren't at any immediate risk — but any new
  formula should use [WEIBULL.DIST](/docs/statistical/weibull-dist)
  instead.
</Callout>

## Return value

With `cumulative` `TRUE`: the probability that a Weibull-distributed
random variable is less than or equal to `x`. With `cumulative`
`FALSE`: the density of that curve at `x` — exactly what
[WEIBULL.DIST](/docs/statistical/weibull-dist) would return.

The same shape-2, scale-5 scenario used on
[WEIBULL.DIST](/docs/statistical/weibull-dist)'s own page, returning
the identical values — `WEIBULL(5, 2, 5, TRUE)` and
`WEIBULL.DIST(5, 2, 5, TRUE)` both return `0.6321`.

## Common errors

### #NUM! — x is negative, or alpha/beta isn't positive

<ExcelCode>{`WEIBULL(-1, 2, 5, TRUE) → #NUM!`}</ExcelCode>

`x` must be non-negative, and both `alpha` and `beta` must be
strictly positive.

### Assuming alpha = 1 always models "typical" failure behavior

<ExcelCode>{`WEIBULL(x, 1, beta, TRUE) → assumes a constant failure rate, unrealistic for most mechanical wear-out`}</ExcelCode>

Most real mechanical components wear out over time (`alpha > 1`), not
fail at a constant random rate — fitting `alpha = 1` by default
without checking the actual failure pattern can badly misrepresent
reliability.
