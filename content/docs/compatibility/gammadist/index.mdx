GAMMADIST is the original name for what's now called
[GAMMA.DIST](/docs/statistical/gamma-dist) — part of the same 2010
renaming wave as [BETADIST](/docs/compatibility/betadist). Unlike
BETADIST, this one **is** a pure rename: the legacy function already
required a `cumulative` argument, so the two functions are otherwise
identical — same arguments, same order, same results.

<Callout type="warn">
  Microsoft's own documentation says GAMMADIST "may not be available
  in future versions of Excel." It still works today, and existing
  workbooks that use it aren't at any immediate risk — but any new
  formula should use [GAMMA.DIST](/docs/statistical/gamma-dist)
  instead.
</Callout>

## Return value

With `cumulative` `TRUE`: the probability that a gamma-distributed
random variable with shape `alpha` and scale `beta` is less than or
equal to `x`. With `cumulative` `FALSE`: the density of that curve at
`x` — exactly what [GAMMA.DIST](/docs/statistical/gamma-dist) would
return.

The same shape-2, scale-3 scenario used on
[GAMMA.DIST](/docs/statistical/gamma-dist)'s own page, returning the
identical values — `GAMMADIST(6, 2, 3, TRUE)` and
`GAMMA.DIST(6, 2, 3, TRUE)` both return `0.5940`.

## Common errors

### #NUM! — x is negative, or alpha/beta isn't positive

<ExcelCode>{`GAMMADIST(-1, 2, 3, TRUE) → #NUM!`}</ExcelCode>

`x` must be non-negative, and both `alpha` and `beta` must be
strictly positive.

### #VALUE! — any argument is nonnumeric

<ExcelCode>{`GAMMADIST(6, 2, 3, "x") → #VALUE!`}</ExcelCode>

Every numeric argument must be an actual number — text that can't be
interpreted as one returns `#VALUE!`.
