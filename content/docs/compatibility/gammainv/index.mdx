GAMMAINV is the original name for what's now called
[GAMMA.INV](/docs/statistical/gamma-inv) — part of the same 2010
renaming wave as [BETAINV](/docs/compatibility/betainv). The two
functions are **identical**: same arguments, same order, same
results.

<Callout type="warn">
  Microsoft's own documentation says GAMMAINV "may not be available in
  future versions of Excel." It still works today, and existing
  workbooks that use it aren't at any immediate risk — but any new
  formula should use [GAMMA.INV](/docs/statistical/gamma-inv) instead.
</Callout>

## Return value

The value `x` such that `GAMMADIST(x, alpha, beta, TRUE)` equals
`probability` — exactly what
[GAMMA.INV](/docs/statistical/gamma-inv) would return.

The same shape-2, scale-3 scenario used on
[GAMMA.INV](/docs/statistical/gamma-inv)'s own page, returning the
identical values — `GAMMAINV(0.5, 2, 3)` and `GAMMA.INV(0.5, 2, 3)`
both return `5.0350`, the distribution's true median.

## Common errors

### #NUM! — probability is not strictly between 0 and 1

<ExcelCode>{`GAMMAINV(1, 2, 3) → #NUM!`}</ExcelCode>

`probability` must be greater than `0` and less than `1`, and both
`alpha` and `beta` must be strictly positive.

### #VALUE! — any argument is nonnumeric

<ExcelCode>{`GAMMAINV(0.5, 2, "x") → #VALUE!`}</ExcelCode>

Every argument must be an actual number — text that can't be
interpreted as one returns `#VALUE!`.
