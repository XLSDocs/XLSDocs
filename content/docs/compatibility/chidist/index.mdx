CHIDIST is the original name for what's now called
[CHISQ.DIST.RT](/docs/statistical/chisq-dist-rt) — the right-tailed
chi-square distribution, same shape of probability `CHISQ.TEST`
reports internally. The two functions are otherwise **identical**:
same arguments, same order, same results.

<Callout type="warn">
  Microsoft's own documentation says CHIDIST "may not be available in
  future versions of Excel." It still works today, and existing
  workbooks that use it aren't at any immediate risk — but any new
  formula should use
  [CHISQ.DIST.RT](/docs/statistical/chisq-dist-rt) instead.
</Callout>

## Return value

The right-tailed probability of the chi-square distribution — the
area under the curve to the right of `x` — exactly what
[CHISQ.DIST.RT](/docs/statistical/chisq-dist-rt) would return.

The same 4-degrees-of-freedom scenario used on
[CHISQ.DIST.RT](/docs/statistical/chisq-dist-rt)'s own page, returning
the identical values — `CHIDIST(9.488, 4)` and
`CHISQ.DIST.RT(9.488, 4)` both return `0.0500`, the standard 5%
significance threshold at this degree of freedom.

## Common errors

### #NUM! — x is negative, or deg_freedom is less than 1

<ExcelCode>{`CHIDIST(2, 0) → #NUM!`}</ExcelCode>

`x` must be non-negative and `deg_freedom` must be at least 1.

### #VALUE! — any argument is nonnumeric

<ExcelCode>{`CHIDIST(2, "x") → #VALUE!`}</ExcelCode>

Every argument must be an actual number — text that can't be
interpreted as one returns `#VALUE!`.
