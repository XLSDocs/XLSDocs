TINV is the original name for what's now called
[T.INV.2T](/docs/statistical/t-inv-2t) — **not**
[T.INV](/docs/statistical/t-inv), despite the name looking like a
closer match. Legacy TINV was always the two-tailed inverse; it never
had a one-tailed mode the way [TDIST](/docs/compatibility/tdist) did.

<Callout type="warn">
  `TINV(probability, deg_freedom)` is equivalent to
  `T.INV.2T(probability, deg_freedom)` — plain `T.INV` is a different
  function (the one-tailed inverse) and returns a different value for
  the same inputs.
</Callout>

## Return value

The positive t-value `x` such that `TDIST(x, deg_freedom, 2)` equals
`probability` — exactly what
[T.INV.2T](/docs/statistical/t-inv-2t) would return.

The same 12-degrees-of-freedom scenario used on
[T.INV.2T](/docs/statistical/t-inv-2t)'s own page, returning the
identical values — `TINV(0.05, 12)` and `T.INV.2T(0.05, 12)` both
return `2.1788`, independently confirmed here by direct computation
of the t-distribution's inverse CDF rather than taken on faith.

## Common errors

### #NUM! — probability is not strictly between 0 and 1

<ExcelCode>{`TINV(0, 12) → #NUM!`}</ExcelCode>

`probability` must be greater than `0` and less than `1`.

### Assuming TINV maps to T.INV

<ExcelCode>{`TINV(0.05, 12) → 2.1788, matching T.INV.2T(0.05, 12) — NOT T.INV(0.05, 12), which returns 1.7823`}</ExcelCode>

The shorter modern name (`T.INV`) is the one-tailed version, not the
direct replacement for TINV. Use `T.INV.2T` to match TINV's actual
legacy behavior.

## Related functions

- [T.INV.2T](/docs/statistical/t-inv-2t) — the modern replacement;
  use this in any new formula.
- [TDIST](/docs/compatibility/tdist) — the legacy forward lookup,
  which splits across two different modern functions depending on its
  `tails` argument.
- [T.INV](/docs/statistical/t-inv) — a different modern function
  (one-tailed), easy to confuse with this one by name alone.
