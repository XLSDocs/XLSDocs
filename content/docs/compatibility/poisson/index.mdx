POISSON is the original name for what's now called
[POISSON.DIST](/docs/statistical/poisson-dist) — the probability of a
given number of events occurring in a fixed interval, given a known
average rate. The two functions are **identical**: same arguments,
same order, same results.

<Callout type="warn">
  Microsoft's own documentation says POISSON "may not be available in
  future versions of Excel." It still works today, and existing
  workbooks that use it aren't at any immediate risk — but any new
  formula should use [POISSON.DIST](/docs/statistical/poisson-dist)
  instead.
</Callout>

## Return value

With `cumulative` `TRUE`: the probability of `x` or fewer events
occurring. With `cumulative` `FALSE`: the probability of exactly `x`
events occurring — exactly what
[POISSON.DIST](/docs/statistical/poisson-dist) would return.

The same `mean = 4` scenario used on
[POISSON.DIST](/docs/statistical/poisson-dist)'s own page, returning
the identical values — `POISSON(4, 4, TRUE)` and
`POISSON.DIST(4, 4, TRUE)` both return `0.6288`.

## Common errors

### #NUM! — x or mean is negative

<ExcelCode>{`POISSON(-1, 4, TRUE) → #NUM!`}</ExcelCode>

`x` must be a non-negative integer, and `mean` must be a positive
number.

### Using POISSON when events aren't actually independent

<ExcelCode>{`POISSON(10, 4, TRUE) → assumes each event's timing is unaffected by the others`}</ExcelCode>

If one event happening makes another more or less likely soon after,
the Poisson assumption of independent events at a constant rate
breaks down and the result won't reflect the true probability.

## Related functions

- [POISSON.DIST](/docs/statistical/poisson-dist) — the modern
  replacement; use this in any new formula.
- [EXPONDIST](/docs/compatibility/expondist) — models the *waiting
  time* between Poisson-distributed events, rather than the event
  count itself.
- [BINOMDIST](/docs/compatibility/binomdist) — the fixed-trials
  distribution the Poisson distribution approximates in the
  large-trials, small-probability limit.
