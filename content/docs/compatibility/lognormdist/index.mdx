LOGNORMDIST is the original name for what's now called
[LOGNORM.DIST](/docs/statistical/lognorm-dist) — but like
[BETADIST](/docs/compatibility/betadist), this isn't a pure rename.
LOGNORMDIST always computed the cumulative lognormal probability;
LOGNORM.DIST added a **required** `cumulative` argument, letting it
also return the probability density instead.

<Callout type="warn">
  `LOGNORMDIST(x, mean, standard_dev)` is equivalent to
  `LOGNORM.DIST(x, mean, standard_dev, TRUE)` — dropping in the new
  name alone, without adding `TRUE`, returns `#VALUE!` instead of the
  probability you expected.
</Callout>

## Return value

The cumulative lognormal probability — the probability that a
lognormally-distributed random variable is less than or equal to
`x` — always the cumulative form, with no way to request the density
instead.

`LOGNORM.DIST(1, 0, 0.5, TRUE)` both return `0.5000`.

## Common errors

### #NUM! — x or standard_dev is not positive

<ExcelCode>{`LOGNORMDIST(-1, 0, 0.5) → #NUM!`}</ExcelCode>

`x` must be greater than `0`, and `standard_dev` must be positive.

### Assuming LOGNORM.DIST(x, mean, standard_dev) alone works as the direct replacement

<ExcelCode>{`LOGNORM.DIST(1, 0, 0.5) → #VALUE! (missing the required cumulative argument) — use LOGNORM.DIST(1, 0, 0.5, TRUE) instead`}</ExcelCode>

Dropping in the new name alone doesn't work — `cumulative` is
required, and must be `TRUE` to match LOGNORMDIST's legacy behavior.
