---
title: Compatibility
description: The pre-2010 statistical function names, kept working for old workbooks but superseded by more accurately-named replacements.
---

Compatibility functions are the **old names** for functions Excel
renamed in 2010 and later, usually to make a function's behavior
clearer (`NORMSDIST` became `NORM.S.DIST`, for instance) or to split
one overloaded function into several more specific ones. Every
function here still works — old workbooks built on them haven't
broken — but Microsoft's own documentation says they "may not be
available in future versions of Excel," and each one has a direct,
already-documented modern replacement elsewhere on this site.
