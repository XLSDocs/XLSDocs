ZTEST is the original name for what's now called
[Z.TEST](/docs/statistical/z-test) — a one-tailed test of whether a
sample's mean is significantly different from a hypothesized value,
when the population standard deviation is known. The two functions
are **identical**: same arguments, same order, same results.

<Callout type="warn">
  Microsoft's own documentation says ZTEST "may not be available in
  future versions of Excel." It still works today, and existing
  workbooks that use it aren't at any immediate risk — but any new
  formula should use [Z.TEST](/docs/statistical/z-test) instead.
</Callout>

## Return value

A probability between 0 and 1 — the one-tailed likelihood of
observing a sample mean at least this far above `x` by chance alone —
exactly what [Z.TEST](/docs/statistical/z-test) would return.

## Common errors

### #N/A — array contains no numeric values

<ExcelCode>{`ZTEST(A1:A5, 90) → #N/A when A1:A5 has no numbers`}</ExcelCode>

`array` needs at least one numeric value to compute a mean and
standard deviation from.

### Misreading the result as a two-tailed p-value

<ExcelCode>{`ZTEST(array, x, sigma) → one-tailed only, not directly comparable to a two-tailed TTEST result`}</ExcelCode>

ZTEST's raw output answers "is the mean greater than x," not "is the
mean different from x." Double the smaller tail — `=2 * MIN(ZTEST(array, x, sigma), 1 - ZTEST(array, x, sigma))`
— before comparing it to a two-tailed significance threshold.

## Related functions

- [Z.TEST](/docs/statistical/z-test) — the modern replacement; use
  this in any new formula.
- [CONFIDENCE](/docs/compatibility/confidence) — another legacy
  normal-distribution function, for a margin of error instead of a
  hypothesis test.
- [TTEST](/docs/compatibility/ttest) — the more common choice when
  the population standard deviation isn't actually known.
