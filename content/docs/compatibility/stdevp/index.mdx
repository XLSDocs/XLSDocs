STDEVP is the original name for what's now called
[STDEV.P](/docs/statistical/stdev-p) — the standard deviation of an
entire population, not a sample. The two functions are **identical**:
same arguments, same order, same results.

<Callout type="warn">
  Microsoft's own documentation says STDEVP "may not be available in
  future versions of Excel." It still works today, and existing
  workbooks that use it aren't at any immediate risk — but any new
  formula should use [STDEV.P](/docs/statistical/stdev-p) instead.
</Callout>

## Return value

The population standard deviation of the supplied numbers — exactly
what [STDEV.P](/docs/statistical/stdev-p) would return. Text and
blank cells within a range are ignored.

## Common errors

### Treating a sample as a population

<ExcelCode>{`STDEVP(SurveyResponses) → understated spread if respondents are a sample, not everyone`}</ExcelCode>

Not an error, but a common source of subtly wrong statistics — most
real-world datasets are samples of a larger group, which calls for
`STDEV` (or modern `STDEV.S`), not STDEVP.

### Empty range

<ExcelCode>{`STDEVP(A1:A1) → #DIV/0! if the range has no numeric values`}</ExcelCode>

STDEVP needs at least one numeric value to compute against; a fully
blank or text-only range returns an error.
