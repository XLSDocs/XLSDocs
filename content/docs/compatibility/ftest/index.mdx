FTEST is the original name for what's now called
[F.TEST](/docs/statistical/f-test) — the standard way to check whether
two samples likely come from populations with the same variance. The
two functions are otherwise **identical**: same arguments, same
order, same results.

<Callout type="warn">
  Microsoft's own documentation says FTEST "may not be available in
  future versions of Excel." It still works today, and existing
  workbooks that use it aren't at any immediate risk — but any new
  formula should use [F.TEST](/docs/statistical/f-test) instead.
</Callout>

## Return value

A two-tailed probability between 0 and 1 — the likelihood of seeing a
ratio of variances at least this extreme by chance alone — exactly
what [F.TEST](/docs/statistical/f-test) would return.

## Common errors

### #DIV/0! — array2's variance is zero

<ExcelCode>{`FTEST(A2:A6, B2:B6) → #DIV/0! when every value in B2:B6 is identical`}</ExcelCode>

A variance of zero can't appear in the denominator of the F-statistic
— `array2` needs at least some spread in its values.

### #N/A — fewer than 2 numeric values in either array

<ExcelCode>{`FTEST(A1, B2:B6) → #N/A`}</ExcelCode>

Sample variance is undefined with fewer than 2 numbers — both arrays
need at least 2 numeric values each.
