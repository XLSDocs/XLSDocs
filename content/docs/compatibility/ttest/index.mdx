TTEST is the original name for what's now called
[T.TEST](/docs/statistical/t-test) — the standard way to test whether
two samples likely come from populations with the same mean. Unlike
[TDIST](/docs/compatibility/tdist) and
[TINV](/docs/compatibility/tinv), this one **is** a pure rename: same
four arguments, same order, same results.

<Callout type="warn">
  Microsoft's own documentation says TTEST "may not be available in
  future versions of Excel." It still works today, and existing
  workbooks that use it aren't at any immediate risk — but any new
  formula should use [T.TEST](/docs/statistical/t-test) instead.
</Callout>

## Syntax

<ExcelCode>{`=TTEST(array1, array2, tails, type)`}</ExcelCode>

## Return value

A probability between 0 and 1 — the likelihood of seeing a difference
between the two samples' means at least this large by chance alone —
exactly what [T.TEST](/docs/statistical/t-test) would return.

## Common errors

### #N/A — array1 and array2 are different sizes with type = 1

<ExcelCode>{`TTEST(A2:A6, B2:B4, 2, 1) → #N/A`}</ExcelCode>

A paired test requires each value in `array1` to correspond to one in
`array2` — the two ranges must contain the same number of values.

### #NUM! — tails is not 1 or 2

<ExcelCode>{`TTEST(array1, array2, 3, 2) → #NUM!`}</ExcelCode>

`tails` only accepts `1` (one-tailed) or `2` (two-tailed); any other
value is invalid.

## Related functions

- [T.TEST](/docs/statistical/t-test) — the modern replacement; use
  this in any new formula.
- [TDIST](/docs/compatibility/tdist) — a related legacy function from
  the same family, but genuinely split across two modern functions
  rather than a pure rename.
- [TINV](/docs/compatibility/tinv) — the legacy critical-value lookup,
  always two-tailed.
