VARP is the original name for what's now called
[VAR.P](/docs/statistical/var-p) — the variance of an entire
population, not a sample. The two functions are **identical**: same
arguments, same order, same results.

<Callout type="warn">
  Microsoft's own documentation says VARP "may not be available in
  future versions of Excel." It still works today, and existing
  workbooks that use it aren't at any immediate risk — but any new
  formula should use [VAR.P](/docs/statistical/var-p) instead.
</Callout>

## Return value

The population variance of the supplied numbers — exactly what
[VAR.P](/docs/statistical/var-p) would return. Text and blank cells
within a range are ignored.

## Common errors

### Treating a sample as a population

<ExcelCode>{`VARP(SurveyResponses) → understated spread if respondents are a sample, not everyone`}</ExcelCode>

Not an error, but a common source of subtly wrong statistics — most
real-world datasets are samples of a larger group, which calls for
`VAR` (or modern `VAR.S`), not VARP.

### Misinterpreting the units

<ExcelCode>{`VARP(Prices) → a number in "dollars squared," not dollars`}</ExcelCode>

Variance is always in squared units of the original data. Use
`STDEVP` for a directly interpretable number.

## Related functions

- [VAR.P](/docs/statistical/var-p) — the modern replacement; use this
  in any new formula.
- [STDEVP](/docs/compatibility/stdevp) — the square root of this
  function, in the same units as the original data.
- [VAR](/docs/statistical/var) — the legacy sample version, for data
  that represents a subset of a larger group.
