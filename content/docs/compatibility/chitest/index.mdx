CHITEST is the original name for what's now called
[CHISQ.TEST](/docs/statistical/chisq-test) — the standard
goodness-of-fit test for categorical data. The two functions are
otherwise **identical**: same arguments, same order, same results.

<Callout type="warn">
  Microsoft's own documentation says CHITEST "may not be available in
  future versions of Excel." It still works today, and existing
  workbooks that use it aren't at any immediate risk — but any new
  formula should use [CHISQ.TEST](/docs/statistical/chisq-test)
  instead.
</Callout>

<ExcelCode>{`=CHITEST(actual_range, expected_range)`}</ExcelCode>

## Return value

A probability between 0 and 1 — the likelihood of seeing a deviation
between observed and expected counts at least this large by chance
alone — exactly what [CHISQ.TEST](/docs/statistical/chisq-test) would
return.

The same 100-observations-across-3-categories scenario used on

exactly, from `0.8521` when the counts are close to expectation down
to `0.0009` when they're strongly skewed.

## Common errors

### #N/A — actual_range and expected_range are different sizes

<ExcelCode>{`CHITEST(A2:A4, B2:B5) → #N/A`}</ExcelCode>

Every category in `actual_range` needs a matching expected value in
`expected_range` — the two ranges must be the same size and shape.

### #DIV/0! — an expected value is zero

<ExcelCode>{`CHITEST(A2:A4, B2:B4) → #DIV/0! when any value in B2:B4 is 0`}</ExcelCode>

Each term in the chi-square statistic divides by the expected count
for that category, so no expected value can be zero.
