BETADIST is the original name for what's now called
[BETA.DIST](/docs/statistical/beta-dist) — but like
[NORMSDIST](/docs/compatibility/normsdist), this isn't a pure rename.
BETADIST always computed the cumulative beta probability; BETA.DIST
added a **required** `cumulative` argument, letting it also return the
probability density instead.

<Callout type="warn">
  `BETADIST(x, alpha, beta, [A], [B])` is equivalent to
  `BETA.DIST(x, alpha, beta, TRUE, [A], [B])` — dropping in the new
  name alone, without adding `TRUE`, returns `#VALUE!` instead of the
  probability you expected.
</Callout>

## Return value

The cumulative beta probability — the probability that a
beta-distributed random variable is less than or equal to `x` —
always the cumulative form, with no way to request the density
instead.

The same `alpha = 2`, `beta = 5` scenario used on
[BETA.DIST](/docs/statistical/beta-dist)'s own page, returning
identical values — `BETADIST(0.3, 2, 5)` and
`BETA.DIST(0.3, 2, 5, TRUE)` both return `0.5798`.

## Common errors

### #NUM! — x is outside the [A, B] interval, or alpha/beta isn't positive

<ExcelCode>{`BETADIST(1.5, 2, 5) → #NUM!, since 1.5 is outside the default [0,1] range`}</ExcelCode>

`x` must fall between `A` and `B` (0 and 1 by default), and both
`alpha` and `beta` must be strictly positive.

### Assuming BETA.DIST(x, alpha, beta) alone works as the direct replacement

<ExcelCode>{`BETA.DIST(0.3, 2, 5) → #VALUE! (missing the required cumulative argument) — use BETA.DIST(0.3, 2, 5, TRUE) instead`}</ExcelCode>

Dropping in the new name alone doesn't work — `cumulative` is
required, and must be `TRUE` to match BETADIST's legacy behavior.

## Related functions

- [BETA.DIST](/docs/statistical/beta-dist) — the modern replacement;
  use `BETA.DIST(x, alpha, beta, TRUE, A, B)` in any new formula.
- [BETAINV](/docs/compatibility/betainv) — this function's inverse,
  which (unlike this function) renamed as a pure drop-in.
- [NORMSDIST](/docs/compatibility/normsdist) — another function
  missing a required `cumulative` argument, defaulting to the same
  value (`TRUE`) for the same underlying reason.
