BETAINV is the original name for what's now called
[BETA.INV](/docs/statistical/beta-inv) — part of the same 2010
renaming wave as [CRITBINOM](/docs/compatibility/critbinom). The two
functions are otherwise **identical**: same arguments, same order,
same results.

<Callout type="warn">
  Microsoft's own documentation says BETAINV "may not be available in
  future versions of Excel." It still works today, and existing
  workbooks that use it aren't at any immediate risk — but any new
  formula should use [BETA.INV](/docs/statistical/beta-inv) instead.
</Callout>

## Return value

The value `x` such that `BETADIST(x, alpha, beta, A, B)` equals
`probability` — exactly what [BETA.INV](/docs/statistical/beta-inv)
would return.

both return `0.2644`.

## Common errors

### #NUM! — probability is not strictly between 0 and 1

<ExcelCode>{`BETAINV(0, 2, 5) → #NUM!`}</ExcelCode>

`probability` must be greater than `0` and less than `1`, and both
`alpha` and `beta` must be strictly positive.

### #VALUE! — any argument is nonnumeric

<ExcelCode>{`BETAINV(0.5, 2, "x") → #VALUE!`}</ExcelCode>

Every argument must be an actual number — text that can't be
interpreted as one returns `#VALUE!`.
