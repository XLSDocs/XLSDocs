CHIINV is the original name for what's now called
[CHISQ.INV.RT](/docs/statistical/chisq-inv-rt) — the inverse of the
right-tailed chi-square distribution, matching the same convention
`CHISQ.TEST` reports a p-value in. The two functions are otherwise
**identical**: same arguments, same order, same results.

<Callout type="warn">
  Microsoft's own documentation says CHIINV "may not be available in
  future versions of Excel." It still works today, and existing
  workbooks that use it aren't at any immediate risk — but any new
  formula should use
  [CHISQ.INV.RT](/docs/statistical/chisq-inv-rt) instead.
</Callout>

## Return value

The chi-square value `x` such that `CHIDIST(x, deg_freedom)` equals
`probability` — exactly what
[CHISQ.INV.RT](/docs/statistical/chisq-inv-rt) would return.

The same 4-degrees-of-freedom scenario used on
[CHISQ.INV.RT](/docs/statistical/chisq-inv-rt)'s own page, returning
the identical values — `CHIINV(0.05, 4)` and `CHISQ.INV.RT(0.05, 4)`
both return `9.4877`, the critical value for a 5% significance level.

## Common errors

### #NUM! — probability is not strictly between 0 and 1

<ExcelCode>{`CHIINV(0, 4) → #NUM!`}</ExcelCode>

`probability` must be greater than `0` and less than `1`, and
`deg_freedom` must be at least `1`.

### #VALUE! — any argument is nonnumeric

<ExcelCode>{`CHIINV(0.05, "x") → #VALUE!`}</ExcelCode>

Every argument must be an actual number — text that can't be
interpreted as one returns `#VALUE!`.
