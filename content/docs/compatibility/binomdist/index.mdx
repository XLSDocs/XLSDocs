BINOMDIST is the original name for what's now called
[BINOM.DIST](/docs/statistical/binom-dist) — part of the same 2010
renaming wave as [NORMDIST](/docs/compatibility/normdist). The two
functions are otherwise **identical**: same arguments, same order,
same results.

<Callout type="warn">
  Microsoft's own documentation says BINOMDIST "may not be available
  in future versions of Excel." It still works today, and existing
  workbooks that use it aren't at any immediate risk — but any new
  formula should use [BINOM.DIST](/docs/statistical/binom-dist)
  instead.
</Callout>

## Syntax

<ExcelCode>{`=BINOMDIST(number_s, trials, probability_s, cumulative)`}</ExcelCode>

## Return value

The binomial distribution's cumulative probability or individual-term
probability for `number_s` successes, exactly as
[BINOM.DIST](/docs/statistical/binom-dist) would return.

The same 20-trial, 30%-success scenario used on
[BINOM.DIST](/docs/statistical/binom-dist)'s own page, returning the
identical values — `BINOMDIST(6, 20, 0.3, TRUE)` and
`BINOM.DIST(6, 20, 0.3, TRUE)` both return `0.6080`.

## Common errors

### #NUM! — number_s is negative or greater than trials

<ExcelCode>{`BINOMDIST(25, 20, 0.3, TRUE) → #NUM!`}</ExcelCode>

You can't have more successes than there were trials — `number_s`
must fall between `0` and `trials`, inclusive.

### #VALUE! — any argument is nonnumeric

<ExcelCode>{`BINOMDIST(6, 20, "x", TRUE) → #VALUE!`}</ExcelCode>

Every argument except the `cumulative` flag must be an actual number —
text that can't be interpreted as one returns `#VALUE!`.
