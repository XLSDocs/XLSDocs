NORMINV is the original name for what's now called
[NORM.INV](/docs/statistical/norm-inv) — Excel 2010 renamed it to
match [NORM.DIST](/docs/statistical/norm-dist)'s own rename. The two
functions are otherwise **identical**: same arguments, same order,
same results.

<Callout type="warn">
  Microsoft's own documentation says NORMINV "may not be available in
  future versions of Excel." It still works today, and existing
  workbooks that use it aren't at any immediate risk — but any new
  formula should use [NORM.INV](/docs/statistical/norm-inv) instead.
</Callout>

## Return value

The value `x` such that `NORMDIST(x, mean, standard_dev, TRUE)` would
return `probability` — exactly what
[NORM.INV](/docs/statistical/norm-inv) would return.

The same IQ-score scenario (mean `100`, standard deviation `15`) used

`NORM.INV(0.975, 100, 15)` both return about `129.4`.

## Common errors

### #NUM! — probability is 0, 1, or outside that range

<ExcelCode>{`NORMINV(1, 100, 15) → #NUM!`}</ExcelCode>

`probability` must be strictly between `0` and `1` (not including
either endpoint) — the same restriction NORM.INV has.

### #NUM! — standard_dev is 0 or negative

<ExcelCode>{`NORMINV(0.5, 100, 0) → #NUM!`}</ExcelCode>

A standard deviation of `0` or less isn't mathematically valid.
