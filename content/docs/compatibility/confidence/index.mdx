CONFIDENCE is the original name for what's now called
[CONFIDENCE.NORM](/docs/statistical/confidence-norm) — the margin of
error for a population mean, using a normal distribution. The two
functions are **identical**: same arguments, same order, same
results.

<Callout type="warn">
  Microsoft's own documentation says CONFIDENCE "may not be available
  in future versions of Excel." It still works today, and existing
  workbooks that use it aren't at any immediate risk — but any new
  formula should use
  [CONFIDENCE.NORM](/docs/statistical/confidence-norm) instead.
</Callout>

## Return value

The margin of error — a single number — exactly what
[CONFIDENCE.NORM](/docs/statistical/confidence-norm) would return.
The full confidence interval is the sample mean plus or minus this
value.

## Common errors

### #NUM! — alpha is outside the 0–1 range, or size is less than 1

<ExcelCode>{`CONFIDENCE(1.5, 5, 40) → #NUM!`}</ExcelCode>

`alpha` must be strictly between `0` and `1`, and `size` must be at
least `1`.

### #VALUE! — any argument is non-numeric

<ExcelCode>{`CONFIDENCE("high", 5, 40) → #VALUE!`}</ExcelCode>

All three arguments need to be numbers — a text significance level
can't be evaluated.

## Related functions

- [CONFIDENCE.NORM](/docs/statistical/confidence-norm) — the modern
  replacement; use this in any new formula.
- [CONFIDENCE.T](/docs/statistical/confidence-t) — a different,
  newer function for small samples, not a replacement for this one.
- [ZTEST](/docs/compatibility/ztest) — another legacy normal-
  distribution function, testing a sample mean instead of estimating
  a margin of error.
