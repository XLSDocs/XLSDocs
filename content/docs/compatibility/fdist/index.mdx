FDIST is the original name for what's now called
[F.DIST.RT](/docs/statistical/f-dist-rt) — the right-tailed
F-distribution, the shape behind one-tailed variance comparisons and
ANOVA p-values. The two functions are otherwise **identical**: same
arguments, same order, same results.

<Callout type="warn">
  Microsoft's own documentation says FDIST "may not be available in
  future versions of Excel." It still works today, and existing
  workbooks that use it aren't at any immediate risk — but any new
  formula should use [F.DIST.RT](/docs/statistical/f-dist-rt) instead.
</Callout>

## Return value

The right-tailed probability of the F-distribution — the area under
the curve to the right of `x` — exactly what
[F.DIST.RT](/docs/statistical/f-dist-rt) would return.

## Try it

<TryIt
  data={{ '0.5': '0.6906', '1': '0.4323', '2': '0.1780', '3.71': '0.0499' }}
  defaultValue="1"
  label={'Live preview — =FDIST({x}, 3, 10)'}
  fieldLabel="x"

The same 3-and-10-degrees-of-freedom scenario used on
[F.DIST.RT](/docs/statistical/f-dist-rt)'s own page, returning the
identical values — `FDIST(3.71, 3, 10)` and `F.DIST.RT(3.71, 3, 10)`
both return almost exactly `0.0499`, the standard 5% significance
threshold for this pair of degrees of freedom.

## Common errors

### #NUM! — x is negative, or either deg_freedom is less than 1

<ExcelCode>{`FDIST(-1, 3, 10) → #NUM!`}</ExcelCode>

`x` must be non-negative, and both degrees-of-freedom arguments must
be at least `1`.

### #VALUE! — any argument is nonnumeric

<ExcelCode>{`FDIST(1, 3, "x") → #VALUE!`}</ExcelCode>

Every argument must be an actual number — text that can't be
interpreted as one returns `#VALUE!`.
