FINV is the original name for what's now called
[F.INV.RT](/docs/statistical/f-inv-rt) — the inverse of the
right-tailed F-distribution, matching the convention most printed
F-tables and Excel's own ANOVA output use. The two functions are
otherwise **identical**: same arguments, same order, same results.

<Callout type="warn">
  Microsoft's own documentation says FINV "may not be available in
  future versions of Excel." It still works today, and existing
  workbooks that use it aren't at any immediate risk — but any new
  formula should use [F.INV.RT](/docs/statistical/f-inv-rt) instead.
</Callout>

## Return value

The F-value `x` such that `FDIST(x, deg_freedom1, deg_freedom2)`
equals `probability` — exactly what
[F.INV.RT](/docs/statistical/f-inv-rt) would return.

The same 3-and-10-degrees-of-freedom scenario used on
[F.INV.RT](/docs/statistical/f-inv-rt)'s own page, returning the
identical values — `FINV(0.05, 3, 10)` and `F.INV.RT(0.05, 3, 10)`
both return `3.7083`, the critical value for a 5% significance level.

## Common errors

### #NUM! — probability is not strictly between 0 and 1

<ExcelCode>{`FINV(0, 3, 10) → #NUM!`}</ExcelCode>

`probability` must be greater than `0` and less than `1`, and both
degrees-of-freedom arguments must be at least `1`.

### #VALUE! — any argument is nonnumeric

<ExcelCode>{`FINV(0.05, 3, "x") → #VALUE!`}</ExcelCode>

Every argument must be an actual number — text that can't be
interpreted as one returns `#VALUE!`.
