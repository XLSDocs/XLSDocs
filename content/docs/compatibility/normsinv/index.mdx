NORMSINV is the original name for what's now called
[NORM.S.INV](/docs/statistical/norm-s-inv) — Excel 2010 renamed it to
match [NORM.S.DIST](/docs/statistical/norm-s-dist)'s own rename. Unlike
[NORMSDIST](/docs/compatibility/normsdist), this one IS a pure rename:
same single argument, same result.

<Callout type="warn">
  Microsoft's own documentation says NORMSINV "may not be available in
  future versions of Excel." It still works today, and existing
  workbooks that use it aren't at any immediate risk — but any new
  formula should use [NORM.S.INV](/docs/statistical/norm-s-inv)
  instead.
</Callout>

## Return value

The z-score such that `NORMSDIST(z)` would return `probability` —
exactly what [NORM.S.INV](/docs/statistical/norm-s-inv) would return.

The same probability scenario used on
[NORM.S.INV](/docs/statistical/norm-s-inv)'s own page, returning the
identical values — `NORMSINV(0.975)` and `NORM.S.INV(0.975)` both
return `1.96`, the critical z-value behind a 95% two-tailed confidence
interval.

## Common errors

### #NUM! — probability is 0, 1, or outside that range

<ExcelCode>{`NORMSINV(1) → #NUM!`}</ExcelCode>

`probability` must be strictly between `0` and `1` (not including
either endpoint) — the same restriction NORM.S.INV has.

### #VALUE! — probability is nonnumeric

<ExcelCode>{`NORMSINV("x") → #VALUE!`}</ExcelCode>

`probability` must be an actual number — text that can't be
interpreted as one returns `#VALUE!`.
