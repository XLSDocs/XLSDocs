PERCENTRANK is the original name for what's now called
[PERCENTRANK.INC](/docs/statistical/percentrank-inc) — a value's rank
within a dataset, expressed as a fraction from 0 to 1. The two
functions are **identical**: same arguments, same order, same
results.

<Callout type="warn">
  Microsoft's own documentation says PERCENTRANK "may not be available
  in future versions of Excel." It still works today, and existing
  workbooks that use it aren't at any immediate risk — but any new
  formula should use
  [PERCENTRANK.INC](/docs/statistical/percentrank-inc) instead.
</Callout>

## Return value

The rank of `x` within `array`, as a fraction from `0` (the minimum)
to `1` (the maximum) — exactly what
[PERCENTRANK.INC](/docs/statistical/percentrank-inc) would return.

## Common errors

### #N/A — x falls outside the range of array

<ExcelCode>{`PERCENTRANK({10,30,50,70}, 100) → #N/A`}</ExcelCode>

`x` must fall between the minimum and maximum values in `array` —
PERCENTRANK can't extrapolate a rank for a value outside the observed
range.

### #NUM! — significance is less than 1

<ExcelCode>{`PERCENTRANK({10,30,50,70}, 40, 0) → #NUM!`}</ExcelCode>

`significance` controls how many digits the returned fraction is
rounded to, and needs to be at least 1.

## Related functions

- [PERCENTRANK.INC](/docs/statistical/percentrank-inc) — the modern
  replacement; use this in any new formula.
- [PERCENTRANK.EXC](/docs/statistical/percentrank-exc) — a different,
  newer function using a stricter method, not a replacement for this
  one.
- [QUARTILE](/docs/compatibility/quartile) — a related legacy
  function, for the reverse operation at four fixed cutoffs.
