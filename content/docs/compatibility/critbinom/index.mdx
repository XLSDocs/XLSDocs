CRITBINOM is the original name for what's now called
[BINOM.INV](/docs/statistical/binom-inv) — part of the same 2010
renaming wave as [NORMINV](/docs/compatibility/norminv). Unlike
[NEGBINOMDIST](/docs/compatibility/negbinomdist), this one IS a pure
rename: same three arguments, same order, same result.

<Callout type="warn">
  Microsoft's own documentation says CRITBINOM "may not be available
  in future versions of Excel." It still works today, and existing
  workbooks that use it aren't at any immediate risk — but any new
  formula should use [BINOM.INV](/docs/statistical/binom-inv) instead.
</Callout>

## Return value

The smallest number of successes for which the cumulative binomial
distribution is greater than or equal to `alpha` — exactly what
[BINOM.INV](/docs/statistical/binom-inv) would return.

The same 20-trial, 30%-success scenario used on
[BINOM.INV](/docs/statistical/binom-inv)'s own page, returning the
identical values — `CRITBINOM(20, 0.3, 0.9)` and
`BINOM.INV(20, 0.3, 0.9)` both return `9`.

## Common errors

### #NUM! — alpha or probability_s is outside (0, 1)

<ExcelCode>{`CRITBINOM(20, 0.3, 1) → #NUM!`}</ExcelCode>

Both `probability_s` and `alpha` must be strictly between `0` and `1`
— neither endpoint is valid.

### #VALUE! — any argument is nonnumeric

<ExcelCode>{`CRITBINOM(20, 0.3, "x") → #VALUE!`}</ExcelCode>

Every argument must be an actual number — text that can't be
interpreted as one returns `#VALUE!`.
