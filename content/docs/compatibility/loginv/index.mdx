LOGINV is the original name for what's now called
[LOGNORM.INV](/docs/statistical/lognorm-inv) — part of the same 2010
renaming wave as [NORMSINV](/docs/compatibility/normsinv). The two
functions are **identical**: same arguments, same order, same
results.

<Callout type="warn">
  Microsoft's own documentation says LOGINV "may not be available in
  future versions of Excel." It still works today, and existing
  workbooks that use it aren't at any immediate risk — but any new
  formula should use [LOGNORM.INV](/docs/statistical/lognorm-inv)
  instead.
</Callout>

## Return value

The value `x` such that `LOGNORMDIST(x, mean, standard_dev)` equals
`probability` — exactly what
[LOGNORM.INV](/docs/statistical/lognorm-inv) would return.

The same `mean = 0`, `standard_dev = 0.5` scenario used on
[LOGNORM.INV](/docs/statistical/lognorm-inv)'s own page, returning
the identical values — `LOGINV(0.5, 0, 0.5)` and
`LOGNORM.INV(0.5, 0, 0.5)` both return exactly `1.0000`.

## Common errors

### #NUM! — probability is not strictly between 0 and 1

<ExcelCode>{`LOGINV(1, 0, 0.5) → #NUM!`}</ExcelCode>

`probability` must be greater than `0` and less than `1`, and
`standard_dev` must be positive.

### #VALUE! — any argument is nonnumeric

<ExcelCode>{`LOGINV(0.5, 0, "x") → #VALUE!`}</ExcelCode>

Every argument must be an actual number — text that can't be
interpreted as one returns `#VALUE!`.
