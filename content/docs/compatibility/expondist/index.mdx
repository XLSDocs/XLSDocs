EXPONDIST is the original name for what's now called
[EXPON.DIST](/docs/statistical/expon-dist) — the exponential
distribution, the standard model for waiting time between
independent, randomly-occurring events. The two functions are
**identical**: same arguments, same order, same results.

<Callout type="warn">
  Microsoft's own documentation says EXPONDIST "may not be available
  in future versions of Excel." It still works today, and existing
  workbooks that use it aren't at any immediate risk — but any new
  formula should use [EXPON.DIST](/docs/statistical/expon-dist)
  instead.
</Callout>

## Return value

With `cumulative` `TRUE`: the probability that the waiting time until
the next event is `x` or less. With `cumulative` `FALSE`: the density
of that curve at `x` — exactly what
[EXPON.DIST](/docs/statistical/expon-dist) would return.

The same `lambda = 0.25` scenario used on
[EXPON.DIST](/docs/statistical/expon-dist)'s own page, returning the
identical values — `EXPONDIST(4, 0.25, TRUE)` and
`EXPON.DIST(4, 0.25, TRUE)` both return `0.6321`.

## Common errors

### #NUM! — x is negative, or lambda isn't positive

<ExcelCode>{`EXPONDIST(-1, 0.25, TRUE) → #NUM!`}</ExcelCode>

`x` must be non-negative, and `lambda` must be strictly positive.

### Confusing lambda (a rate) with the mean wait time itself

<ExcelCode>{`EXPONDIST(4, 4, TRUE) → treats 4 as the rate (4 events per unit time), not a 4-unit mean wait`}</ExcelCode>

`lambda` is a rate — events per unit time — not the average wait
directly. If the known quantity is an average wait time, pass its
reciprocal.
