COVAR is the original name for what's now called
[COVARIANCE.P](/docs/statistical/covariance-p) — the population
covariance between two datasets. The two functions are **identical**:
same arguments, same order, same results.

<Callout type="warn">
  `COVAR(array1, array2)` is equivalent to
  `COVARIANCE.P(array1, array2)` — **not**
  [COVARIANCE.S](/docs/statistical/covariance-s). Legacy COVAR always
  divided by `n` (treating the data as a complete population), the
  same convention COVARIANCE.P uses; it has no sample-covariance
  equivalent of its own.
</Callout>

## Return value

The population covariance between `array1` and `array2` — exactly
what [COVARIANCE.P](/docs/statistical/covariance-p) would return.

## Common errors

### #N/A — array1 and array2 are different sizes

<ExcelCode>{`COVAR(A2:A5, B2:B4) → #N/A`}</ExcelCode>

Both arrays must contain the same number of data points.

### #DIV/0! — either array is empty

<ExcelCode>{`COVAR(A1:A1, B2:B5) → #DIV/0! if A1:A1 has no numeric values`}</ExcelCode>

COVAR needs at least one numeric pair to compute against.
